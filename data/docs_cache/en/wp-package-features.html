WordPress Installation Kit Features When installing the Virtuozzo Application Management WordPress packages, you can customize your WordPress environment by selecting the necessary options in the installation window. The following features are available for configuration: LiteSpeed High-Performance Web Server - installs WordPress solution based on the LiteSpeed Web Server. This option provides the highest possible speed of website content delivery to clients via modern HTTP/3 protocol. If you untick this option, the NGINX-based solution will be installed. The following two additional features are available for LiteSpeed-based installations only:Brute Force Attack Protection secures the WordPress admin panel by limiting failed login attempts. The default action is Throttle, and the number of allowed attempts is 100. Web Application Firewall (WAF) enables/disables the feature that protects your WordPress website by applying rules for filtering out attacking requests by checking for known attack signatures.Note: Refer to the LiteSpeed Web Server documentation for more details on these features and their configuration. Let’s Encrypt SSL with Auto-Renewal add-on issues trusted, free certificate for a custom domain. The built-in functionality employs periodical renewal to prevent certificate expiration. The appropriate notifications are sent by email. WordPress Multisite Network enables the same-named feature.

Some additional features are available for the WordPress Cluster packages only: MariaDB Galera Cluster is a multi-primary database cluster based on synchronous replication and the InnoDB engine. With the Galera Cluster, you can perform direct read and write operations to any node. In the case of a single instance failure, there will be no cluster downtime and no complex failover procedures. If you untick the checkbox, a Primary-Primary database cluster will be installed.Tip: Refer to the MariaDB/MySQL/Percona Auto-Clustering documentation for more details on implementation specifics and comparison of replication types.
