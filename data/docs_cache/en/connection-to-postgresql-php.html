Connection to PostgreSQL for PHP Applications Follow the instruction below to learn how to connect your PHP application, hosted within the platform, to the PostgreSQL database server: create environment configure PHP server check connection Create Environment 1. Log into the platform dashboard. 2. Create an environment with the PHP application server (e.g., Apache PHP) and the PostgreSQL database. 3. Check your email inbox for a message with database credentials (login and password). Now, you can access your database via web admin panel and connect it to your PHP application. There are two main PG functions for operating with a database server: opening PostgreSQL connection: 1 pg_connect("host={host} port={port} dbname={dbname} user={user} password={password}"); where: {host} - the PostgreSQL server Host (i.e., access URL without http://) that you’ve received via email, for example node171206-php-postgresql.jelastic.com {port} - a connection port (the default one is 5432) {dbname} - a name of your database {user} - an account name to access database with (we’ll use the default webadmin one) {password} - a password for the appropriate user closing PostgreSQL connection: pg_close() 5.
