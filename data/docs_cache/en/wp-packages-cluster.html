WordPress Cluster Package The WordPress Cluster package is an automated solution for high-availability WordPress installation inside a cluster of lightweight containers. The package performs all the necessary configuration steps required to set up a WordPress cluster, including the installation of a web server, database, load balancer, and shared storage. It also configures automatic horizontal scaling based on the load and interconnects all components to work as a single system. This allows you to run large-scale projects with high traffic and ensures that your WordPress site remains available even during peak loads. It offers enterprise-grade performance and reliability without the need for extensive DevOps knowledge. In order to get the most from your WordPress Cluster, the following benefits can be configured: install a WordPress cluster powered by LightSpeed and a highly available MariaDB Galera cluster attach a fault-tolerant Shared Storage cluster based on GlusterFS software get a free Let’s Encrypt SSL certificate with automatic renewal bind a custom domain and update the certificate scale dynamically based on the load WordPress Cluster Installation To install the WordPress Cluster package, follow these steps: 1.
