How to Deploy Ganib to PaaS Ganib Enterprises is one of the world’s most popular and widely used open source project management software. The open source Ganib product suite includes an array of modules that provide project management system (PMS), project portfolio management (PPM), project plans, project dashboard, documents management, time and attendance tracking (PTO), timesheet, desktop time tracking and screen capture tool, etc. Let’s see how to deploy Ganib to the platform. A. Create an Environment 1. Open environment topology wizard by clicking Create environment button and choose Tomcat application server and MySQL database nodes. Set resource limits for them, enter environment name, and press Create. 2. In a few moments your new environment will appear at the panel. B. Ganib Deployment 1. To download Ganib project management system’s community edition navigate to the Sourceforge page. 2. Open the latest release folder (Ganib 3.3 in our case) and download ganib.war file it contains. 3. Navigate back to the platform dashboard and upload .war file you’ve just downloaded. 4. Finally, click Deploy to button and choose previously created environment in the list. 5. In a minute Ganib application will be deployed to the chosen environment. C. MySQL Configuration 1. Click Open in browser button next to the MySQL node in your environment. 2. While you were creating the environment, the platform sent you the email with credentials to the database.

Save the changes you’ve made. 5. Press Restart next to the Tomcat node in order to apply the configuration changes. E. Start the Application 1.
