How to Deploy Liferay Liferay Portal is a popular enterprise Java-based web platform for building business solutions, equipped with the features, that are commonly required for the development of websites and portals. It includes a built-in web CMS with an assembly of themes, pages, portlets, and gadgets available. Automatic Installation You can have a Liferay instance up and running within minutes using Virtuozzo Application Management pre-packaged solutions. Just follow the instructions below to deploy your Liferay Portal to the cloud. If you already have a Virtuozzo Application Management account, you can deploy the Liferay Portal with a dedicated database cluster in one click using integrated Marketplace. Note: If you don’t have an account yet, you can go to the package page on GitHub and click the Deploy to Cloud button. Follow the steps on the opened page to automatically create an account and deploy the Liferay Portal solution. 1. Log in to the PaaS dashboard and click the Marketplace button at the top of the page. 2. Find the Liferay application in the list of available solutions and click Install. 3. In the opened dialog, specify the environment and display name for your Liferay instance. If available, you can also select the region. Click Install. 4. Wait a few minutes for the installation process to complete. Then, click Open in Browser to access your Liferay Portal. On the first launch, Liferay will install the needed dependencies, which can take up to 5 minutes.

In case you would like to configure and run your Liferay instance manually, just follow the step-by-step instructions below. Manual Installation You can manually install the Docker-based Liferay Portal solution to the Virtuozzo Application Management. 1. Login to the platform dashboard using your credentials and click the New Environment button. 2. In the topology wizard, go to the Custom tab and click the Select Image button. Search for the liferay/portal image and add it to the environment. Set the required amount of resources (at least 32 cloudlets are recommended) and click Create. 3. Once the environment is created, open the container’s configuration file manager and create a new file named portal-ext.properties in the /opt/liferay directory. 4. Add the following parameter to the file: 1 web.server.host={hostname} Here, the {hostname} placeholder must be replaced with the actual hostname of your environment. You can find it under the environment name in the dashboard (see in the image). 5. Save the changes and Restart the Liferay container. 6. After the container is restarted, click the Open in Browser button to start using your Liferay Portal.
