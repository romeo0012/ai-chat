Tento odkaz vede k dokumentaci aplikace PHP-App Servers, která poskytuje informace o správě aplikací PHP na různých platformách.

Následující text je příklad konfiguračního souboru pro PHP-App Servers:

# PHP-App Servers configuration file
Set the application root directory

app_root = /var/www/myapp
Set the application URL

app_url = http://myapp.example.com
Set the PHP version

php_version = 7.4
Set the maximum execution time

max_execution_time = 300
Set the memory limit

memory_limit = 128M
Set the error reporting level

error_reporting = E_ALL &amp; ~E_NOTICE &amp; ~E_STRICT
Set the timezone

timezone = Europe/Prague

Tento soubor obsahuje nastavení pro aplikaci PHP na serveru, včetně adresy kořenového adresáře aplikace, adresy URL aplikace, verze PHP, maximálního času spouštění, limitu paměti, úrovně zpracování chyb a časového pásma.
