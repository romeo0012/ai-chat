Aplikace server LEMP (od verze 1.16.1) & LLSMP je připravena na podporu HTTP/3, což je umožněno výchozí podporou funkcí. Pro práci přímo s serverem přes HTTP/3 je však požadována veřejná IP adresa, aby se obešla Shared Load Balancer. LEMP je řešení software bundle, které se opírá o operační systém Linux, webový server NGINX HTTP, databázi MariaDB a programovací jazyk PHP. Tento model je oblíbený mezi vývojáři, protože je dostatečný k hostování širokého spektra projektů v jednom kontejneru. Pokud platforma poskytuje podporu LiteSpeed, může být k dispozici podobná LLSMP (Linux, LiteSpeed, MariaDB, PHP) stack. Pro další informace o LiteSpeed Web Server můžete nalézt na odkazu výše. Struktura topologie v LEMP a LLSMP kontejneřech je následující: PHP-obsluhovaný NGINX nebo LiteSpeed aplikační server s vbudovanou databázovou serverem MariaDB, která slouží k ukládání vašich projektů dat. Výchozí je také spuštění Memcached serveru jako řešení pro objektovou cache. Další specifické vlastnosti stacků mohou být zobrazeny v příslušné části níže.   1. Mohou být použity několik prostředí proměnných k řízení vašeho kontejneru LEMP/LLSMP:

- ADMINPANEL_ENABLED - umožňuje (hodnota true, výchozí hodnota) nebo zakazuje (hodnota false) přístup k konzoli phpMyAdmin pro integrální MariaDB databázový server
- CACHE_ENABLED - umožňuje (hodnota true, výchozí hodnota) nebo zakazuje (hodnota false) objektní uložení s Memcached
- CP_MEM_LIMIT - definuje část RAM, která má být rezervována pro aplikační server (NGINX/LiteSpeed), 50% celkové RAM kontejneru výchozí hodnotou
- CACHE_MEM_LIMIT - definuje část RAM, která má být rezervována pro Memcached uložiště, 10% celkové RAM kontejneru výchozí hodnotou
- DB_MEM_LIMIT - definuje část RAM, která má být rezervována pro MariaDB databázový server, 40% celkové RAM kontejneru výchozí hodnotou

Poznámka: Tyto RAM limity mohou být určeny v megabajtech (m|mb|M|MB), gigabajtech (g|gb|G|GB), nebo procentech (%). Pokud jednotky jsou omítnuty, hodnoty jsou považovány za procenta. Aby se změny těchto parametrů aplikovaly, je nutné obnovit spuštění kontejneru. Poznámka: LLSMP má další proměnné (např., WAF, WP_PROTECT, WP_PROTECT_LIMIT) specifické pro LiteSpeed stack, které popisují věnovaný dokument.
