Tato sekce vysvětluje hostování Kubernetes v Virtuozzo Application Management. Zde se popisují instalace clusteru, škálování, nasazení aplikací, správa dat trvalých a správa clusteru. Tato sekce také popisuje pokročilé téma, jako je federace clusteru v mnoha oblastech, přístup pomocí veřejné IP adresy, Traefik ingress a automatické aktualizace clusteru. V této sekci:

Kubernetesový cluster Správa Kubernetes Kubernetes Škálování Nasazení aplikací Správa dat trvalých Traefik v2 Ingress Controller Veřejná IP pro přístup k Kubernetes Multi-Region Cluster Federace Automatická aktualizace clusteru Časté otázky Co je Kubernetes hostování v platformě?Kubernetes hostování umožňuje nasadit a spravovat Kubernetesové cluster na Virtuozzo Application Management, což znamená, že můžete mít prostředí pro skalabilní a kontejnerizované aplikace. Nastavení clusteru je plně automatizováno a optimizováno pro nejlepší výkon. Jak vytvořit Kubernetesový cluster?Řešení Kubernetesového clusteru je k dispozici pro automatickou instalaci prostřednictvím platformy Marketplace. Můžu aktualizovat Kubernetesový cluster?Ano. Použijte automatický proces aktualizace z Kubernetes Cluster Configuration add-on. Jak nasadit aplikace do Kubernetesového clusteru?Nasadit aplikace pomocí standardních Kubernetesových manifestů (yaml nebo json soubory) nebo pomocí Helm chartů. Jak externě vystavit služby?Nastavte ingress (např. Traefik) a, pokud je potřeba, připojte veřejnou IP. Další možnosti zahrnují služby jako NodePort a LoadBalancer.

Jak se spravuje trvalé úložiště?Platforma nabízí možnost připojit a automaticky konfigurovat věcnou NFS úložiště s dynamickou poskytováním pro vaši Kubernetesový cluster. Alternativně můžete nastavit a spravovat vlastní řešení úložiště.
