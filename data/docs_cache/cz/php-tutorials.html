    1. PHP Výuky pro začátečníky

V tomto článku se dozvíte, jak začít s programováním v PHP. PHP je jedním z nejpopulárnějších programovacích jazyků pro vytváření webových stránek.

  1. Instalace PHP

Než začnete s výukou PHP, musíte mít PHP nainstalovaný na svém počítači. Pokud ještě nemáte PHP nainstalovaný, můžete si ho stáhnout z [oficiálního webu PHP](http://www.php.net/downloads.php).

  1. Vytvoření prvního PHP skriptu

Po instalaci PHP můžete vytvořit svůj první PHP skript. Vytvořte nový soubor s příponou .php a otevřete ho v textovém editoru. Nyní můžete začít psát PHP kód.

  1. Výuky PHP pro pokročilé

Pokud již máte zkušenosti s PHP, můžete se podívat na následující výuky, které se zaměřují na pokročilé téma.

  • [PHP OOP](http://www.php.net/manual/en/language.oop5.php)
  • [PHP Frameworky](http://www.php.net/manual/en/index.php?title=Category:Frameworks)
  • [PHP a databáze](http://www.php.net/manual/en/ref.pdo-mysql.php)
    1. PHP Frameworky

PHP Frameworky jsou soubory kódu, které vám umožní rychleji vytvářet webové aplikace. Některé z nejpopulárnějších PHP Frameworků zahrnují:

  • [Laravel](https://laravel.com/)
  • [Symfony](https://symfony.com/)
  • [CodeIgniter](https://codeigniter.com/)
    1. PHP a databáze

PHP můžete použít k vytváření databázových aplikací. Nejčastěji se používá MySQL, ale můžete také použít jiné databáze, jako je například PostgreSQL nebo MongoDB.

  1. PHP a e-mail

PHP můžete také použít k odesílání e-mailů. Můžete použít funkci mail() nebo můžete použít knihovnu PHPMailer.

  1. PHP a formuláře

PHP můžete také použít k zpracování formulářů. Můžete použít funkci $_POST nebo můžete použít knihovnu Form.

  1. PHP a soubory

PHP můžete také použít k práci s soubory. Můžete otevírat, ukládat a smazávat soubory pomocí funkcí file_get_contents() a file_put_contents().

  1. PHP a zabezpečení

PHP můžete také použít k zabezpečení vaší webové aplikace. Můžete použít funkce htmlspecialchars() a escapeshellcmd() k zabezpečení proti útokům XSS a SQL injection.
