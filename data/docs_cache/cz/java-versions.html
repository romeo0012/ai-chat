Aktuální seznam dostupných verzí na platformě poskytuje pomocí věnovaného, pravidelně aktualizovaného dokumentu Software Stack Versions. Dále můžete snadno změnit používanou verzi motoru pro existující prostředí:

  1. Přihlaste se k PaaS panelu a klikněte na tlačítko New Environment. V otevřeném wizardu přepněte na kartu Java, vyberte požadovanou aplikační server a verzi motoru (jako je to znázorněno na obrázku výše).
  1. Chcete-li změnit verzi Java v existujícím prostředí, předeployte odpovídající kontejner(y): Proto, vyberte požadovanou Tag (verze stacku a distribuce JDK) a klikněte na Redeploy. Potvrďte akci v otevřeném dialogu a počkejte několik minut na aplikování změn. Co dále?
