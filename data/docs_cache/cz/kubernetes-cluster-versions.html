Kubernetes Klaster: Verze a Změny
Platforma poskytuje předinstalované řešení Kubernetes (K8s) Klastru s automatickou instalací. Kubernetes je portabilní, rozšiřitelná a otevřená platforma pro správu kontejnerových úloh a služeb, která umožňuje jak deklarativní konfiguraci, tak automatizaci. Jeho funkce se velmi překrývají s PaaS, což umožňuje nastavit aplikace na základě systému Kubernetes přímo v platformě. Výhody, které získáte v rámci hostování Kubernetes Klastru v platformě:

  • Jednoduché spuštění - automatická instalace za několik kliknutí nevyžaduje žádnou ruční intervenci
  • Hyper škálovatelnost - klastr může být automaticky škálován vertikálně i horizontálně
  • Multi-Cloud Dostupnost - možnost kombinovat různé možnosti cloudu podle potřeby projektu
  • Zjednodušená správa - jediný bod správy prostřednictvím intuitivního UI a vbudovaného Web SSH
  • Flexibilní automatizace - automatizace procesů DevOps pomocí otevřeného API a Cloud Scripting
  • Ekonomická efektivita - platíte pouze za spotřebované zdroje, získáváte výhody z hustoty kontejnerů a škálovatelnosti

Doporučení: Další podrobnosti a rozsáhlejší popis s příklady použití naleznete v příslušném článku Kubernetes Klastru v našem blogu. Níže přehledně popíšeme všechny verze Kubernetes Klastru a popisujeme implementované změny a upravování.
