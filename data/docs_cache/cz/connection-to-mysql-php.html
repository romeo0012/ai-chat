Připojení k MySQL/MariaDB/Percona pro PHP
MySQL, MariaDB a Percona jsou velmi populární otevřené zdrojové databáze, které používají vývojáři po celém světě. Následující instrukce vám ukážou, jak připojit své PHP aplikace, hostované na platformě, k jednomu z těchto DB serverů: vytvořit prostředí, připojit se k databázi, ověřit připojení, vykonat požadavek a další konfigurace.

Prostředí vytvoření

  1. Přihlaste se k svému účtu PaaS a vytvořte prostředí s MySQL nebo MariaDB databázovým serverem (obě jsou k dispozici v sekci SQL wizard). Pro poskytnutí příkladu připojení jsme přidali Apache PHP aplikační server.
  1. Po vytvoření prostředí získáte e-mail s detaily pro správu a připojení k MySQL (nebo MariaDB):
  1. Vracete se zpět na svůj dashboard a klikněte na tlačítko Open in Browser pro vhodný databázový uzel (nebo MySQL nebo MariaDB). Přihlaste se do otevřené správce pomocí přijatých v předchozím e-mailu přihlašovacích údajů.
  1. Přejděte na kartu Databáze a vytvořte novou databázi (např., mysqldb). Nyní můžete nasadit svou aplikaci (nebo z archivu nebo z repozitáře GIT/SVN) do vytvořeného prostředí.

Připojení k databázi
Po úspěšném nasazení vaší aplikace potřebujete připojit ji k vaší databázi. Pro to musí být vaše aplikace správně nakonfigurovaná, například pomocí vbudovaného MySQLi (MySQL Improved) rozhraní.

Do vašich databáze. Pro toto je nutné, aby vaše aplikace byla správně konfigurovaná, například pomocí vbudované MySQLi (MySQL zlepšená) rozšíření. Odkazujte se na spojenou dokumentační stránku s plným seznamem dostupných funkcí, zatímco níže přehledně představíme jen základní:

  1. Získat řetězec pro připojení k vašemu MySQL/MariaDB uzlu:

1 mysqli_connect('{host}', '{user}', '{password}', '{db_name}');

Mějte na paměti, že odpovídající značky by měly být nahrazeny vašimi data pro připojení k MySQL nebo MariaDB uzlu:

  • {host} - odkaz na vaši DB uzl bez části protokolu
  • {user} a {password} - přihlašovací údaje pro správce databáze (pro produkční použití je doporučeno vytvořit vhodného uživatele s odpovídajícími oprávněními)
  • {db_name} - název požadované databáze (například předchozí databáze mysqldb)
    1. Pro přepnutí na jinou databázi na stejném serveru použijte následující funkci:

    1 mysql_select_db('{connect}','{db_name}');

Zde by měla být značka {connect} nahrazena řetězcem získaným pomocí popsané výše mysqli_connect funkce.

  1. Chcete-li ukončit připojení k databázi, provedete následující:

1 mysqli_close( );

Poznámka: Nutno zadat potřebné funkce na každé *.php stránce, která by měla být připojena k databázi. Pro kontrolu spojení můžete použít následující kód:

<?
// Kontrola spojení
if (!$conn = mysqli_connect('{host}', '{user}', '{password}', '{db_name}')) {
die("Connection failed: " . mysqli_connect_error());
}

// Vybrání databáze
if (!mysqli_select_db($conn, '{db_name}')) {
die("Database selection failed: " . mysqli_error($conn));
}

// Ukončení spojení
mysqli_close($conn);
?>

Vykonání jednoduchého požadavku

Níže naleznete příklad, jak provedět jednoduchý požadavek na vaši databázi a zobrazit výsledky v tabulce. Následující jednoduchý PHP skript zřídí spojení s vaším databázovým serverem (nezapomeňte zadat odpovídající hostname a přihlašovací údaje), se připojí k výchozí databázi mysql, kterou obsahuje, čte hodnoty z tabulky help_topic a zobrazí je v samostatně vytvořené tabulce.
php
<?php
// Kontrola spojení:
$link = mysqli_connect('{host}', '{user}', '{password}', '{db_name}');
if (!$link) {
echo "<h2>MySQL Error!";
}
// Vykonání požadavku a zobrazení výsledků v tabulce:
$sql = "SELECT * FROM help_topic";
$result = mysqli_query($link, $sql);
echo "<table border='1'>
<tr>
<th>ID</th>
<th>Název tématu</th>
<th>Popis tématu</th>
</tr>";
while($row = mysqli_fetch_assoc($result)) {
echo "<tr>";
echo "<td>" . $row['id'] . "</td>";
echo "<td>" . $row['name'] . "</td>";
echo "<td>" . $row['description'] . "</td>";
echo "</tr>";
}
echo "</table>";
mysqli_close($link);
?>

<?php
// Kontrola spojení:
$link = mysqli_connect('{host}', '{user}', '{password}', '{db_name}');
if (!$link) {
echo "<h2>Chyba MySQL!</h2>";
exit;
}
// Přepnutí na jinou databázi:
$db="mysql";
mysqli_select_db($link, $db);
// Výpis hlavičky tabulky:
echo "<table border=\"1\" width=\"100%\" bgcolor=\"#FFFFE1\">";
echo "<tr><td>Hodnota1</td><td>Hodnota2</td><td>Hodnota3</td>";
// SQL-žádost:
$q = mysqli_query ($link, "SELECT * FROM help_topic;");
// Výpis výsledků tabulky pro každý řádek
for ($c=0; $c<mysqli_num_rows($q); $c++) {
echo "<tr>";
$f = mysqli_fetch_array($q);
// Vrátí pole, které odpovídá získané řádce a posune vnitřní ukazatel dále.
echo "<td>$f[0]</td><td>$f[1]</td><td>$f[5]</td>";
echo "</tr>";
}
echo "</table>";
?>
