NGINX PHP Stack

Stav NGINX PHP je připravený na podporu HTTP/3 od verze 1.16.1 pro PHP 7.2.26, 7.3.13, 7.4.1 a vyšší. Pro práci přímo s serverem přes HTTP/3 je však požadována veřejná IP adresa, aby se obešla Shared Load Balancer. NGINX je rychlý a lehký HTTP server, který je široce používán vývojáři po celém světě. Je velmi přizpůsobitelný díky modulární struktuře, která umožňuje používat pouze potřebné funkce a zároveň zajišťuje efektivní využití zdrojů. Platforma upravuje a optimalizuje NGINX, aby se poskytl jako PHP aplikační server plně kompatibilní s platformovými funkcemi. V porovnání s Apache PHP je vhodnější pro zpracování webů s statickým obsahem, ale díky podpoře FastCGI může zpracovávat i složité skripty. Při použití NGINX jako serveru aplikace existují některé omezení velikosti nahrávaných souborů do aplikace. Můžete provedět následující konfigurace, aby se toto upravilo:

  1. Přiblížte si NGINX aplikační server a klikněte na vzniklý tlačítko Konfigurace.
  1. V otevřeném správci konfiguračních souborů najděte a upravte soubor /etc/nginx/nginx.conf tím, že do sekce http přidáte následující řetězec:

1 client_max_body_size 50m; Můžete použít libovolnou požadovanou hodnotu místo 50MB použitého v předchozím příkladu. Poznámka: Nevážete se na nastavení výše, pokud pracujete prostřednictvím vlastního správce souborů platformy, je omezena velikost nahrávání na 150MB (může se lišit podle nastavení poskytovatele hostingu). Pro práci s většími soubory je třeba připojit veřejný IP a použít vlastní správce (například můžete použít doplněk FTP).
  1. Uložte provedené změny a ještě je aplikujte kliknutím na tlačítko Restart Nodes. Další informace o konfiguraci PHP serverů naleznete v příslušných průvodcích: PHP Dev Center PHP Extensions PHP Accelerators PHP Auto Configurations Co dále?
