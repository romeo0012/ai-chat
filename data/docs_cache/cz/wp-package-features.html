WordPress Installation Kit Features

Instalace balíčku WordPress Kit Virtuozzo Application Management nabízí možnost přizpůsobit své prostředí WordPress vybráním potřebných možností ve výchozím okně instalace. Následující funkce jsou k dispozici pro konfiguraci:

LiteSpeed Vysokorychlostní webový server - instaluje řešení WordPress na základě LiteSpeed Web Serveru. Tato volba poskytuje nejvyšší možnou rychlost dodávky obsahu webu klientům prostřednictvím moderního protokolu HTTP/3. Pokud nezvolíte tuto volbu, bude instalován řešení NGINX-based. Následující dvě další funkce jsou k dispozici pouze pro instalace na základě LiteSpeed:

Brute Force Attack Protection zabezpečuje WordPress admin panel tím, že omezuje počet neúspěšných pokusů o přihlášení. Výchozí akce je Throttle, a počet povolených pokusů je 100. Web Application Firewall (WAF) umožňuje/zakazuje funkci, která chrání vaši webovou stránku WordPress tím, že aplikuje pravidla pro filtrování útočných požadavků tím, že kontroluje známé znaky útoku.

Poznámka: Pro další informace o těchto funkcích a jejich konfiguraci se odkazujte na dokumentaci LiteSpeed Web Serveru.

Let’s Encrypt SSL s funkcí Auto-Renewal vydává důvěryhodný, zdarma certifikát pro vlastní dominu. Využívá vbudované funkce pro periodické obnovování, aby se zabránilo vypršení platnosti certifikátu. Vyplňují se vhodné upozornění po e-mailu.

WordPress Multisite Network povoluje stejnojmennou funkci.

Obnovování periodicky k prevenování vypršení certifikátu. Správné oznámení jsou odeslána po e-maile. WordPress Multisite Network umožňuje stejnojmennou funkci. Umožňuje aplikaci chovat se jako centrální bod sítě WordPress, kde může sít mít více webů. S tímto vbudovanou funkcí a automatizací platformy můžete vytvořit nezávislou sít webů a pozvat další osoby, aby na stejné síti vytvářeli své webové stránky, i pro komerční použití. WooCommerce je volný a otevřený WordPress plugin, který přidává funkce e-commerce do vašeho webu WordPress. Tento možnost povolte, aby se automaticky instalovala tato vynikající platforma pro obchod jakékoliv velikosti. Několik dalších funkcí je k dispozici pouze pro balíčky WordPress Cluster: MariaDB Galera Cluster je multi-primární databázový cluster založený na synchronizní replikaci a InnoDB motoru. S Galerou Cluster můžete provádět přímo čtení a zápis do libovolného uzlu. V případě selhání jednoho uzlu dojde k žádnému zastavení clusteru a žádným složitým postupům přechodu. Pokud zrušíte zaškrtnutí políčka, bude instalován primární-primární databázový cluster.Tip: Odvozujte se k dokumentaci MariaDB/MySQL/Percona Auto-Clustering pro další podrobnosti o implementačních detailech a porovnání typů replikace. GlusterFS Cluster poskytuje řešení pro širokou dostupnost a škálovatelnost pro statické prostředky vašeho clusteru WordPress.
