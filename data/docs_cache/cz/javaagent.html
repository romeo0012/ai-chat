Java Agent Integrace
Java agent je průvodce v přední části aplikace hlavní metody. Obvykle jde o .jar balíček, který je staticky nahrán v metodě PreMain-Class, která implementuje mechanismus přepsání obsahu spouštěných tříd. Platforma umožňuje automaticky spouštět takový applet při spuštění (po inicializaci JVM). Tip: Všechny platformně certifikované Java stacks spouští jelastic-gc-agent.jar Java agenta jako součást standardní optimizace. Vykonává periodické volání Full GC, aby snížil spotřebu paměti a vrátil nevyužitou RAM zpět do OS. Díky přispění platformy k vývoji Java, je podobná funkcionalita nativně implementována od verze 12 JDK. Zkontrolujte Memory Agent add-on, abyste se dozvěděli více o platformní automatické optimizaci spravovaných Java stacks nebo abyste mohli použít k optimizaci libovolného vlastního Java kontejneru.   1. Přihlaste se k panelu správy platformy pomocí svých údajů a klikněte na tlačítko Konfigurace pro aplikační server v vašem Java prostředí:
  1. V otevřeném správci konfiguračních souborů můžete nahrát svůj Java agent .jar soubor do libovolného volného umístění. Použijte seznam akcí v horní panelu (pro současný adresář) nebo kontextové menu při přehledu konkrétního adresáře. Poskytněte odkaz na požadovaný soubor nebo ho naleznete na místním počítači k nahrání.
  1. Následně přečtete si proměnné.
