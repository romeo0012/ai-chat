Česká konfigurace Java Application Server
Provedení potřebných konfigurací stiskněte tlačítko Config uvažující na vašem aplikačním serveru. V případě, že máte více aplikačních serverů, můžete je konfigurovat společně nebo samostatně. K tomu následují kroky:

  1. Otevřete rozevírací seznam v horní části karty konfigurace. Zahrnuje seznam všech aplikačních serverů v vašem prostředí.
  1. Vyberte ten, který potřebujete a provedete konfiguraci.
  1. Chcete-li uložit změny: pouze pro zvolený server - stiskněte tlačítko Uložit pouze pro aktuální instance z rozevíracího seznamu, pro všechny servery - stiskněte tlačítko Uložit Poznámka: Pokud vytvoříte/přejmenujete soubor nebo složku v Konfiguračním manažeru, bude to platit pouze pro seznam zvoleného uzlu. Nemůžete uložit tuto změnu pro všechny dostupné aplikační servery v prostředí. Pokud chcete také vytvořit/přejmenovat soubor nebo složku v ostatních serverech, musíte to provést ručně. Níže naleznete seznam konfiguračních souborů dostupných ke změně v Java aplikačních serverech: Tomcat TomEE GlassFish Jetty

Chcete-li získat další informace o možných nastaveních v poskytnutých konfiguračních složkách, použijte odpovídající popisy: server home webapps/work JAVA_HOME lib cron keys contexts server_lib apps SERVER
Hlavní konfigurace Java servlet containeru se provádí v souborech, umístěných v adresáři server. Pomocí následujících konfiguračních souborů můžete provést akce uvedené níže (jedná se o některé příklady): context.xml

Konfigurace kontejnerů se provádí v souborech, které se nacházejí v adresáři na serveru. Pomocí následujících konfiguračních souborů můžete provést akce, které jsou uvedeny níže (jedná se o několik příkladů):

  • context.xml - konfigurace replikace relací sezení pomocí Memcached
  • web.xml - konfigurace přístupu vzdáleně pomocí WebDav serveru
  • server.xml - povolení proměnných pro více domén
  • variables.conf - konfigurace nastavení paměti pro vaše Java kontejnery, uvedením vlastních parametrů GC, -Xmx, -Xms (použijte standardní parametry, každý na novém řádku):

1
2
-Xmx< velikost >m
-Xms< velikost >m

  • Konfigurace vlastních systémových proměnných pro Tomcat, TomEE, Jetty nebo GlassFish:

1
2
-Dvar1=value1
-Dvar2=value2
-Dmy.var3=/my/value

  • Konfigurace JavaAgent interceptoru pro povolení vzdáleného ladění:

1
2
-Xdebug
-Xrunjdwp:transport=dt_socket,server=y,suspend=n,address={port_number}

Poznámka: Tento soubor je k dispozici pouze pro aplikační servery Tomcat a TomEE. Pro konfiguraci serveru GlassFish použijte Admin Panel. Zpět k seznamu HOME

Pokud potřebujete použít jakékoliv vlastní soubory/adresáře pro konfiguraci vaší aplikace, můžete je stáhnout/vytvořit v adresáři, který se používá jako úložiště v Java serveru. Zpět k seznamu WEBAPPS / PRACE Složky webapps (pro Tomcat/TomEE) a prace (pro Jetty) slouží k uložení nezabalované aplikace nasazené do prostředí. Zpět k seznamu JAVA_HOME Složka JAVA_HOME obsahuje konfigurační soubory a knihovny Java. Zde můžete upravovat nastavení Java a nahrát další knihovny Java. Zpět k seznamu LIB Složka LIB slouží k uložení výchozích a nahrání vlastních souborů .jar. Zpět k seznamu CRON Servery obsahují složku cron s konfiguračním souborem, kde mohou být konfigurovány cronjobs. Podrobnější informace o konfiguraci cronjobů naleznete v dokumentu Nastavení cronjobu. Zpět k seznamu KEYS Složka keys slouží jako umístění pro nahrání libovolného soukromého klíče, který je potřebný pro vaši aplikaci. Vytvořte klíč, uložte ho jako jednoduchý soubor a nahrávejte do složky keys. Může být použit pro různé případy, pouze uvedením cesty k vašemu klíči: 1 /var/lib/jelastic/keys/{key_file_name} Zpět k seznamu CONTEXTS Složka contexts obsahuje XML konfigurační soubory pro každý nasazený kontext. Všechny tyto soubory jsou otevřené pro úpravy. Zpět k seznamu SERVER_LIB Složka server_lib je konfigurační složka GlassFish s všemi dostupnými knihovnami serveru.

Pro každý nasazený kontext. Všechny tyto soubory jsou otevřené pro úpravy. Zpět k seznamu SERVER_LIB Složka server_lib je konfigurační adresář GlassFish s všemi dostupnými knihovnami serveru.
