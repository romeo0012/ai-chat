Přizpůsobení vlastních proměnných prostředí
Proměnné prostředí představují druh místníků, kde můžete uložit často používané hodnoty parametrů nebo řetězců, aby se nemuseli zadávat ručně do kódu každé doby, kdy je potřeba. Je zde počet přednastavených proměnných prostředí, které jsou přednastaveny a mohou být použity v kódu vaší aplikace nebo dokonce upravovány před vytvořením uzlu k aplikaci nějaké personalizace, což vám umožní pracovat s platformou ještě více užitečně. V tomto průvodci popíšeme nejčastější způsoby přidání vlastních proměnných pro libovolný uzl v platformě:
pomocí věcného oddílu dashboardu pomocí konfiguračních souborů shell prostřednictvím souboru variables.conf (pouze pro Java) Přizpůsobení prostředí proměnných prostředí pomocí UI

  1. Přiblížte se k skupině uzlů v dashboardu, rozbalte sekci Další a vyberte možnost Proměnné.
  1. V otevřeném rámečku můžete upravit seznam proměnných prostředí podle potřeby (pomocí tlačítek v panelu nástrojů). Poznámka: Implementace platformy Dockerových kontejnerů umožňuje použití existujících proměnných prostředí k definování dalších. Například hodnota MY$HOME bude automaticky převedena na MY\ (nebo podobně podle hodnoty proměnné HOME). Nezapomeňte na Použití změn, které jste provedli. Nastavení prostředí proměnných prostředí pomocí shell configs

Můžete poskytnout vlastní proměnné pomocí souborů shell config: ~/.bash_profile se spouští pouze při přihlášení přes konzoli.

Nastavte prostřední proměnné prostřednictvím konfiguračních souborů shellu. Můžete poskytnout své vlastní proměnné pomocí souborů konfiguračních souborů shellu: ~/.bash_profile se spouští pouze při přihlášení pomocí konzole počítače, ~/.bashrc se spouští pro každý nový instance shellu. Chcete-li vám pomoci s udržováním těchto souborů, platforma automaticky zahrnuje zdroje souboru .bashrc do .bash_profile. Tímto způsobem můžete poskytnout vlastní proměnné prostřednictvím bývalého souboru:

  1. Vytvořte nebo upravte soubor .bashrc v adresáři domovském pomocí následujícího formátu:

1. export {název_proměnné} = {hodnota_proměnné}
kde {název_proměnné} - název proměnné, kterou chcete nastavit
{hodnota_proměnné} - hodnota proměnné
  1. Každý nový instance shell bude nyní poskytnut vlastní proměnné. Chcete-li nainstalovat nové nastavení pro aktuální relaci, použijte následující příkaz a poté ověřte dostupnost nových proměnných:

1. 2
zdroj ~/.bashrc
echo $ {název_proměnné}
Jak se vidí, změny byly úspěšně aplikovány.

Nastavte prostředí Java prostřednictvím správce konfigurací. Následující jednoduchý postup je identický pro všechny platformy spravované Java aplikační servery.

  1. Klikněte na tlačítko Konfigurace pro vaši aplikační server, abyste mohli přístup k správci souborů kontejneru.
  1. V otevřené kartě přejděte do kategorie proměnných.

1. Klikněte na tlačítko Konfigurace pro vaši aplikační server Java, abyste mohli přístupit k správci souborů kontejneru.

  1. V otevřené kartě se přesuňte k souboru variables.conf v jednom z následujících umístění: Tomcat, TomEE - /opt/tomcat/conf/variables.conf Jetty - /opt/jetty/etc/variables.conf Spring Boot - /opt/shared/conf/variables.conf GlassFish - /opt/glassfish/glassfish/domains/domain1/config/variables.conf Payara - /opt/payara/glassfish/domains/domain1/config/variables.conf WildFly - /opt/wildfly/conf/variables.conf Zde můžete poskytnout své vlastní proměnné (každá se musí oddělovat mezerou nebo novou řádkou) nebo upravit Java možnosti pro vaši aplikaci. Například: -Dvar1=hodnota1 -Dvar2=hodnota2 -Dmy.var3=/můj/hodnota Tip: Alternativně některé aplikační servery (např. GlassFish, Payara, WildFly) nabízejí správce panelu, který umožňuje přidat JVM možnosti a vlastní proměnné: Nezapomeňte uložit konfigurace, které jste vytvořili.
  1. Restartujte uzly vašeho aplikačního serveru, aby se změny aplikovaly.
  1. Nové proměnné mohou být volány prostřednictvím vašeho Java kódu pomocí metody System.getProperty("vaše_proměnná") k určení určených hodnot pro potřebné argumenty. Například: String var1 = System.getProperty("var1"); String var2 = System.getProperty("var2"); String var3 = System.getProperty("my.var3") Nyní můžete upravit svůj aplikační kód pomocí těchto nových proměnných.
