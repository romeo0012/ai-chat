Podpora Websockets pro Apache a NGINX
Websockets PHP je široce rozšířená technologie klient-server, která umožňuje implementovat výměnu okamžitých zpráv v aplikaci. Tento proces je dosažen vytvořením trvalé plnoduplexní TCP-závislé spojnice mezi serverem a prohlížečem klienta. Tento způsob komunikace vede k velmi nízké latenci spojení a rychlé interakci, současně zajišťuje streaming prostřednictvím proxy a zákonů firewall, oběma směry současně. Platforma poskytuje pokročilou a doplněnou podporu Websockets prostřednictvím integrace této technologie do Shared Load Balancer a uzlu NGINX-balancer, takže můžete ji používat i bez externího IP adresy připojené k vašemu serveru. Toto je dosaženo tím, že se přenášejí různé porty, používané vašimi Websockets aplikacemi, na jeden – 80 pro HTTP a 443 pro HTTPS. Nejjednodušším způsobem konfigurace podpory Websockets pro vaši aplikaci je umístění uzlu NGINX balanceru před ní (podrobnější instrukce mohou být nalezeny v odpovídajícím dokumentu). Však někdy může tento způsob konfliktovat s vašimi požadavky v nějakém důvodu, zatímco aplikace potřebuje tuto technologii implementovat. Pro takové případy platforma zajišťuje plnou podporu Websockets v dostupných aplikačních serverech, včetně Apache (určeného k poskytování PHP, Ruby a Python aplikací) a NGINX (pro PHP a Ruby aplikace).

Pokud máte otázky nebo potřebujete další informace, neváhejte se obrátit na podporu naší platformy.

Podpora WebSockets v Apache serveru poskytuje modul proxy_wstunnel_module, který je přidán do výchozího serveru. K NGINX aplikačnímu serveru se používá schopnost proxying WebSockets spojení podobně, jak to dělá NGINX-balancer. Je tedy čas nakonfigurovat svůj aplikační server.

  1. Klikněte na tlačítko Konfigurace vedle vašeho node aplikačního serveru:
  1. V otevřeném okně Configuration Manager provedete kroky z jedné z následujících sekcí instrukcí, podle zvoleného serveru: pro Apache aplikační server Najděte soubor httpd.conf v adresáři conf a odkomentujte následující řádky na konci tohoto souboru (přibližně na 962. řádku).

1 2 3 4
<Location /ws>
ProxyPass ws://127.0.0.1:<PORT>
ProxyPassReverse ws://127.0.0.1:<PORT>
</Location>
Nyní změňte oba parametry <PORT> na číslo portu, který posluchá vaše WebSockets aplikace (například naši používá 9000).
