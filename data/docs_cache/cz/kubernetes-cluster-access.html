Přístup k Kubernetes Cluster po úspěšné instalaci clusteru existují různé způsoby, aby se mohlo spravovat: Kubernetes Dashboard kubectl klient Kubernetes Dashboard

  1. Po instalaci se zobrazí zpráva s všemi potřebnými informacemi pro připojení k Kubernetes Dashboard - odkaz a token přístupu. Též se tyto informace poskytují prostřednictvím vhodné e-mailové notifikace.
  1. Vyberte si odkaz, vyberte možnost Token a vložte požadovanou hodnotu. Tip: Je možné se přihlásit pomocí souboru kubeconfig, ale potřebujete si k tomu instalovat kubectl a nastavit správný kontext (viz níže).
  1. Pokud jste ztratili e-mail s přístupovým tokenem k Kubernetes clusteru, můžete ho zobrazit spuštěním následujícího příkazu na hlavním uzlu (například prostřednictvím Web SSH):

1 kubectl -n kube-system describe secret $(kubectl -n kube-system get secret | grep fulladmin | awk '{print $1}') | grep 'token:' | sed -e's/token:\| //g' Nyní můžete znovu přistoupit k Kubernetes Dashboard. Kubectl Klient Kubectl je příkazový nástroj pro ovládání Kubernetes clusteru. Platforma ho automaticky instaluje na všech hlavních uzlech při vytváření prostředí. Můžete se začít pracovat se svým clusterem pomocí kubectl okamžitě, prostřednictvím SSH se připojte k požadovanému uzlu.
  1. Pro použití místního kubectl následujte následující kroky.

Všimněte si, že technické termíny, kódy, příkazy, cesty souborů a URL zůstávají v původním jazyce.

Připravte se na práci s vaším clusterem pomocí kubectl. Můžete začít práci s vaším clusterem přímo, pouze se připojte k požadovanému uzlu pomocí SSH.

  1. Následujte kroky pro použití místního kubectl. Poté spusťte následující příkaz k vytvoření vzdálené spojení:

1 2 3 4 5 kubectl config set-cluster jelastic --server={api-endpoint} && \ kubectl config set-context jelastic --cluster=jelastic && \ kubectl config set-credentials user --token={token} && \ kubectl config set-context jelastic --user=user && \ kubectl config use-context jelastic
Zaměňte značky {api-endpoint} a {token} na skutečné hodnoty URL Remote API a přístupového tokenu. Tip: Pokud jste Remote API neaktivovali při instalaci, můžete to udělat pomocí vbudovaného add-onu dostupného pro hlavní uzly v panelu nástrojů platformy.
  1. Můžete zkontrolovat, zda má kubectl přístup k clusteru pomocí následujícího příkazu:

1 kubectl get pods
