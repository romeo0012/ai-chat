LSCache poskytuje také osobní podporu pro WooCommerce, takže nemáte nic, co se obávat. Bezpečnostní ochrana S titulem nejlepšího CMS na trhu přichází také bezpečnostní hrozbě. Otevřený zdrojový kód WordPressu zvyšuje riziko. Asi 70% webů, která běží na WordPressu, padají oběti útokům hackerů prostřednictvím škodlivého software v pluginu. Další populární způsob útoků je použití programů, které odhadují hesla pro přihlášení admina, také známé jako útoky brute force. Kromě toho, že představují bezpečnostní riziko, tyto útoky zatěžují významně serverové zdroje. Pokud je váš heslo neodhadnuto, může se server stát pomalejším. K zabránění takových útoků chrání LiteSpeed nejvíce citlivé soubory xmlrpc.php a wp-login.php. Dále přesouvá bezpečnostní Captcha z úrovně aplikace na úroveň serveru a zabraňuje nežádaným pokusům o přihlášení pomocí automatického blokování IP adres. Dosahuje se toto pomocí nastavení automatického kvóty pro přihlášení, která se snižuje po každé neúspěšné snaze. Když se kvóta vyčerpá, se aplikuje ochrana proti požadavkům pomocí zpomalování, odmítnutí nebo odstranění požadavků, aby chránila vaši instalaci WordPress.
