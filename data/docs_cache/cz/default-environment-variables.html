Prostřední proměnné prostředí
Proměnné prostředí slouží k uložení hodnot často používaných parametrů, které poskytují software programu během spouštění. Tímto způsobem se aplikace stává portabilnější a flexibilnější. Nejčastějším použitím proměnných je rychlé upravování konkrétních hodnot, které se v kódu aplikace vyskytují vícekrát. Pokud potřebujete vytvořit vlastní proměnné prostředí pro svůj projekt, přečtěte si průvodce, který je zde odkazován. Dalším scénářem pro použití proměnných je konfigurace aplikace pomocí sad predefinovaných hodnot (povolení/zakázání funkcí, změna chování atd.). Platforma doplňuje většinu certifikovaných software stacků sadou výchozích proměnných, které mohou být využity vývojáři při hostování aplikace. Seznam výchozích proměnných
