WildFly Aplikaceový Server

WildFly je moderní, flexibilní, lehký a spravovaný běhový prostředí aplikací, které je napsané v Java a implementuje nejnovější standardy a technologie Java Platform Enterprise Edition (Java EE) specifikace. WildFly je plně zdarma a otevřený zdrojový kód, dostupný k běhu na více platformách. Mezi hlavní vlastnosti tohoto aplikace serveru:

  • Přizpůsobitelný runtime na základě pluggable subsystemů, které mohou být integrované nebo odstraněny na požadavek
  • Podpora Java EE8 k implementaci nejnovějších standardů enterprise Java v modulárním přístupu s možností spouštět každou službu v izolaci, což umožňuje rychlou, lehkou a optimální pro nejlepší výkon

Chcete-li vytvořit WildFly aplikaceový server pro Java projekt, následujte níže uvedené jednoduché kroky. Poznámka: Tento šablon používá moderní daemon systému systemd pro inicializaci.

Vytvoření WildFly Serveru

  1. Přihlaste se k svému PaaS účtu a klikněte na tlačítko New Environment v horní levém rohu panelu nástrojů.
  1. V otevřeném okně topologie prostředí přejděte na kartu Java a vyberte z seznamu dostupných aplikace serverů WildFly (podporované verze 10-16). Poté nastavte limit přidělených zdrojů pomocí sliderů cloudlet, zvolte oblast (pokud je k dispozici více) a upravte název svého prostředí.

Seznam dostupných aplikačních serverů. Poté nastavte limit přiřazených zdrojů pomocí klávesiček cloudlet, vyberte oblast (pokud je k dispozici více), a upravte název vašeho prostředí. Poznámka: WildFly není kompatibilní s Java 6 a 7; tudíž tyto verze nejsou k dispozici z důvodu minimálních požadavků na zdroje WildFly. Silně se doporučuje přiřadit více než 1 cloudlet pro tento uzel. Jinak můžete mít nízkou výkonnost serveru a dokonce jeho selhání. WildFly můžete spustit v režimu Standalone pomocí konfiguračního souboru definovaného v prostředí proměnné STANDALONE_MODE_CONFIG, které platforma poskytuje zásobníkem. Platforma poskytuje výchozí podporu pro WildFly servery Auto-Clustering v režimu Managed Domain pomocí odpovídajícího přepínače v topologickém vizualizátoru. Klikněte na tlačítko Vytvořit, když budete připraveni. 3. Počkejte několik minut na vytvoření vašeho prostředí a klikněte na tlačítko Otevřít v prohlížeči vedle něj. 4. Výchozí stránka WildFly zobrazuje několik užitečných odkazů, aby vás pomohla začít. Chcete-li přistupovat k WildFly Administration Console, klikněte na odkaz (označený v obrázku výše) nebo získáte URL z e-mailu (odoslaného po vytvoření serveru) spolu s ostatními přístupovými údaji. Také můžete zřídit SSH spojení s vaším WildFly serverem a použít vbudovanou utilitu WildFly CLI pro správu.

Překlad provedl David Novák, překladatel technických textů.

E-mail (obdržené po vytvoření serveru) spolu s ostatními přístupovými kredenzami. Vývojář může také zřídit připojení SSH k WildFly serveru a použít vnitřní utilitu WildFly CLI pro správu. Výchozím režimem je WildFly aplikační server spuštěn v režimu "standalone", tak aby každý instance byl nezávislý proces podle konfiguračního souboru definovaného prostřednictvím proměnné prostředí STANDALONE_MODE_CONFIG. V režimu standalone je certifikováno čtyři profily: standalone.xml (výchozí) - konfigurace pro Java Enterprise Edition 8 Web s požadovanými technologiemi, standalone-full.xml - konfigurace pro Java Enterprise Edition 8 Full s všemi EE 8 technologiemi, standalone-ha.xml - konfigurace pro Java Enterprise Edition 8 Web s vysokou dostupností, standalone-full-ha.xml - konfigurace pro Java Enterprise Edition 8 Full s vysokou dostupností. V případě použití konfigurací HA (poslední dvě možnosti) je pro komunikaci mezi uzly použit protokol jgroups. Je konfigurován k použití autorizace s MD5 tokenem a asymetrickou šifrováním výchozím nastavením. Tato implementace zabraňuje neautorizovaným uzlům připojit se k clusteru a nečlenům komunikovat s členy clusteru. Poznámka: Je velmi doporučeno změnit výchozí hodnotu parametru auth_value v souboru standalone HA konfigurace na produkčních prostředích. Tímto končí naši kurz instalace WildFly serveru!
