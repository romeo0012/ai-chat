WordPress Klasterový Balíček

WordPress Klasterový balíček je automatizovanou řešením pro vysokou dostupnost instalace WordPressu v klastru lehkých kontejnerů. Balíček provede všechny nutné konfigurační kroky k nastavení WordPressu v klastru, včetně instalace webového serveru, databáze, balanceru zatížení a sdíleného úložiště. Také konfiguruje automatickou horizontální škálování podle zatížení a propojuje všechny komponenty, aby fungovaly jako jeden systém. To umožňuje spouštět velká města s vysokým provozem a zajišťuje, že vaše WordPressová stránka zůstane dostupná i při vrcholných zatíženích. Nabízí podnikovou kvalitu výkonu a spolehlivosti bez nutnosti rozsáhlé znalosti DevOps. Chcete-li získat nejvýhodnější z WordPress Clustera, mohou být následující výhody nakonfigurovány:

  • Instalace WordPressu klastru s rychlým LiteSpeed a vysokou dostupností MariaDB Galera clusteru
  • Připojení vadové odolného Shared Storage clusteru na základě GlusterFS software
  • Získání zdarma Let’s Encrypt SSL certifikátu s automatickou obnovou
  • Připojení vlastního domény a aktualizace certifikátu
  • Škálování dynamicky podle zatížení

Instalace WordPress Clustera

Chcete-li nainstalovat WordPress Cluster balíček, proveďte následující kroky:

  1. Klikněte na tlačítko Marketplace na vrcholu Virtuozzo Application Management dashboardu.
  1. Použijte vyhledávací pole, abyste nalezli balíček WordPress Cluster Kit a klikněte na *Instalovat.

1. Klikněte na tlačítko Marketplace na vrcholu správního panelu Virtuozzo Application Management.

  1. Použijte vyhledávací pole, abyste nalezli balíček WordPress Cluster Kit a klikněte na *Instalovat.
  1. V otevřeném okně instalace můžete zvolit Scaling Strategy podle očekávané zátěže. Podle našich zkušeností nabízíme tři běžné scénáře automatizace zátěže pro WordPress, aby se zabránilo přetížení (these settings mohou být upravovány po instalaci): Malá zátěž přidá 1 serverovou instanci aplikace (až 16) pokud je zátěž vyšší než 70% odstraňuje 1 serverovou instanci aplikace (od 2) pokud je zátěž nižší než 20% Střední zátěž přidá 1 serverovou instanci aplikace (až 16) pokud je zátěž vyšší než 50% odstraňuje 1 serverovou instanci aplikace (od 2) pokud je zátěž nižší než 20% Vysoká zátěž přidá 2 serverové instanci aplikace (až 16) pokud je zátěž vyšší než 30% odstraňuje 1 serverovou instanci aplikace (od 2) pokud je zátěž nižší než 10%

Přetížení 2 uzlů serveru aplikace (až 16) se přidá, pokud je zatížení vyšší než 30%, odstraňuje se 1 uzl serveru aplikace (minimálně 2), pokud zatížení klesne pod 10%.

  1. Nastavte potom svůj cluster aplikace WordPress zvolením nutných vyspělých funkcí:
  • Vyberte LiteSpeed High-Performance Web Server místo výchozího NGINX web serveru
  • Povolte funkce Brute Force Attack Protection a Web Application Firewall pro LiteSpeed
  • Vyberte MariaDB Galera Cluster místo výchozího Primary-Primary databázového clusteru
  • Nainstalujte Let’s Encrypt SSL s funkcí Auto-Renewal k vydání automaticky bezplatného SSL certifikátu
  • Vyberte GlusterFS Cluster místo výchozího Shared Storage
  • Nastavte WordPress Multisite Network

- Nainstalujte WooCommerce addon pro WordPress
Konečně, zadejte prostředí a název zobrazení, vyberte dostupnou oblast (pokud je k dispozici), a klikněte na Install.
  1. V průběhu několika minut bude vytvořen a nastaven WordPress Cluster podle zvolených možností. To je vše! Můžete nyní přistupovat k prostředí WordPress Cluster a začít stavět svůj web.
