PHP Versions

← Chat

V PHP hosting na platformě jsou podporovány následující verze PHP engine: PHP 8.1.33, PHP 8.2.31, PHP 8.3.31, PHP 8.4.22, PHP 8.5.7. Seznam aktuálních verzí k dispozici na platformě získáte prostřednictvím věnovaného Software Stack Versions dokumentu, který se pravidelně (týdně) aktualizuje. Můžete si zvolit potřebnou verzi při vytváření prostředí a později snadno přepínat mezi nimi pomocí topologického asistenta. Průběh procesu je následující:

  1. Kliknutím na tlačítko Nové prostředí v horní části panelu na dashboardu otevřete okno Environment Wizard.
  1. Přesuňte se na kartu PHP jazyka a vyberte požadovaný aplikační server. Vyberte požadovanou verzi engine pomocí druhé svislé lišty v centrálním panelu. Nastavte limity zdrojů, vyberte požadovanou oblast, zadejte název prostředí (nebo ponechte výchozí název) a klikněte na tlačítko Vytvořit. Tip: Pro další informace o specifických aspektech PHP hostingu na platformě a možností, které nabízí, přečtěte si dokument PHP Developer’s Center.
  1. Chcete-li změnit verzi PHP pro již existující prostředí, klikněte na ikonu Přepustit kontejnery vedle vhodné vrstvy.
  1. Vyberte požadovanou verzi engine z seznamu Tagů otevřeného okna. Kliknutím na Přepustit potvrďte změny. Poznámka: Při přepnutí na PHP 7 z starších verzí můžete muset ručně aktivovat určité PHP moduly, protože některé z nich byly změněny na dynamické (tj. aktivovat je pouze v případě potřeby).
