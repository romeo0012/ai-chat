Bezpečnostní konfigurace aplikací Jetty Tento dokument vám pomůže konfigurovat bezpečnostní domény pro vaši server aplikace Jetty, aby zlepšil ochranu vaší aplikace. Správně nakonfigurované domény poskytují možnost nastavit ověřování a kontrolu přístupu pro vaši webovou aplikaci Jetty. Doména je služba ověřování, která je k dispozici všem webovým aplikacím na serveru, pokud je definována v souboru konfigurace Jetty. Každá doména obsahuje rozsah uživatelů a má své unikátní jméno. Každý uvedený uživatel má informace o ověřování a sadu rolí spojených s ním. Můžete nakonfigurovat jednu nebo více různých domén podle potřeby. Níže naleznete příklad, jak nakonfigurovat kontrolu přístupu pro vaši aplikaci Jetty v Managementu aplikací Virtuozzo: ověřování pro vaši aplikaci brána firewall omezení přístupu podle adresy klienta IP Autentizace Chcete-li nakonfigurovat požadavek na ověřování před vaším serverem aplikace Jetty, následujte následující kroky: 1. Klikněte na tlačítko Konfigurace vedle vašeho serveru aplikace Jetty v panelu nástrojů platformy. 2. Přejděte do adresáře /opt/jetty/etc a vytvořte soubor realm.properties tam. 3. Tento soubor poskytuje informace o uživatelích a jejich rolích, které budou použity pro ověřování. Uveďte uživatele a jejich role ve následujícím formátu: 1 2 # {uživatel}:{heslo},{role1},{role2},{role3} test: heslo, admin V příkladu výše vytvořili jsme uživatele test s rolí admin.

<!DOCTYPE Configure PUBLIC "-//Jetty//Configure//EN" "http://jetty.org/configure_10_0.dtd">
<Configure id="Server" class="org.eclipse.jetty.server.Server">
<Call id="ResourceFactory" class="org.eclipse.jetty.util.resource.ResourceFactory" name="of">
<Arg><Ref refid="Server" /></Arg>
<Call id="realmResource" name="newResource">
<Arg><Property name="jetty.demo.realm" default="etc/realm.properties" /></Arg>
</Call>
</Call>
<Call name="addBean">
<Arg>
<New class="org.eclipse.jetty.security.HashLoginService">
<Set name="name">MyRealm</Set>
<Set name="config"><Ref refid="realmResource"/></Set>
</New>
</Arg>
</Call>
</Configure>

Chcete-li zajistit bezpečnost vaší aplikace Jetty, je nutné řídit přístup k ní podle IP adres klienta. Toto lze provést konfigurací pravidel brány firewall pro vaši Jetty server. Správce aplikací Virtuozzo nabízí vbudovanou bránu firewall, která umožňuje provedení všech potřebných nastavení k flexibilnímu řízení přístupu k vaší aplikaci. Poznámka: Musíte přidat veřejnou IP adresu do vašeho Jetty serveru, aby se na něj aplikovala brána firewall. Například, pokud chcete odmítnout přístup k aplikaci Jetty pro určitou IP adresu, postupujte následovně: 1. Klikněte na tlačítko Konfigurace vedle vašeho prostředí Jetty a přejděte do sekce Firewall. 2. Přepněte se na kartu Pravidla příchozích zpráv a klikněte na tlačítko Přidat, aby vytvořili nové pravidlo. Chcete-li odmítnout připojení z určité IP, vyplňte pole následovně: Uzly - vyberte Jetty server Název - zadejte libovolné požadované jméno pravidla Protokol - vyberte TCP požadovaný protokol Portový rozsah - odmítněte přístup k všem portům, zanechte toto pole prázdné Zdroj - vyberte možnost Vlastní IP adresy a zadejte potřebnou IP v poli IP adresa rozsah Zásada - nastavte vhodnou prioritu pro tuto pravidlo (například 900, aby se před prioritami výchozími) Akce - vyberte možnost Odmítnout Klikněte na Přidat, aby uložili a automaticky aplikovali vaše pravidlo. 3.
