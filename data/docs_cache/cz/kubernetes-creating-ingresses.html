Kubernetes Klaster: Vytváření Ingressů

Ingress je balancer zatížení Kubernetes Klastru, který spravuje vnější přístup k službám a poskytuje terminační SSL a virtuální hostování jméno-závislé. Spravuje se pomocí sad pravidel (spec), která se porovnávají s všemi příchozími požadavky. Tip: Porovnání k vystavení služby prostřednictvím NodePort je možné použít ingress, ale je to silnější, ale také složitější možnost. Nejvíce se hodí k tomu, aby se představily více služeb pod stejnou IP adresou. Další věc, kterou ingressy poskytují, je správa pomocí kontroléru, který poskytuje mnoho funkcí zásadní (SSL, auth, routing, atd.) zásadní. V Kubernetes Klastru se ingressy spravují kontrolérem ingress Traefik výchozím způsobem, s možnostmi HAProxy a NGINX dostupnými v následující verzi balíčku 1.15.5. Sleduje objekty, parsuje specy/annotace a překládá je na pravidla přesměrování. Pozor: Není možné změnit vybraného kontroléru ingress pomocí doplňku správy Kubernetes nebo nějaké jiné automatizační nástroje po instalaci. Operace můžete provést ručně, kontaktujte prosím podporu, pokud potřebujete pomoc. Spec ingressu je kombinací pravidla cesty, služby back-end a port. Například vaši ingress může vypadat následovně:

  1. apiVersion: extensions/v1beta1
  1. kind: Ingress
  1. metadata:

labels:
app: myapp
name: myapp
  1. annotations:

kubernetes.io/ingress.class: traefik
ingress.kubernetes.io/secure-backends: "true"
traefik.frontend.rule.

V tomto příkladu je spec ingressu kombinací pravidla cesty, služby back-end a portu. V tomto příkladu je spec ingressu pro službu s názvem myapp.

1. API verze: extensions/v1beta1
Typ: Ingress
Metadata:
Vlastnosti:
app: myapp
název: myapp
Značky:
kubernetes.io/ingress.class: traefik
ingress.kubernetes.io/secure-backends: "true"
traefik.frontend.rule.type: PathPrefixStrip
Spec:
Pravidla:
- http:
Cesty:
- cesta: /myapp
Zadání:
služba: myapp
port: 8080

Tento příklad vystavuje službu myapp, která je vázána na port 8080 na cestě vašeho prostředí Kubernetes v doméně výchozího typu s příponou /myapp (tedy např. https://${envName}.${platformDomain.com}/myapp).
