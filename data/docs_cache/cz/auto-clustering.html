Nastavení Auto-Klusteringu s Cloud Scripting

Chcete-li definovat nastavení auto-klusteringu ve svých řešeních JPS, můžete použít novou vlastnost clusteru. Například:

  1. Povolit nebo zakázat auto-klustering pro konkrétní vrstvu.

1 2 "nodeGroup": "couchbase", "cluster": true | false
  1. Další parametry pro auto-klustering mohou být poskytnuty následovně (například mohou být požadovány k vybrání databázového clusterového schématu):

1 2 3 4 "nodeGroup": "mysql", "cluster": { "scheme": "master" }
  1. Pokud to potřebujete, můžete nahradit výchozí manifest JPS s kroky klusteringem vlastním:

1 2 3 4 5 6 7 "nodeGroup": "mysql", "cluster": { "jps": "http://.../custom-manifest.jps", "settings": { "scheme": "master" } }
  1. Podle konkrétních požadavků na cluster mohou být nutné určité omezení topologie (například mohou být nutné pro vytvoření clusteru s více vrstvami):

1 2 3 4 5 6 7 8 "nodeGroup": "mysql", "cluster": { "jps": "http://.../custom-manifest.jps", "settings": { "scheme": "master", "multiLayer": true } }

"nastavení": { "schéma": "master" } }

  1. V závislosti na požadavcích konkrétního clusteru mohou být nutné určité omezení topologie (například minimální/maximální počet uzlů, režim škálování atd.).
