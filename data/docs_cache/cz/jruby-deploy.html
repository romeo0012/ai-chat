Jak nasadit JRuby
JRuby je implementací Ruby programovacího jazyka v Java. Umožňuje vložení interpretru do jakékoliv Java aplikace s plným, dvoustranným přístupem mezi Java a Ruby kódem. Pokud jste Ruby vývojář a chcete nasadit svou aplikaci do cloudu, PaaS je nejlepší cestou. Je snadné a rychlé. Chcete-li vidět, jak snadné je, následujte následující kroky: Vytvořte aplikaci 1. Nejdřív musíte nainstalovat JVM pro vaši operační systém. 2. Přejděte na [www.jruby.org](http://www.jruby.org) a stáhněte si nejnovější verzi JRuby vydání (podporuje se JVM-based languages). Nezabývajte se toho: je to Ruby pro JVM a nebude se žádné problémy. 3. Extrahujte soubory z archivu, který jste právě stáhli. 4. Nainstalujte Rails, otevřený zdrojový webový framework, který vám umožní psát "krásný kód tím, že preferuje konvence před konfigurací". Je to velmi snadné, prostě zadejte následující řetězce do příkazového řádku:
1 2 3 c:\cd jruby-1.6.5.1 c:\ jruby-1.6.5.1>cd bin c:\ jruby-1.6.5.1\ bin>gem install rails Gem je rozhraní příkazového řádku pro RubyGems, standardní řídicího program balíčků pro Ruby. Pomocí RubyGems můžete nainstalovat Rails a jeho závislosti prostřednictvím příkazového řádku.

  1. Nainstalujte warbler, který vám umožní vytvořit jar a war soubory z aplikace.

1 c:\jruby-1.6.5.1\bin>gem install warbler
  1. Vytvořte nový projekt v rails_projects, například app:

1 c:\rails_projects>rails new app
  1. Vytvořte své .WAR soubor s jediným příkazem warble:

1 c: rails_projects\app>warble Vytvořte prostředí 1.

1 c:\rails_projects>rails new app

  1. Vytvořte svůj soubor .WAR jednoduše pomocí jedné příkazovky warble:

1 c: rails_projects\app>warble Vytvořit prostředí
  1. Přihlaste se na dashboard platformy.
  1. Vytvořte nové prostředí.
  1. V okně Topologie prostředí vyberte svůj server aplikace (např., Tomcat 6) a zadejte jméno svého prostředí, například RubyonRails, poté klikněte na tlačítko Vytvořit.
  1. Za minutu bude vaše prostředí se Tomcatem úspěšně vytvořeno.

Nahrávejte Java Balíček
  1. Nahrávejte svůj soubor WAR do Manažera nasazení.
  1. Když balíček bude na dashboardu, nasaďte ho do prostředí, které jste právě vytvořili.
  1. Nakonec můžete otevřít svou aplikaci v prohlížeči a užít si! Co dále? Kurzy podle kategorií Java Kurzy Nastavení prostředí
