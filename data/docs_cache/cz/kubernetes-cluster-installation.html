Kubernetes Klaster: Instalace balíku
Řešení Kubernetes Klaster je k dispozici pro automatickou instalaci prostřednictvím platformy Marketplace v kategorii Klastry (nebo použijte Hledat, abyste ho nalezli). Upozornění: Tato řešení pro klastry je k dispozici pouze pro zákazníky s placením. V otevřeném rámci instalace upravte dostupné možnosti, abyste získali klastr, který vám odpovídá: Verze - vyberte verzi Kubernetes pro váš klaster K8s Dashboard - vyberte mezi možnostmi v2 a Skooner (pozor, některé metriky v dashboardu Skooner nefungují s ingres kontrolérem HAProxy) TopologieRozvoj - jeden instanci správce (1) a jeden škálovatelný pracovník (1+) Produkce - více instancí správce (3) s balancery API (2+) a škálovatelnými pracovníky (2+)
Poznámka: Topologie rozvoje není doporučována pro projekty produkce, protože nemůže spolehlivě zpracovat vysokou zátěž díky jediné instanci správce.
Ingress Controller - vyberte preferovaný ingres controller pro váš klaster (NGINX, Traefik, nebo HAProxy).

Přejít na jeden instanci správce kontroleru. Kontrolér vstupu - vyberte preferovaný kontrolér vstupu pro vaši cluster (NGINX, Traefik, nebo HAProxy). Doporučujeme použití NGINX, protože poskytuje největší flexibilitu Nasazení čistého clusteru s přednasazeným příkladem HelloWorld Pomocí Helmu či nasazením pomocí příkazu shell - vyberte tuto možnost, pokud chcete ručně poskytnout příkazy pro nasazení vlastní aplikace z repozitáře Helmu NFS Uložiště - povolte, aby bylo možné připojit věcnou NFS Uložiště s dynamickou zásobováním objemů (zakázat, pokud chcete registrovat vlastní třídu uložiště, požaduje zásah do K8s) Moduly (mohou být povoleny později pomocí doplňků)Prometheus & Grafana - zkontrolujte, aby byly tyto nástroje pro monitorování nainstalovány (povoleno). Tato instalace vyžaduje přidat dalších 5GB diskového prostoru pro trvalé objemy a spotřebuje asi 500 MB RAM Jaeger Tracing Tools - zvěčněte, aby byly nainstalovány nástroje pro sledování a řešení problémů Jaeger Tracing System pro monitorování a řešení problémů Remote API Access - zkontrolujte, pokud plánujete používat nástroj kubectl příkazového řádku nebo nějaké jiné vzdálené klienty Prostředí - poskytněte název pro vaše prostředí Zobrazovací jméno - určete alias Region - vyberte region (pokud je k dispozici) Kliknutím na Instalovat a počkejte několik minut na to, aby se platforma automaticky konfigurovala vaši Kubernetes cluster.
