PHP Composer pro správné řízení závislostí vašich cloudových aplikací
Composer je jedním z nejpopulárnějších nástrojů pro řízení závislostí v PHP, inspirovaných npm pro Node.js a bundlerem pro Ruby. Tento nástroj vám umožní inteligentně spravovat všechny potřebné knihovny a balíčky pro vaši aplikaci. Běží na úrovni jednotlivých projektů a určuje, které verze kterých balíčků vaše aplikace závisí a instaluje je do pracovního adresáře. Dalším výhodným vlastností je autoload, který vám umožní udržovat balíčky aktuální. Tento nástroj je v integrální součásti všech serverů PHP (Apache, NGINX, LiteSpeed, LEMP a LSSMP) a je instalován do adresáře /usr/local/bin, který je přidán do proměnné PATH, což znamená, že Composer je operovatelný z libovolného místa na uzlu prostřednictvím komandového příkazu composer (např. composer about). Pokud má vaše aplikace soubor composer.json, Composer může spravovat závislosti přímo během instalace pomocí skriptu Post-Deploy hook. Všechno, co musíte udělat, je přesunout se do adresáře svého projektu a spustit příkaz composer install:
1 2
cd $WEBROOT/{project_name}
composer install

Není nutné vytvořit celý kontejner znovu. Následující kroky vám pomůžou nainstalovat nejnovější verzi Composer do svého PHP kontejneru:

  1. Připojte se k vhodnému uzlu pomocí SSH. Například pomocí vbudovaného Web SSH.
  1. Stáhněte si instalační skript Composer pomocí následujícího příkazu:

1 php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
  1. Nainstalujte Composer do aktuálního adresáře.

1 php composer-setup.php --install-dir=./ --filename=composer
Doporučení: Pokud je nutné, můžete se přesunout do požadovaného adresáře před operací nebo upravit cestu pomocí parametru install-dir. Však není možné nainstalovat do adresáře /usr/local/bin/ s prvním instancem Composer.
  1. Nyní spusťte tuto místní verzi Composer (tedy pomocí relativní nebo absolutní cesty) k ověření, že funguje správně. Například:

1 ./composer about
Doporučení: Pokud funguje správně správce závislostí, doporučujeme odstranit instalační skript (protože již není potřeba).
1 php -r "unlink('composer-setup.php');"
