Bezpečnostní nastavení PHP.INI

Existují několik funkcí PHP, které je doporučeno správně konfigurovat, aby ochránily vaši server před škodou. Zřejmě celkové zajištění systému může být poměrně složité a vyžadovat mnoho specifických nástrojů, ale v tomto kurzu se budeme zabývat základními kroky, které nevyžadují žádné další výdaje. Takže, nechte se nám ukázat, jak provedeme některé počáteční konfigurace, aby zlepšily bezpečnost vašeho PHP aplikace, hostované na platformě. Hlavní PHP konfigurační soubor, nazvaný php.ini, obsahuje řadu výchozích nastavení, která můžete upravit, nebo dokonce přidat vlastní podle potřeby vaší aplikace. Nachází se v adresáři etc vašeho Apache nebo NGINX-PHP aplikačního serveru. Tento soubor je plně upravitelný pro vás zákazníka platformy, takže nechte se nám podívat, která nastavení můžete aplikovat, aby zlepšila bezpečnost vašeho serveru. Poznamenejte si, že hodnoty popsané níže jsou pouze doporučení. Než je aplikujete, ujistěte se, že požadavky vaší aplikace se shodují s těmito nastaveními, aby nezmenšila její výkonnost. Stiskněte tlačítko Konfigurace pro svůj Apache nebo NGINX server. V otevřeném okně přejděte do adresáře etc a otevřete soubor php.ini. Následující instrukce vám pomůžou provedení potřebných konfigurací:

  1. Tlačítko pro vaši Apache nebo NGINX server. Ve vytvořeném panelu přejděte do adresáře etc a otevřete soubor php.ini. Následující instrukce vám pomůžou provedení potřebných nastavení:
  1. Přidejte následující řetězec k deaktivaci nebezpečných funkcí:
disable_functions = phpinfo, system, mail, exec

Další bezpečnost můžete získat deaktivací následujících funkcí: 
disable_functions = exec,passthru,shell_exec,system,proc_open,popen,curl_exec,curl_multi_exec,parse_ini_file,show_source
  1. Omezte počet povolených zdrojů, pokud to přijme vaše aplikace:
  • Maximální doba spouštění skriptu (v sekundách) max_execution_time = 30
  • Maximální doba zpracování dat požadavku každým skriptem max_input_time = 60
  • Maximální velikost nahrávaného souboru upload_max_filesize = 2M
  • Maximální množství paměti pro skript (8MB) memory_limit = 8M (výchozí hodnota je 128M, ale je přijatelné nastavit nižší hodnotu, pokud to nezhorší výkon vaší aplikace)
  • Maximální velikost POST dat, přijatelná pro PHP post_max_size = 8M

Překlad:

  1. Hodnota je 128M, ale je přijatelné nastavit nižší hodnotu, pokud to nezpomalí výkon vašeho aplikace. Maximální velikost POST dat, přijatelná pro PHP, je post_max_size = 8M
  1. Níže uvedené funkce mohou být omezeny v případě, že nejsou pro vaši aplikaci potřebné:

Zakázat HTTP file uploads: file_uploads = Off
Zakázat zobrazování PHP chybových zpráv pro uživatele: display_errors = Off
Omezit externí přístup k vašemu PHP prostředí: safe_mode_allowed_env_vars = PHP_
Omezit vracení PHP informací: expose_php = Off
Zakázat registraci globálních proměnných pro vstupní data: register_globals = Off
Zakázat otevírání vzdálených souborů: allow_url_fopen = Off
  1. Chcete-li získat více informací o stavu bezpečnosti, zapněte následující funkce:

Ujistěte se o přijatelnosti PHP přesměrování: cgi.force_redirect = 0
Zapněte všechny možné záznamy chyb: log_errors = On
  1. Zapněte k dispozici dostupné bezpečnostní režimy:

Zapněte bezpečnostní režim: safe_mode = On
Zapněte SQL bezpečnostní režim: sql.safe_mode = On
Poznámka: Při nastavování uvedených nastavení se musíte věnovat požadavkům vaší aplikace, v některých případech mohou být některé funkce nek dispozici. Co dál? Konfigurace PHP Application Server
