Apache
Zpracování dynamických požadavků v Apache PHP je implementováno pomocí modulu prefork Multi-Processing Module (MPM), který pomáhá odhalit plnou potenciál serveru. Direktivy MPM jsou uvedeny v hlavním Apache konfiguračním souboru /etc/httpd/conf/httpd.conf. Níže je kompletní seznam parametrů, které platforma konfiguruje pro modul prefork:
StartServers - nastaví počet dítěcích procesů serveru vytvořených při spuštění.
MinSpareServers (MaxSpareServers) - definuje minimální (maximální) počet dítěcích procesů, které se udržují ve stavu volného.
ServerLimit - nastaví nejvyšší povolenou hodnotu pro příkaz MaxRequestWorkers.
MaxRequestWorkers - konfiguruje limit počtu současných požadavků, které se mohou zpracovávat.
MaxConnectionsPerChild - definuje počet požadavků, které může sloužit jeden dítěcí proces.

Ujistěte se, že je dostatek RAM. Správu zpracování PHPRequestů v aplikaci serveru NGINX PHP řídí Správce procesů FastCGI (FPM), který můžete konfigurovat pomocí souboru /etc/php-fpm.conf. Tento soubor je automaticky přidán do oblíbeného seznamu v manažeru souborů kontejneru pro rychlý přístup: FPM pracuje v režimu ondemand (přímořím) a vytváří nové procesy, když to potřebuje (tedy na požadavek) a odstraňuje nečinné. Jediné další parametry pro tento režim jsou:

  • pm.max_children - definuje maximální počet dítěcích procesů (rovná se počtu dostupných jádra pro kontejner, ale nejméně 2)
    Tip: Hodnota je přesně určena kapacitou CPU poskytovanou vaším konkrétním poskytovatelem hostingu a počtem alokovaných cloudletů pro kontejner. Tímto způsobem se zvětšení počtu cloudletů vede k automatickému zvětšení parametru pm.max_children. Tento příkaz můžete definovat explicitně bez zakázání automatické optimalizace prostřednictvím vhodné proměnné PHPFPM_MAX_CHILDREN.
  • pm.process_idle_timeout - nastavuje zpoždění před zabitím nečinného procesu (60 sekund)
