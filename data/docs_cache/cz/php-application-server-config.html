Konfigurace PHP Aplikace Serveru

Pro provedení potřebných konfigurací stiskněte tlačítko Config u vašeho aplikace serveru. V případě, že máte více aplikace serverů, můžete je konfigurovat společně nebo samostatně. K tomu následují kroky:

  1. Otevřete rozevírací seznam v horní části karty konfigurace. Zobrazí se zde seznam všech aplikace serverů v vašem prostředí.
  1. Vyberte ten, který potřebujete a provedete konfiguraci.
  1. Chcete-li uložit změny: pro zvolený server stiskněte tlačítko Uložit pouze pro aktuální instance z rozevíracího seznamu; pro všechny servery stiskněte tlačítko Uložit pro všechny instance. Poznámka: pokud vytvoříte/přejmenujete soubor nebo složku v Konfiguračním manažeru, tyto změny se uplatní pouze v seznamu zvoleného uzlu. Tato změna nelze uložit pro všechny aplikace servery v prostředí. Pokud chcete také vytvořit/přejmenovat soubor nebo složku na ostatních serverych, musíte to provést ručně. Níže naleznete seznam konfiguračních souborů dostupných ke změně v PHP aplikace serverech:

Apache Složka Soubor Cesta k souboru
etc php.ini /etc conf.d modules.conf aliases.conf geoip.conf mod_security.conf php.conf ssl.conf welcome.conf /etc/httpd/conf.d/ conf httpd.conf /etc/httpd/conf/ webroot /var/www/webroot cron apache /var/spool/cron keys /var/lib/jelastic/keys modules /usr/lib64/php/modules
NGINX-PHP Složka Soubor Cesta k souboru
etc php-fpm.conf php.ini /etc conf.d virtual.conf ssl.conf /etc/nginx/conf.d conf nginx.conf

Apache klíčové složky se nacházejí v adresáři /var/spool/cron a v adresáři /var/lib/jelastic/keys, moduly PHP se nacházejí v adresáři /usr/lib64/php/modules. NGINX-PHP adresář, souborová cesta atd. php-fpm.conf, php.ini se nacházejí v adresáři /etc/conf.d. Další soubory, jako je virtual.conf, ssl.conf, se nacházejí v adresáři /etc/nginx/conf.d. Konfigurační soubor nginxu se nazývá nginx.conf a nachází se v adresáři /etc. Webový kořen je umístěn v adresáři /var/www/webroot.

Kliknutím na odkazy získáte další informace o nastaveních, která mohou být upravována v příslušných adresářích. ETC

Hlavní konfigurace serveru PHP se provádí v souboru php.ini, který se nachází v adresáři etc. Například zde můžete nastavit: PHP Extensions, PHP Accelerators, Uložení PHP sesíí v Memcached. PHP.INI Bezpečnostní Nastavení

Apache

Pro aplikaci serveru Apache je hlavním konfiguračním souborem httpd.conf, který se nachází v adresáři conf. Pomocí něj můžete provést následující akce:

nastavit více domén
povolit vlastní Apache moduly
použít WebDav modul
vykonat potřebné bezpečnostní nastavení
nastavit jméno-závislou virtuální hostitelství
povolit modul pro zobrazení statistik serveru

Varování: K provedení jakýchkoli vlastních konfigurací v souboru httpd.conf je třeba odstranit řetězec #Jelastic autoconfiguration mark z počátku souboru.

Počet pracovníků pro zpracování PHP žádostí se automaticky zvyšuje v Apache serveru podle množství cloudletů, které jste pro něho určili. Chcete-li to ověřit, najděte a uložte si hodnotu MaxClients v souboru httpd.conf.

PHP požadavky se automaticky zvětšují v Apache serveru v závislosti na počtu cloudletů, které jste určili pro ně. Chcete-li to ověřit, najděte a uložte si hodnotu MaxClients v souboru httpd.conf. Poté změňte topologii svého prostředí zvětšením nebo snížením limitu cloudletů pro vaši server. Vracíte se zpět do souboru httpd.conf - po změně se číslo MaxClients zvětšilo/zmenšilo. Poznámka: Tato funkce bude zakázána, pokud odstraníte řádek s označením Jelastic autoconfiguration mark string na začátku souboru httpd.conf.

NGINX Pro provedení nutných konfigurací pro NGINX-PHP server se používá soubor nginx.conf, nacházející se v adresáři conf. Použijte ho k nastavení následujících konfigurací:

  • Nastavení více domén
  • Použití modulu WebDav
  • Provedení nutných zabezpečovacích konfigurací

Zpět na seznam

CONF.D Adresář conf.d se používá pro ukládání a správu subkonfigurací.

Zpět na seznam

WEBROOT Adresář webroot se používá pro ukládání nezapackovaného aplikace nasazené do prostředí.

Zpět na seznam

CRON Servery app zahrnují adresář cron s konfiguračním souborem, kde mohou být konfigurovány cronjobs. Další informace o konfiguraci cronjobů naleznete v dokumentu Setting Up a Cronjob.

Zpět na seznam

KEYS Adresář keys se používá jako umístění pro nahrání libovolného soukromého klíče, který je potřebný pro vaši aplikaci. Vytvořte klíč, uložte ho jako jednoduchý soubor a nahrávejte ho do adresáře keys.

Nyní můžete s ním pracovat v různých případech, použitím cesty k vašemu klíči: /var/lib/jelastic/keys/{key_file_name}

Zpět na seznam

MODULES Adresář modules obsahuje PHP moduly, které jsou dostupné na platformě vůbec. Můžete také nahrát své vlastní PHP moduly do tohoto adresáře, aby je aktivovali. Další informace naleznete v dokumentu PHP Modules.
