NGINX PHP

NGINX PHP je open-source web server, který spolupracuje s PHP. Je určen pro rychlé a efektivní službu webových stránek.

NGINX Security Configurations

Zpevnění bezpečnosti NGINX je důležité pro ochranu serveru před útoky. Následující konfigurace poskytují základní zpevnění pro NGINX server.

  • Zakázání direktiv allow a deny v oddílu http
  • Použití server_tokens off pro zakázání zobrazení verze serveru
  • Použití server_names_hash_bucket_size pro optimalizaci zpracování názvů serveru
  • Použití server_names_hash_max_size pro omezení počtu názvů serveru
  • Použití ssl_certificate a ssl_certificate_key pro zabezpečení SSL
  • Použití access_log pro záznam přístupu
  • Použití error_log pro záznam chyb

NGINX Modules

NGINX moduly poskytují rozšíření funkčnosti serveru. Následující moduly jsou k dispozici pro NGINX:

  • http_auth_basic_module pro základní autentizaci
  • http_auth_digest_module pro zabezpečenou autentizaci
  • http_gzip_module pro kompresi odpovědí
  • http_realip_module pro zjišťování IP adresy klienta
  • http_rewrite_module pro přesměrování adres
  • http_ssl_module pro podporu SSL
  • http_sub_module pro podporu podmnožin URL
  • http_upstream_module pro distribuci zatížení

NGINX WebDav Module

NGINX WebDAV module umožňuje klientům ovládat soubory na serveru pomocí WebDAV protokolu. Následující konfigurace poskytují základní konfiguraci pro WebDAV module:

  • Použití listen pro určení portu pro WebDAV
  • Použití location pro určení adresy pro WebDAV
  • Použití auth_basic pro základní autentizaci
  • Použití auth_pam pro autentizaci pomocí PAM
  • Použití limit_rate pro omezení rychlosti přenosu souborů
  • Použití if_modified_since pro kontrolu verze souboru
  • Použití if_none_match pro kontrolu verze souboru
