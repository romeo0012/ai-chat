Apache PHP Platform přizpůsobuje silnou, komerční a otevřenou verzi Apache HTTP Server ("httpd") k vytvoření bezpečného, efektivního a škálovatelného serveru pro hostování PHP. Stack Apache PHP platformy poskytuje zásadní podporu jazyka PHP a protokolu HTTP/2 (je nutné SSL) díky použití modulů php7_module a http2_module. Poznámky: Tato šablona využívá moderní daemon inicializace systemd. Seznam všech modulů na serveru můžete zobrazit pomocí příkazu apachectl -M nebo na výchozí stránce phpinfo. Chcete-li získat svůj Apache PHP server, následujte níže uvedené kroky:

  1. Přihlaste se k svému PaaS účtu a klikněte na New Environment v horní části.
  1. V otevřeném topologickém vizualizátoru přepněte na kartu PHP a vyberte Apache jako svůj server aplikace. Nastavte ostatní konfigurace podle svých potřeb (např., limit cloudletů, veřejné IP adresy, oblast, atd.). Zadejte jméno svého prostředí a klikněte na Create.
  1. Po vytvoření prostředí můžete kliknutím na tlačítko Open in Browser vedle Apache application server otevřít.
  1. Na otevřené výchozí stránce zobrazíte informace o vašem serveru phpinfo. Nyní můžete svou PHP aplikaci nasadit do prostředí.

Konfigurace Apache
Apache PHP má několik hlavních konfiguračních souborů, které můžete upravit k přizpůsobení svého serveru aplikace podle svých specifických potřeb:

/etc/php.ini - obsahuje direktivy, které konfigurují vaši PHP nastavení
/etc/httpd/conf.d/php.ini - obsahuje konfiguraci Apache pro PHP

Chcete si přizpůsobit vaši aplikační server k vašim konkrétním potřebám: /etc/php.ini - obsahuje direktivy, které konfigurují vaši nastavení PHP /etc/httpd/conf.d/php.conf - konfiguruje provádění skriptů PHP /etc/httpd/conf/httpd.conf - obsahuje direktivy, které konfigurují vaši Apache server

Konkrétním příkladem bude ukázání, jak změnit velikost souborů, které mohou být nahrány do vaší aplikace.

  1. Kliknutím na tlačítko Config pro vaši Apache server přistupujete k správci konfiguračních souborů:
  1. Otevřete soubor /etc/php.ini (dostupný prostřednictvím zkratky Oblíbené) a vyhledejte následující parametry:

- upload_max_filesize - maximální velikost souborů, které mohou být nahrány na server (100MB vůbec)
- post_max_size - maximální velikost dat POST, která přijme PHP (100MB vůbec)

Poznámka: Tyto nastavení neovlivňují maximální velikost souboru, který může být nahrán prostřednictvím platformního manažera souborů z lokálního počítače. Maximální velikost souboru, který může být nahrán, je 150MB (může se lišit podle nastavení poskytovatele služeb). Pro operaci větších souborů použijte možnost URL nebo připojte veřejný IP a použijte vlastní manažer (např. přídavný modul FTP).

  1. Nezapomeňte Uložit změny a Restartovat uzly vašeho aplikačního serveru, aby se nová nastavení aplikovala. Pro podrobnější informace o konfiguraci serveru PHP se přejděte na odpovídající návody: PHP Dev Center PHP.INI Security Settings PHP Extensions PHP Accelerators PHP Auto Configurations
