Příprava Java Opcí a Argumentů

Chcete-li zajistit efektivitu nákladů, jsou všechny Java servery spravované platformou automaticky konfigurovány tak, aby se využívala paměť v nejvýhodnější možné míře. Toto se dosahuje upravováním hlavních parametrů Java paměti na základě prostředků přidělených kontejneru. Tip: Vlastní Java servery (například uvnitř kontejnerů Docker nebo VPS) mohou být optimizovány podobně pomocí přídavku Java Memory Agent. Výchozí možnosti mohou být ručně upraveny, aby se zajistila vysoká výkonnost nebo podpora jakékoliv vlastní implementace.

  1. Chcete-li poskytnout všechny preferované možnosti Java v jednom kroku, můžete se využít souboru variables.conf. V závislosti na konkrétním serveru aplikace, kterou pracujete, může se umístění tohoto souboru lišit: Tomcat, TomEE - /opt/tomcat/conf/variables.conf Jetty - /opt/jetty/etc/variables.conf Spring Boot - /opt/shared/conf/variables.conf GlassFish - /opt/glassfish/glassfish/domains/domain1/config/variables.conf Payara - /opt/payara/glassfish/domains/domain1/config/variables.conf WildFly - /opt/wildfly/conf/variables.conf Pokud je třeba, můžete přepsat hlavní možnosti paměti prostřednictvím proměnných kontejneru.
  1. Nezapomeňte na restartování uzlů, aby se změny uplatnily. Tak je to! Nyní běží vaše aplikace s vašimi vlastními možnostmi Java. -XX:MaxPermSize, *-XX:+Use.GC) mohou být předeffenovány pomocí věcných proměnných prostředí. Například můžete přidat možnost -Xmx (tj., maximální velikost pro paměť Java heap): Tip: Platforma podporuje dvě další proměnné, které umožňují nastavit hlavní parametry RAM jako procento celkové dostupné paměti: XMS_DEF_PERCENT - počáteční velikost (%) alokace paměťového poolu XMX_DEF_PERCENT - maximální velikost (%) alokace paměťového poolu Tyto hodnoty se automaticky ověřují - pokud XMS je větší než XMX, jeho skutečná hodnota je nastavena na XMX. Při práci s šablonami Spring Boot a Java Engine můžete poskytnout dvě další proměnné: JAVA_OPTS - k přizpůsobení možností Java pro vaši aplikaci (podobně jako soubor variables.conf) JAVA_ARGS - k přenosu nějakých vlastních argumentů do hlavní funkce vaší aplikace Nezapomeňte na restartování svého serveru aplikace(ů), aby se změny vztahovaly.
