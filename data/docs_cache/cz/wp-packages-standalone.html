WordPress Samostatný Balíček

WordPress Samostatný balíček je automatizovaný řešení pro efektivní instalaci WordPressu do jednoho lehkého kontejneru pro běh malých a středních projektů. Balíček provede všechny potřebné konfigurace, což vám umožní se soustředit na svůj projekt místo toho, že byste strávili čas správou serveru. Podle vašich preferencí můžete vybrat mezi šablonami LLSMP (Linux + LiteSpeed + MariaDB + PHP) nebo LEMP (Linux + NGINX + MariaDB + PHP). Vaše WordPress samostatný kontejner automaticky spustí následující komponenty: PHP-bázovaný aplikační server (nebo LiteSpeed nebo NGINX) databázi MariaDB server Redis vysokorychlostní RAM-přidělenou datovou strukturu další funkce mohou být povoleny prostřednictvím pokročilých nastavení.

Instalace WordPressu Samostatného Balíčku

Chcete-li instalovat WordPress Samostatný balíček, proveďte následující kroky:

  1. Klikněte na tlačítko Marketplace na vrcholu správce aplikací Virtuozzo.
  1. Použijte vyhledávací pole, abyste nalezli balíček WordPress Standalone Kit a klikněte na Install.
  1. 1. Klikněte na tlačítko Marketplace v horní části správy aplikací Virtuozzo.
  1. Využijte vyhledávač pro hledání balíčku WordPress Standalone Kit a klikněte na Install.
  1. V otevřeném okně instalace nastavte si WordPress standalone aplikaci vybráním potřebných možností: zvolte verzi PHP, zvolte LiteSpeed High-Performance Web Server místo výchozího NGINX web serveru, povolte Brute Force Attack Protection a Web Application Firewall funkce pro LiteSpeed, instalujte Let’s Encrypt SSL s Auto-Renewal přídavnou funkcí pro vydání automaticky platného SSL certifikátu, nakonfigurujte WordPress Multisite Network a přidajte WooCommerce addon pro WordPress, nakonec zadejte název prostředí a zvolte dostupnou oblast (pokud je dostupná), a klikněte na Install.
  1. WordPress Standalone prostředí bude automaticky vytvořeno a nakonfigurováno podle zvolených možností za několik minut. Všechno!
