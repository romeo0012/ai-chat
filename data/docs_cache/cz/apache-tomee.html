Apache TomEE

Apache TomEE je Java server připravený pro podnikové použití, vytvořený na základě Apache Tomcat s implementací funkcí MicroProfile a Jakarta EE. Porovnání podporované funkce je k dispozici na stránce dokumentace. Platforma poskytuje čtyři různé distribuce TomEE: WebProfile - poskytuje Jakarta EE implementaci, včetně Servletů, JSP, JSF, JTA, JPA, CDI, Bean Validation a EJB Lite MicroProfile - rozšiřuje možnosti WebProfile o plnou podporu MicroProfile Plus - obsahuje všechny technologie v MicroProfile s přidáním JAX-WS, JEE Connectorů a JMS PluME - podporuje vše, co je v profilu Plus, včetně Eclipse Mojarra a EclipseLink (tato distribuce je potřebná pro organizace, které migrují z Eclipse Glassfish na projekt Apache TomEE)

Poznámka: Tento šablon používá moderní daemon systému systemd pro inicializaci. Server aplikace TomEE běží bez žádných dalších požadavků na běhový prostředí nebo zahájení pro větší aplikace a je kompatibilní s většinou nástrojů Tomcat-vědomých a Tomcat-testovaných. Níže popisujeme, jak spustit Apache TomEE na platformě.

  1. Přihlaste se k dashboardu PaaS a klikněte na tlačítko New Environment.
  1. V dialogu topologie wizard vyberte TomEE jako svůj server aplikace (na kartě Java). Pokud je nutné, nastavte škálování uzlů (vertikální a horizontální), veřejné IP adresy, název prostředí atd. Klikněte na Create, když jste připraveni.

Český překlad:

  1. Kliknutím na kartu Java). Pokud je nutné, nastavte škálování uzlu (vertikální a horizontální), veřejné IP adresy, název prostředí apod. Kliknutím na Tvořit se připravíte. Tip: Platforma poskytuje možnost jednoklikové automatické klasifikace, která automaticky konfiguruje vysokojícivou TomEE klastr. Výsledkem je hotový Java klastr s měnitelným počtem připojených TomEE serverů s přednastavenou replikací relací a balancováním zatížení.
  1. V novém prostředí s Apache TomEE Java aplikační serverem se vytvoří za minutu. Kliknutím na tlačítko Otevřít v prohlížeči můžete přistoupit k výchozí stránce serveru. Nyní můžete pokračovat v nasazování aplikace. Tip: Tomcat a TomEE servery jsou poskytovány s speciální proměnnou HOT_DEPLOY (ne nastavenou vzhledem k výchozímu nastavení), která definuje, zda server by měl být obnoven (false, zakázáno, 0) nebo ne (true, povoleno, 1) během nasazování aplikace. Hot deploy (beze restartu) je rychlejší a umožňuje vyhnout se zastavení během procesu nasazování. Nicméně není podporováno některými aplikacemi a tak je vypnuté výchozí nastavení. Co dál?
