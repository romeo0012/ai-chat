Java Engine Server
Java Engine software stack je obraz základního šablonu CentOS/AlmaLinux s předinstalovaným JDK. Poskytuje minimální požadavky pro hostování Java aplikací, zatímco zajišťuje kompatibilitu s všemi platformními funkcemi (automatizované vertikální a horizontální škálování, veřejný IP, izolační skupiny, pravidla firewallu, přístup API a SSH, atd.). Java Engine je navržen pro nasazení a hostování Java aplikací na základě tlustého JAR / uber JAR (tedy spustitelný JAR s všemi třídami, zdroji a závislostmi). Využívá Java Memory Agent k automatickému optimizování vaší aplikace tunováním konfigurací podle nápory a dostupných zdrojů. Poznámka: Tato šablona používá moderní daemon systemd pro inicializaci systému. Vytvoření Java Engine
Následující jednoduché kroky vám pomůžou vytvořit nový prostředí s serverem Java Engine.

  1. Přihlaste se k panelu správy platformy a klikněte na tlačítko New Environment v horní levé části.
  1. Ve vytvořeném topologickém vizualizátoru přepněte na kartu Java, vyberte server Java Engine a požadovanou verzi JDK (označené v následujícím obrázku). Můžete upravit libovolný další parametr podle potřeby, například limity zdrojů, diskový prostor, externí IP, oblast (pokud je k dispozici), atd. Klikněte na Create, aby se proces vytváření prostředí spustil.
  1. Vaše prostředí by mělo být hotovo za minutu.
