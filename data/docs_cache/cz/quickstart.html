Rychlý start
Tato sekce vysvětluje, jak začít s Virtuozzo Application Management a rychle se orientovat v hlavních zdrojích platformy. Obsahuje přehled platformy, první nastavení účtu, vítězný kurz pro nasazení své první aplikace, a praktickou použití panelu pro správu prostředí. Tato sekce také zahrnuje odkazy na dostupné poskytovatele hostingu, podporované verze software stacku a poznámky k aktualizacím platformy. V této sekci: Co je Application Management? Potřebujete účet na platformě a přístup k panelu dashboardu poskytovatele hostingu. Odkazujte se na průvodce Rychlý start pro podrobnosti. Jak rychle mohu spustit první prostředí? Většina prostředí může být vytvořena a nasazena za několik minut. Kde začít jako nový uživatel? Začněte s průvodcem Příručka pro nové uživatele pro krok za krokem vstup do prostředí. Odkazujte se na Průvodce panelem pro podrobnější přehled platformového rozhraní. Je dostupný testovací účet? Mnoho poskytovatelů nabízí testovací účty s omezenými zdroji; dostupnost se liší. Kde mohu zkontrolovat podporované verze stacku? Viz stránku Software Stack Versions pro aktuální seznam.
