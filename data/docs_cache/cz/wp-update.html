WordPress Update Guide
Aktualizace WordPressu je důležitou součástí správy bezpečnosti a výkonu vašeho webu. Pravidelné aktualizace zajistí, že máte nejnovější funkce, opravy chyb a bezpečnostní patchy. Tento průvodce vás provede procesem aktualizace vaší instalace WordPressu: Poznámka: Doporučujeme, abyste před provedením jakékoliv změn, včetně aktualizací, zabezpečili zálohu svého webu WordPressu. Tím se zajistí, že můžete svůj web vrátil do předchozího stavu v případě, že se něco při procesu aktualizace pokazí.

  1. WordPress software updates (jádro, témy a pluginy) mohou být provedeny z WordPress admin panelu. Pokud jsou k dispozici jakékoliv aktualizace, zobrazí se vám upozornění v WordPress admin panelu. Aktualizaci jádra WordPressu můžete provést přejít na Dashboard > Aktualizace a kliknutím na tlačítko Update to version X.X.X.
  1. Pluginy a témy mohou být aktualizovány z stejné stránky. Protože si vyberete ty, které chcete aktualizovat, a kliknutím na tlačítko Update Plugins nebo Update Themes.
  1. K aktualizaci serverových komponent, na kterých běží vaše WordPress, (application server, databáze, atd.) najděte potřebnou v dashboardu Virtuozzo Application Management a kliknutím na tlačítko Redeploy. Tím otevřete okno pro přehrávač, kde můžete vybrat nejnovější verzi serveru, včetně verze PHP pro application server: Tip: Při přehrávači skalovaných komponent WordPressu můžete zabránit výpadku tím, že vyberete možnost sequential deployment.

server: Tip: Při přehrávači skalovaných komponent WordPressu můžete zabránit výpadku tím, že vyberete možnost sequential deployment. Tím se zajistí, že se instance aktualizují po sobě, aby se vaše webová stránka WordPress zůstala dostupná během procesu aktualizace. Kliknutím na tlačítko Redeploy nebude ovlivnit vaše data WordPressu, protože bude aktualizovat pouze software serveru.
