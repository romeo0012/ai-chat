.NET Core Aplikace server .NET Core je otevřený zdrojový, křížový platformní verze .NET pro vytváření webových stránek, služeb a konzolových aplikací. Často se používá pro cloudové aplikace nebo převod velkých podnikových aplikací do mikroslužeb. .NET Core se skládá ze následujících komponent: .NET Core runtime - poskytuje esenciální služby (systém typů, nahrávání sestav, sběrač odpadku, atd.). Knihovny rámce poskytují základní datové typy, typy složení a základní nástroje ASP.NET Core runtime - poskytuje rámec pro vytváření moderních, cloudových, internetově propojených aplikací (webové aplikace, aplikace IoT a mobilní back-endy) .NET Core SDK a jazykové kompilátory (Roslyn a F#) - umožňují vývoj .NET Core projektů dotnet příkaz - spouští aplikace .NET Core a příkazy CLI. Vybírá a hostuje runtime, poskytuje politiku nahrávání sestav a spouští aplikace a nástroje.

Poznámka: Dostupnost této stavy závisí na nastavení konkrétního poskytovatele hostování. Tento šablonu používá moderní systémd inicializační daemon.

Vytvoření .NET Core Server

  1. Přihlaste se k PaaS panelu a klikněte na tlačítko New Environment v horní levém rohu.
  1. V otevřeném topologickém vizualizátoru navigačníte k .NET kartě a vyberte .NET Core aplikace server. Nastavte ostatní parametry (cloudlety, limit disků, veřejné IP adresy, atd.) podle potřeby. Klikněte na Create, aby se proces pokračoval.
  1. Vaše prostředí s .NET Core serverem bude vytvořeno za několik minut.

Parametry (cloudlety, diskový limit, veřejné IP adresy, atd.) podle vašich potřeb. Kliknutím na Tvořit pokračujete. 3. Vaše prostředí s serverem .NET Core bude vytvořeno za několik minut. Server aplikace operuje v odděleném kontejneru (node) - izolovaném virtuálizovaném instanci - zprostředkované pro software stack. Kontejner má vlastní soukromou IP adresu a unikátní záznam DNS. Nasazování Aplikace do serveru .NET Core
Platforma poskytuje mnoho možností k automatickému nasazení projektů. V tomto příkladu přidáme jednoduché .NET projekt umístěné na GitHub. 1. Otevřete kartu Git/SVN správce nasazení, aby se přidala nová repozitář. Tip: Pokud jste zajímaví o vytvoření vlastní .NET aplikace, následujte oficiální dokumentaci. 2. Poskytněte nutné URL a větev pro vaši aplikaci. Poznámka: .NET Core podporuje několik specifických proměnných, které mohou pomoci s nasazováním aplikace: APP_NAME - ukazuje na určitou složku (pokud jsou v jednom repozitáři více aplikací) nebo spouští konkrétní .dll soubor v vašem projektu ASPNETCORE_URLS - konfiguruje služby pro práci s určenou URL RUN_OPTION - poskytuje další možnosti dotnet run pro vaši projekt Kliknutím na Uložit uložte projekt v správci nasazení. 3. Otevřete dialog nasazení pomocí jedné z dvou tlačítek na obrázku níže: 4. V otevřeném rámci potřebujete vybrat aplikaci k nasazení, větev a cílové prostředí. Poznámka: Podobně jako Python, Node.js a Go programovací jazyky, .NET podporuje stejné proměnné pro nasazování aplikace: APP_NAME - ukazuje na určitou složku (pokud jsou v jednom repozitáři více aplikací) nebo spouští konkrétní .dll soubor v vašem projektu ASPNETCORE_URLS - konfiguruje služby pro práci s určenou URL RUN_OPTION - poskytuje další možnosti dotnet run pro vaši projekt Kliknutím na Nasazit nasažete aplikaci.

V otevřeném okně si musíte vybrat aplikaci pro nasazení, větev a cílovou prostředí. Poznámka: Stejně jako Python, Node.js a Go, má .NET Core jediný kontext (tedy jedna aplikace může být nasazena najednou). Nastavte libovolné další parametry podle vašich potřeb podle návodu na nasazení. 5. Za minutu bude aplikace nasazena a může se zobrazit pomocí tlačítka Otevřít v prohlížeči vedle serveru .NET Core.
