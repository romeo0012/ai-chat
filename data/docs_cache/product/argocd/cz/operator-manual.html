Prerequisites¶

  • Kubernetes cluster with RBAC enabled
  • kubectl configured to access the cluster
  • Helm 3 installed
  • Git repository with application manifests

Installation¶

  1. Install Argo CD

   helm repo add argoproj-helm https://argoproj.github.io/helm-charts
   helm install argocd argoproj-helm/argocd
  1. Access the Argo CD web UI

   kubectl port-forward svc/argocd-server 8080:443
   open http://localhost:8080
  1. Create initial admin secret

   kubectl create secret generic argocd-initial-admin-secret --from-literal=password=YOUR_PASSWORD
  1. Login to Argo CD

Visit http://localhost:8080, enter the following credentials:

* Username: admin
* Password: YOUR_PASSWORD

After login, you will be redirected to the Argo CD dashboard.

Configuration¶

  1. Configure Argo CD to manage your application

* Import your Git repository
* Create a new application
* Configure the application to sync with your Git repository

  1. Configure Argo CD to use your Kubernetes cluster

* Update the Kubernetes configuration in Argo CD
* Configure RBAC in your Kubernetes cluster to allow Argo CD to manage your applications

  1. Configure Argo CD to use Helm

* Install the Helm custom resource definition (CRD) in your Kubernetes cluster
* Configure Argo CD to use Helm for deploying and managing your applications

  1. Configure Argo CD to use GitOps

* Enable GitOps in Argo CD
* Configure GitOps to use your Git repository for managing your applications

  1. Configure Argo CD to use custom resources

* Define custom resources in your Git repository
* Configure Argo CD to use custom resources for deploying and managing your applications

  1. Configure Argo CD to use external secrets

* Configure Argo CD to use external secrets for managing sensitive data

Instalace¶

   helm repo add argoproj-helm https://argoproj.github.io/helm-charts
   helm install argocd argoproj-helm/argocd
  1. Přístup k Argo CD web UI

   kubectl port-forward svc/argocd-server 8080:443
   open http://localhost:8080
  1. Vytvořte inicialní tajný klíč pro správce

   kubectl create secret generic argocd-initial-admin-secret --from-literal=password=VAŠÍ_HESLO
  1. Přihlaste se k Argo CD

Navštivte http://localhost:8080, zadejte následující údaje:

* Uživatelské jméno: admin
* Heslo: VAŠÍ_HESLO

Po přihlášení budete přesměrováni na dashboard Argo CD.
