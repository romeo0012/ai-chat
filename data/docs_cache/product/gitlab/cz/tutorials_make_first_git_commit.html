Návod: Vytvořte svůj první commit Git
Tento návod vás učí malou mírou, jak Git funguje. Prochází vás krokům vytvoření vlastního projektu, úpravy souboru a komitování změn do Gitového repozitáře přímo z příkazového řádku. Když budete hotovi, máte projekt, na kterém můžete cvičit se Gitem. Před tím, než začnete

Instalace Git na místní počítač. Ujistěte se, že můžete přihlásit k instanci GitLab. Pokud vaše organizace nemá GitLab, vytvořte si účet na GitLab.com. Vytvořte SSH klíče a přidejte je do GitLab. SSH klíče jsou způsobem, jak bezpečně komunikujete mezi vaším počítačem a GitLab. Co je Git? Než se přesuneme k krokům, rozhodneme se o základních Git konceptech. Git je systém řízení verzí. Je používán k záznamu změn souborů. Ukládáte soubory, jako kód nebo dokumenty, do Gitového repozitáře. Když chcete upravit soubory, klonujete repozitář na svůj počítač, provedete změny a poskytnete zpět změny do repozitáře. V GitLab, Gitový repozitář se nachází v projektu. Každýkrát, kdy poskytnete změnu, Git ji zaznamená jako unikátní commit. Tyto commity tvoří historii změn, kdy a jak se soubor změnil, a kdo jej změnil.

Když pracujete v repozitáři Git, pracujete v větvích. Výchozí obsah repozitáře je v výchozí větvi. Chcete-li provést změny, provedete následující kroky:
Vytvořte vlastní větev, která je snímkem výchozí větve v době vytvoření. Provedete změny a poskytnete je do vlastní větve. Každý push vytvoří commit. Když jste připraveni, sloučte svou větev do výchozí větve.

Pokud vše to zatím znělo trochu překvapivě, neztráť se. Brzy si tohle vidíte v praktickém provozu. Kroky
Následující je přehled toho, co budeme dělat: Vytvořit ukázkový projekt. Klonovat repozitář. Vytvořit větví a provedět změny. Zkomitovat a poslat změny. Sloučit změny. Zobrazit změny v GitLab.

Vytvořit ukázkový projekt
Začněte vytvořením ukázkového projektu v GitLab. V GitLabu, v horní pravé části, vyberte Vytvořit nový ( plus ) a Nový projekt/repozitář. Pro Název zadejte Moje ukázkový projekt. Slug projektu je automaticky vygenerován pro vás. Tento slug je URL, kterou můžete použít k přístupu k projektu po jeho vytvoření. Ujistěte se, že je vybráno Inicializovat repozitář s README. Zbytek polí můžete dokončit podle svých potřeb. Vyberte Vytvořit projekt.

Klonovat repozitář
Nyní můžete repozitář klonovat do svého projektu. Klonování repozitáře znamená, že vytvoříte kopii na vašem počítači, nebo kdekoli jinam uložit a pracovat s soubory. Na stránce přehledu projektu, v horní pravé části, vyberte Code, poté zkopírujte URL pro Klonování pomocí SSH. Otevřete terminál na vašem počítači a přejděte do adresáře, kde chcete klonovat soubory. Zadejte git clone a vložte URL: git clone git@gitlab.com:gitlab-example/my-sample-project.git Přejděte do adresáře: cd my-sample-project

Ve výchozím nastavení jste klonovali výchozí větev pro repozitář.

URL: git clone git@gitlab.com:gitlab-example/my-sample-project.git Přejít do adresáře: cd my-sample-project Výchozí branch pro repozitář je klonován po úmočí. Obvykle je to branch main. Chci-li to potvrdit, získáme jméno výchozího branch: git branch Váš branch je označen hvězdičkou. Stisknutím Q na klávesnici se vracíte do hlavního terminálového okna. Vytvořte si branch a provedte změny

Nyní máte kopii repozitáře, vytvořte si vlastní branch, abyste mohli pracovat na svých změnách nezávisle. Vytvořte nový branch s názvem example-tutorial-branch. git checkout -b example-tutorial-branch V textovém editoru jako Visual Studio Code, Sublime, vi nebo jakýkoli jiný editor otevřete soubor README.md a přidejte tento text: Hello world! Jsem v Gitu! Uložte soubor. Git sleduje změněné soubory. Chci-li potvrdit, které soubory byly změněny, získáte stav. git status By mělo být výstup podobný následujícímu: Na branch example-tutorial-branch Změněné soubory: (použijte "git add <soubor>..." k aktualizaci, co bude komitováno) (použijte "git restore <soubor>..." k zrušení změn v pracovním adresáři) upraveno: README.md žádné změny přidány k commitu (použijte "git add" a/nebo "git commit -a") Zkomitujte a odeslete své změny

Vy učinili změny v souboru ve vašem repozitáři. Nyní je čas tyto změny zaznamenat tím, že vytvoříte svůj první commit. Přidejte soubor README.md do staging area. Staging area je místo, kde umístíte soubory před tím, než je komitujete. git add README.md

Tyto změny provedete tím, že provedete svůj první commit. Přidejte soubor README.md do oblasti předstihu. Oblast předstihu je místo, kde umístíte soubory před tím, než je spustíte. git add README.md Potvrďte, že soubor je ve stavu předstihu: git status Byste měli získat výstup podobný následujícímu, a soubor by měl být v zeleném textu. Na větví example-tutorial-branch Změny k provedení komitování: (použijte "git restore --staged <soubor>..." k odstranění souboru z předstihu) upraveno: README.md Nyní komitujte stavovaný soubor a zahrňte zprávu, která popisuje změnu, kterou provedli. Ujistěte se, že zprávu obklopíte dvojitými uvozovkami ("). git commit -m "Přidala jsem text do souboru README" Změna byla provedena v vaší větvi, ale vaše větev a její komity jsou stále k dispozici pouze na vašem počítači. Nikdo jiný ještě nemá přístup k nim. Vytáhněte svou větev do GitLabu: git push origin example-tutorial-branch Vaše větev je nyní k dispozici na GitLabu a viditelná ostatním uživatelům v projektu. Složte své změny Nyní jste připraveni složit změny z vaší větvě example-tutorial-branch do výchozí větvě (main). Zkontrolujte si výchozí větev pro vaši repozitář. git checkout main Složte svou větev do výchozí větvě. git merge example-tutorial-branch Vytáhněte změny. git push Pro tuto ukázku složíte svou větev přímo do výchozí větvě pro vaši repozitář. V GitLabu používáte obvykle žádost o sloučení k sloučení své větvě. Zobrazte své změny v GitLabu Už to je! Aktualizovali jste soubor README.

Váš výchozí větev pro repozitář. V GitLabu se obvykle používá žádost o sloučení k sloučení vaší větev. Zkontrolujte své změny v GitLabu. Hotovo! Aktualizovali jste soubor README.md ve vaší větvi a sloučili tyto změny do hlavní větve. Potvrďte si změny v UI. Přejděte k vašemu projektu. Scrollte dolů a zobrazte obsah souboru README.md. Vaše změny by se měly zobrazit. V horní části nad souborem README.md zobrazte text v sloupci Poslední commit. Vaše zpráva o commitu je zobrazena v tomto sloupci: Nyní můžete se vrátili do příkazového řádku a změnit zpět na svou osobní větev (git checkout example-tutorial-branch).
