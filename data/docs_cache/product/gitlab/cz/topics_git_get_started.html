Git je systém kontroly verzí, který používáte k sledování změn v vašem kódu a spolupráci s ostatními. GitLab je správce repozitářů Git na webu, který poskytuje CI/CD a další funkce, aby vám pomohl spravovat životní cyklus vývoje softwaru. Můžete použít webový rozhraní GitLab pro mnoho operací Git, ale pochopení příkazů Git poskytne další flexibilitu a kontrolu. Základy Gitu jsou součástí většího workflow: Vyberte si cestu k učení: Instalace Git Naučte se: Vytvořte svůj první Git commit Rozumějte Gitovým konceptům: Pokračujte v čtení Repozitáře Gitový repozitář je adresář, který obsahuje všechny soubory, složky a historii verzí vašeho projektu. Slouží jako centrální místo, kde Git spravuje a sleduje změny v vašem kódu. Když inicializujete Gitový repozitář nebo klonujete existující jeden, Git vytvoří skrytou adresářku .git v adresáři projektu. Adresář obsahuje všechny důležité metadata a objekty, které Git používá k spravování vašeho repozitáře, včetně kompletní historie všech změn provedených ve vašich souborech. Git sleduje změny na úrovni souborů, takže můžete zobrazit změny provedené v jednotlivých souborech v průběhu času. Další informace najdete v repozitářích. Pracovní adresáře Vaše pracovní adresář je místo, kde provádíte změny v kódu. Když klonujete Gitový repozitář, vytvoříte místní kopii repozitáře ve vaší pracovní adresáři. Můžete upravovat soubory, přidávat nové a testovat svůj kód.

K spolupráci můžete: Commit: Po provedení změn ve vašem pracovním adresáři, komitujte tyto změny do vašeho místního repozitáře. Push: Pushujte své změny do vzdáleného Git repozitáře hostovaného na GitLab. Tím se vaše změny stávají dostupné pro ostatní členy týmu. Pull: Pullujte změny provedené ostatními z vzdáleného repozitáře, a ujistěte se, že je vaše místní repozitář aktualizován na nejnovější změny. Další informace naleznete v běžných Git příkazech. Větvě V Gitu můžete použít větve k práci na různých funkcionalitách, opravách chyb nebo experimentech současně bez narušování práce ostatních. Větvování umožňuje vytvořit izolované prostředí, ve kterém můžete provádět a testovat změny bez ovlivňování výchozí větev. V GitLabu je výchozí větev obvykle nazývána main. Splnit větev Po dokončení funkce nebo opravě chyby můžete větev sloučit do výchozí větev. Můžete to udělat v žádosti o sloučení. Sloučení je bezpečným způsobem přinášet změny z jedné větve do druhé zachováním historie změn. Pokud dochází k konfliktům mezi větvěmi, například pokud upravíte stejné řádky kódu v obou větvích, GitLab to označí jako konflikty mezi větvěmi. Tyto musí být řešeny ručně tím, že se prozkoumá a upraví kód.

Standardní Gitový pracovní tok zahrnuje následující kroky: Klonovat repozitář: Vytvořte místní kopii repozitáře tím, že ho klonujete na své zařízení. Můžete pracovat na projektu bez toho, aby to ovlivnilo původní repozitář. Vytvořit novou větev: Před tím, než provedete žádné změny, je doporučeno vytvořit novou větev. Tím se zajistí, že vaše změny jsou izolovány a neznečišťují práci ostatních na výchozí větvi. Upravit soubory: Upravte soubory v pracovním adresáři. Můžete přidat nové funkce, opravit chyby nebo provést jiné změny. Zapojit změny: Po provedení změn v souborech zapojte změny, které chcete spustit. Zapojení říká Git, které změny by měly být zahrnuty do dalšího commitu. Spustit změny: Spusťte zapojené změny do svého místního repozitáře.

Některé organizace, zejména ty, které pracují s otevřenými projekty, mohou používat různé workflowy. Například forky. Fork je osobní kopie repozitáře, která existuje v prostoru vašeho účtu. Použijte tento workflow při přispívání k otevřeným projektům nebo pokud vaše tým používá centrální repozitář. Instalace Git
Chcete-li používat Git příkazy a přispívat do GitLab projektů, je nutné stáhnout a nainstalovat Git klienta na svém počítači. Instalace se liší podle operačního systému. Například Windows, MacOS nebo Linux. Další informace o instalaci Git naleznete v článku install Git. Git příkazy
Chcete-li interagovat s Git z příkazového řádku, můžete použít Git příkazy: git clone: Klonujte repozitář na své místní zařízení. git branch: Zobrazíte, vytvoříte nebo odstraníte větve v místním repozitáři. git checkout: Přepnete se mezi různými větvemi v místním repozitáři.

Klonování repozitáře: Klonujte repozitář do vašeho místního počítače. git branch: Seznamujte se, vytvořte nebo odstraňte větvě v místním repozitáři. git checkout: Přepněte mezi různými větvěmi v místním repozitáři. git add: Označte změny pro komit. git commit: Uložte označené změny do místního repozitáře. git push: Vložte místní komity do vzdáleného repozitáře. git pull: Získáte změny z vzdáleného repozitáře a sloučíte je do vaší místní větvě. Pro podrobnější informace a podrobné vysvětlení se přečtěte průvodce běžnými Gitovými příkazy. Použití SSH s Git
Při práci s vzdálenými repozitáři byste měli používat SSH pro bezpečnou komunikaci. GitLab používá protokol SSH k bezpečné komunikaci s Git. Při použití SSH klíčů k ověření sebe-sobě na vzdáleném serveru GitLab je není nutné zadávat své uživatelské jméno a heslo každýkrát. Chcete-li použít SSH s GitLab, musíte:

  1. Vytvořit pár SSH klíčů na svém místním systému.
  1. Přidat svůj SSH klíč do svého účtu GitLab.
  1. Ověřit svou SSH spojení s GitLab.

Další informace najdete v článku použití SSH klíčů s GitLab.
