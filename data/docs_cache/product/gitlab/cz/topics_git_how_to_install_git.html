Instalace Git K vkládání do projektů GitLab je nutné stáhnout, nainstalovat a nakonfigurovat klienta Git na vašem místním počítači. GitLab používá pro bezpečnou komunikaci s Git protokol SSH. S pomocí SSH můžete ověřit se na vzdáleném serveru GitLab bez zadávání svého uživatelského jména a hesla každýkrát. Po instalaci a nakonfiguraci Gitu vytvořte a přidejte SSH klíčovou dvojici do svého účtu GitLab.

Instalace a aktualizace Gitu pro macOS
Though a verze Git je dodávána macOS, je vhodné nainstalovat nejnovější verzi Git. Běžným způsobem instalace Git je pomocí Homebrew. Chcete-li nainstalovat nejnovější verzi Git pro macOS pomocí Homebrew:
Pokud jste ještě nikdy Homebrew nenainstalovali, následujte instrukce pro instalaci Homebrew. V terminálu nainstalujte Git spuštěním příkazu brew install git. Potvrďte, že Git funguje na vašem místním počítači: git --version Aktualizujte Git pravidelně spuštěním následujícího příkazu: brew update && brew upgrade git

Instalace a aktualizace Gitu pro Ubuntu Linux
Though a verze Git je dodávána Ubuntu, je vhodné nainstalovat nejnovější verzi Git. Nejnovější verze je k dispozici pomocí osobní archivy balíčků (PPA).

Přeloženo do češtiny:

Git Ubuntu Linux
Though a version of Git je poskytnutý Ubuntu, byste měli nainstalovat nejnovější verzi Git. Nejnovější verze je k dispozici pomocí Osobního Archivu Balíčků (PPA). Chcete-li nainstalovat nejnovější verzi Git na Ubuntu Linux s PPA: V terminálu nakonfigurujte požadovaný PPA, aktualizujte seznam balíčků Ubuntu a nainstalujte git: 

sudo apt-add-repository ppa:git-core/ppa
sudo apt-get update
sudo apt-get install git

Ověřte, že Git funguje na vašem místním počítači: 
git --version

Aby Git zůstal aktuální, periodicky spusťte následující příkaz: 
sudo apt-get update &amp;&amp; sudo apt-get install git

Konfigurace Git
Chcete-li začít používat Git z vašeho místního počítače, musíte zadat své údaje o sobě, aby bylo možné identifikovat autora práce. Můžete konfigurovat své Git identity místně nebo globálně:

Místně: Použit pro aktuální projekt pouze.
Globálně: Použit pro všechny současné a budoucí projekty.

Místní nastavení
Nastavte Git identity místně pro použití v aktuálním projektu pouze. Plné jméno a email by měl odpovídat těm, které používáte v GitLab. V terminálu přidejte své plné jméno. Například: 

git config --local user.name "Alex Smith"

Přidejte svůj email. Například: 
git config --local user.email "your_email_address@example.com"

Přejmenování. Například: git config --local user.name "Alex Smith" Zadejte svou e-mailovou adresu. Například: git config --local user.email "your_email_address@example.com" Chcete-li kontrolovat konfiguraci, spusťte: git config --local --list Nastavení globální konfigurace Git identity nastavte globálně pro použití všech aktuálních a budoucích projektů na vašem počítači. Plné jméno a e-mailová adresa by měla odpovídat těm, které používáte v GitLab. V terminálu zadejte své plné jméno. Například: git config --global user.name "Sidney Jones" Zadejte svou e-mailovou adresu. Například: git config --global user.email "your_email_address@example.com" Chcete-li kontrolovat konfiguraci, spusťte: git config --global --list Kontrola nastavení konfigurace Git Spusťte: git config user.name && git config user.email Tématy související s konfigurací Git Konfigurace Git dokumentace Použijte klíče SSH k komunikaci s GitLab
