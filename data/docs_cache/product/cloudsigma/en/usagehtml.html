Usage Allowed HTTP methods Method Description GET get / list object/s Note See RFC 2616#section-9 for more details on HTTP methods semantics Listing GET /usage/ Retrieve the usage data for a specific time range. The start and end times are specified using the poll_time_gt (greater than) and poll_time_lt (less than) query parameters, along with an optional limit parameter to define the number of results returned.
