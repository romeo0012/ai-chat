Více informací o použití VLANů v konfiguracích NIC. IPs 🔍
Objekt IP obsahuje skutečný IP v jeho atributu uuid. Seznam IPů zahrnuje IPy, které jsou vlastněné (podílené) uživatelem, a IPy, které jsou dynamicky přiřazeny uživatelům serverům. Vlastněné IPy se od dynamicky přijímaných IPů liší tím, že mají připojenou předplatnou (jejich atribut předplatniny není prázdný). Detailní seznam obsahuje další informace o objektu IP, jako je netmaska, DNS serverové a brána, která se nastaví na NIC. Hodnota netmasky je v CIDR notaci (/24 pro masku 255.255.255.0). Atribut DNS serverů obsahuje seznam DNS serverů, které budou přiřazeny prostřednictvím DHCP, a atribut brána obsahuje IP výchozí brány pro aktuální IP. Povolené metody HTTP 🔍
