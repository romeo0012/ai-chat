Zálohování vzdáleně Zálohování vzdáleně jsou verze v daný čas drives. Mohou být klonovány do celého drive, což umožňuje obnovit starší verzi obrázku virtuálního stroje. Zálohování vzdáleně jsou naším řešením zálohování. Pokud drive zanikne a vzdálené zálohování je vytvořeno, vzdálené zálohování nezanikne. Všechna vzdálená zálohování (zálohy) zmazaných drives lze nalézt v UI -> Uložiště -> Zálohy. Ale vzdálená zálohování aktivních drives lze nalézt v Uložiště -> Drive -> Detailní zobrazení drive -> Oddíl Zálohy. Zálohování vzdáleně jsou fakturována podle jejich obsazeného prostoru. Protože se do zálohování ukládají pouze rozdíly oproti aktuálnímu obrázku drive, velikost jednoho zálohování bude rovna velikosti dat, která se změnila od vytvoření vzdáleného zálohování. Pokud se žádná data nezměnila, velikost vzdáleného zálohování bude nula. Pozor, že vzdálená zálohování jsou fakturována jako záloha, takže aby se nezaplácelo za překročení vzdálených zálohování, je třeba koupit předplatné zálohování. Máme vzdálená zálohování v následujících lokalitách: GVA, ZRH, FRA, CWL, LON, a DUB Metody HTTP Metoda Popis Description GET získat / seznam objektů/ů POST vytvořit nový objekt/y PUT aktualizovat / upravit objekt/y DELETE odstranit objekt/y Pozor Viz RFC 2616#section-9 pro další podrobnosti o semantice metod HTTP.
