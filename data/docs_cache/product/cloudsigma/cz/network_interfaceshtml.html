Server Sítové rozhraní 🔍 Sítová rozhraní soukromá a veřejná 🔍 Každé sítové rozhraní může mít tři konfigurace, které určují, jak se chová. Ne všechny kombinace konfigurací jsou platné: vlan: Soukromá sítová rozhraní ip_v4_conf: Veřejná IPv4 sítová rozhraní, buď statická, DHCP nebo ručně přiřazená. ip_v6_conf: Veřejná IPv6 sítová rozhraní, buď statická, DHCP nebo ručně přiřazená. Výsledky konfigurace vlan ip_v4_conf ip_v6_conf Pravda Pravda Pravda Chyba: Nelze přiřadit všechny konfigurace na jedno rozhraní Pravda Pravda Nepravda Chyba: Nelze přiřadit obě soukromou a veřejnou na jedno rozhraní Pravda Nepravda Pravda Chyba: Nelze přiřadit obě soukromou a veřejnou na jedno rozhraní Pravda Nepravda Nepravda Soukromá sítová rozhraní přiřazena Ne Pravda Pravda Pravda Oba IPv4 a IPv6 přiřazeny Ne Pravda Pravda Nepravda Pouze IPv4 přiřazeno Ne Nepravda Pravda Oba IPv6 přiřazeny Ne Nepravda Ne Nepravda Žádná konfigurace přiřazena IP Přiřazování IP adres pro veřejná rozhraní 🔍 Přiřazování IP adres na soukromé sítové rozhraní je na uživateli. Pro veřejná sítová rozhraní je možné konfigurovat způsob přiřazení adresy nastavením atributu “conf” na objekt ip_v4_conf nebo ip_v6_conf: “dhcp”: Adresa je volena systémem při spuštění a přiřazena prostřednictvím DHCP. Na každém restartu může virtuální stroj získat jinou adresu. Chyba: Specifikovat IP adresu pro “conf”: “dhcp”. Možno získat aktuálně přiřazenou dynamickou IP adresu NIC z běžícího serveru runtime serveru. { "ip_v4_conf": { "conf": "dhcp" } } “static”: Adresa je volena a zadána uživatelem.

Poznámka: Tato stránka popisuje pouze konfiguraci sítových rozhraní. Další konfigurace, jako například konfigurace brány firewall, jsou mimo rozsah této stránky.

Chodící server. { "ip_v4_konfigurace": { "konfigurace": "dhcp" } } "statická": Adresa je vybrána a určena uživatelem. Je přiřazena k NIC prostřednictvím DHCP a nezmění se mezi restarty. Atribut "ip" je povinný a IP adresa může být přiřazena z adres vlastněných uživatelem. { "ip_v4_konfigurace": { "konfigurace": "statická", "ip": "94.26.101.182" } } "ruční": Ke NIC není adresa přiřazena, a uživatel musí adresu IP zadat zevnitř VMs. Při použití tohoto nastavení je NIC povolena k použití všech IP adres, pro které má uživatel předplatné. Toto "konfigurace" může být použito k přiřazení více IP adres k stejné NIC. { "ip_v4_konfigurace": { "konfigurace": "ruční" } } Poznámka Cloudová zbraň neumožňuje provozovat provoz mezi/mezi IP adresami, které nejsou vlastněny nebo nebyly přiřazeny k VM. Výjimkou je nastavení "ruční", kde VM je povolena k použití jakýchkoli IP adres, které vlastní uživatel (uživatel má předplatné na ně). MAC adresy -------- Nově vytvořené NICs mají svou MAC adresu generovanou náhodně. Poznámka Všechny zprávy z MAC adres odlišných od přiřazených systémem jsou zastaveny cloudovou zbraní, takže uživatelé neměli pokusit se změnit své MACy zevnitř své VMs. Chcete-li aktualizovat definici NIC, musí být v definici "mac" atribut naplněn. Pokud na seznamu "nics" aktualizujete MAC adresu, adresa MAC z listu zmizí a odpovídající NIC bude odstraněna.

Překlad:

Atribut vyplněný. Pokud se na seznamu "nics" objeví zmizení MAC adresy z seznamu, odpovídající NIC je odstraněna. Pokud se MAC objeví v novém seznamu, odpovídající NIC je aktualizována, a pokud na NIC není zadán žádný MAC, nová NIC je vytvořena. Chyba nastane, pokud se pokusíte zadat MAC adresu, která nebyla dříve v seznamu "nics". Pořadí NIC v atributu "nics" je důležité, protože je to také pořadí, v němž NIC prezentují VMs. Je možné NIC rearrangovat rearrangováním jejich pořadí v seznamu "nics".
