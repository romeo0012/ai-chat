Remote Snapshots

← Chat

Remote-Screenshots 📄 Remote-Screenshots sind zeitstempelbasierte Versionen eines Laufwerks. Sie können auf eine vollständige Laufwerkskopie klonen, was es ermöglicht, eine ältere Version einer VM-Bilddatei wiederherzustellen. Remote-Screenshots sind unsere Backup-Lösung. Wenn das Laufwerk gelöscht wird und ein remote-Screenshot erstellt wurde, verschwindet der remote-Screenshot nicht. Alle remote-Screenshots (Backups) gelöschter Laufwerke können im UI -> Speicher -> Backups gefunden werden. Aber die remote-Screenshots aktiver Laufwerke können im Speicher -> Laufwerke -> Ein Laufwerk in Detailansicht -> Backups-Abschnitt gefunden werden. Remote-Screenshots werden nach ihrer belegten Größe berechnet. Da nur die Unterschiede zum aktuellen Laufwerksbild gespeichert werden, beträgt die Größe eines einzelnen remote-Screenshots der Größe des geänderten Datensatzes seit dem Zeitpunkt des remote-Screenshots. Wenn kein Datensatz geändert wurde, beträgt die Größe des remote-Screenshots null. Bemerkung: Remote-Screenshots werden nach dem Backup berechnet, daher sollten Backup-Abonnements erworben werden, um nicht bei der Nutzung von remote-Screenshots zu übersteigen. Wir haben remote-Screenshots in den folgenden Standorten: GVA, ZRH, FRA, CWL, LON und DUB Allowierte HTTP-Methoden 📄 Methode Beschreibung GET get / list object/s POST create new object/s PUT update / modify object/s DELETE delete object/s Hinweis: Siehe RFC 2616#section-9 für weitere Details zur Semantik der HTTP-Methoden. Listing 📄 GET /remotesnapshots/ 📄 Ruft die Liste der remote-Screenshots ab, zu denen der authentifizierte Benutzer Zugriff hat. Parameter: fields – Eine Menge von Feldnamen, die die zurückgegebenen Felder bestimmen.
