Paginierung Optionen 🔍
Alle API-Anfragen, die Listen von Objekten zurückgeben, unterstützen Paginierung. Dies geschieht über zwei GET-Parameter: offset gibt den Index an, ab dem Objekte zurückgegeben werden sollen. Es handelt sich um eine nullbasierte Index. limit gibt die maximale Anzahl von Objekten an, die zurückgegeben werden sollen. Wenn auf 0 gesetzt, werden alle Ressourcen zurückgegeben. In diesem Beispiel wird gezeigt, wie die Paginierung bei API-Anfragen umgesetzt wird. Die Parameter offset und limit werden verwendet, um die Anzahl der zurückgegebenen Objekte zu begrenzen. Die Anfrage wird mit GET-Methode und HTTP/1.1-Version gestartet. Der Content-Type wird als application/json festgelegt und die Autorisierung erfolgt über Basic-Authentifizierung. Die Antwort wird mit HTTP/1.1 200 OK und Content-Type application/json; charset=utf-8 zurückgegeben. Die Antwort enthält eine Meta-Information, die die Anzahl der zurückgegebenen Objekte, den Index und die Gesamtanzahl der Objekte angibt. Die Objekte werden in einem Array zurückgegeben.
