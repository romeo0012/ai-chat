GET /ipaliases/{ipalias_uuid}/

Ruft Informationen zu einem IP Alias mit der ipalias_uuid ab.

Löschen 📝
DELETE /ipaliases/{ipalias_uuid}/ 📝
Löscht eine einzelne IP-Alias, das durch ipalias_uuid identifiziert wird. statuscode 204: Kein Inhalt, Objektlöschung gestartet. Beispielanfrage:
DELETE /api/2.0/ipaliases/f317b570-1693-4002-95fe-172cd4327cb2/ HTTP/1.1
Content-Type: application/json
Authorization: Basic SWYgeW91IGZvdW5kIHRoaXMsIGhhdmUgYSBjb29raWUsIHlvdSBkZXNlcnZlIGl0IDop
