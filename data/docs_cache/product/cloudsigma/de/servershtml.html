Servers / VMs 🠊 Hypervisors 🠊 Servers besitzen Hypervisor- und cpu_type-Parameter, deren Kombination mit derjenigen in den Fähigkeiten der Cloud übereinstimmen muss. Dieser Abschnitt behandelt allgemeine Server-Operationen. Es gibt Spezifika für jeden Typ von Hypervisor: kvm Der Standard-Hypervisor ist kvm, um die Rückwärtskompatibilität zu gewährleisten, und der Standard-cpu_type ist amd. Wenn Sie einen anderen Hypervisor und keinen cpu_type angeben, verwendet die API trotzdem amd. Zulässige HTTP-Methoden 🠊 Methodenbeschreibung GET get / listet Objekte/n aus. POST erstellt neue Objekte/n. PUT aktualisiert / modifiziert Objekte. DELETE löscht Objekte. Hinweis Siehe RFC 2616#section-9 für mehr Details über die Semantik von HTTP-Methoden.
