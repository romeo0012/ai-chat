Allgemein 🔍 Die API für Konten unterstützt die folgenden Aktionen
Erstellen eines Kontos 🔍 POST /konten/aktion/?do=create
Erstellt ein Konto im System. Im Falle eines Erfolgs muss der Benutzer seinen E-Mail-Adressen für eine Bestätigungslink prüfen, der ihn dazu auffordert, ein Passwort für das Konto zu erstellen. Statuscodes: 200 OK – kein Fehler
Parameter: email – Die E-Mail-Adresse des Kontos, das erstellt werden soll
promo – Aktivierungs-Code für initiale Abonnements und Demo-Server (optional)
Beispielanfrage: POST /api/2.0/konten/aktion/?do=create HTTP/1.1
Content-Type: application/json
{
"email": "john_doe+42@cloudsigma.com",
"promo": null
}
Beispielantwort: HTTP/1.1 200 OK
Content-Type: application/json; charset=utf-8
{
"success": true,
"uuid": "ba8cce4c-9809-4389-a41e-2f9faabf87e9"
}
Anmelden/Abmelden 🔍 POST /konten/aktion/?do=anmelden
Anmelden bei dem System über Cookie-Authentifizierung
Statuscodes: 200 OK – kein Fehler
401 Unauthorized – unautorisiert
Beispielanfrage: POST /konten/aktion/?do=anmelden HTTP/1.1
Host: api.cloudsigma.com
Accept: application/json
Request body
{
'username':'123@asd.com',
'password':'parola'
}
Antwort: Leer

Prüfe, wie ein authentifizierter Dienst den UUID eines Benutzers über die Cloudsigma API erhalten kann

Accept: application/json
