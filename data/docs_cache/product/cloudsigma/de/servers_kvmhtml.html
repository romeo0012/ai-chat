KVM-Server-Einstellungen 📄 Device channel 📄

Device channel dient dazu, den Steuerungszahl und die Einheitsnummer für jedes angeschlossene Gerät zu spezifizieren. Dadurch bleibt das Gerät bei jedem Neustart der virtuellen Maschine auf demselben Ort im Gast-Betriebssystem (z.B. /dev/sdc)

Du spezifizierst den Kanal in folgendem Format - {Controller}:{Unit} mit den folgenden Grenzen für ide und virtio-Geräte:

  • ide - 0:0, 0:1, 1:0, 1:1 (insgesamt 4 Geräte, max. 2 Einheiten pro Steuerung, also 0-1)
  • virtio - 0:0, …, 0:5, …, 1:0, usw. (insgesamt 1024 Geräte, max. 6 Einheiten pro Steuerung, also 0-5)

VNC-Tunnel öffnen 📄 POST /servers/{uuid}/action/?do=open_vnc 📄

Das Konsolen-Interface (virtueller Tastatur, Maus und Anzeige) des Servers wird dem Benutzer über das VNC-Protokoll zur Verfügung gestellt. Der open_vnc-Aufruf öffnet einen VNC-Tunnel zum Server. Das zurückgegebene Objekt enthält einen vnc_url, der den Endpunkt angibt, an den der VNC-Client verbunden werden soll. Das Passwort für den VNC-Zugang ist im vnc_password-Feld auf der Serverdefinition angegeben. Hinweis: Der Tunnel wird nicht geschlossen, bis der Server neu gestartet wird, also kannst du ihn, falls du es vorziehst, mit der close_vnc-Aktion schließen.

Statuscodes: 202 Accepted – Aktion angenommen, Ausführung läuft weiter. Hinweis: Der VNC-URL ändert sich jedes Mal, wenn du den Tunnel schließen und öffnen möchtest. Beispielanfrage: POST /api/2.0/servers/42cb8991-a39a-4ed3-b549-efd6a1dedd48/action/?do=open_vnc HTTP/1.1 Content-Type: application/json Authorization: Basic SWYgeW91IGZvdW5kIHRoaXMsIGhhdmUgYSBjb29raWUsIHlvdSBkZXNlcnZlIGl0IDop {}

} cpus_statt_Kerne: Typ: wahr/falsch Beschreibung: wählt aus, ob die SMP als Kerne eines einzelnen CPUs oder separate CPUs angezeigt wird. Dies sollte auf false für Windows gesetzt werden, weil es Lizenzanforderungen für mehrere CPUs gibt. enable_numa: Typ: wahr/falsch Beschreibung: Diese Option zeigt die NUMA/CPU-Topologie des Hypervisors der virtuellen Maschine an. Sie verbessert die Leistung für NUMA-bewusste Anwendungen. Die Option sollte auf true für Server mit SMP größer als 6 gesetzt werden, da dies die Anzahl der Kerne pro NUMA-Knoten auf dem Hypervisor entspricht. Wenn auf true gesetzt, sollte cpus_statt_Kerne auch auf true für Linux gesetzt werden, weil einige Linux-Distributionen keine Unterstützung für mehrere NUMA-Knoten auf mehreren Kernen, sondern nur auf mehreren CPUs haben. hv_gelockert Typ: wahr/falsch Beschreibung: Löst die Einschränkungen für Timer auf. Dies verbessert das Verhalten von VMs, die Windows ausführen. hv_tsc: Typ: wahr/falsch Beschreibung: Aktiviert genauere Timer für Windows. Dies verbessert die Leistung für Timer-spezifische Code. Warnung: hv_gelockert und hv_tsc sollten auf false gesetzt werden, wenn VMs Linux ausführen.
