Aufgaben 🔍 Aufgaben werden verwendet, um den Fortschritt langsam laufender Aufgaben zu verfolgen. Ein gutes Beispiel für eine langsam laufende Aufgabe ist die Kopie von Laufwerken und Servern. Je nach aktuellem Verbrauch von Cloud-Ressourcen und den Vorlieben des Benutzers (Erstellen von Laufwerken in einer anderen Verfügbarkeitsgruppe (Create/Clone vermeiden) ) kann eine Kopiervorgang einige Zeit in Anspruch nehmen. Derzeit werden die Operationen, die eine Aufgabe für die Überwachung erstellen, wie folgt: Laufwerkskopie Serverkopie

Wie es funktioniert 🔍 Laufwerkskopie 🔍 Nach erfolgreicher Auslösung eines Kopiervorgangs über die API erhält man die Definition des neu erstellten Laufwerks. Alle Laufwerke haben ein Feld "Jobs", das Verweise auf alle langsam laufenden Aufgaben enthält, die auf ihnen ausgeführt wurden. Das Ziel, da es sich um ein neues Laufwerk handelt, verweist nur auf eine Aufgabe - die derzeit laufende. Das Quelllaufwerk kann mehr Aufgaben enthalten, je nachdem, wie oft es kopiert wurde. Die Geschichte abgeschlossener Aufgaben wird für 3 Tage gespeichert. Ältere Aufgaben werden gelöscht. Beispiel Kopieranfrage:

Die Klonung eines Servers ist etwas komplexer. Da Servers in der Regel Laufwerke enthalten, müssen auch die Laufwerke geklont werden. Deshalb unterstützen Jobs Sub-Jobs. Wenn Sie einen Klon-Server-Anforderung senden, erhalten Sie die Definition des neu erstellten Servers. Es hat auch einen Felder jobs, das die Definitionen von Jobs und Sub-Jobs enthält. Beispiel Klon-Anforderung:

POST /api/2.0/servers/ee11b9d1-e837-4f27-91a4-d1ae4c621bd1/action/?do=clone HTTP/1.1
Content-Type: application/json
Authorization: Basic SWYgeW91IGZvdW5kIHRoaXMsIGhhdmUgYSBjb29raWUsIHlvdSBkZXNlcnZlIGl0IDop
{
"name": "test_cloned_server_name",
"random_vnc_password": true
}

Beispiel Klon-Antwort:
