Metadata
Es ist möglich, beliebiges Schlüssel-Wert-Daten zu einer VLAN-Definition hinzuzufügen. Siehe Objekte’s metadata-Feld für mehr Informationen. Löschen
Nicht anwendbar - Das VLAN verschwindet, wenn das Abonnement für es abläuft. Anhängen an Server
Ein VLAN kann an mehreren Servern angehängt werden. Siehe Server Network Interfaces für mehr Informationen über die Verwendung von VLANs in NIC-Konfigurationen. IPs
Das IP-Objekt, enthält die tatsächliche IP in seinem uuid-Attribut.

Mehr Informationen zum Verwenden von VLANs in NIC-Konfigurationen. IPs 🔍
Der IP-Objekt enthält die tatsächliche IP in seinem uuid-Attribut. Die Liste der IPs umfasst die IPs, die der Benutzer (abonniert hat) besitzt, und die IPs, die dynamisch den Servern des Benutzers zugewiesen werden. Die von dem Benutzer besitzten IPs werden durch die Tatsache, dass sie ein Abonnement besitzen (ihre Abonnement-Attribut ist nicht leer), unterschieden. Die ausführliche Liste enthält mehr Informationen zum IP-Objekt, wie z.B. Netzmaske, Nameserver und Gateway, die auf dem NIC gesetzt werden. Der Netzmaske-Wert ist in CIDR-Notation (/24 für eine 255.255.255.0-Maske). Das Nameservers-Attribut enthält eine Liste von DNS-Servern, die über DHCP zugewiesen werden, und das Gateway-Attribut enthält den IP-Adress des Standard-Gateways für die aktuelle IP. Metadata
Es ist möglich, beliebiges Schlüssel-Wert-Daten zu einem IP-Definition hinzuzufügen. Weitere Informationen finden Sie im Metadatenfeld von Objekten. Löschen
Nicht anwendbar - Die IP wird verschwinden, wenn die Abonnement für sie abläuft. Zuordnen zu servers
Eine IP kann an ein einzelnes Server zugeordnet werden. Um zu überprüfen, ob die IP derzeit an einem Server angehängt ist, betrachten Sie den Attribut auf dem Objekt in der detaillierten Liste oder auf der Einzelobjekt-Ausgabe. Wenn server leer ist, dann ist die IP nicht an einem Server angehängt und kann für statische IP-Konfiguration verwendet werden. Weitere Informationen finden Sie unter Server Netzwerk-Schnittstellen für Informationen zur Verwendung von IPs in NIC-Konfigurationen. Schema
