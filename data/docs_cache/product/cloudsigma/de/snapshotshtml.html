Aufnahmen 🔃
Aufnahmen sind zeitstempelbasierte Versionen eines Laufwerks. Sie können auf ein volles Laufwerk klonen, was es ermöglicht, eine ältere Version einer VM-Bilddatei wiederherzustellen. Aufnahmen werden nach ihrer belegten Größe berechnet. Da nur die Änderungen vom aktuellen Laufwerksbild gespeichert werden, beträgt die Größe einer einzelnen Aufnahme die Größe der geänderten Daten seit der Aufnahme wurde aufgenommen. Wenn kein Daten geändert wurde, beträgt die Größe der Aufnahme null. Bemerkung: Aufnahmen werden wie Laufwerke berechnet, daher sollten Laufwerk-Abonnements erworben werden, um nicht durch die Nutzung von Aufnahmen zu explodieren. Zugelassene HTTP-Methoden 🔃
Methodenbeschreibung: GET - listet Objekte/n auf; POST - erstellt neue Objekte/n; PUT - aktualisiert/änderte Objekte/n; DELETE - löscht Objekte/n.
Siehe RFC 2616#section-9 für weitere Details zur Semantik der HTTP-Methoden.
