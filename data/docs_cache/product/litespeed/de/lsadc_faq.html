Frequently Asked Questions¶

← Chat

Häufig gestellte Fragen¶ Ist dies eine Lösung, die mit einer Steuerungspanel-Software funktioniert?¶ cPanel-Nutzer können versuchen, ZeroConf zu verwenden. Ist ein IP-Failover-Setup verfügbar auf ADC?¶ Ja, es ist. Bitte siehe High Availability für Konfigurationsanweisungen. Unterstützt Web ADC IPs auf verschiedenen Schnittstellen?¶ Es sollte kein Problem mit mehreren Netzwerk-Schnittstellen geben, sofern Keepalived es zulässt. Unterstützt Web ADC die Daten-Synchronisation zwischen Backend-Knoten?¶ Nein. Die Daten-Synchronisation zwischen Backend-Knoten ist keine Aufgabe des ADC. Web ADC ist nur für seine eigenen internen Zustände verantwortlich. Für Backend-Knoten benötigen Sie ein gemeinsames Speicherplatz für Dateien und eine Datenbank-Replikation für Datenbanken. Ist DB-Hochverfügbarkeit nicht erforderlich, können Sie mehrere Web-Knoten einrichten, die sich mit einer DB-Server verbinden. Ist Web ADC in der Lage, MySQL zu load balancen?¶ Nein. Web ADC ist ein Layer 7 Load Balancer. Für MySQL wird Layer 4 verwendet, daher kann Web ADC nicht auf einer pro-Abfrage-Ebene Verkehr leiten und es kann keine Trennung von Lesevorgängen und Schreibvorgängen vorgenommen werden. Wo sollen Cache-Regeln definiert werden: Web ADC, oder die unterliegenden Webserver(s)?¶ LSCache ist für die Verwendung am ADC-Level verfügbar, jedoch empfehlen wir für die meisten Basis-Einstellungen, LSCache am Backend-Server-Level zu aktivieren stattdessen. Wenn Sie LSCache am ADC-Level aktivieren, müssen Sie darauf achten, keine Inkonsistenzen mit dem Backend einzuführen. Unterstützt Web ADC mod_security-Regeln?¶ Ja. Der ModSec-Engine in LiteSpeed Web ADC ist ähnlich demjenigen in unserem LiteSpeed Web Server.

WebADC unterstützt die Laden eines Unterverzeichnisses einer Seite von einer separaten Quelle?¶ Ja. Sie müssen einen Kontext für das Unterverzeichnis definieren und dann diesem anderen Cluster zuweisen. Beispiel: example.com load balances über fünf Server. example.com/blog lädt von einer separaten IP. Hostheaders werden benötigt, da die IP nur auf Anfragen für example.com antwortet.
