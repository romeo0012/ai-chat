Frequently Asked Questions¶

← Chat

Častěná otázka¶ Je to řešení, které funguje s kontrolním panelem?¶ Uživatelé cPanel mohou zkusit ZeroConf. Je možné nastavit přesměrování IP adres na ADC?¶ Ano, je to možné. Pro instrukce k nastavení naleznete si v High Availability. Má Web ADC podporu IP adres na různých rozhraních?¶ Nebylo by to problém s více sítovými rozhraními karetami (NIC), pokud to umožňuje Keepalived. Má Web ADC zodpovědnost za synchronizaci dat mezi zadavateli?¶ Ne. Synchronizace dat mezi zadavateli není zodpovědností ADC. Web ADC má zodpovědnost pouze za vlastní vnitřní stavy. Pro zadavatele budete potřebovat sdílenou úložiště pro soubory a replikaci databáze pro databáze. Pokud není požadována vysoká dostupnost databáze, můžete nastavit více webových uzlů, které se spojují s jednou databázovou serverovou. Má Web ADC schopnost rovnoměrně rozložit zatížení MySQL?¶ Ne. Web ADC je 7. vrstva rovnoměrného zatížení. Pro MySQL je používána 4. vrstva, takže Web ADC nemůže rozložit provoz na úrovni jednotlivých dotazů a nedokáže rozdělit čtení a zápis. Kde by měly být definovány pravidla pro uložení do mezipaměti: Web ADC, nebo podle webových serverů(s)?¶ LSCache je k dispozici pro použití na úrovni ADC, ale pro většinu základních nastavení nám doporučujeme povolit LSCache na úrovni zadavatele místo toho. Pokud si však vyberete povolit LSCache na úrovni ADC, musíte být opatrní, aby se nevytvořily žádné nesouhlasnosti s zadavatelem. Má Web ADC podporu pravidel mod_security?¶ Ano. ModSec engine v LiteSpeed Web ADC je podobný tomu, který máme v našem LiteSpeed Web Serveru.

WebADC podporuje načítání podadresáře na stránku z odlišného zdroje?¶ Ano. Musíte definovat kontext pro podadresář a pak mu přiřadit jiný cluster. Například example.com se rovnoměrně rozložuje mezi pěti servery. example.com/blog se načítá z odlišné IP adresy. Host headers budou potřeba zachovat, protože IP odpovídá pouze na požadavky pro example.com.
