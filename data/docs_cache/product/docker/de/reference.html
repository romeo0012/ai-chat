Dateiformate

Dockerfile
Definiert den Inhalt und das Startverhalten eines einzelnen Containers.

Compose file
Definiert eine multi-container Anwendung.

Befehlszeilenschnittstellen (CLIs)

Docker CLI
Die Haupt-Docker-CLI, um alle docker-Befehle zu verwenden.

Compose CLI
Die CLI für Docker Compose, um multi-container Anwendungen zu erstellen und auszuführen.

Daemon CLI (dockerd)
Persistentes Prozess, das Containern verwaltet.

Anwendungsprogrammierungsinterfaces (APIs)

Engine API
Die Haupt-API für Docker, bietet programmatische Zugriff auf einen Daemon.

Docker Hub API
API, um mit Docker Hub interagieren zu können.

DVP Data API
API für Docker Verified Publishers, um Analytics-Daten abzurufen.

Registry API
API für Docker Registry.
