Um Tests in einem Container auszuführen, führen Sie die Tests mithilfe der dev-Stufe Ihrer Dockerfile aus:
$ docker compose run --build --rm --no-deps server npm test

Das --no-deps Flag überspringt den Start der Datenbank, da die Einheitstests dies nicht benötigen. Das --rm Flag entfernt den Container, wenn die Tests beendet sind. Sie sollten die gleiche Testausgabe wie bei der lokalen Ausführung erhalten.
