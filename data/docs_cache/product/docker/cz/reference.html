Začátek Návodů Dokumentace referenční Dokumentace pro různé API, CLIs, řidiče a specifikace, a formáty souborů platformy Docker. Formáty souborů
Dockerfile Definuje obsah a zahájení chování jednoho kontejneru.
Compose file Definuje aplikaci s více kontejnery.
Command-line interfaces (CLIs)
Docker CLI Hlavní CLI Docker, zahrnuje všechny příkazy docker.
Compose CLI CLI pro Docker Compose, pro sestavování a spouštění aplikací s více kontejnery.
Daemon CLI (dockerd) Trvalý proces, který spravuje kontejnery.
Application programming interfaces (APIs)
Engine API Hlavní API pro Docker, poskytuje programatický přístup k daemonu.
Docker Hub API API pro interakci s Docker Hub.
DVP Data API API pro Docker Verified Publishers pro získání analytických dat.
Registry API API pro Docker Registry.
