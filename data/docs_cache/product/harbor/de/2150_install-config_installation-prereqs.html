Harbor-Installationsvoraussetzungen
Harbor kann auf einem Docker-Host mithilfe von Docker Compose oder auf einem Kubernetes-Cluster mithilfe von Helm installiert werden.

Ressourcenanforderungen
Die Tabelle unten gibt die minimale und empfohlene Ressourcenanforderungen für die Installation von Harbor an.

| Ressource | Mindestanforderung | Empfohlene Anforderung |
| --- | --- | --- |
| CPU | 2 CPU | 4 CPU |
| Arbeitsspeicher | 4 GB | 8 GB |
| Speicherplatz | 40 GB | 160 GB |

Software-Stack-Anforderungen

| Software | Version | Beschreibung |
| --- | --- | --- |
| Docker Engine | > 20.10 | Docker Engine Installation |
| Docker Compose | docker compose > 2.3 | Docker Compose ist Teil von Docker Engine |
| OpenSSL | neueste Version (optional) | Verwendet zur Erstellung von Zertifikat und Schlüssel für Harbor |

Netzwerkports
Harbor benötigt, dass die folgenden Ports offen sind auf dem Zielhost.

| Port | Protokoll | Beschreibung |
| --- | --- | --- |
| 443 | HTTPS | Harbor-Portal und Core-API akzeptieren HTTPS-Anfragen auf diesem Port. Sie können diesen Port in der Konfigurationsdatei ändern. |
| 80 | HTTP | Harbor-Portal und Core-API akzeptieren HTTP-Anfragen auf diesem Port. Sie können diesen Port in der Konfigurationsdatei ändern. |

Harbor installieren auf Kubernetes
Um Docker mit Helm auf einem Kubernetes-Cluster zu installieren, siehe den speziellen Repository github.com/goharbor/harbor-helm

Laden Sie den Harbor-Installer herunter.
