Test Harbor mit dem Demo-Server

Die Harbor-Mitarbeiter haben einen Demo-Harbor-Instanz bereitgestellt, die Sie verwenden können, um Harbor zu testen und seine Funktionalitäten auszuprobieren. Wenn Sie den Demo-Server verwenden, bitte beachten Sie die Nutzungsbedingungen. Nutzungsbedingungen des Demo-Servers

Der Demo-Server ist nur für experimentelle Verwendung reserviert, um Ihnen zu ermöglichen, Harbor-Funktionalitäten zu testen. Bitte uploaden Sie keine sensiblen Bilder auf den Demo-Server. Der Demo-Server ist kein Produktionsumgebung. Die Harbor-Mitarbeiter übernehmen keine Haftung für jede Verlust von Daten, Funktionalität oder Service, der durch seine Nutzung resultieren könnte. Der Demo-Server wird alle zwei Tage gereinigt und zurückgesetzt. Der Demo-Server erlaubt es nur, Benutzerfunktionalitäten zu testen. Sie können Administratorfunktionalitäten nicht testen. Um Administratorfunktionalitäten und fortgeschrittene Funktionen zu testen, richten Sie eine Harbor-Instanz ein. Bitte uploaden Sie keine Bilder mit einer Größe von mehr als 100MB auf den Demo-Server, da er eine begrenzte Speicherkapazität hat. Wenn Sie während der Nutzung des Demo-Servers Probleme haben, öffnen Sie ein Issue auf GitHub oder kontaktieren Sie die Harbor-Mitarbeiter auf Slack.

Zugriff auf den Demo-Server

Gehen Sie zu https://demo.goharbor.io. Klicken Sie auf "Sign up for an account". Erstellen Sie ein Benutzerkonto, indem Sie einen Benutzernamen, Ihre E-Mail-Adresse, Ihren Vornamen und ein Passwort bereitstellen. Melden Sie sich mit dem von Ihnen erstellten Konto bei der Harbor-Schnittstelle an. Navigieren Sie durch die Standard-Projekt, Bibliothek. Klicken Sie auf "New Project", um Ihr eigenes Projekt zu erstellen. Informationen zum Erstellen eines Projekts finden Sie unter Create a Project.

Mit dem von Ihnen erstellten Konto navigieren Sie. Erkunden Sie den Voreinstellungsprojekt, Bibliothek. Klicken Sie auf New Project, um Ihren eigenen Projekt zu erstellen. Informationen zum Erstellen eines Projekts finden Sie unter Create a Project. Öffnen Sie ein Docker-Client und melden Sie sich bei Harbor mit den oben erstellten Anmeldeinformationen an.

docker login demo.goharbor.io

Erstellen Sie einen sehr einfachen Dockerfile mit den folgenden Inhalten.

FROM busybox:latest

Bauen Sie eine Image aus diesem Dockerfile und markieren Sie es.

docker build -t demo.goharbor.io/your-project/test-image .

Versenden Sie das Image in Ihr Projekt von Harbor.

docker push demo.goharbor.io/your-project/test-image

Im Harbor-Interface navigieren Sie zu Projects > your_project > Repositories, um den Image-Repository anzuzeigen, den Sie in Ihr Harbor-Projekt hochgeladen haben.

Weitere Schritte siehe Harbor Installation Prerequisites.
