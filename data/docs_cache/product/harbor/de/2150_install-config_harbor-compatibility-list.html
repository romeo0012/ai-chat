Prüfungsfähig bedeutet, dass die Scanner-Implementierung offiziell getestet und verifiziert wurde.
Standardmäßig bedeutet, dass der Scanner als Standardoption bereitgestellt und zusammen mit den Hauptkomponenten von Harbor installiert werden kann, indem man zusätzliche Optionen während der Installation bereitstellt. Andere Scanner müssen manuell installiert werden.
