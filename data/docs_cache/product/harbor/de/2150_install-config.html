Harbor-Installation und Konfiguration
Dieser Abschnitt beschreibt, wie Sie eine neue Installation von Harbor durchführen. Wenn Sie von einer früheren Version von Harbor aufwerten möchten, könnten Sie möglicherweise die Konfigurationsdatei aktualisieren und Ihre Daten auf die Datenbankschema der späteren Version anpassen müssen. Informationen zum Upgraden finden Sie unter Upgrading Harbor. Bevor Sie Harbor installieren, können Sie die neueste Version von Harbor auf einer von der Harbor-Mannschaft betreuten Demo-Umgebung testen. Informationen dazu finden Sie unter Testen von Harbor mit der Demo-Server. Harbor unterstützt die Integration mit verschiedenen 3. Partei-Replikationsadaptern für die Datenreplikation, OIDC-Adaptern für die authN/authZ und Scanner-Adaptern für die Sicherheitsprüfung von Container-Bildern. Informationen zu den unterstützten Adaptern finden Sie auf der Harbor-Kompatibilitätsliste. Installationsprozess
Der Standard-Installationsprozess von Harbor besteht aus den folgenden Schritten:
Stellen Sie sicher, dass Ihre Ziel-Host die Voraussetzungen für die Installation von Harbor erfüllt.
Laden Sie den Harbor-Installer herunter
Konfigurieren Sie den HTTPS-Zugriff auf Harbor
Konfigurieren Sie den Harbor YML-Datei
Konfigurieren Sie die Aktivierung des internen TLS
Führen Sie das Installer-Skript aus
Wenn die Installation fehlschlägt, finden Sie Hilfe unter Troubleshooting Harbor Installation.
Bereitstellen Sie Harbor auf Kubernetes
Sie können auch Helm verwenden, um Harbor auf einem Kubernetes-Cluster zu installieren, um Harbor hochverfügbar zu machen. Informationen dazu finden Sie unter Bereitstellung von Harbor mit Hochverfügbarkeit über Helm.

Verfügbar. Informationen zum Installieren von Harbor mit Helm auf einem Kubernetes-Cluster finden Sie unter Deploying Harbor mit High Availability via Helm. Post-Installation-Konfiguration Informationen zum Verwalten Ihrer bereitgestellten Harbor-Instanz finden Sie unter Reconfigure Harbor und Manage the Harbor Lifecycle. Standardmäßig verwendet Harbor sein eigenes privates Schlüsselpaar, um sich mit Docker zu authentifizieren. Informationen zum optionalen Anpassen Ihrer Konfiguration, um Ihr eigenes Schlüsselpaar zu verwenden, finden Sie unter Customize the Harbor Token Service. Nach der Installation melden Sie sich bei Ihrem Harbor über die Web-Konsole an, um die Instanz unter ‘configuration’ zu konfigurieren. Harbor bietet auch eine Befehlszeilenschnittstelle (CLI), die Ihnen erlaubt, Harbor System Settings an der Befehlszeile zu konfigurieren. Harbor-Komponenten Die Tabelle unten listet einige der wichtigsten Komponenten auf, die bei der Bereitstellung von Harbor bereitgestellt werden.

| Komponente | Version |
| --- | --- |
| Postgresql | 15.10 |
| Redis | 7.2.6 |
| Beego | 2.3.4 |
| Distribution/Distribution | 2.8.3 |
| Helm | 2.9.1 |
| Swagger-ui | 5.9.1 |

Die Versionen von postgresql und redis können in einem minor patch aktualisiert werden.
