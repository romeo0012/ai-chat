Herunterladen des Harbor-Installs
Sie können die Harbor-Installer von der offiziellen Veröffentlichungen-Seite herunterladen. Wählen Sie entweder den Online-Installer oder den Offline-Installer. Online-Installer: Der Online-Installer läd die Harbor-Bilder von Docker Hub herunter. Daher ist der Installer sehr klein. Offline-Installer: Verwenden Sie den Offline-Installer, wenn der Host, auf den Sie Harbor deployen, keinen Internetzugang hat. Der Offline-Installer enthält vorab gebaute Bilder, weshalb er größer ist als der Online-Installer. Die Installationsprozesse sind fast identisch für den Online- und Offline-Installer. Herunterladen und Entpacken des Installers
Navigieren Sie zur Harbor-Veröffentlichungen-Seite. Laden Sie den Online- oder Offline-Installer für die Version herunter, die Sie installieren möchten. Optional laden Sie den entsprechenden *.asc-Datei herunter, um zu überprüfen, dass das Paket echt ist. Die *.asc-Datei ist ein OpenPGP-Schlüssel-Dateiformat. Führen Sie die folgenden Schritte aus, um zu überprüfen, dass das heruntergeladene Paket echt ist. Erhalten Sie das öffentliche Schlüsselpaar für die *.asc-Datei.

gpg --keyserver hkps://keyserver.ubuntu.com --receive-keys 644FF454C0B4115C

Sie sollten die Nachricht "öffentlicher Schlüssel 'Harbor-sign (Der Schlüssel für die Signierung von Harbor-Builds) <jiangd@vmware.com>' importiert" sehen.

Verifizieren Sie das Paket, indem Sie entweder den folgenden Befehl für den Online-Installer oder den Offline-Installer ausführen.

Online-Installer:

gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-online-installer-version.tgz.asc

Offline-Installer:

gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-offline-installer-version.tgz.asc

Der folgenden Befehlen. Online-Installer: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-online-installer-version.tgz.asc
Offline-Installer: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-offline-installer-version.tgz.asc

Der gpg-Befehl überprüft, ob die Signatur des Bundles mit der *.asc-Schlüsseldatei übereinstimmt. Sie sollten eine Bestätigung erhalten, dass die Signatur korrekt ist.
gpg: Armor-Header: Version: GnuPG v1
gpg: es wird angenommen, dass signiertes Daten in 'harbor-online-installer-v2.0.2.tgz' vorliegen
gpg: Signatur erstellt Donnerstag, 28. Juli 2020 09:49:20 UTC
gpg: Verwendung von RSA-Schlüssel 644FF454C0B4115C
gpg: Verwendung von pgp-Vertrauensmodell
gpg: Gute Signatur von "Harbor-sign (Der Schlüssel für die Signierung von Harbor-Build) <jiangd@vmware.com>" [unbekannt]
gpg: WARNING: Diese Schlüssel ist nicht mit einer vertrauenswürdigen Signatur zertifiziert!
gpg: Es gibt keine Anzeichen, dass die Signatur dem Besitzer gehört.
Primärer Schlüsselfingerabdruck: 7722 D168 DAEC 4578 06C9 6FF9 644F F454 C0B4 115C
gpg: binäre Signatur, Hash-Algorithmus SHA1, Schlüsselalgorithmus rsa4096

Verwenden Sie tar, um das Installer-Paket auszupacken:
Online-Installer: bash $ tar xzvf harbor-online-installer-version.tgz
Offline-Installer: bash $ tar xzvf harbor-offline-installer-version.tgz

Hinweise zum Installer-Verzeichnis
Sie können den Harbor-Installer in jedem Verzeichnis extrahieren.

Konfigurieren des Zugriffs auf HTTPS auf Harbor. Um Ihre Harbor-Installation zu konfigurieren, siehe Konfigurieren des Harbor YML-Datei. Hinweise zum Installationsverzeichnis Sie können den Harbor-Installer in jedem Verzeichnis extrahieren. Der Benutzer, der die Installationsskript ausführt, muss Berechtigungen haben, Docker-Befehle auszuführen (normalerweise durch Mitgliedschaft in der docker-Gruppe). Dieses Verzeichnis wird nur für die Installation und Konfiguration verwendet. Es ist nicht das Verzeichnis, in dem die dauerhafte Daten von Harbor gespeichert werden. Alle Harbor-Dienste laufen innerhalb von Docker-Containern und ihre Daten werden in Docker-Volumes gespeichert. Sie sollten dieses Verzeichnis beibehalten, um Ihre Harbor-Instanz später zu verwalten (z.B. für Upgrades oder Konfigurationsänderungen).
