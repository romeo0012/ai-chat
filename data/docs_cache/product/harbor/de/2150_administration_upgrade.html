Wenn Sie eine Harbor-Instanz upgraden, die Sie mit Helm bereitgestellt haben, sehen Sie sich Upgrading Harbor Deployed with Helm an.

Beim Upgrade einer bestehenden Harbor-Instanz auf eine neue Version könnten Sie die Einstellungen in harbor.yml migrieren müssen. Da die Migration die Datenbankschema und die Einstellungen von harbor.yml verändern kann, sollten Sie immer Ihre Daten vor jeder Migration sichern.

Wichtige Upgrade-Hinweise

Bitte beachten Sie erneut, dass Sie Ihre Daten vor jeder Datenmigration sichern müssen.

In Harbor v2.9 verwenden Sie, wenn Sie eine externe Datenbank verwenden, sicherzustellen, dass die Version von PostgreSQL >= 12 ist.

Anmelden Sie sich bei dem Harbor-Host an und, wenn er noch laufen sollte, stoppen und entfernen Sie die aktuelle Harbor-Instanz.

cd harbor
docker compose down

Back up die aktuellen Dateien von Harbor, damit Sie, falls nötig, auf die aktuelle Version zurückrollen können.

mv harbor /my_backup_dir/harbor

Back up die Datenbank, die standardmäßig im Verzeichnis /data/database liegt.

Um die aktuellen Harbor-Dateien zu sichern, damit Sie, falls nötig, auf die aktuelle Version zurückrollen können. mv harbor /my_Backup_Dir/harbor
Speichere die Datenbank ab, die standardmäßig in dem Verzeichnis /data/database liegt. cp -r /data/database /my_Backup_Dir/
Hol dir das aktuelle Harbor-Release-Paket von https://github.com/goharbor/harbor/releases und extrahiere es. Weitere Informationen findest du unter Download des Harbor-Installer. Bevor du Harbor aktualisierst, führt eine Migration durch. Das Migrationswerkzeug befindet sich in den harbor-prepare-Tools, die als Docker-Bild geliefert werden. Du kannst das Bild von docker hub ziehen. Im folgenden Befehl:

docker pull goharbor/prepare:[tag]

Alternativ kannst du, wenn du ein offline-Installationspaket verwendest, das Image-Tarball aus dem offline-Installationspaket laden. Ersetze [tag] mit der neuen Harbor-Version, z.B. v1.10.0, im folgenden Befehl:

tar zxf <offline package>
docker image load -i harbor/harbor.[version].tar.gz

Kopiere den /path/to/old/harbor.yml in harbor.yml und aktualisiere es.

docker run -it --rm -v /:/hostfs goharbor/prepare:[tag] migrate -i ${path to harbor.yml}

HINWEIS: Die Schema-Aktualisierung und die Datenmigration der Datenbank wird von core bei Start von Harbor durchgeführt. Wenn die Migration fehlschlägt, prüfe den core-Log, um zu debuggen. Im ./harbor-Verzeichnis startet das ./install.sh-Skript die neue Harbor-Instanz. Um Harbor mit Trivy zu installieren, siehe Run the Installer Script für weitere Informationen.
