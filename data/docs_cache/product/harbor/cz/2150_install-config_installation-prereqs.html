Nastavení instalace Harbor
Harbor můžete nasadit na Docker host pomocí Docker Compose, nebo na Kubernetes cluster pomocí Helm.

Základní požadavky na zdroje
Níže uvedená tabulka ukazuje minimální a doporučené požadavky na zdroje pro nasazení Harbor.

| Zdroj | Minimální | Doporučené |
|-------|-----------|------------|
| CPU | 2 | 4 |
| Mem | 4 GB | 8 GB |
| Disk | 40 GB | 160 GB |

Požadavky na software
Níže uvedená tabulka uvádí software, který musí být nainstalován na cílový host.

| Software | Verze | Popis |
|----------|-------|-------|
| Docker Engine | > 20.10 | Nainstalovat Docker Engine |
| Docker Compose | docker compose > 2.3 | Docker Compose je součástí Docker Engine |
| OpenSSL | Nejnovější (volitelné) | Používá se k generování certifikátů a klíčů pro Harbor |

Porty, které musí být otevřeny
Harbor vyžaduje, aby následující porty byly otevřeny na cílovém hostu.

| Port | Protokol | Popis |
|------|----------|-------|
| 443 | HTTPS | Portal a jádro API přijímají požadavky HTTPS na tomto portu. Můžete změnit tento port v konfiguračním souboru. |
| 80 | HTTP | Portal a jádro API přijímají požadavky HTTP na tomto portu. Můžete změnit tento port v konfiguračním souboru. |
