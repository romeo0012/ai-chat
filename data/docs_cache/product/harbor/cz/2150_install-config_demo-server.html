Testování Harbor s Demo Serverem

Tým Harbor nabídl dostupný demo instance Harboru, kterou můžete použít k experimentování s Harbor a testování jeho funkcí. Při použití demo serveru, prosím si všimte podmínek použití. Podmínky použití Demo Serveru

Demo server je určen pouze pro experimentální použití, aby vám umožnil testovat funkce Harboru. Ne nahraňujte na demo serveru citlivé obrázky. Demo server není prostředí pro produkci. Tým Harboru není odpovědný za jakékoliv ztráty dat, funkce nebo služby, které mohou vzniknout z jeho použití. Demo server je čistě každých dvou dní. Demo server umožňuje pouze testovat funkce uživatele. Nemůžete testovat funkce správce. Chcete-li testovat funkce správce a pokročilé funkce, vytvořte vlastní instance Harboru. Ne nahrávejte obrázky s velikostí přes 100MB na demo server, protože má omezenou kapacitu úložiště. Pokud se při použití demo serveru vyskytne nějaký problém, otevřete problém na GitHubu nebo kontaktujte tým Harboru na Slacku.

Přístup k Demo Serveru
Pojďte na https://demo.goharbor.io. Klikněte na Registrovat se na účet. Vytvořte účet uživatele poskytnutím uživatelského jména, vaší e-mailové adresy, jména a hesla. Přihlaste se do rozhraní Harboru pomocí vytvořeného účtu. Prozkoumejte výchozí projekt, knihovnu. Klikněte na Nový projekt, abyste vytvořili vlastní projekt. Další informace o tom, jak vytvořit projekt, naleznete v článku Vytvoření projektu.

Použijte si vytvořené účet. Prozkoumejte výchozí projekt, knihovnu. Kliknutím na Nový projekt vytvořte svůj vlastní projekt. Informace o tom, jak vytvořit projekt, naleznete v článku Vytvořit projekt. Otevřete klienta Docker a přihlaste se k Harbor pomocí přihlašovacích údajů, které jste vytvořili výše.

docker login demo.goharbor.io

Vytvořte velmi jednoduchý Dockerfile s následujícími obsahy.

FROM busybox:latest

Vybudujte obrázek z tohoto Dockerfile a označte ho.

docker build -t demo.goharbor.io/your-project/test-image .

Vložte obrázek do vašeho projektu v Harbor.

docker push demo.goharbor.io/your-project/test-image

V rozhraní Harbor přejděte na Projects > your_project > Repositories, abyste mohli zobrazit obrazový repozitář, který jste do svého projektu v Harboru vložili.
