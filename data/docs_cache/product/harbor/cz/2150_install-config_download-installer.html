Stáhněte si instalační program Harbor
Můžete stáhnout instalační programy Harbor z stránky oficiálních vydání. Stáhněte si buď online instalační program nebo offline instalační program. Online instalační program: Online instalační program stahuje obrázky Harbor z Docker hub. Proto je instalační program velmi malý. Offline instalační program: Použijte offline instalační program, pokud host, na který nasazujete Harbor, nemá připojení k internetu. Offline instalační program obsahuje předem sestavené obrázky, takže je větší než online instalační program. Instalace probíhají velmi podobně pro online a offline instalační program. Stáhněte a rozbalte instalační program
Pojďte na stránku vydání Harbor. Stáhněte si online nebo offline instalační program pro verzi, kterou chcete nainstalovat. Volitelně stáhněte si odpovídající soubor *.asc, abyste mohli ověřit, že balíček je pravý. Soubor *.asc je soubor OpenPGP klíče. Provedete následující kroky k ověření, zda stažený balíček je pravý. Získáte veřejný klíč pro soubor *.asc.
gpg --keyserver hkps://keyserver.ubuntu.com --receive-keys 644FF454C0B4115C
Byli byste měli vidět zprávu "veřejný klíč 'Harbor-sign (Klíč pro podepisování staveb Harbor) <jiangd@vmware.com>' importován". Ověřte, zda balíček je pravý tím, že spustíte jednu z následujících příkazů. Online instalační program: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-online-installer-version.tgz.asc Offline instalační program: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-offline-installer-version.tgz.

Přeložení následujících příkazů. Instalační program online: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-online-installer-version.tgz.asc
Offline instalační program: gpg -v --keyserver hkps://keyserver.ubuntu.com --verify harbor-offline-installer-version.tgz.asc
Příkaz gpg ověří, že podpis balíčku odpovídá *.asc souboru klíče. Byste měli vidět potvrzení, že podpis je správný.

Použijte tar, aby se extrahoval instalační balíček:
Online instalační program: bash $ tar xzvf harbor-online-installer-version.tgz
Offline instalační program: bash $ tar xzvf harbor-offline-installer-version.tgz
Další kroky
Chcete-li zajistit bezpečnost připojení k Harboru, přečtěte si Nastavení přístupu HTTPS k Harboru.
Chcete-li nastavit svou instalaci Harboru, přečtěte si Nastavení souboru YML Harboru.
Poznámky k adresáři Instalační program
Můžete extrahovat instalační program Harboru do libovolného umístění.

Nastavte přístup k HTTPS k Harboru. Chcete-li konfigurovat své instalaci Harboru, přečtěte si Nastavení souboru YML Harboru. Poznámky k adresáři Instalátoru Můžete extrahovat instalační balíček Harboru do libovolného umístění. Uživatel, který spouští skript instalace, musí mít oprávnění k spouštění příkazů Docker (obvykle jako člen skupiny docker). Tento adresář se používá pouze pro instalaci a konfiguraci. Neobsahuje se zde trvalé data Harboru. Všechny služby Harboru běží v kontejnerech Dockeru a jejich data se ukládají do Dockerových objemů. Udržujte si tento adresář, abyste mohli později spravovat svůj instance Harboru (např. pro aktualizace nebo změny konfigurace).

Poznámka: Všechny technické termíny, kódy, příkazy, cesty k souborům, URL a formátování zůstávají v původním anglickém jazyce.
