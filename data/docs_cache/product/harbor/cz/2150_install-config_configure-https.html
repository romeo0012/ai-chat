Nastavte přístup HTTPS k Harboru
Důležité: Použití existujících třetích stranních certifikátů
Pokud už máte TLS certifikát a klíč od důvěryhodné autority (např. Let's Encrypt, DigiCert, GoDaddy), můžete přeskočit kroky generování vlastního certifikátu na této stránce. Prosim umístěte své certifikát a klíčové soubory na hostiteli Harboru a poskytněte jejich cesty v souboru harbor.yml, jak je popisováno v ./configure-yml-file.md. Tento je doporučený přístup pro všechny produkční prostředí. Výchozí nastavení Harboru neobsahuje certifikáty. Je možné nasadit Harbor bez zabezpečení, takže můžete se k němu připojit přes HTTP. Však použití HTTP je přijatelné pouze v uzavřených testovacích nebo vývojových prostředích, která nemají připojení k vnějšímu internetu. Použití HTTP v prostředích, která nejsou uzavřená, vystavuje riziko man-in-the-middle útoků. V produkčních prostředích vždy použijte HTTPS. Chcete-li nakonfigurovat HTTPS, musíte vytvořit certifikáty SSL. Můžete použít certifikáty, které jsou podepsané důvěryhodnou třetí stranou CA, nebo můžete použít vlastněné certifikáty. Tato část popisuje, jak pomocí OpenSSL vytvořit CA a jak pomocí vaší CA podepsat certifikát serveru a certifikát klienta. Můžete použít jiné CA poskytovatele, například Let's Encrypt. Následující postupy předpokládají, že doména vašeho registru Harboru je yourdomain.com a že její DNS záznam ukazuje na hostitele, na kterém běží Harbor.

Například Let’s Encrypt. Následující postupy předpokládají, že doména vašeho registru Harbor je yourdomain.com, a že její DNS záznamy ukazují na počítač, na kterém běží Harbor. Vytvořte Certifikát Autority Certifikát V produkčním prostředí byste měli získat certifikát od CA. V testovacím nebo vývojovém prostředí můžete vytvořit vlastní CA. Chcete-li vytvořit certifikát CA, spusťte následující příkazy. Vytvořte certifikát CA soukromý klíč. 

openssl genrsa -out ca.key 4096

Vytvořte certifikát CA. Upravte hodnoty v opci -subj, aby odpovídaly vaší organizaci. Pokud používáte FQDN pro připojení hostitele Harbor, musíte určit ho jako atribut jméno společnosti (CN). 
openssl req -x509 -new -nodes -sha512 -days 3650 \
    -subj "/C=CN/ST=Beijing/L=Beijing/O=example/OU=Personal/CN=MyPersonal Root CA" \
    -key ca.key \
    -out ca.crt

Vytvořte certifikát serveru. Certifikát obvykle obsahuje soubor .crt a soubor .key, například yourdomain.com.crt a yourdomain.com.key. Vytvořte soukromý klíč. 
openssl genrsa -out yourdomain.com.key 4096

Vytvořte žádost o podepsání certifikátu (CSR). Upravte hodnoty v opci -subj, aby odpovídaly vaší organizaci. Pokud používáte FQDN pro připojení hostitele Harbor, musíte určit ho jako atribut jméno společnosti (CN) a použít ho v názvech souborů klíče a CSR. 
openssl req -sha512 -new \
    -subj "/C=CN/ST=Beijing/L=Beijing/O=example/OU=Personal/CN=yourdomain.com" \
    -key yourdomain.com.key \
    -out yourdomain.com.csr

V připojení k vašemu hostiteli Harbor buďto FQDN nebo IP adresou, musíte vytvořit tento soubor, aby mohli být vytvořeny certifikát pro vaši hostitelnu Harbor, který odpovídá požadavkům na Název alternativy (SAN) a v3 rozšíření. Nahraďte záznamy DNS, aby odpovídaly vašemu doméně.

cat &gt; v3.ext &lt;&lt;-EOF
authorityKeyIdentifier=keyid,issuer
basicConstraints=CA:FALSE
keyUsage = digitalSignature, nonRepudiation, keyEncipherment, dataEncipherment
extendedKeyUsage = serverAuth
subjectAltName = @alt_names
[alt_names]
DNS.1=yourdomain.com
DNS.2=yourdomain
DNS.3=hostname
EOF

Použijte soubor v3.ext k vytvoření certifikátu pro vaši hostitelnu Harbor. Nahraďte názvy souborů v CSR a CRT v příkazech níže názvem vaší hostitelny Harbor.

openssl x509 -req -sha512 -days 3650 \
-extfile v3.ext \
-CA ca.crt -CAkey ca.key -CAcreateserial \
-in yourdomain.com.csr \
-out yourdomain.com.crt

Po vytvoření souborů ca.crt, yourdomain.com.crt a yourdomain.com.key pro vlastní certifikát bezpečnostní zásady, musíte je poskytnout Harbor a Docker daemonu. Vytvořte adresář pro certifikáty pro Harbor.

mkdir -p /etc/docker/certs.d/yourdomain.com
cp ca.crt yourdomain.com.crt yourdomain.com.key /etc/docker/certs.d/yourdomain.com/

Váš vlastní certifikát SSL, musíte ho poskytnout Harboru a Dockeru daemonu. Vytvořte adresář certifikátů pro Harbor. Adresář /data/cert/ je výchozí umístění, kde Harbor hledá své certifikáty, ale tento adresář neexistuje vždy v předem. Musíte ho vytvořit nejprve. 

sudo mkdir -p /data/cert/

Kopírujte certifikát Serveru a Klíč do adresáře Harboru. 
cp yourdomain.com.crt /data/cert/
sudo cp yourdomain.com.key /data/cert/

Nastavte Docker Daemon, aby důvěřoval certifikátu. Chcete-li umožnit Dockeru klientovi vytahovat a odesílat obrázky, musí se také Docker daemon důvěřovat certifikátu. Proto převéřte svůj certifikát z .crt na .cert, protože Docker daemon tento typ požaduje. 
openssl x509 -inform PEM -in yourdomain.com.crt -out yourdomain.com.cer

Vytvořte věnovný adresář pro vaši doménu Harboru a vložte všechny tři soubory certifikátů do něj. 
mkdir -p /etc/docker/certs.d/yourdomain.com/
cp yourdomain.com.cert /etc/docker/certs.d/yourdomain.com/
cp yourdomain.com.key /etc/docker/certs.d/yourdomain.com/
cp ca.crt /etc/docker/certs.d/yourdomain.com/

Restartujte Docker Engine. 
systemctl restart docker

Mohli byste potřebovali certifikát důvěřovat na úrovni operačního systému. Viz Troubleshooting Harbor Installation pro další informace. Následující příklad ilustruje konečnou strukturu adresářů Dockeru, který používá vaše vlastní certifikáty. 
/etc/docker/certs.d/
└── yourdomain.com:port
    ├── yourdomain.com.cert
    ├── yourdomain.com.key
    └── ca.crt

Cílevý adresář pro Docker s vašimi vlastními certifikáty. /etc/docker/certs.d/ └── yourdomain.com:port
├── yourdomain.com.cert
├── yourdomain.com.key
└── ca.crt

Nastavení nebo přizpůsobení Harboru
Pokud ještě nenastavili Harbor, podívejte se na Nastavení souboru YML Harboru pro informace o tom, jak nastavit Harbor tak, aby používal certifikáty, upravit atributy hostname a https v harbor.yml. Pokud již máte nasazený Harbor s HTTP a chcete ho přizpůsobit pro použití HTTPS, proveďte následující kroky. Spusťte skript prepare k povolení HTTPS. Harbor používá nginx instance jako reverzní proxy pro všechny služby. Používáte skript prepare k nakonfigurování nginx pro použití HTTPS. Skript prepare je v balíčku instalace Harboru, na stejné úrovni jako skript install.sh.
./prepare

Pokud je Harbor spuštěný, zastavte a odstraňte existující instance. Vaše data obrázků zůstávají v systému souborů, takže žádná data nejsou ztracena.
docker compose down -v
Obnovte Harbor: docker compose up -d

Ověření spojení HTTPS po nastavení HTTPS pro Harbor můžete ověřit provedením následujících kroků. Otevřete prohlížeč a zadejte https://yourdomain.com. Bylo by vám zobrazeno rozhraní Harboru. Některé prohlížeče mohou zobrazit varování, že Certifikátní autorita (CA) je neznámá. Toto se stává, když používáte vlastní CA, která není od důvěryhodné třetí strany CA. Můžete importovat CA do prohlížeče, aby se odstranilo varování.
