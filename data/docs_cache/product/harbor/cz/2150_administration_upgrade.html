Pokud aktualizujete instance Harboru, kterou jste nasadili pomocí Helmu, přečtěte si Upgrading Harbor Deployed with Helm.

Při aktualizaci existující instance Harboru na novější verzi můžete potřebovat migraci nastavení v harbor.yml. Migrace může upravit databáze schéma a nastavení harbor.yml, takže vždycky před migrací zabejte zálohu svých dat.

Důležité poznámky k aktualizaci
Opakujeme, musíte zabezpečit zálohu svých dat před každou migrací.

V verzi Harboru 2.9, pokud používáte vnější databázi, ujistěte se, že verze PostgreSQL je >= 12.

Aktualizace a migrace Harboru
Přihlaste se k hostiteli Harboru a, pokud je stále spuštěn, zastavte a odstraňte existující instance Harboru.

cd harbor
docker compose down

Zabejte zálohu souborů Harboru, abyste mohli vrátit se zpět na aktuální verzi, pokud bude to nutné.

mv harbor /my_backup_dir/harbor

Zabejte zálohu databáze, která se vztahem výchozí.

/data/database.

Přesuňte soubory Harbor tak, abyste mohli vrátil se zpět k aktuální verzi, pokud bude nutné.

mv harbor /můj_zásobník_záznamů/harbor

Zálohujte databázi, která se vzorově nachází v adresáři /data/database.

cp -r /data/database /můj_zásobník_záznamů/

Stáhněte si nejnovější balíček Harbor z https://github.com/goharbor/harbor/releases a rozbalte ho. Další informace naleznete v článku Stáhněte si instalační balíček Harbor. Než začnete s aktualizací Harbor, provedte migraci. Nástroj pro migraci je v harbor-prepare tools, který je dodáván jako obrázek Docker. Můžete ho stáhnout z Docker Hub. V následujícím příkazu:

docker pull goharbor/prepare:[tag]

Alternativně, pokud používáte instalační balíček offline, můžete ho zahrnout do obrázku Docker z balíčku offline instalátoru. Nahraďte [tag] novou verzí Harbor, například v1.10.0, v následujícím příkazu:

tar zxf <balíček offline> docker image load -i harbor/harbor.[verze].tar.gz

Kopírujte /cesta/k/starému/harbor.yml do harbor.yml a aktualizujte ho.

docker run -it --rm -v /:/hostfs goharbor/prepare:[tag] migrate -i ${cesta k harbor.yml}

POZOROVÁNÍ: Schéma aktualizace a migrace databáze je prováděna jádrem při spuštění Harbor. Pokud se migrace nezdaří, zkontrolujte záznamy jádra k ladění. V adresáři ./harbor spusťte skript ./install.sh, aby instaloval nový instance Harbor. K instalaci Harbor s Trivy, naleznete další informace v článku Spustit instalační skript. Pokud potřebujete vrátil se zpět k předchozí verzi Harbor, naleznete další informace v článku Vrátil se zpět z aktualizace.
