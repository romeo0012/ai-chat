Překlad prozatímního obsahu:

Začínáme
Tato sekce poskytuje přehled o tom, co je Apache Kafka, proč je užitečné a jak začít s jeho použitím.

Úvod
Apache Kafka je distribuovaný systém pro zpracování streamových dat. Je navržený pro zpracování velkých množin dat v reálném čase. Apache Kafka je open source a je podporován Apache Software Foundation.

Příklady použití
Apache Kafka může být použit pro širokou škálu úloh, včetně:

  • Zpracování reálných časových dat
  • Zpracování velkých množin dat
  • Zpracování dat v reálném čase
  • Zpracování dat v reálném čase z různých zdrojů
  • Zpracování dat v reálném čase pro analýzu a zpracování
  • Zpracování dat v reálném čase pro streamování

Rychlý start
Tady je rychlý start pro začátek práce s Apache Kafka:

  1. Stáhněte si Apache Kafka z [oficiální stránky Apache Kafka](https://kafka.apache.org/downloads).
  1. Nainstalujte Apache Kafka na svůj počítač.
  1. Spusťte Apache Kafka.
  1. Vytvořte téma a odešlete zprávu.
  1. Přijměte zprávu z tématu.

Ekosystém
Apache Kafka má velkou komunitu a bohatý ekosystém. Následující jsou některé z nejdůležitějších komponent:

  • Apache Kafka Connect: Apache Kafka Connect umožňuje připojit Apache Kafka k různým zdrojům dat a jímky.
  • Apache Kafka Streams: Apache Kafka Streams umožňuje zpracovat streamování dat v reálném čase.
  • Apache Kafka MirrorMaker: Apache Kafka MirrorMaker umožňuje synchronizovat data mezi různými Apache Kafka kluster.
  • Apache Kafka REST Proxy: Apache Kafka REST Proxy umožňuje přístup k Apache Kafka pomocí REST API.

Aktualizace KRaftu vs ZooKeeper
Apache Kafka používá KRaft pro správu dat a synchronizaci mezi klusterem. KRaft je alternativou k ZooKeeperu. KRaft je navržený pro vysokou dostupnost a vysokou škálovatelnost.

Kompatibilita
Apache Kafka je kompatibilní s různými verzemi Java.

Docker
Apache Kafka můžete spustit v Dockeru. Následující je příklad Docker Compose souboru pro spuštění Apache Kafka:

version: '3'
services:
  zookeeper:
    image: confluentinc/cp-zookeeper:5.5.0
    hostname: zookeeper
    container_name: zookeeper
    ports:
      - "2181:2181"
    environment:
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ZOOKEEPER_CLIENT_PORT: 2181
      KAFKA_ZOOKEEPER_TICK_TIME: 2000
  kafka:
    image: confluentinc/cp-kafka:5.5.0
    hostname: kafka
    container_name: kafka
    ports:
      - "9092:9092"
    environment:
      KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
      KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
      KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
      KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR: 1
      KAFKA_GROUP_INITIAL_REBALANCE_DELAY_MS: 1000
      KAFKA_JMX_PORT: 9999
      KAFKA_JMX_HOSTNAME: kafka
