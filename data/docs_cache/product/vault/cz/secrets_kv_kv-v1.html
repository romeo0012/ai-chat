KV tajemství pro vedení - verze 1

Tajemství KV je používáno k uložení libovolných tajemství do konfigurovaného fyzického úložiště pro Vault. Zapisování do klíče v základním zadávacím prostředí kv backend nahradí staré hodnoty; podpolí se nekombinují. Jména klíčů musí vždy být řetězce. Pokud zadáte neřetězcové hodnoty přímo prostřednictvím příkazového řádku, převede se na řetězce. Nicméně můžete uchovat neřetězcové hodnoty, zapsáním párů klíč/hodnota do Vault z JSON souboru nebo pomocí HTTP API. Tento tajemství engine respektuje rozlišení mezi schopnostmi vytváření a aktualizace v rámci ACL politik. Poznámka: Cesta a názvy klíčů nejsou zastrašovány nebo šifrované; pouze hodnoty nastavené na klíče. Neuskladujte citlivá informace jako součást cesty tajemství. Nastavení

Chcete-li povolit verzi 1 kv úložiště:
$ vault tajemství povolit -verze=1 kv

Použití
Po nakonfigurování tajemství engine a uživatele/počítače s Vault tokenem s odpovídajícím oprávněním, může vytvářet kredence. KV tajemství engine umožňuje zapisovat klíče s libovolnými hodnotami. Zapište libovolné data:
$ vault kv přidat kv/můj-tajemství můj-hodnota=s3kr3t Úspěch! Data napsána do: kv/můj-tajemství Čtěte libovolná data:
$ vault kv získat kv/můj-tajemství Klíč Hodnota --- ----- můj-hodnota s3kr3t Seznam klíčů:
$ vault kv seznam kv/ Klíče ---- můj-tajemství Smazání klíče:
$ vault kv odstranit kv/můj-tajemství Úspěch! Data smazána (pokud existovala) v: kv/můj-tajemství

Můžete také použít funkci hesla Vault pro vytváření libovolných hodnot.

TEXT v Čeština:
---- my-secret Odstranit klíč: $ vault kv delete kv/my-secret Úspěch! Data odstraněna (pokud existovala) v: kv/my-secret Můžete také využít funkci heslového zásobníku Vault pro generování libovolných hodnot. Napište heslovou politiku: $ vault write sys/policies/heslo/příklad politika=-<<EOF délka=20 pravidlo "charset" { charset = "abcdefghij0123456789" min-počet znaků = 1 } pravidlo "charset" { charset = "!@#$%^&*STUVWXYZ" min-počet znaků = 1 } EOF Napište data pomocí příkladové politiky: $ vault kv put kv/můj-generovaný-heslo \ heslo=$(vault read -field heslo sys/policies/heslo/příklad/generate) Zobrazte generovaná data: $ vault kv get kv/můj-generovaný-heslo ====== Data ====== Klíč Hodnota --- ----- heslo ^dajd609Xf8Zhac$dW24 TTLs V rozdílu od ostatních sekretních engineů neenforceuje sekretní engine KV TTL pro vypršení platnosti. Místo toho je lease_duration pouze nápovědou pro frekvenci, jak často konzumenti kontrolují novou hodnotu. Pokud poskytnete klíč ttl, sekretní engine KV použije tento hodnotu jako lease duration: $ vault kv put kv/můj-sekret ttl=30m hodnota=s3cr3t Úspěch! Data napsána do: kv/můj-sekret Ačkoliv je ttl nastaven, sekretní engine nikdy neodstraňuje data samostatně. TTL klíč je pouze poradní. Když čtete hodnotu s ttl, oba klíče ttl a interval aktualizace odražují hodnotu: $ vault kv get kv/můj-sekret Klíč Hodnota --- ----- hodnota s3cr3t ttl 30m API Sekretní engine KV má plnou API HTTP.
