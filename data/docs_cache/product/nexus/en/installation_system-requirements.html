Sonatype has not tested nor supported other operating systems.Use a dedicated user accountWe recommend using a dedicated operating system user account to run each unique process on a given host. The Nexus Repository process user must be able to create a valid shell.Do not run Nexus Repository as the root user.Required file handle limitsNexus Repository consumes more file handles than the default value allowed by Linux or MacOS operating systems.
