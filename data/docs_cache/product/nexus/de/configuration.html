Nexus Repository Administration – Sonatype Help

In diesem Abschnitt werden die Details zur Verwaltung des Nexus Repositorys erläutert. Diese Funktionen sind nur für autorisierte Nutzer zugänglich.

Verwaltungsmenu

Das Verwaltungsmenu befindet sich auf der linken Seite und enthält die folgenden Abschnitte:

  • Repository: Verwalten Sie alle Repositories und verwandte Konfigurationen wie Routing und Ziele.
  • Sicherheit: Konfigurieren Sie die Authentifizierung und Autorisierung von Benutzern.
  • IQ Server: Stellen Sie die Verbindung zum IQ Server für die Repository Firewall und die Sonatype Lifecycle Integration ein.
  • Support: Verwalten und überwachen Sie Ihr Nexus Repository mithilfe der Werkzeuge, die im Support-Abschnitt zu finden sind. Verpacken Sie einen Support-ZIP-Datei für Unterstützung bei der Sonatype Enterprise Support.
  • System: Allgemeine Konfiguration für Automatisierung und Benachrichtigungen.
