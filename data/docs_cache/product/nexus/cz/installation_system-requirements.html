Podpora pro antivirový software
Sonatype neoficiálně podporuje ani doporučuje používat antivirový software s Nexus Repository. Zkušenosti jsme s 10x delšími dobývacími dobami na serverech Windows a významným zpomalováním výkonu při použití antivirového software k monitorování adresáře instalace.

Podporované verze Java
Nexus Repository je testován a podporuje OpenJDK a vyžaduje Java 21. Nexus Repository je kompatibilní s oběma Intel a AMD architekturami CPU. Od verze 3.78.0 je do balíčku Nexus Repository zařazen doporučený JVM. Viz Matice kompatibility Java.

Výkon CPU je hlavně omezeno IO (disk a síť) místo CPU. Dostupné CPU budou mít vliv na delší běžící operace a počet vláken. Viz algoritmy alokace vláken webového kontejneru.

Požadavky na diskový prostor
Požadovaný diskový prostor pro Nexus Repository se liší podle velikosti a složitosti nasazení. Musíte mít k dispozici alespoň 4GB volného diskového prostoru vždy; pokud je volného diskového prostoru méně než 4GB, přešne se databáze do režimu pouze čtení.

Sonatype Nexus Repository vyžaduje diskový prostor pro dvě hlavní adresáře:

Adresář Aplikace - Velikost se mírně liší podle verze; k srpnu 2024 je asi 390MB. Je normální mít instalované na stejném hostiteli více adresářů aplikace při aktualizaci.
Adresář Data - Velikost se liší podle složitosti a formátů. Plánujte na velký diskový prostor. Poznamenejte si, že formáty jako Docker a Maven mohou využívat velké množství úložného prostoru (500GB snadno).
