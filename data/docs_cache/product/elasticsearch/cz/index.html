Elastic Docs / Reference Elasticsearch
Elasticsearch je rozložený vyhledávací a analýzovací engine, škálovatelný datový úložiště a databáze vektorů, postavený na Apache Lucene. Je optimizován pro rychlost a relevanci na produkční skalovacích zátěžích. Použijte Elasticsearch k vyhledávání, indexování, ukládání a analýze dat různých tvarů a velikostí v přibližně reálném čase.
