Varnish 6.6
Změny v Varnish 6.6

This text contains a list of changes and updates for Varnish, a caching HTTP reverse proxy server, and its VMODs (Varnish Modules). The list includes changes to the varnishd daemon, VCL (Varnish Configuration Language), logs, timeouts, and platform support. It also mentions new features and interface changes that may require adjustments for developers and VMOD authors. The text is structured in a way that each version of Varnish (7.5, 7.4, 7.3, 7.2, 7.1, 7.0, and 6.6) has its own section with the changes and updates specific to that version. The technical terms, code blocks, commands, file paths, and URLs are preserved as they are in the original text.
