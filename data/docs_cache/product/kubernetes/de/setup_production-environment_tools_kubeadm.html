Bootstrapping Cluster mit kubeadm

Installieren von kubeadm

Um kubeadm zu installieren, führen Sie die folgenden Schritte aus:

  1. Aktualisieren Sie Ihr System:

sudo apt-update
sudo apt-upgrade -y
  1. Registrieren Sie das Kubernetes-Repository:

sudo apt-mark hold apt-transport-https ca-certificates curl
curl -s https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo apt-key add -
echo "deb https://apt.kubernetes.io/ kubernetes-xenial main" | sudo tee /etc/apt/sources.list.d/kubernetes.list
  1. Installieren Sie kubeadm, kubelet und kubectl:

sudo apt-get update &amp;&amp; sudo apt-get install -y kubelet kubeadm kubectl

Probleme beheben mit kubeadm

Wenn Sie Probleme beim Installieren oder Konfigurieren von kubeadm haben, können Sie die folgenden Schritte ausführen, um Fehler zu beheben:

  1. Löschen Sie die vorhandenen kubeadm-Konfigurationen:

sudo kubeadm reset
  1. Starten Sie kubeadm neu:

sudo systemctl restart kubelet
  1. Überprüfen Sie die Statusmeldungen von kubeadm:

sudo kubeadm status

Erstellung eines Clusters mit kubeadm

Um einen Cluster mit kubeadm zu erstellen, führen Sie die folgenden Schritte aus:

  1. Starten Sie kubeadm auf einem Master-Knoten:

sudo kubeadm init --pod-network-cidr=10.244.0.0/16
  1. Verwenden Sie die Token-Informationen, um sich als Admin anzumelden:

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
  1. Installieren Sie ein Pod-Netzwerk:

kubectl apply -f https://docs.projectcalico.org/manifests/calico.yaml

Anpassen von Komponenten mit der kubeadm API

Mit der kubeadm API können Sie die Komponenten Ihres Clusters anpassen. Weitere Informationen finden Sie in der [Dokumentation](https://kubernetes.io/docs/reference/command-line-tools-reference/kubeadm/).

Optionen für eine hochverfügbare Topologie

Um einen hochverfügbaren Cluster mit kubeadm zu erstellen, können Sie die folgenden Optionen verwenden:

  1. Verwenden Sie mehrere Master-Knoten:

kubeadm init --pod-network-cidr=10.244.0.0/16 --control-plane-endpoint=&lt;IP-Master1&gt;:6443 --control-plane-endpoint=&lt;IP-Master2&gt;:6443
  1. Verwenden Sie ein hochverfügbares etcd-Cluster:

[Hier finden Sie Informationen zur Konfiguration eines hochverfügbaren etcd-Clusters mit kubeadm](#set-up-a-high-availability-etcd-cluster-with-kubeadm).

Erstellung eines hochverfügbaren Clusters mit kubeadm

Um einen hochverfügbaren Cluster mit kubeadm zu erstellen, können Sie die folgenden Schritte ausführen:

  1. Starten Sie kubeadm auf mehreren Master-Knoten:

kubeadm init --pod-network-cidr=10.244.0.0/16 --control-plane-endpoint=&lt;IP-Master1&gt;:6443 --control-plane-endpoint=&lt;IP-Master2&gt;:6443
  1. Verwenden Sie die Token-Informationen, um sich als Admin anzumelden:

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
  1. Installieren Sie ein Pod-Netzwerk:

kubectl apply -f https://docs.projectcalico.org/manifests/calico.yaml
  1. Konfigurieren Sie jeden kubelet in Ihrem Cluster mithilfe von kubeadm:

[Hier finden Sie Informationen zur Konfiguration jedes kubelet in Ihrem Cluster mithilfe von kubeadm](#configuring-each-kubelet-in-your-cluster-using-kubeadm).

Zwei-Stack-Unterstützung mit kubeadm

Mit kubeadm können Sie auch Dual-Stack-Cluster erstellen, die sowohl IPv4 als auch IPv6 unterstützen. Weitere Informationen finden Sie in der [Dokumentation](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/create-dual-stack-cluster/).
