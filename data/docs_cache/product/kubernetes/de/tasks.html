Aufgaben
Dieser Abschnitt der Kubernetes-Dokumentation enthält Seiten, die zeigen, wie einzelne Aufgaben durchgeführt werden. Eine Aufgaben-Seite zeigt, wie man etwas einmal, typischerweise durch eine kurze Folge von Schritten, durchführen kann. Wenn Sie eine Aufgaben-Seite schreiben möchten, sehen Sie sich bitte bei der Erstellung einer Dokumentation Pull Request an. Installieren von Werkzeugen Einrichten von Kubernetes-Werkzeugen auf Ihrem Computer. Verwalten einer Cluster Lernen Sie allgemeine Aufgaben für die Verwaltung einer Cluster kennen. Konfigurieren von Pods und Containern Durchführen Sie allgemeine Konfigurationsaufgaben für Pods und Containern. Monitoring, Logging und Debugging Einrichten Sie Monitoring und Logging, um eine Cluster oder einen containerisierten Anwendung zu troubleshooten. Verwalten von Kubernetes-Objekten Verwenden Sie den deklarativen und imperativen Paradigma, um mit der Kubernetes-API zu interagieren. Verwalten von Geheimnissen Verwalten Sie geheime Einstellungsdaten mithilfe von Geheimnissen. Speichern von Daten in Anwendungen Spezifizieren Sie Konfiguration und andere Daten für die Pods, die Ihre Arbeit lasten ausführen. Ausführen von Anwendungen Ausführen und verwalten Sie beide statische und stateful Anwendungen. Ausführen von Jobs Ausführen Sie Jobs mithilfe von parallelen Verarbeitungen. Zugriff auf Anwendungen in einer Cluster Konfigurieren Sie Load Balancing, Port-Weiterleitung oder setup Firewall oder DNS-Konfigurationen, um auf Anwendungen in einer Cluster zuzugreifen. Erweitern von Kubernetes Verstehen Sie fortgeschrittene Wege, um Ihren Kubernetes-Cluster an die Anforderungen Ihrer Arbeitsumgebung anzupassen. TLS Verstehen Sie, wie Sie den Verkehr innerhalb Ihrer Cluster mit Transport Layer Security (TLS) schützen können. Verwalten von Cluster-Daemons Durchführen Sie allgemeine Aufgaben für das Verwalten eines DaemonSets, wie z. B. eine rollende Aktualisierung.
