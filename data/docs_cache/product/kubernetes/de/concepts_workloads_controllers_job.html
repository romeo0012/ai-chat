Aufgaben
Aufgaben repräsentieren einmalige Aufgaben, die bis zum Abschluss ausgeführt und anschließend automatisch beendet werden. Eine Aufgabe erstellt eine oder mehrere Pods und versucht die Ausführung der Pods bis zu einer angegebenen Anzahl erfolgreich abgeschlossener Pods wiederholt. Während Pods erfolgreich abgeschlossen werden, überwacht die Aufgabe die erfolgreichen Abschlüsse. Wenn eine angegebene Anzahl erfolgreiche Abschlüsse erreicht ist, ist die Aufgabe (also die Task) abgeschlossen. Löschen einer Aufgabe führt zur Bereinigung der Pods, die sie erstellt hat. Unterbrechen einer Aufgabe führt zur Löschung der aktiven Pods, bis die Aufgabe wieder aufgenommen wird. Ein einfaches Beispiel ist die Erstellung einer einzigen Aufgabeobjekt, um sicherzustellen, dass eine Pod zu Ende ausgeführt wird. Das Aufgabeobjekt startet eine neue Pod, wenn die erste Pod fehlschlägt oder gelöscht wird (z.B. aufgrund eines Hardwarefehlers des Knoten oder eines Neustarts des Knotens). Man kann auch eine Aufgabe verwenden, um mehrere Pods parallel auszuführen. Wenn man eine Aufgabe (entweder eine einzelne Task oder mehrere parallel) auf einem Zeitplan ausführen möchte, siehe CronJob. Ausführung eines Beispiel-Jobs Hier ist ein Beispiel für eine Aufgabe-Konfiguration. Sie berechnet π bis zu 2000 Stellen und gibt es aus. Dies dauert ungefähr 10s.
controllers/job.yaml
apiVersion: batch/v1
kind: Job
metadata:
name: pi
spec:
template:
spec:
containers:
- name: pi
image: perl:5.34.0
command: ["perl", "-Mbignum=bpi", "-wle", "print bpi(2000)"]
restartPolicy: Never
backoffLimit: 4
Sie können das Beispiel mit folgendem Befehl ausführen:
kubectl apply -f https://kubernetes.io/examples/controllers/job.yaml
Das Ergebnis ist ähnlich wie folgt:
job.pi

Die Ausgabe ist ähnlich wie folgt:

name:         pi
namespace:    default
status:       Completed
succeeded:    1
failed:       0
startTime:    Wed, 01 Jan 2003 05:00:01 -0500
completionTime:    Wed, 01 Jan 2003 05:00:11 -0500
