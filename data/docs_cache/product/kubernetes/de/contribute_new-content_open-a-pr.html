Öffnen Sie einen Pull Request (PR)
Hinweis: Code-Entwickler: Wenn Sie eine neue Funktion für den nächsten Kubernetes-Release dokumentieren, sehen Sie sich bitte hier an: Dokumentieren Sie eine neue Funktion. Um neue Inhaltsseiten zu beitragen oder bestehende Inhaltsseiten zu verbessern, öffnen Sie einen Pull Request (PR). Stellen Sie sicher, dass Sie alle Anforderungen in der Abschnitt Before you begin befolgen. Wenn Ihre Änderung klein ist, oder Sie mit Git unbekannt sind, lesen Sie sich hier an: Änderungen mit GitHub, um zu erfahren, wie Sie eine Seite bearbeiten. Wenn Ihre Änderungen groß sind, lesen Sie sich hier an: Arbeiten Sie von einer lokalen Fork aus, um Änderungen lokal auf Ihrem Computer vorzunehmen.
