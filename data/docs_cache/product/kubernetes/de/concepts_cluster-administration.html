Clusterverwaltung
Untereinzelheiten, die für die Erstellung oder Verwaltung eines Kubernetes-Clusters relevant sind.
Die Clusterverwaltung Übersicht ist für jeden, der eine Kubernetes-Cluster erstellt oder verwaltet. Sie setzt ein Grundverständnis von Kernkonzepten von Kubernetes voraus.
Planung eines Clusters
Siehe die Leitfäden in Setup, um Beispiele für die Planung, Einrichtung und Konfiguration von Kubernetes-Clustern zu finden. Die in diesem Artikel aufgeführten Lösungen heißen distros.
Hinweis:
Nicht alle distros werden aktiv gepflegt. Wählen Sie distros aus, die mit einer neueren Version von Kubernetes getestet wurden.
Vor der Auswahl eines Leitfadens gibt es folgende Überlegungen:
Möchten Sie Kubernetes auf Ihrem Computer testen, oder möchten Sie eine hochverfügbar, mehr-Knoten-Cluster bauen? Wählen Sie die distros aus, die Ihren Bedürfnissen entsprechen.
Möchten Sie eine gehostete Kubernetes-Cluster, wie z.B. Google Kubernetes Engine, verwenden, oder möchten Sie Ihren eigenen Cluster hosten?
Ihr Cluster wird auf-premises oder in der Cloud (IaaS) liegen? Kubernetes unterstützt nicht direkt hybride Cluster. Stattdessen können Sie mehrere Cluster einrichten.
Wenn Sie Kubernetes auf-premises konfigurieren, überlegen Sie sich, welcher Netzwerkmodell am besten passt.
Möchten Sie Kubernetes auf "bare metal" Hardware oder virtuellen Maschinen (VMs) ausführen?
Möchten Sie einen Cluster ausführen, oder erwarten Sie aktive Entwicklung von Kubernetes-Projektcode? Wenn letzteres der Fall ist, wählen Sie eine aktiv entwickelte distro. Einige distros verwenden nur Binärveröffentlichungen, bieten aber eine größere Auswahl an.
Familiarisieren Sie sich mit den Komponenten, die für die Ausführung eines Clusters erforderlich sind.

Verwenden Sie nur binäre Veröffentlichungen, bieten Sie jedoch eine größere Auswahl an Optionen. Familiarisiere dich mit den Komponenten, die erforderlich sind, um einen Cluster auszuführen.
