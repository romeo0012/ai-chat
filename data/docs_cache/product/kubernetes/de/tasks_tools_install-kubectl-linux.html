Installieren und Konfigurieren von kubectl auf Linux

Vor dem Start
Sie müssen eine kubectl-Version verwenden, die maximal einen Minor-Version-Unterschied zu Ihrem Cluster hat. Beispielhaft kann ein v1.36-Client mit v1.35, v1.36 und v1.37 Control Planes kommunizieren. Durch Nutzung der aktuell kompatiblen Version von kubectl können unerwartete Probleme vermieden werden.

Installieren von kubectl auf Linux
Es gibt folgende Möglichkeiten, kubectl auf Linux zu installieren:

  • Installieren des kubectl-Binaries mit curl auf Linux
  • Installieren über native Paketverwaltung
  • Installieren über andere Paketverwaltung

Installieren des kubectl-Binaries mit curl auf Linux
Mit dem folgenden Befehl wird das neueste Release heruntergeladen:

x86-64 ARM64 

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl"

Hinweis:
Um eine spezifische Version herunterzuladen, ersetzen Sie den Teil des Befehls $(curl -L -s https://dl.k8s.io/release/stable.txt) durch die Version.
Beispielhaft, um Version 1.36.0 auf Linux x86-64 herunterzuladen, tippen Sie: 
curl -LO https://dl.k8s.io/release/v1.36.0/bin/linux/amd64/kubectl

Und für Linux ARM64: 
curl -LO https://dl.k8s.io/release/v1.36.0/bin/linux/arm64/kubectl

(Optional) Validieren des Binaries
Mit dem folgenden Befehl wird das kubectl-Binär validiert:

x86-64 ARM64 

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl.sha256"
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl.sha256"

Hinweis:
Um die Validierung zu aktivieren, müssen Sie die SHA256-Checksumme des heruntergeladenen Binaries mit der SHA256-Checksumme des Binaries auf der offiziellen Website vergleichen.

Hier sind die Verfahren zum Einrichten der Autovervollständigung für Bash, Fish und Zsh.

Einführung
Das kubectl-Vollständigkeitsskript für Bash kann mit dem Befehl kubectl completion bash erstellt werden. Durch das Einbinden des Vollständigkeitsskripts in Ihr Shell-Programm ermöglicht es automatische Vollständigkeitsfunktionen für kubectl.
Allerdings hängt das Vollständigkeitsskript von bash-completion ab, was bedeutet, dass Sie dieses Software-Paket zuerst installieren müssen (Sie können überprüfen, ob Sie bash-completion bereits installiert haben, indem Sie den Befehl type _init_completion ausführen).

Installieren Sie bash-completion
bash-completion wird von vielen Paketverwaltern bereitgestellt (siehe hier). Sie können es mit apt-get install bash-completion oder yum install bash-completion usw. installieren.
Die oben angegebenen Befehle erzeugen /usr/share/bash-completion/bash_completion, das Hauptskript von bash-completion. Je nachdem, welcher Paketverwalter Sie verwenden, müssen Sie dieses Skript manuell in Ihrer ~/.bashrc-Datei einbinden.
Um zu finden, laden Sie Ihre Shell neu und führen Sie den Befehl type _init_completion aus. Wenn der Befehl erfolgreich ist, sind Sie bereits bereit, andernfalls fügen Sie den folgenden Code Ihrer ~/.bashrc-Datei hinzu: 

source /usr/share/bash-completion/bash_completion

Laden Sie Ihre Shell neu und überprüfen Sie, ob bash-completion korrekt installiert ist, indem Sie den Befehl type _init_completion ausführen.

Aktivieren Sie kubectl-Vollständigkeitsfunktionen
Bash
Sie müssen jetzt sicherstellen, dass das kubectl-Vollständigkeitsskript in allen Ihren Shell-Sitzungen eingebunden wird. Es gibt zwei Möglichkeiten, wie Sie dies tun können:
Benutzer System 

echo 'source &lt;(kubectl completion bash)' &gt;&gt;~/.bashrc
kubectl completion bash | sudo tee /etc/bash_completion.d/kubectl &gt; /dev/null
sudo chmod a+r /etc/bash_completion.d/kubectl

oder
Zeige System 
kubectl completion bash | sudo tee /etc/bash_completion.d/kubectl &gt; /dev/null
sudo chmod a+r /etc/bash_completion.d/kubectl

Diese Befehle sichern sicher, dass das kubectl-Vollständigkeitsskript in Ihrer Shell-Umgebung eingebunden wird.

System echo 'source <(kubectl completion bash)' >>~/.bashrc
kubectl completion bash | sudo tee /etc/bash_completion.d/kubectl > /dev/null
sudo chmod a+r /etc/bash_completion.d/kubectl

Wenn Sie einen Alias für kubectl haben, können Sie die Shell-Vervollständigung so erweitern, dass sie mit diesem Alias funktioniert:
echo 'alias k=kubectl' >>~/.bashrc
echo 'complete -o default -F __start_kubectl k' >>~/.bashrc

Hinweis: bash-completion lässt alle Vervollständigungsskripte in /etc/bash_completion.d lesen. Beide Ansätze sind gleichwertig. Nachdem Sie Ihren Shell neu laden, sollte die Vervollständigung für kubectl funktionieren. Um die bash-Vervollständigung in der aktuellen Shell-Sitzung zu aktivieren, laden Sie die ~/.bashrc-Datei ein:
source ~/.bashrc

Hinweis: Die Vervollständigung für Fish erfordert kubectl 1.23 oder höher. Die kubectl-Vervollständigungsskript für Fish kann mit dem Befehl kubectl completion fish erstellt werden. Durch Sourcen des Vervollständigungsskripts in Ihrer Shell aktiviert die kubectl-Vervollständigung. Um dies in allen Ihren Shell-Sitzungen zu tun, fügen Sie den folgenden Befehl in Ihre ~/.config/fish/config.fish-Datei ein:
kubectl completion fish | source

Nachdem Sie Ihren Shell neu geladen haben, sollte die Vervollständigung für kubectl funktionieren.

Der kubectl-Vervollständigungsskript für Zsh kann mit dem Befehl kubectl completion zsh erstellt werden. Durch Sourcen des Vervollständigungsskripts in Ihrer Shell aktiviert die kubectl-Vervollständigung. Um dies in allen Ihren Shell-Sitzungen zu tun, fügen Sie den folgenden Befehl in Ihre ~/.zshrc-Datei ein:
source <(kubectl completion zsh)

Wenn Sie einen Alias für kubectl haben, funktioniert die kubectl-Vervollständigung automatisch mit diesem Alias.

In all Ihrer Shell-Sitzungen sollte Sie dem folgenden Code in Ihrer ~/.zshrc-Datei hinzufügen: 

source &lt;(kubectl completion zsh)

Wenn Sie für kubectl eine Alias definiert haben, funktioniert die Autovervollständigung von kubectl automatisch mit ihm. Nach dem Neustarten Ihrer Shell sollte die Autovervollständigung von kubectl funktionieren. Wenn Sie einen Fehler wie 2: command not found: compdef erhalten, sollten Sie dem Anfang Ihrer ~/.zshrc-Datei den folgenden Code hinzufügen: 
autoload -Uz compinit
