Lokalisieren Sie die Dokumentation von Kubernetes
Diese Seite zeigt Ihnen, wie Sie die Dokumentation für eine andere Sprache lokalisieren. Beitragen Sie zu einer bestehenden Lokalisierung
Sie können helfen, das Inhalt einer bestehenden Lokalisierung zu erweitern oder zu verbessern. Im Kubernetes Slack können Sie für jede Lokalisierung einen Kanal finden. Es gibt auch einen allgemeinen SIG Docs Localizations Slack-Kanal, an dem Sie sich melden können. Hinweis: Für weitere Details zur Beitragung zu einer bestimmten Lokalisierung suchen Sie nach einer lokalisierten Version dieser Seite. Ihre zwei-buchstabige Sprachcode suchen
Zunächst beachten Sie den ISO 639-1-Standard, um Ihre Lokalisierungssprachcode zu finden. Beispiel: Der zweibuchstabige Code für Koreanisch ist ko. Einige Sprachen verwenden eine klein geschriebene Version des Landescodes, wie sie im ISO-3166 definiert sind, zusammen mit ihren Sprachcodes. Beispiel: Der Sprachcode für Brasilianisches Portugiesisch ist pt-br. Forken und klonen das Repo
Zunächst erstellen Sie Ihre eigene Fork des Repositories kubernetes/website. Anschließend klonen Sie Ihre Fork und navigieren Sie dorthin: 

git clone https://github.com/&lt;username&gt;/website
cd website

Das Inhaltsverzeichnis des Websites enthält Unterverzeichnisse für jede Sprache. Die Lokalisierung, die Sie unterstützen möchten, befindet sich in content/<two-letter-code>. Änderungen Vorschlagen
Erstellen Sie oder aktualisieren Sie Ihre gewählte lokalisierte Seite auf Basis der englischen Originalversion. Weitere Informationen finden Sie unter lokalisieren Inhalt.
