Install Tools

Setzen Sie die Kubernetes-Tools auf Ihrem Computer ein.
Hinweis: Siehe die Seite zur Lernumgebung, um eine Übungsumgebung einzurichten.

kubectl
Das Kubernetes-Befehlszeilentool, kubectl, ermöglicht Ihnen, Befehle gegen Kubernetes-Cluster auszuführen. Mit kubectl können Sie Anwendungen bereitstellen, Ressourcen des Clusters inspecten und verwalten und Logs anzeigen. Weitere Informationen, einschließlich einer vollständigen Liste der kubectl-Befehle, finden Sie in der kubectl-Referenzdokumentation. kubectl ist auf einer Vielzahl von Linux-Plattformen, macOS und Windows installierbar. Ihre bevorzugte Betriebssystem-Variante finden Sie unten.

kubectl installieren auf Linux
kubectl installieren auf macOS
kubectl installieren auf Windows

kind
Mit kind können Sie Kubernetes auf Ihrem lokalen Computer ausführen. Dieses Tool erfordert, dass Sie entweder Docker oder Podman installiert haben.

Die Seite zum schnellen Start von kind zeigt Ihnen, was Sie tun müssen, um mit kind aufgerichtet zu werden.

View kind Quick Start Guide

minikube
Wie kind, minikube ist ein Tool, das Ihnen erlaubt, Kubernetes lokal auszuführen. minikube startet einen einzelnen oder mehreren lokalen Kubernetes-Cluster auf Ihrem persönlichen Computer (einschließlich Windows, macOS und Linux-PCs), damit Sie Kubernetes testen können oder für tägliche Entwicklungsarbeit.

Wenn Sie sich auf die Installation des Tools konzentrieren möchten, können Sie die offizielle Get Started!-Anleitung folgen.

View minikube Get Started! Guide

Nachdem Sie minikube eingerichtet haben, können Sie es verwenden, um eine Beispielanwendung auszuführen.

kubeadm
Mit dem kubeadm-Tool können Sie Kubernetes-Cluster erstellen und verwalten.

Werkzeug installiert. Ansehen Minikube Starten! Anleitung
Nachdem Sie Minikube funktioniert, können Sie es verwenden, um eine Beispielanwendung auszuführen.
kubeadm
Das kubeadm-Werkzeug kann verwendet werden, um Kubernetes-Cluster zu erstellen und zu verwalten. Es führt die notwendigen Aktionen durch, um ein mindestens funktionierendes, sicheres Cluster in einer benutzerfreundlichen Weise aufzubauen.
Installation von kubeadm zeigt Ihnen, wie Sie kubeadm installieren. Nach der Installation können Sie es verwenden, um einen Cluster zu erstellen.
