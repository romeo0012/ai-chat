minikube start

minikube ist lokales Kubernetes, das sich auf die Einfachheit des Lernens und Entwicklens für Kubernetes konzentriert. Alles, was Sie benötigen, ist Docker (oder eine ähnlich kompatible) Container- oder eine virtuelle Umgebung, und Kubernetes ist nur ein einziger Befehl entfernt: minikube start

Was Sie benötigen:

  • 2 CPUs oder mehr
  • 2GB freies Speicher
  • 20GB freies Speicherplatz
  • Internetverbindung
  • Container- oder virtueller Maschinenmanager, wie z.B.: Docker, QEMU, Hyperkit, Hyper-V, KVM, Parallels, Podman, VirtualBox, oder VMware Fusion/Workstation

Bereitstellung von Anwendungen
Erstelle eine Beispielbereitstellung und stelle sie auf Port 8080 bereit:
kubectl create deployment hello-minikube --image=kicbase/echo-server:1.0
kubectl expose deployment hello-minikube --type=NodePort --port=8080
Es kann einige Sekunden dauern, aber Ihre Bereitstellung wird bald aufgeführt werden, wenn Sie folgendes ausführen:
kubectl get services hello-minikube
Die einfachste Möglichkeit, diesen Dienst zu erreichen, ist es, minikube zu ermöglichen, Ihnen einen Webbrowser zu starten:
minikube service hello-minikube
Alternativ können Sie den Port mit kubectl umleiten:
kubectl port-forward service/hello-minikube 7080:8080
Tada! Ihre Anwendung ist jetzt auf http://localhost:7080/ verfügbar. Sie sollten in der Anwendungsausgabe die Anfragemetadata sehen können. Versuche den Pfad der Anfrage zu ändern und beobachte die Änderungen. Ähnlich können Sie eine POST-Anfrage ausführen und die Anfragekörperausgabe in der Ausgabe anzeigen. Um auf eine LoadBalancer-Bereitstellung zuzugreifen, verwenden Sie den Befehl "minikube tunnel". Hier ist ein Beispiel für eine Bereitstellung:

kubectl create deployment balanced --image=kicbase/echo-server:1.0

In einer anderen Konsole starten Sie den Tunnel, um eine routable IP für die ‘balanced’-Bereitstellung zu erhalten:

Um die routable IP zu finden, führen Sie diesen Befehl aus und betrachten Sie die EXTERNAL-IP-Spalte:

kubectl get services balanced

Ihre Bereitstellung ist jetzt unter <EXTERNAL-IP>:8080 verfügbar.

Aktivieren Sie den ingress-Addon:

minikube addons enable ingress

Hier ist ein Beispiel für einfache echo-server-Dienste und ein Ingress-Objekt, um diese Dienste zu routen.

apiVersion: v1
kind: Pod
metadata:
  name: foo-app
  labels:
    app: foo
spec:
  containers:
  - name: foo-app
    image: 'kicbase/echo-server:1.0'


apiVersion: v1
kind: Service
metadata:
  name: foo-service
spec:
  selector: app: foo
  ports:
  - port: 8080


apiVersion: v1
kind: Pod
metadata:
  name: bar-app
  labels:
    app: bar
spec:
  containers:
  - name: bar-app
    image: 'kicbase/echo-server:1.0'


apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: example-ingress
spec:
  rules:
  - http:
      paths:
      - pathType: Prefix
        path: /foo
        backend:
          service:
            name: foo-service
            port:
              number: 8080
      - pathType: Prefix
        path: /bar
        backend:
          service:
            name: bar-service
            port:
              number: 8080

Führen Sie die Inhalte aus:

kubectl apply -f &lt;URL&gt;

Um die Inhalte aus einer Datei anzuwenden, ersetzen Sie <URL> durch den Pfad zur Datei.

Hinweis für Nutzer von Docker Desktop: Um die Ingress-Funktion zu aktivieren, müssen Sie ein neues Terminalfenster öffnen und minikube tunnel ausführen und in den folgenden Schritt 127.0.0.1 anstelle von <IP_oben> verwenden. Jetzt überprüfen Sie, ob die Ingress-Funktion funktioniert

Verwalten Ihrer Cluster

Pause: Kubernetes ohne Auswirkung auf ausgeführte Anwendungen: 

minikube pause

Wiederaufnahme einer pausierter Instanz: 

minikube unpause

Halt: 

minikube stop

Ändern des Standard-Speicherlimits (erfordert einen Neustart): 

minikube config set memory 9001

Durchsuchen des Katalogs leicht installierbarer Kubernetes-Dienste: 

minikube addons list

Erstellen einer zweiten Cluster-Instanz mit einem älteren Kubernetes-Release: 

minikube start -p aged --kubernetes-version=v1.34.0

Löschen aller minikube-Cluster: 

minikube delete --all
