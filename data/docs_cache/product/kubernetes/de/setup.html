Anfänge

Dieser Abschnitt listet die verschiedenen Möglichkeiten auf, Kubernetes einzurichten und auszuführen. Wenn Sie Kubernetes installieren, wählen Sie einen Installationstyp aufgrund: der Wartung, der Sicherheit, der Kontrolle, der verfügbaren Ressourcen und der Fachkenntnisse, die erforderlich sind, um einen Cluster zu betreiben und zu verwalten. Sie können Kubernetes herunterladen, um einen Kubernetes-Cluster auf einem lokalen Rechner, in der Cloud oder für Ihren eigenen Datacenter zu bereitstellen. Mehrere Kubernetes-Komponenten wie z.B. kube-apiserver oder kube-proxy können auch als Container-Images innerhalb des Clusters bereitgestellt werden. Es wird empfohlen, Kubernetes-Komponenten als Container-Images zu betreiben, wo immer möglich, und Kubernetes sollte diese Komponenten verwalten. Komponenten, die Containers ausführen - insbesondere der kubelet - können in dieser Kategorie nicht enthalten sein. Wenn Sie kein Kubernetes-Cluster selbst verwalten möchten, könnten Sie eine verwaltete Dienstleistung wählen, einschließlich zertifizierter Plattformen. Es gibt auch andere standardisierte und benutzerdefinierte Lösungen für einen weiten Bereich von Cloud- und Bare-Metal-Umgebungen.

Lernumgebung

Wenn Sie Kubernetes lernen, verwenden Sie die von der Kubernetes-Community unterstützten Werkzeuge, oder Werkzeuge aus dem Ökosystem, um einen Kubernetes-Cluster auf einem lokalen Rechner einzurichten. Weitere Informationen finden Sie unter Learning environment

Produktionsumgebung

Wenn Sie eine Lösung für eine Produktionsumgebung bewerten, überlegen Sie, welche Aspekte des Betriebs eines Kubernetes-Clusters (oder Abstraktionen) Sie selbst verwalten möchten und welche Sie einem Anbieter überlassen möchten.
