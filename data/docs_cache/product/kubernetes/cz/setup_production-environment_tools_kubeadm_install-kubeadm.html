Kontrolujte, zda je MAC adresa a product_uuid jedinečná pro každý uzel.

Můžete získat MAC adresu sítových rozhraní pomocí příkazu ip link nebo ifconfig -a

Product_uuid můžete kontrolovat pomocí příkazu sudo cat /sys/class/dmi/id/product_uuid

Ve velmi vysoké míře je pravděpodobné, že hardware zařízení mají jedinečné adresy, although některé virtuální stroje mohou mít shodné hodnoty. Kubernetes používá tyto hodnoty k jedinečné identifikaci uzlů v clusteru. Pokud tyto hodnoty nejsou jedinečné pro každý uzel, proces instalace může selhat.

Kontrolujte síťová rozhraní

Pokud máte více než jedno síťové rozhraní, a pokud komponenty Kubernetes nejsou dosažitelné po výchozí trase, doporučujeme vám přidat IP trasu(y), aby adresy Kubernetes clusteru procházely přes vhodné rozhraní.

Kontrolujte požadované porty

Tato požadovaná porta musí být otevřena, aby se mohly komponenty Kubernetes komunikovat mezi sebou. Můžete použít nástroje jako netcat, aby zjistili, zda port je otevřen. Například:

nc 127.0.0.1 6443 -zv -w 2

Plug-in pro sítě podle vašeho volby může také vyžadovat, aby určité porty byly otevřeny.

Pro kontrolu, zda je port otevřený, můžete použít nástroj netcat. Například: 

nc 127.0.0.1 6443 -zv -w 2

Podle toho, jaký podsítový plugin používáte, mohou být nutné určité porty otevřené. Protože to se liší u každého podsítového pluginu, prosím se podívejte na dokumentaci pluginů, abyste se dozvěděli, jaké porty potřebují.

Změna konfigurace
Výchozí chování kubeletu je, aby se nezapočítal, pokud je na uzlu detekováno zaměnitelné paměti. Toto znamená, že se musí zaměnitelné paměti buď vypnout nebo tolerovat kubeletem.
Chcete-li tolerovat zaměnitelné paměti, přidejte failSwapOn: false do konfigurace kubeletu nebo jako argument příkazu. Poznámka: i když je failSwapOn: false poskytnut, pracovní zátěže nemají přístup k zaměnitelné paměti v případě výchozího nastavení. To můžete změnit nastavením chování zaměnitelné paměti, opět v konfiguračním souboru kubeletu. Chcete-li používat zaměnitelné paměti, nastavte chování zaměnitelné paměti jiným nastavením než výchozí nastavení NoSwap. Další podrobnosti naleznete v článku Zaměnitelné paměti.

Zapnutí nebo vypnutí zaměnitelné paměti
Chcete-li zaměnitelnou paměť zapnout, můžete použít příkaz sudo swapoff -a k dočasnému zablokování zaměnitelné paměti. Chcete-li si toto změnit trvalé po rebootu, ujistěte se, že je zaměnitelná paměť vypnuta v konfiguračních souborech, jako je /etc/fstab, systemd.swap, podle toho, jaká byla konfigurace na vašem systému.

Instalace runtime kontaineru
Chcete-li spouštět kontainery v Podech, používá Kubernetes runtime kontaineru.
Výchozí nastavení Kubernetesu je, aby používalo rozhraní pro práci s kontainery (CRI), aby se mohlo připojit k vašemu zvolenému runtime kontaineru.
Pokud nezadáte runtime, kubeadm automaticky zkoumá instalovaný runtime kontaineru, procházejícím seznamem známých koncových bodů.

Instalace kubeadm, kubelet a kubectl
Instalujete tyto balíčky na všech vašich počítačích:
kubeadm: příkaz k inicializaci clusteru.
kubelet: komponenta, která běží na všech počítačích v clusteru a provádí věci jako spouštění podů a kontejnerů.
kubectl: příkazový řádek pro komunikaci s vaším clusterem.
 cluster.kubelet: Komponenta, která běží na všech počítačích v vašem clusteru a provádí činnosti jako spouštění podů a kontejnerů.kubectl: příkazová řádka pro komunikaci s vaším clusterem.kubeadm nebude instalovat nebo spravovat kubelet ani kubectl pro vás, takže budete muset zajistit, aby odpovídaly verzi Kubernetes control plane, kterou chcete kubeadm instalovat. Pokud to neudělejete, je riziko vzniku skewa verzí, který může vést k neočekávanému, chybějícímu chování. Nicméně, malý skew verzí mezi kubeletem a control plane je podporován, ale verze kubeletu nikdy nesmí přesáhnout verzi API serveru. Například kubelet běžící na verzi 1.7.0 by měl být plně kompatibilní s API serverem verze 1.8.0, ale to neplatí v opačném směru.Další informace o instalaci kubectl naleznete zde: Installace a nastavení kubectlVarování: Tyto instrukce vyloučí všechny balíčky Kubernetes z jakékoliv aktualizace systému. Poznámka: V předchozích verzích než Debian 12 a Ubuntu 22.04 se adresář /etc/apt/keyrings výchozí nevytvoří a by měl být vytvořen před curl příkazem.Přidejte odpovídající Kubernetes repozitář APT. Prosím poznamenejte si, že tento repozitář obsahuje balíčky pouze pro Kubernetes 1.36; pro ostatní menší verze Kubernetes je třeba změnit menší verzi Kubernetes v URL na odpovídající verzi (věnujte pozornost tomu, že čtete dokumentaci pro verzi Kubernetes, kterou plánujete nainstalovat).

Toto přepsává jakékoliv existující konfigurace v /etc/apt/sources.list.d/kubernetes.list

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.36/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list

Nastavte SELinux v režimu permisivním (efektivně ho vypnete)
bash
sudo setenforce 0
sudo sed -i 's/^SELINUX=enforcing$/SELINUX=permissive/' /etc/selinux/config 
Pozor: Nastavení SELinux v režimu permisivním pomocí příkazu setenforce 0 a sed ... efektivně ho vypne. Toto je nutné, aby kontejnery mohly přistupovat k hostitelskému souborovému systému; například některé clusterové sítě pluginů vyžadují to. Musíte to udělat, dokud nebude SELinux podporován v kubeletu.
Můžete SELinux zanechat zapnutým, pokud vímete, jak ho nakonfigurovat, ale to může vyžadovat nastavení, která není podporována kubeadm.
Přidejte repozitář Kubernetes pro yum. Parametr exclude v definici repozitáře zajistí, že balíčky související s Kubernetes nebudou aktualizovány při spuštění příkazu yum update, protože je nutné následovat speciální postup pro aktualizaci Kubernetes. Prosím poznamenejte si, že tento repozitář obsahuje balíčky pouze pro Kubernetes 1.36; pro ostatní minor verze Kubernetes musíte změnit minor verzi v URL, aby odpovídala vaší požadované minor verzi (vyhledejte také dokumentaci pro verzi Kubernetes, kterou plánujete nainstalovat).
Toto přepsává jakékoliv existující konfigurace v /etc/yum.repos.d/kubernetes.repo
bash
cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io
exclude=kubelet kubeadm kubectl
repo_gpgcheck=1
repo_gpgcheck_exclude=kubernetes$
EOF

Nastavení cgroup driver
Oba container runtime a kubelet mají vlastnost s názvem "cgroup driver", která je důležitá pro správu cgroup na Linuxových počítačích.

Varování: Odpovídající cgroup driver container runtime a kubelet musí být nastaveny nebo jinak se proces kubelet nezdaří.Viz Nastavení cgroup driver pro další podrobnosti.
