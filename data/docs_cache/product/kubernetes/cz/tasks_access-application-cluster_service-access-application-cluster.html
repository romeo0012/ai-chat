Použití služby k přístupu k aplikaci v clusteru
Tato stránka ukazuje, jak vytvořit objekt služby Kubernetes, který mohou externí klienti použít k přístupu k aplikaci běžící v clusteru. Služba poskytuje rozložení zátěže pro aplikaci, která má dvě běžící instanci.
Než začnete
Musíte mít Kubernetes cluster a nástroj kubectl pro příkazovou řadu musí být nakonfigurován k komunikaci s vaším clusterem. Doporučujeme spustit tento kurz na clusteru s alespoň dvěma uzly, které nejsou hosty řídícího uzlu. Pokud ještě nemáte cluster, můžete ho vytvořit pomocí minikube nebo můžete použít jeden z těchto Kubernetes playgroundů:

Vytváření služby pro aplikaci běžící v dvou pod
Zde je konfigurační soubor pro aplikaci Deployment:
service/access/hello-application.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
název: hello-world
spec:
selektor:
label: run: load-balancer-example
replicas: 2
template:
metadata:
label: run: load-balancer-example
spec:
kontainer:
- název: hello-world
image: us-docker.pkg.dev/google-samples/containers/gke/hello-app:2.0
porty:
- containerPort: 8080
protocol: TCP
Spusťte aplikaci World Hello v clusteru:
Vytvořte aplikaci Deployment pomocí souboru výše:
kubectl apply -f https://k8s.

TCP Spusťte aplikaci "Hello World" ve vašem clusteru: Vytvořte nasazení aplikace pomocí souboru výše: 

kubectl apply -f https://k8s.io/examples/service/access/hello-application.yaml

Tento příkaz vytvoří Nasazení a spojený ReplicaSet. ReplicaSet má dva Pods, každý z nich spouští aplikaci "Hello World". Zobrazte informace o Nasazení: 
kubectl get deployments hello-world
kubectl describe deployments hello-world

Zobrazte informace o Vašich objektech ReplicaSet: 
kubectl get replicasets
kubectl describe replicasets

Vytvořte objekt Service, který vystaví nasazení: 
kubectl expose deployment hello-world --type=NodePort --name=example-service

Zobrazte informace o Service: 
kubectl describe services example-service

Výstup je podobný tomuto: 
Název: example-service
Prostor: výchozí
Značky: run=load-balancer-example
Anotace: &lt;žádné&gt;
Selektor: run=load-balancer-example
Typ: NodePort
IP: 10.32.0.16
Port: &lt;neupraveno&gt; 8080/TCP
TargetPort: 8080/TCP
NodePort: &lt;neupraveno&gt; 31496/TCP
Endpoints: 10.200.1.4:8080,10.200.2.5:8080
Sesízní vazba: Žádná
Události: &lt;žádné&gt;

Zapište si hodnotu NodePort pro Service. Například v předchozím výstupu je hodnota NodePort 31496.Zobrazte pods, které spouští aplikaci "Hello World": 
kubectl get pods --selector="run=load-balancer-example" --output=wide

Výstup je podobný tomuto: 
Jméno Připojeno Stav ... IP NODE
hello-world-2895499144-bsbk5 1/1 Běží ... 10.200.1.4

Přeložte následující text z angličtiny do češtiny. Pouze přeložte prozaický text. Zachovejte technické termíny, bloky kódu, příkazy, cesty k souborům a adresy URL v originální podobě. Zachovejte strukturu odstavců.

TEXT:
get pods --selector="run=load-balancer-example" --output=wide The output is similar to this:
NAME READY STATUS ... IP NODE
hello-world-2895499144-bsbk5 1/1 Running ... 10.200.1.4 worker1
hello-world-2895499144-m1pwt 1/1 Running ... 10.200.2.5 worker2

Získání veřejné IP adresy jednoho z vašich uzlů, který spouští pod Hello World, závisí na tom, jak jste nastavili cluster. Například pokud používáte Minikube, můžete vidět IP adresu uzlu spuštěním příkazu kubectl cluster-info. Pokud používáte Google Compute Engine instances, můžete použít příkaz gcloud compute instances list, abyste viděli veřejné adresy vašich uzlů.
Na vašem zvoleném uzlu vytvořte pravidlo firewallu, které umožňuje TCP provoz na vašem uzlovém portu. Například pokud má Vaše služba hodnotu NodePort 31568, vytvořte pravidlo firewallu, které umožňuje TCP provoz na portu 31568. Různé cloudové poskytovatele nabízejí různé způsoby konfigurace pravidel firewallu.
Použijte IP adresu uzlu a uzlový port k přístupu k aplikaci Hello World:
curl http://<public-node-ip>:<node-port>
kde <public-node-ip> je veřejná IP adresa vašeho uzlu, a <node-port> je hodnota NodePort pro vaši službu. Odpověď na úspěšnou žádost je zpráva:
Hello, world! Version: 2.0.0 Hostname: hello-world-cdd4458f4-m47c8

Zrušení

Chcete-li odstranit službu, zadejte následující příkaz: 

kubectl delete services example-service

Chcete-li odstranit nasazení, ReplicaSet a Pods, která spouští aplikaci Hello World, zadejte následující příkaz: 

kubectl delete deployment hello-world
