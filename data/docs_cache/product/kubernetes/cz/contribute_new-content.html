Základní informace o přispívání

  • Zapište dokumenty v Markdownu a vytvořte Kubernetes web stránky pomocí Hugo.
  • Kubernetes dokumentace používá CommonMark jako svůj typ Markdownu.
  • Zdroj je na GitHubu.
  • Kubernetes dokumentace najdete na /content/en/docs/.

Tento diagram ukazuje informace, které byste měli znát před tím, než začnete přispívat.

  • Podepište CLA CNCF.
  • Vyberte Git větev.
  • Každý PR obsahuje jeden jazyk.
  • Stáhněte si nástroje pro přispěvatele.
