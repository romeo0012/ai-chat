Nainstalování a nastavení kubectl na Linux
Před tím, než začnete
Musíte použít verzi kubectl, která je v jedné menší verzní rozdílnosti od vašeho clusteru. Například verze v1.36 klienta může komunikovat s control planes verzí v1.35, v1.36 a v1.37. Použití nejnovější kompatibilní verze kubectl pomáhá vyhnout se neočekávaným problémům.

Nainstalovat kubectl na Linux
Následující metody existují pro nainstalování kubectl na Linux:

Nainstalovat kubectl binář pomocí curl na Linux

Stáhněte si nejnovější vydání pomocí následujícího příkazu:
x86-64 ARM64 curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl"

Poznámka:
Chcete-li stáhnout konkrétní verzi, nahraďte část $(curl -L -s https://dl.k8s.io/release/stable.txt) příkazu konkrétní verzí.
Například pro stahování verze 1.36.0 na Linux x86-64, zadejte:
curl -LO https://dl.k8s.io/release/v1.36.0/bin/linux/amd64/kubectl
A pro Linux ARM64, zadejte:
curl -LO https://dl.k8s.io/release/v1.36.0/bin/linux/arm64/kubectl

(Volitelné) Ověření bináře
Stáhněte si soubor kontrolního souhrnu:

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/arm64/kubectl.sha256"

Instalace pomocí jiného systému správy balíčků Snap Homebrew
Pokud jste na Ubuntu nebo jiné Linuxové distribuci, která podporuje správce balíčků snap, je kubectl dostupný jako aplikace snap.

Ověřte konfiguraci kubectl
Chcete-li, aby kubectl nalezl a přístup k Kubernetesu clusteru, potřebuje soubor kubeconfig, který se vytvoří automaticky při vytvoření clusteru pomocí kube-up.sh nebo úspěšném nasazení Minikube clusteru. Výchozí umístění kubectl konfigurace je ~/.kube/config.

Ověřte, zda je kubectl správně konfigurován tím, že získáte stav clusteru:
kubectl cluster-info

Pokud zobrazíte odpověď URL, kubectl je správně konfigurován k přístupu k vašemu clusteru.

Pokud zobrazíte zprávu podobnou následující, kubectl není správně konfigurován nebo není schopen se připojit k Kubernetesu clusteru.
Chyba připojení k serveru <server-name:port> - zadali jste správný hostitel nebo port?

Není nakonfigurovaný správně nebo není schopný se připojit k clusteru Kubernetes. Odmítl se připojit k serveru <server-name:port> - zda jste určili správný hostitel nebo port? Například pokud chcete spustit cluster Kubernetes na svém počítači (místně), musíte nainstalovat nástroj Minikube nejprve a poté znovu spustit uvedené příkazy.Pokud se kubectl cluster-info vrátí odpověď URL, ale nemůžete přistupovat k vašemu clusteru, ověřte, zda je nakonfigurovaný správně pomocí následujícího příkazu:

kubectl cluster-info dump

Volitelná konfigurace a pluginy kubectl

Kubectl poskytuje podporu autodokončování pro Bash, Zsh, Fish a PowerShell, což může zvýšit efektivnost.

Níže jsou postupy k nastavení autodokončování pro Bash, Fish a Zsh.

Úvod

Kubectl kompletní skript pro Bash můžete vytvořit pomocí příkazu kubectl completion bash.

Ryby a Zsh. Bash Fish Zsh

Úvod

Skript na dokončení kubectl pro Bash lze vytvořit pomocí příkazu kubectl completion bash. Sourcing kompletní skript v shellu umožní autodokončování kubectl.

Avšak skript závisí na bash-completion, což znamená, že musíte tento software nejprve nainstalovat (můžete zkontrolovat, zda již máte nainstalovaný bash-completion tím, že spustíte příkaz type _init_completion).

Instalace bash-completion

bash-completion je poskytován mnoha package managerům (viz zde). Můžete ho nainstalovat pomocí příkazu apt-get install bash-completion nebo yum install bash-completion, atd.

Tyto příkazy vytvoří /usr/share/bash-completion/bash_completion, který je hlavní skript bash-completion. V závislosti na package manageru musíte ručně sourcing tento soubor do vašeho ~/.bashrc souboru.

Chcete-li to zjistit, obnovte svůj shell a spusťte příkaz type _init_completion. Pokud příkaz úspěšně funguje, je již nastaveno, jinak přidejte následující do svého ~/.bashrc souboru:

source /usr/share/bash-completion/bash_completion

Obnovte svůj shell a ověřte, že bash-completion je správně nainstalováno tím, že spustíte příkaz type _init_completion.

Povolení autodokončování kubectl

Bash

Nyní musíte zajistit, aby skript kubectl completion byl sourced v každé sesíoni shellu. Můžete to provést dvěma způsoby:

  1. Uživatel

echo 'source <(kubectl completion bash)' >>~/.bashrc

  1. Systém

kubectl completion bash | sudo tee /etc/bash_completion.d/kubectl > /dev/null
sudo chmod a+r /etc/bash_completion.d/kubectl

Tento skript kubectl completion je nyní sourced v každé sesíoni shellu.

Systém echo 'source <(kubectl completion bash)' >>~/.bashrc
kubectl completion bash | sudo tee /etc/bash_completion.d/kubectl > /dev/null
sudo chmod a+r /etc/bash_completion.d/kubectl
Pokud máte alias pro kubectl, můžete rozšířit dokončování pro toto alias:
echo 'alias k=kubectl' >>~/.bashrc
echo 'complete -o default -F __start_kubectl k' >>~/.bashrc

Poznámka: bash-completion zpracovává všechny dokončovací skripty v /etc/bash_completion.d. Obě metody jsou ekvivalentní. Po obnovení shellu by měla být funkce dokončování kubectlu pracovat. Chcete-li povolit dokončování bashu v aktuálním okně shellu, zadejte následující příkaz:
source ~/.bashrc

Poznámka: Dokončování pro Fish vyžaduje kubectl 1.23 nebo novější verzi. Skript dokončování kubectl pro Fish můžete vytvořit pomocí příkazu kubectl completion fish. Sourcing kompletní skript do vašeho shellu povolí dokončování kubectl. Chcete-li to provést v všech vašich shellových sesíích, přidejte následující řádek do vašeho ~/.config/fish/config.fish souboru:
kubectl completion fish | source

Po obnovení shellu by měla být funkce dokončování kubectl pracovat.

Skript dokončování kubectl pro Zsh můžete vytvořit pomocí příkazu kubectl completion zsh. Sourcing kompletní skript do vašeho shellu povolí dokončování kubectl. Chcete-li to provést v všech vašich shellových sesíích, přidejte následující do vašeho ~/.zshrc souboru:
source <(kubectl completion zsh)

Pokud máte alias pro kubectl, dokončování kubectl automaticky funguje s tímto aliasem.

Všechny vaše shellové relace si upravte tak, aby se v souboru ~/.zshrc přidalo následující: 

source &lt;(kubectl completion zsh)

Pokud máte pro kubectl alias, bude automaticky fungovat autodokončování kubectl. Po obnovení shellu by mělo být autodokončování kubectl fungovat. Pokud dostanete chybu jako 2: command not found: compdef, přidejte následující do počátku souboru ~/.zshrc: 
autoload -Uz compinit
compinit
