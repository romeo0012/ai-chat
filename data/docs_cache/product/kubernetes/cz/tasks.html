Úkoly
Tato část dokumentace Kubernetes obsahuje stránky, které ukazují, jak provést jednotlivé úkoly. Stránka úkolu ukazuje, jak provést jednu věc, obvykle dáváním krátkého řetězce kroků. Pokud byste chtěli napsat stránku úkolu, podívejte se na Vytváření žádosti o příměření dokumentace. Nastavení nástrojů Nastavte nástroje Kubernetes na vašem počítači. Správa clusteru Učte se běžných úkolů pro správu clusteru. Konfigurace Podů a kontejnerů Provedete běžné konfigurační úkoly pro Pody a kontejnery. Monitorování, záznamy a ladění Nastavte monitorování a záznamy k řešení problémů s clusterem, nebo ladění aplikace v kontejneru. Správa objektů Kubernetes Objects Vede k interakci s API Kubernetes pomocí deklarativních a imperativních paradigmat. Správa tajných Spravujte tajné nastavení dat pomocí Tajných. Vložení dat do aplikací Určete konfiguraci a další data pro Pody, které spouštíte vaši pracovní zátěž. Spouštění aplikací Spouštějte a spravujte obě statické a stavové aplikace. Spouštění úloh Spouštějte úlohy pomocí paralelního zpracování. Přístup k aplikacím v clusteru Nastavte balancování zatížení, portovou přesměrovávání nebo nastavte konfigurace brány zabezpečení nebo DNS, abyste mohli přístup k aplikacím v clusteru. Rozšiřování Kubernetes Rozumějte pokročilým způsobům, jak adaptovat svůj cluster Kubernetes k potřebám vašeho pracovního prostředí. TLS Rozumějte, jak chránit provoz v clusteru pomocí Transport Layer Security (TLS). Správa demonů Provédejte běžné úkoly pro správu DaemonSetu, například provádění aktualizace.

Poznámka: Všechny technické termíny, kódy, příkazy, cesty souborů, URL a formáty zůstávají v původním anglickém jazyce.
