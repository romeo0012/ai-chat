Správa clusteru
Detaily na nižší úrovni relevantní pro vytváření nebo správu Kubernetes clusteru.
Přehled správy clusteru je určeným kýmkoli, kdo vytváří nebo spravuje Kubernetes cluster. Předpokládá se, že má nějakou znalost základních konceptů Kubernetes.
Plánování clusteru
Viz návody v Setup pro příklady plánování, nastavení a konfigurace Kubernetes clusterů. Řešení uvedená v tomto článku se nazývají distros.
Poznámka:
Nikoliv všechny distros jsou aktivně udržovány. Vyberte distros, které byly testovány s novou verzí Kubernetes.
Před volbou návodu, zvažte následující faktory:
Chcete-li zkusit Kubernetes na svém počítači, nebo chcete vytvořit vysokou dostupnostní, vícenodový cluster? Vyberte distros, které odpovídají vašim potřebám.
Budete používat hostovaný Kubernetes cluster, jako je Google Kubernetes Engine, nebo budete vlastní cluster hostovat?
Bude vaši cluster na místě, nebo v cloudu (IaaS)? Kubernetes nepodporuje hybridní cluster. Místo toho můžete nastavit více clusterů.
Pokud konfigurujete Kubernetes na místě, zvažte, která síťová topologie se nejlépe hodí.
Budete spouštět Kubernetes na "bare metal" hardwareu nebo na virtuálních strojích (VMs)?
Chcete spustit cluster, nebo očekáváte aktivní vývoj kódu projektu Kubernetes? Pokud to poslední, vyberte aktivně vyvíjenou distro. Některé distros používají pouze vydání binárních verzí, ale nabízejí větší škálu možností.

Ovládání přístupu k Kubernetes API popisuje, jak Kubernetes implementuje vlastní ovládání přístupu pro svůj vlastní API.
Autentizace vysvětluje autentizaci v Kubernetes, včetně různých možností autentizace. Autorizace je oddělena od autentizace a řídí, jak se zpracovávají HTTP volání.

Auditing popisuje, jak interagovat s auditovými záznamy Kubernetes.
