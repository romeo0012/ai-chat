3Interakce s vaším clusterem
Pokud už máte nainstalovaný kubectl (podívejte se na dokumentaci), můžete nyní použít k přístupu k vašemu leskavému novému clusteru: kubectl get po -A
Alternativně můžete minikube stáhnout odpovídající verzi kubectl a můžete ho používat takto: minikube kubectl -- get po -A
Můžete si také život zjednodušit tím, že přidáte následující do konfigurace svého shellu: (pro další podrobnosti zkontrolujte: kubectl) alias kubectl="minikube kubectl --"
Po vytvoření některých služeb, jako je například storage-provisioner, mohou být v počátečním stavu neběžící. Tento stav je běžný při spouštění clusteru a bude se řešit samovolně. Další informace o stavu vašeho clusteru můžete získat pomocí Kubernetes Dashboard, který minikube společně s vás připraví k přizpůsobení novému prostředí: minikube dashboard

4Vyvíjení aplikací
Vytvořte ukázkovou nasazení a zpřístupněte ho na portu 8080: kubectl create deployment hello-minikube --image=kicbase/echo-server:1.

prostředí: minikube dashboard
Vytvořte ukázkové nasazení a vystavte ho na portu 8080: kubectl create deployment hello-minikube --image=kicbase/echo-server:1.0 kubectl expose deployment hello-minikube --type=NodePort --port=8080
Může to trvat chvíli, ale vaše nasazení se brzy zobrazí, když spustíte: kubectl get services hello-minikube
Nejjednodušší způsob, jak přistupovat k tomuto službě, je povolit minikube spustit pro vás webový prohlížeč: minikube service hello-minikube
Alternativně můžete použít kubectl k přesměrování portu: kubectl port-forward service/hello-minikube 7080:8080
Tady! Vaše aplikace je nyní dostupná na <http://localhost:7080/>. Byste měli moci vidět metadata požadavku v aplikaci výstupu. Zkuste změnit cestu požadavku a pozorujte změny. Stejně tak můžete provést POST požadavek a pozorovat, jak se tělo zobrazí v výstupu. K přístupu k nasazení s Balancerem použijte příkaz "minikube tunnel". Níže je příklad nasazení: kubectl create deployment balanced --image=kicbase/echo-server:1.0

Chcete-li přistoupit k nasazení LoadBalancer, použijte příkaz "minikube tunnel". Níže je ukázkové nasazení: 

kubectl create deployment balanced --image=kicbase/echo-server:1.0
kubectl expose deployment balanced --type=LoadBalancer --port=8080

V dalším okně spusťte tunel, aby vytvořil přístupný IP pro ‘balanced’ nasazení: 
minikube tunnel

Chcete-li zjistit přístupný IP, spusťte následující příkaz a zkontrolujte sloupec EXTERNAL-IP: 
kubectl get services balanced

Vaše nasazení je nyní dostupné na <EXTERNAL-IP>:8080
Povolte přídavný balíček ingress: 
minikube addons enable ingress

Níže je ukázkový příklad vytvoření jednoduchých služeb echo-server a Ingress objektu pro routování k těmto službám. 
apiVersion: v1
kind: Pod
metadata:
  name: foo-app
  labels:
    app: foo
spec:
  containers:
  - name: foo-app
    image: 'kicbase/echo-server:1.0'


apiVersion: v1
kind: Service
metadata:
  name: foo-service
spec:
  selector: app: foo
  ports:
  - port: 8080


apiVersion: v1
kind: Pod
metadata:
  name: bar-app
  labels:
    app: bar
spec:
  containers:
  - name: bar-app
    image: 'kicbase/echo-server:1.0'


apiVersion: v1
kind: Service
metadata:
  name: bar-service
spec:
  selector: app: bar
  ports:
  - port: 8080


apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: example-ingress
spec:
  rules:
  - http:
      paths:
      - pathType: Prefix
        path: /foo
        backend:
          service:
            name: foo-service
            port:
              number: 8080
      - pathType: Prefix
        path: /bar
        backend:
          service:
            name: bar-service
            port:
              number: 8080

Spravujte svůj cluster:
Zastavit Kubernetes bez dopadu na nasazené aplikace: minikube pause
Obnovit zastavený instance: minikube unpause
Zastavit cluster: minikube stop
Změnit výchozí limit paměti (požaduje restart): minikube config set memory 9001
Prohlédněte seznam snadno nainstalovatelných služeb Kubernetes: minikube addons list
Vytvořte druhý cluster spouštějící starší verzi Kubernetes: minikube start -p starý --kubernetes-version=v1.34.0
Smazat všechny minikube cluster: minikube delete --all
