Termín Virtual Host odkazuje na praxi provozování více než jednoho webu (např. company1.příklad.cz a company2.příklad.cz) na jednom počítači. Virtual hosts mohou být "IP-závislé", což znamená, že máte různou IP adresu pro každý web, nebo "jméno-závislé", což znamená, že můžete mít více názvů na každé IP adrese. Tím, že jsou v provozu na stejném fyzickém serveru, není to pro uživatele patrné. Apache byl jedním z prvních serverů, které podporovaly IP-závislé virtual hosts zásadně z boxu. Verze 1.1 a pozdější verze Apache podporují obě IP-závislé a jméno-závislé virtual hosts (vhosts). Tato varianta virtual hostů je někdy také nazývána host-závislá nebo ne-IP virtual hosts.

Configuration directives

¶ Pokud se pokoušíte ladit konfiguraci virtuálních hostů, můžete nalézt příkazovou řádku -S užitečným. Níže jsou příklady pro Unix a Windows:

  • Unix: apachectl -S
  • Windows: httpd.exe -S

Tento příkaz vypíše popis, jak Apache zpracovával konfigurační soubor. Přesné zkoumání IP adres a názvů serverů může pomoci odhalit chyby v konfiguraci. (Viz dokumentace pro program httpd pro další možnosti příkazové řádky)
