Apache HTTP Server je vydáván jako zdrojový kód. Tento dokument se týká sestavování a instalace serveru z zdrojového kódu na systémech Unix a Unix-like. Verze momentálně, a PREFIX musí být nahrazen cestou k adresáři souborů, pod kterým by server měl být instalován. Pokud PREFIX není zadán, výchozí hodnotou je /usr/local/apache2. Požadavky ¶ Následující požadavky existují pro sestavování a spouštění Apache httpd: APR a APR-Util Ujistěte se, že APR a APR-Util jsou již nainstalovány na vašem systému. Pokud nejsou, nebo preferujete nevyužívat verze systému, stáhněte si nejnovější verze obou APR a APR-Util z Apache APR, rozbalte je do /httpd_source_tree_root/srclib/apr a /httpd_source_tree_root/srclib/apr-util (ujištěte se, že názvy adresářů neobsahují verze; například distribuce APR musí být pod /httpd_source_tree_root/srclib/apr/). Použijte možnost --with-included-apr při spouštění ./configure. Na některých platformách můžete muset instalovat odpovídající -dev balíčky, aby se httpd mohl sestavit proti vaší instalované kopii APR a APR-Util. Perl-Compatible Regular Expressions Library (PCRE2) Tato knihovna je požadována, ale není součástí httpd. Stáhněte si zdrojový kód z https://github.com/PCRE2Project/pcre2 nebo ho nainstalujte z balíčku správce balíčků vašeho systému. Pokud je vaše sestavovací prostředí neschopno najít pcre2-config skript instalovaný PCRE2 buildem, uveďte ho pomocí parametru --with-pcre.

Váš systém stavby nemůže nalézt skript pcre2-config instalovaný PCRE2 stavbou. Ukažte si na něj pomocí parametru --with-pcre. Na některých platformách můžete muset instalovat odpovídající -dev balíček (např. libpcre2-dev nebo pcre2-devel), aby mohl httpd stavět proti vaší instalované kopii PCRE2. Prostor na disku Ujistěte se, že máte alespoň 200 MB volného místa na disku pro dočasné soubory. Po instalaci server zabere přibližně 50 MB místa na disku. Skutečné požadavky na místa na disku se velmi liší v závislosti na vašich zvolených konfiguračních možnostech, jakýkoli další třetístranní moduly a, zřejmě, velikost webu nebo webů, které máte na serveru. ANSI-C Compiler a systém stavby Ujistěte se, že máte instalovaný ANSI-C kompilátor. Kompilátor ANSI-C GNU (GCC) z Free Software Foundation (FSF) je doporučený. Pokud nemáte GCC, ujistěte se, že vaši dodavatelova kompilátor je ANSI kompatibilní. Kromě toho musí být vaše PATH obsahovat základní nástroje pro stavbu, jako je make. Správné časové stavování Protokol HTTP používá časové známky, takže musí být vaše systémová hodina přesná. Většina Linuxových distribucí povolí systemd-timesyncd nebo chrony výchozí. Ujistěte se, že je na vašem systému aktivní synchronizace času před spuštěním produkčního serveru. Pokud konfigurační skript nenajde Perl 5 interpretaтор, nebude možné použít dotčené podporující skripty. Zřejmě však budete stále schopni sestavit a používat Apache httpd. Stáhněte si ¶ Stáhněte si zdrojový balíček z webu pro stažení Apache HTTP Server. Po stažení je důležité ověřit, zda máte kompletní a nezměněnou verzi Apache HTTP Server. Toho lze dosáhnout testováním staženého balíčku proti PGP podpisu. Podrobnosti o tom, jak to provést, jsou k dispozici na stránce pro ověření. Extrahování ¶ Extrahujte zdroje z balíčku Apache HTTP Server: $ tar xzf httpd-NN.tar.gz Tento příkaz vytvoří novou složku v aktuální složce obsahující zdrojový kód pro distribuci. Před tím, než budete pokračovat v sestavování serveru, je třeba se přesunout do této složky. Konfigurace stromu zdrojů ¶ Následující krok je konfigurace stromu zdrojů Apache httpd pro vaši konkrétní platformu a osobní požadavky. Toto se provádí pomocí skriptu configure zahrnutého v kořenové složce distribuce. (Rozvojáři stahující nevydanou verzi zdrojového stromu Apache httpd budou muset mít nainstalované autoconf a libtool a budou muset spustit buildconf před pokračováním s dalšími kroky. To není nutné pro oficiální vydání.) Chcete-li konfigurovat strom zdrojů pomocí všech výchozích možností, zadejte ./configure.

Pokyny pro konfiguraci zdrojového stromu (tohoto kroku není nutné pro oficiální vydání.) Chcete-li nakonfigurovat zdrojový strom pomocí všech výchozích možností, zadejte ./configure. Pokud chcete změnit výchozí možnosti, můžete konfiguraci přijmout různé proměnné a možnosti příkazového řádku. Nejdůležitější možností je umístění --prefix, kde bude instalována httpd později, protože httpd musí být konfigurováno pro tuto lokaci, aby fungovala správně. Další přesnější ovládání umístění souborů je možné pomocí dalších možností konfigurace. V této fázi můžete také určit, které funkce chcete zahrnout do httpd, tím, že ho povolíte a zakazujete moduly. httpd přichází s velkým počtem modulů zahrnutých výchozími nastaveními. Budou se překládat jako sdílené objekty (DSOs), které mohou být nahrány nebo odstraněny během běhu. Můžete také zvolit, aby moduly byly kompilovány staticky pomocí možnosti --enable-module=static. Další moduly se zapínají pomocí možnosti --enable-module, kde module je jméno modulu s odstraněným předponou mod_ a s převodem podtržítka na tečku. Stejně tak můžete moduly zakázat pomocí možnosti --disable-module. Použijte tyto možnosti s opatrností, protože konfigurace nemůže varovat, pokud jste zadali modul, který neexistuje; bude ignorovat tuto možnost. Dále můžete poskytnout konfiguračnímu skriptu další informace o umístění vašeho kompilátoru, knihoven nebo hlavičkových souborů. Toto se provede přenosem prostřednictvím prostředníků prostředí nebo příkazového řádku konfiguraci.

$ CC="pgcc" CFLAGS="-O2" \
./configure --prefix=/sw/pkg/apache \
--enable-ldap=shared \
--enable-lua=shared

Když se spustí konfigurace, trvá to několik minut, aby testovala dostupnost funkcí na vašem systému a vytvořila Makefile, které později budou použity k sestavení serveru. Další informace o všech různých možnostech konfigurace naleznete na stránce manuálu konfigurace.

Sestavit ¶ Nyní můžete sestavit různé části, které tvoří balíček httpd, spuštěním:

$ make

Prosím být trpělivý zde, protože základní konfigurace trvá několik minut k sestavení a čas se velmi liší podle vašeho hardware a počtu modulů, které jste povolili.

Instalovat ¶ Nyní je čas instalovat balíček pod konfigurovanou PREFIX (viz --prefix option výše) spuštěním:

$ make install

Tento krok obvykle vyžaduje oprávnění správce, protože PREFIX je obvykle adresář s omezenými právy zápisu. Pokud jste aktualizovali, instalace nezapíše vaše konfigurační soubory nebo dokumenty.

Přizpůsobení ¶ Nyní můžete přizpůsobit svůj Apache HTTP Server upravit konfigurační soubory v adresáři PREFIX/conf/. $ vi PREFIX/conf/httpd.conf Prostudujte se manual Apache HTTP Server v adresáři PREFIX/docs/manual/ nebo porovnejte se se zprávou o verzi https://httpd.apache.org/docs/2.4/ pro nejnovější verzi tohoto manuálu a kompletní referencí dostupných konfiguračních příkazů. Test ¶ Nyní můžete spustit Apache HTTP Server okamžitě spuštěním: $ PREFIX/bin/apachectl -k start Byl byste měl moci požádat svůj první dokument pomocí URL http://localhost/. Webová stránka, kterou vidíte, je umístěna v adresáři DocumentRoot, který bude obvykle PREFIX/htdocs/. Poté zastavte server znovu spuštěním: $ PREFIX/bin/apachectl -k stop Upgradování ¶ Prvním krokem při aktualizaci je čtení zprávy o verzi a souboru CHANGES v distribuci zdrojového kódu, abyste našli jakékoliv změny, které mohou ovlivnit vaši web. Při přechodu mezi hlavními verzemi (například z 2.4 na 2.6) je pravděpodobné, že budou velké rozdíly v konfiguraci při kompilaci a běhu, které budou vyžadovat ruční úpravy. Všechny moduly budou také nutné aktualizovat, aby odpovídaly změnám v rozhraní API modulu. Aktualizace z jedné menší verze na druhou (například z 2.4.66 na 2.4.67) je snadnější.

V modulu API. Vzestup z jedné menší verze na další (například z 2.4.66 na 2.4.67) je snadnější. Proces make install nebude přepsat žádné z vašich existujících dokumentů, logovacích souborů ani konfiguračních souborů. Dále se snaží vývojáři vyhnout nekompatibilním změnám v konfiguraci možností, dynamické konfiguraci nebo API modulu mezi menšími verzemi. Většinou byste měli moci použít stejnou konfigurační příkazovou řadu, stejný konfigurační soubor a všechny vaše moduly by měly fungovat. K vzestupu mezi menšími verzemi je třeba najít soubor config.nice v adresáři build vašeho instalovaného serveru nebo v kořenu zdrojového stromu staré instalace. Tento soubor obsahuje právě tuto konfigurační příkazovou řadu, kterou jste použili k konfiguraci zdrojového stromu. Poté, abyste se vzestoupili z jedné verze na druhou, stačí pouze kopírovat soubor config.nice do zdrojového stromu nové verze, upravit ho pro žádané změny a poté spustit: $ ./config.nice $ make $ make install $ PREFIX/bin/apachectl -k graceful-stop $ PREFIX/bin/apachectl -k start
