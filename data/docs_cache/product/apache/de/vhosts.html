Das Wort Virtual Host bezieht sich auf die Praxis, mehr als eine Webseite (z.B. company1.beispiel.com und company2.beispiel.com) auf einem einzelnen Rechner auszuführen. Virtual Hosts können "IP-basiert" sein, was bedeutet, dass Sie eine andere IP-Adresse für jede Webseite haben, oder "name-basiert", was bedeutet, dass Sie mehrere Namen auf jeder IP-Adresse ausführen. Tatsächlich, dass sie auf demselben physischen Server laufen, ist dem Endnutzer nicht bekannt. Apache war einer der ersten Server, der IP-basierte Virtual Hosts direkt aus dem Paket unterstützte. Versionen 1.1 und später von Apache unterstützen beide IP-basierte und name-basierte Virtual Hosts (vhosts). Die letztere Variante von Virtual Hosts wird manchmal auch als host-basiert oder nicht-IP Virtual Hosts bezeichnet.

Wenn Sie Ihre virtuelle Host-Konfiguration debuggen möchten, können Sie den -S Befehl am Kommandozeilentyp vielleicht hilfreich finden. Unix-Beispiel
apachectl -S
Windows-Beispiel
httpd.exe -S
Dieser Befehl gibt eine Beschreibung der Art und Weise, wie Apache die Konfigurationsdatei interpretiert heraus. Vorsichtige Untersuchung der IP-Adressen und Servernamen kann Fehler in der Konfiguration aufdecken. (Siehe die Dokumentation zum httpd-Programm für weitere Befehlszeilenoptionen)
