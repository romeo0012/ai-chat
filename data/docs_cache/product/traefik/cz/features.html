Inicializace vyhledávání GitHub Traefik Produktové funkce Porovnání¶ Traefik ekosystém nabízí více produktů navržených k zastoupení různých požadavků, od základní funkce reverzního proxy až po komplexní správu API a schopnosti umělé inteligence (AI) brány. Tato matice porovnání vám pomůže pochopit, co je k dispozici v každém produktu a vybrat správnou řešení pro vaši situaci. Přehled produktů¶ Traefik Proxy je otevřená aplikace proxy, která slouží jako základ pro všechny produkty Traefik. Poskytuje esenciální funkce reverzního proxy, zatížení a roztahování a službu objevování služeb. Traefik Hub API Brána se opírá o Traefik Proxy s podnikovou bezpečností, rozptýlenými funkcemi a pokročilým ovládáním přístupu pro scénáře cloud-native API brány. Zahrnuje AI Bránu schopnosti, které transformují každý AI koncový bod do spravované API. Traefik Hub API Správa přidává komplexní řadu funkcí pro správu životního cyklu API, portály pro vývojáře a funkce pro organizace pro týmy, které spravují více API v různých prostředích. Traefik AI Brána transformuje každý AI koncový bod do spravované API s jednotným přístupem k mnoha LLMs, centrální správou kredenčních údajů, semantickým uložení, místní inférenci a komplexní řízení AI funkcemi. Traefik MCP Brána poskytuje zabezpečený a řízený přístup k Model Context Protocol (MCP) serverům pro AI agenty s kontrolou přístupu na základě úloh (TBAC), routování podle sezení a komplexní auditovací schopnosti pro podnikové pracovní postupy AI.

(MCP) servery pro AI agenty s kontrolou přístupu podle úkolů (TBAC), s inteligentní routingem sesíí a komplexními auditní schopnostmi pro AI pracovníky v podnikové síti. Upgrade to Traefik Hub API Gateway¶
Traefik Hub API Gateway přidává na Traefik Proxy enterprise security, distribuovanou koordinaci a umělé inteligence Gateway schopnosti. Upgrade to it when you need: Enterprise security requirements (JWT, OIDC, LDAP) Distributed deployments across multiple clusters Advanced rate limiting and caching WAF a policy enforcement AI Gateway schopnosti Commercial support

Consider Traefik AI Gateway¶
Traefik AI Gateway slouží k centralizovanému řízení a sledování přístupu k LLM aplikacím. Considerejte ho, pokud máte: Multi-LLM applications requiring unified API access Organizations using multiple AI providers (OpenAI, Anthropic, Azure OpenAI, AWS Bedrock, etc.)

Cesta migrace¶
Ekosystém Traefik je navržen pro jednoduché aktualizace. Můžete začít s Traefik Proxy a přidat schopnosti, jak se vaše požadavky rozšiřují:
Traefik Proxy → API brána Hub: Přidat funkce zabezpečení podniku, rozptýlené funkce a funkce AI Gateway
API brána Hub → API správa Hub: Přidat komplexní správu API a funkce řízení
MCP brána: Speciální řešení pro řízení AI agentů a pro správu Model Context Protocol
Všechny produkty sdílejí stejné základní koncepty konfigurace, což zjednodušuje migraci a zachovává vaše dosavadní konfigurace a znalosti o provozu.
