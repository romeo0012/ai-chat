Inicializace hledání GitHub Vítáme¶ Traefik je otevřený zdrojový Aplikační Proxy, který vás umožní publikovat vaše služby zábavným a snadným způsobem. Přijímá požadavky namísto vašeho systému a identifikuje, které komponenty jsou odpovědné za jejich zpracování, a směruje je bezpečně. Co Traefik odlišuje, kromě jeho mnoha funkcí, je to, že automaticky objeví správnou konfiguraci pro vaše služby. Začarování se děje, když Traefik prozkoumá vaši infrastrukturu, kde najde relevantní informace a objeví, která služba slouží pro které požadavky. Traefik je nativně kompatibilní s každou hlavní technologii klastru, jako je Kubernetes, Docker Swarm, AWS, Mesos, Marathon, a seznam pokračuje; a může ručně zpracovávat mnoho současně. (Funguje i pro staré software běžící na neobsluhovaném hardware.) S Traefikem není nutné udržovat a synchronizovat oddělený konfigurační soubor: vše se děje automaticky, v reálném čase (bez restartů, bez přerušení spojení). S Traefikem můžete věnovat čas vývoji a nasazování nových funkcí do vašeho systému, nikoliv konfiguraci a údržbě jeho stavu. A pokud se vaše potřeby změní, můžete přidat schopnosti brány API a správy API k vašim existujícím nasazením Traefik bez potíží. To trvá méně než minutu, není nutné nahradit a všechny vaše konfigurace jsou zachovány. Vítejte se tomu v akci v našem demo videu brány API. Rozvíjíme Traefik, naše hlavní cíl je udělat její použití snadným, a jistě si to budete líbit.
