Initialisierung der Suche GitHub Traefik Produktmerkmale-Vergleich¶ Das Traefik-Ökosystem bietet mehrere Produkte, die unterschiedliche Anforderungen erfüllen sollen, von der Basis-Reverse-Proxy-Funktionalität bis zu umfassender API-Management und künstliche Intelligenz-Gateway-Fähigkeiten. Diese Vergleichstabelle hilft Ihnen, die in jedem Produkt verfügbaren Funktionen zu verstehen und die passende Lösung für Ihr Szenario auszuwählen. Produktübersicht¶ Traefik Proxy ist die open-source Anwendungs-Proxy, die die Basis für alle Traefik-Produkte bildet. Sie bietet essenzielle Reverse-Proxy-, Lastenausgleichs- und Dienstentdeckungs-Funktionalitäten. Traefik Hub API Gateway erweitert Traefik Proxy um Unternehmens-Grade-Sicherheit, verteilte Funktionen und fortschrittliche Zugriffssteuerung für cloud-native API-Gateway-Szenarien. Es umfasst AI Gateway-Fähigkeiten, die jeden künstlichen Intelligenz-Endpunkt in eine verwaltete API verwandeln. Traefik Hub API Management ergänzt umfassende API-Lebenszyklus-Management, Entwickler-Portale und Organisations-Funktionen für Teams, die mehrere APIs in verschiedenen Umgebungen verwalten. Traefik AI Gateway verwandelt jeden künstlichen Intelligenz-Endpunkt in eine verwaltete API mit einheitlichem Zugang zu mehreren LLMs, zentraler Anmeldeverwaltung, semantischem Caching, lokaler Inferenz und umfassender künstlicher Intelligenz-Governance-Funktionalität. Traefik MCP Gateway bietet sichere, gegeneinander abgesicherte Zugang zu Model Context Protocol (MCP) Servern für künstliche Intelligenz-Agenten mit task-basierter Zugriffssteuerung (TBAC), session-smart Routing und umfassenden Audit-Funktionalitäten für Unternehmens-künstliche Intelligenz-Workflows.

Traefik-Proxy ist der ideale Ausgangspunkt für Organisationen, die nach einer zuverlässigen, open-source Anwendungs-Proxy mit wichtigen Netzwerkfunktionen suchen. Verwenden Sie es als Standard-Eingangsebene, wenn Sie folgendes benötigen:

  • Basis-Reverse-Proxy und Lastenausgleich
  • Dienstentdeckung für containerisierte Anwendungen
  • Einfache TLS-Terminierung und Integration von Let's Encrypt
  • Kosteneffiziente Lösung mit Community-Unterstützung (können Sie auf Traefik Hub für weitere Funktionen aufwerten)

Upgrade auf Traefik Hub API Gateway¶
Traefik Hub API Gateway baut auf Traefik Proxy Enterprise-Sicherheit, verteilte Koordination und künstliche Intelligenz-Funktionen auf. Upgrade dazu, wenn Sie folgendes benötigen:

  • Enterprise-Sicherheitsanforderungen (JWT, OIDC, LDAP)
  • Verteilte Bereitstellung in mehreren Clustern
  • Fortschrittliche Rate-Limiting und Cache
  • WAF und Politik-Steuerung
  • KI-Funktionen
  • Kommerzielle Unterstützung

Consider Traefik AI Gateway¶
Traefik AI Gateway vereint den Zugriff auf LLM unter zentralisierter Steuerung und Beobachtung. Überlegen Sie es, wenn Sie folgendes haben:

  • Mehrere LLM-Anwendungen, die eine vereinheitlichte API-Zugriff benötigen
  • Organisationen, die mehrere AI-Anbieter (OpenAI, Anthropic, Azure OpenAI, AWS Bedrock, usw.) verwenden

Wählen Sie Traefik MCP Gateway¶
Traefik MCP Gateway regelt, wie AI-Agenten mit Model Context Protocol-Servern interagieren, indem es task-bewusste Politik und session-intelligente Routing verwendet. Wählen Sie es, wenn Sie:

  • AI-Agenten benötigen, die sicher auf MCP-Servern zugreifen können
  • Taskbasierte Zugriffssteuerung (TBAC) für AI-Workflows benötigen
  • Governance von Model Context Protocol-Interaktionen benötigen
  • session-intelligente Routing für langlaufende Agent-Gespräche benötigen
  • MCP-Servern OAuth 2.1 / 2.0-kompatible Schutz benötigen
  • Audit-bereite Beobachtbarkeit für AI-Agententätigkeiten benötigen
  • feingranulierte Politiksteuerung für AI-Werkzeuge und Ressourcen benötigen

Wählen Sie Traefik Hub API Management¶
Traefik Hub API Management erweitert die Gateway-Basis um API-Lebenszyklus-Werkzeuge, Entwicklererfahrungsfunktionen und Governance-Workflows. Wählen Sie es, wenn Sie:

  • Mehrere APIs benötigen, die zentralisiert verwaltet werden
  • Entwicklerteams Selbstbedienungsportale benötigen
  • Komplexes API-Versionierung und Lebenszyklusanforderungen benötigen
  • Mehrere Clusterumgebungen benötigen, die unifizierte Dashboards benötigen
  • Kompliance- und Governanceanforderungen benötigen
  • Migration benötigen

Migration Weg¶
Das Traefik-Ökosystem ist für flüssige Upgrades konzipiert.

Das Traefik-Ökosystem ist für flüssige Upgrades konzipiert. Sie können mit Traefik Proxy beginnen und Funktionalitäten hinzufügen, je nachdem, wie sich Ihre Anforderungen entwickeln:

Traefik Proxy → Hub API Gateway: Fügen Sie enterprise-Sicherheit, verteilte Funktionen und AI Gateway-Funktionalitäten hinzu
Hub API Gateway → Hub API Management: Fügen Sie umfassende API-Management- und Governance-Funktionalitäten hinzu
MCP Gateway: Speziallösung für die Governance von AI-Agenten und Management des Model Context Protocol

Alle Produkte teilen die gleichen Kernkonzepte der Konfiguration, was die Migration einfach macht und Ihre vorhandenen Konfigurationen und operative Wissen erhalten lässt.
