Module ngx_stream_upstream_module

← Chat

Modul ngx_stream_upstream_module (Version 1.9.0) wird verwendet, um Gruppen von Servern zu definieren, die von der Directive proxy_pass referenziert werden können. Beispielkonfiguration

upstream backend {
    hash $remote_addr consistent;
    server backend1.example.com:12345 weight=5;
    server backend2.example.com:12345;
    server unix:/tmp/backend3;
    server backup1.example.com:12345 backup;
    server backup2.example.com:12345 backup;
}
server {
    listen 12346;
    proxy_pass backend;
}

Dynamisch konfigurierbare Gruppe mit periodischen Gesundheitsprüfungen ist Teil unseres kommerziellen Abonnements:

resolver 10.0.0.1;
upstream dynamic {
    zone upstream_dynamic 64k;
    server backend1.example.com:12345 weight=5;
    server backend2.example.com:12345 fail_timeout=5s slow_start=30s;
    server 192.0.2.1:12345 max_fails=3;
    server backend3.example.com:12345 resolve;
    server backend4.example.com service=http resolve;
    server backup1.example.com:12345 backup;
    server backup2.example.com:12345 backup;
}
server {
    listen 12346;
    proxy_pass dynamic;
    health_check;
}

Standard: —
Kontext: stream
Definiert eine Gruppe von Servern. Servern können auf verschiedenen Ports lauschen. Zusätzlich können Servern, die über TCP und UNIX-Domänen-Sockets lauschen, gemischt werden. Beispiel: upstream backend { server backend1.example.com:12345 weight=5; server 127.0.0.1:12345; }

  server backup1.example.com:12345 backup;

Wenn bei der Kommunikation mit einem Server ein Fehler auftritt, wird die Verbindung an den nächsten Server weitergegeben, und so weiter, bis alle funktionierenden Server versucht wurden. Wenn die Kommunikation mit allen Servern fehlschlägt, wird die Verbindung geschlossen. Ein Domainname, der mehrere IP-Adressen aufweist, definiert mehrere Server gleichzeitig.
