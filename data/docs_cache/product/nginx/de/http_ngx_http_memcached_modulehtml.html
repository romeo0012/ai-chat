Modul ngx_http_memcached_module
===============================

Dieser Modul wird verwendet, um Antworten von einem Memcached-Server zu erhalten. Der Schlüssel wird in der Variable $memcached_key gesetzt. Eine Antwort soll vorher in Memcached gespeichert werden, was über nginx extern geschehen muss.

Beispielkonfiguration 

server {
    location / {
        set $memcached_key "$uri?$args";
        memcached_pass host:11211;
        error_page 404 502 504 = @fallback;
    }
    location @fallback {
        proxy_pass http://backend;
    }
}

Direktiven

Syntax: memcached_allow_upstream string ...;
Default: —
Kontext: http, server, location

Diese Direktive ist ab Version 1.29.3 verfügbar. Definiert die Bedingungen, unter denen der Zugriff auf einen Memcached-Server erlaubt oder verweigert wird. Wenn alle Zeichenfolgenparameter nicht leer und nicht mit "0" gleich sind, wird der Zugriff erlaubt. Die Bedingungen werden jedes Mal vor einer Verbindung zu einem Memcached-Server geprüft. Die Parameterwerte können Variablen enthalten:

server {
    listen 127.0.0.1:8080;
    location / {
        memcached_pass host:11211;
        memcached_allow_upstream $allow;
        ...
    }
}
geo $upstream_last_addr $allow {
    volatile;
    10.10.0.0/24 1;
}

Ort / { memcached_pass host:11211; memcached_allow_upstream $allow; ... } } Dieses Direktiv ist Teil unserer kommerziellen Abonnement-Pakete. Syntax: memcached_bind address [transparent ] | off; Standard: — Kontext: http, server, location Dieses Direktiv ist ab Version 0.8.22 verfügbar. Es verbindet ausgehende Verbindungen mit einem Memcached-Server mit der angegebenen lokalen IP-Adresse und einem optionalen Port (1.11.2). Der Wert des Parameters kann Variablen enthalten (1.3.12). Der Sonderwert off (1.3.12) storniert den Effekt des memcached_bind-Direktivs, das von der vorherigen Konfigurationsstufe geerbt wurde, was dem System erlaubt, die lokale IP-Adresse und den Port automatisch zuzuweisen. Der transparent-Parameter (1.11.0) erlaubt ausgehende Verbindungen zu einem Memcached-Server von einer nicht-lokalen IP-Adresse aus, z.B. von der realen IP-Adresse eines Clients: memcached_bind $remote_addr transparent; Um diesen Parameter funktionieren zu lassen, ist es üblich, dass die Nginx-Worker-Prozesse mit den Superuser-Rechten ausgeführt werden. Auf Linux ist dies nicht erforderlich (1.13.8), da wenn der transparent-Parameter angegeben wird, die Worker-Prozesse die CAP_NET_RAW-Berechtigung vom Master-Prozess erben. Es ist auch erforderlich, die Kernel-Routing-Tabelle für das Netzwerkverkehr des Memcached-Servers zu konfigurieren.

Kontext: http, server, location
Ab der Version 1.3.6 verfügbar. Aktiviert die Testung des Flags in der Antwort des Memcached-Servers und setzt den "Content-Encoding"-Antwortheaderfeld auf "gzip" ein, wenn das Flag gesetzt ist. Syntax: memcached_next_upstream error | timeout | denied | invalid_response | not_found | off ...

"gzip" falls in Kraft, wenn die Flagge gesetzt ist. Syntax: memcached_next_upstream Fehler | Zeitout | verweigert | ungültige_Antwort | nicht_gefunden | ...; Standard: memcached_next_upstream Fehler Zeitout; Kontext: http, server, location

Diese Direktive bestimmt in welchen Fällen eine Anfrage an den nächsten Server weitergeleitet werden soll:

  • Fehler: Ein Fehler ist aufgetreten, während die Verbindung mit dem Server hergestellt, die Anfrage an ihn gesendet oder das Antwort-Header-Feld gelesen wurde.
  • Zeitout: Ein Zeitout ist aufgetreten, während die Verbindung mit dem Server hergestellt, die Anfrage an ihn gesendet oder das Antwort-Header-Feld gelesen wurde.
  • verweigert: Der Server hat die Verbindung abgelehnt (1.29.3)
  • ungültige_Antwort: Der Server hat eine leere oder ungültige Antwort zurückgegeben.
  • nicht_gefunden: Eine Antwort wurde auf dem Server nicht gefunden.
  • off: Die Weiterleitung der Anfrage an den nächsten Server wird deaktiviert. Man sollte daran denken, dass die Weiterleitung der Anfrage an den nächsten Server nur möglich ist, wenn nichts bereits an einen Client gesendet wurde. Das heißt, wenn ein Fehler oder Zeitout im Verlauf der Antwortübertragung auftritt, kann dies nicht korrigiert werden. Die Direktive definiert auch, was als unerfolgreiche Kommunikation mit einem Server betrachtet wird. Die Fälle von Fehler, Zeitout, verweigert und ungültige_Antwort werden immer als unerfolgreiche Kommunikation betrachtet, selbst wenn sie nicht in der Direktive spezifiziert sind. Der Fall von nicht_gefunden wird nie als unerfolgreiche Kommunikation betrachtet. Die Weiterleitung der Anfrage an den nächsten Server kann durch die Anzahl der Versuche und die Zeit begrenzt werden.

unerfolgreiche Versuchsversuche. Eine Anfrage an den nächsten Server können durch die Anzahl der Versuche und die Zeit begrenzt werden. Syntax: memcached_next_upstream_timeout time; Standard: memcached_next_upstream_timeout 0; Kontext: http, server, location Dieser Direktiv erschien in der Version 1.7.5. Begrenzt die Zeit, während die Anfrage an den nächsten Server übertragen werden kann. Der Wert 0 deaktiviert diese Begrenzung. Syntax: memcached_next_upstream_tries number; Standard: memcached_next_upstream_tries 0; Kontext: http, server, location Dieser Direktiv erschien in der Version 1.7.5. Begrenzt die Anzahl möglicher Versuche, um eine Anfrage an den nächsten Server zu übertragen. Der Wert 0 deaktiviert diese Begrenzung. Syntax: memcached_pass address; Standard: — Kontext: location, wenn in location Setzt den memcached-Server-Adressen. Die Adresse kann als Domainname oder IP-Adresse angegeben werden, und ein Port: memcached_pass localhost:11211; oder als UNIX-Domänen-Sockettpfad: memcached_pass unix:/tmp/memcached.socket; Wenn ein Domainname mehrere Adressen aufweist, werden sie im round-robin-Verfahren verwendet. Zusätzlich kann eine Adresse als Servergruppe angegeben werden. Syntax: memcached_read_timeout time; Standard: memcached_read_timeout 60s; Kontext: http, server, location Definiert einen Zeitraum für die Lesung einer Antwort vom memcached-Server. Der Zeitraum wird nur zwischen zwei erfolgreichen Lesevorgängen gesetzt, nicht für die Übertragung der gesamten Antwort. Wenn der memcached-Server innerhalb dieser Zeit keine Antwort übermittelt, wird die Verbindung geschlossen.

Übertragung der gesamten Antwort. Wenn der Memcached-Server innerhalb dieser Zeit nichts überträgt, wird die Verbindung geschlossen. Syntax: memcached_send_timeout time; Standard: memcached_send_timeout 60s; Kontext: http, server, location Setzt einen Zeitlimit für die Übertragung einer Anfrage an den Memcached-Server. Der Zeitlimit wird nur zwischen zwei erfolgreichen Schreibvorgängen, nicht für die Übertragung der gesamten Anfrage, gesetzt. Wenn der Memcached-Server innerhalb dieser Zeit nichts erhält, wird die Verbindung geschlossen. Syntax: memcached_socket_keepalive on | off; Standard: memcached_socket_keepalive off; Kontext: http, server, location Diese Direktive ist ab Version 1.15.6 verfügbar. Konfiguriert das Verhalten von "TCP keepalive" für ausgehende Verbindungen zu einem Memcached-Server. Standardmäßig sind die Einstellungen des Betriebssystems für den Socket in Kraft. Wenn der Wert der Direktive auf den Wert "on" gesetzt wird, wird für den Socket die SO_KEEPALIVE-Option aktiviert. Embedded Variables $memcached_key Definiert einen Schlüssel für das Abrufen der Antwort von einem Memcached-Server.
