Variablen

Das Modul ngx\_http\_gzip\_module ist ein Filter, der Antworten mittels der "gzip"-Methode komprimiert. Dies hilft oft, die Größe der übertragenen Daten um die Hälfte oder mehr zu reduzieren. Wenn das SSL/TLS-Protokoll verwendet wird, können komprimierte Antworten BREACH-Angriffen unterliegen.

Beispielkonfiguration 

gzip on;
gzip_min_length 1000;
gzip_proxied expired no-cache no-store private auth;
gzip_types text/plain application/xml;

Die Variable $gzip\_ratio kann verwendet werden, um den erreichten Kompressionsfaktor zu protokollieren.

Direktiven

Syntax: gzip on | off;
Standard: gzip off;
Kontext: http, server, location, if in location

Aktiviert oder deaktiviert die Komprimierung von Antworten.

Syntax: gzip\_buffers number size;
Standard: gzip\_buffers 32 4k|16 8k;
Kontext: http, server, location

Legt die Anzahl und Größe der verwendeten Kompressions-Buffers fest, um eine Antwort zu komprimieren. Standardmäßig ist die Buffergröße gleich einer Speicherseite. Dies ist entweder 4K oder 8K, je nach Plattform. Bis zur Version 0.7.28 wurden vier 4K oder 8K-Buffers standardmäßig verwendet.

Syntax: gzip\_comp\_level level;
Standard: gzip\_comp\_level 1;
Kontext: http, server, location

Legt den Kompressionsgrad einer Antwort fest. Akzeptable Werte liegen im Bereich von 1 bis 9.

Standard: —
Kontext: http, server, location

Der Direktiv akzeptiert mehrere Parameter: off deaktiviert die Kompression für alle über den Proxy geleiteten Anforderungen, ignorierend alle anderen Parameter; expired aktiviert die Kompression, wenn eine Antwortkopfzeile das "Expires" Feld enthält, mit einem Wert, der den Speichern von Cachen verhindert; no-cache aktiviert die Kompression, wenn eine Antwortkopfzeile das "Cache-Control" Feld enthält, mit dem "no-cache" Parameter; no-store aktiviert die Kompression, wenn eine Antwortkopfzeile das "Cache-Control" Feld enthält, mit dem "no-store" Parameter; private aktiviert die Kompression, wenn eine Antwortkopfzeile das "Cache-Control" Feld enthält, mit dem "private" Parameter; no_last_modified aktiviert die Kompression, wenn eine Antwortkopfzeile nicht das "Last-Modified" Feld enthält; no_etag aktiviert die Kompression, wenn eine Antwortkopfzeile nicht das "ETag" Feld enthält; auth aktiviert die Kompression, wenn ein Anforderungskopf das "Authorization" Feld enthält; any aktiviert die Kompression für alle über den Proxy geleiteten Anforderungen. Syntax: gzip_types mime-type ...; Standard: gzip_types text/html; Kontext: http, server, location Erlaubt die Komprimierung von Antworten für die angegebenen MIME-Typen zusätzlich zu "text/html". Syntax: gzip_vary on | off; Standard: gzip_vary off; Kontext: http, server, location Aktiviert oder deaktiviert das Einfügen des "Vary: Accept-Encoding" Antwortkopf Feldes, wenn die Direktiven gzip, gzip_static oder gunzip aktiv sind.
