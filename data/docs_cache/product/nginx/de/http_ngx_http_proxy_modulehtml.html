Der Modul ngx_http_proxy_module ermöglicht es, Anfragen an einen anderen Server weiterzuleiten.

Setzt die Größe des Buffers, der für das Lesen des ersten Teils der Antwort von dem durch den Proxyserver bereitgestellten Antwort verwendet wird. Der erste Teil enthält meistens einen kleinen Antwortkopf; wenn er die Buffergröße überschreitet, wird die Antwort als ungültig betrachtet. Standardmäßig ist die Buffergröße gleich einer Speicherseite. Dies ist entweder 4K oder 8K, je nach Plattform. Es kann jedoch kleiner gemacht werden. Syntax: proxy_buffering on | off; Default: proxy_buffering on; Kontext: http, server, location

Aktiviert oder deaktiviert das Buffern von Antworten vom durch den Proxyserver bereitgestellten Server. Wenn das Buffern aktiviert ist, empfängt nginx eine Antwort vom durch den Proxyserver bereitgestellten Server so schnell wie möglich und speichert sie in die Büffern, die durch die proxy_buffer_size und proxy_buffers Direktiven festgelegt sind. Wenn der gesamte Antwort nicht in die Speicher passt, kann ein Teil von ihm auf einem Speichermedium des Disks gespeichert werden. Die Schreiboperationen auf temporäre Dateien werden durch die proxy_max_temp_file_size und proxy_temp_file_write_Size Direktiven kontrolliert. Wenn das Buffern deaktiviert ist, wird die Antwort dem Client synchron übergeben, sofort, sobald sie empfangen wird. nginx versucht nicht, das gesamte Antwort vom durch den Proxyserver bereitgestellten Server zu lesen. Die maximale Größe der Daten, die nginx vom Server empfangen kann, wird durch die proxy_buffer_Size Direktive festgelegt. Das Buffern kann auch aktiviert oder deaktiviert werden, indem "yes" oder "no" in dem "X-Accel-Buffering" Antwortkopf-Feld übergeben wird. Diese Funktionalität kann deaktiviert werden, indem die proxy_ignore_Headers Direktive verwendet wird.

Dieses Directive kann verwendet werden, um lokale Kopien statischer unveränderlicher Dateien zu erstellen, z.B.: 

location /images/ {
    root /data/www;
    error_page 404 = /fetch$uri;
}
location /fetch/ {
    internal;
    proxy_pass http://backend/;
    proxy_store on;
    proxy_store_access user:rw group:rw all:r;
    proxy_temp_path /data/temp;
    alias /data/www/;
}

oder so: 
location /images/ {
    root /data/www;
    error_page 404 = @fetch;
}
location @fetch {
    internal;
    proxy_pass http://backend;
    proxy_store on;
    proxy_store_access user:rw group:rw all:r;
    proxy_temp_path /data/temp;
    root /data/www;
}

Context: http, server, location
Setzt die Berechtigungen für neu erstellte Dateien und Verzeichnisse, z.B.: proxy_store_access user:schreibberechtigung gruppe:schreibberechtigung all:lesen;
Wenn für eine Gruppe oder alle Berechtigungen angegeben werden, können die Benutzerberechtigungen ausgelassen werden: proxy_store_access gruppe:schreibberechtigung all:lesen;
Syntax: proxy_temp_file_write_size Größe; Standard: proxy_temp_file_write_size 8k|16k
Context: http, server, location
Begrenzt die Größe der Daten, die in eine temporäre Datei geschrieben werden, wenn die Buffering von Antworten von proxied Servern in temporäre Dateien aktiviert ist. Standardmäßig ist die Größe durch zwei Büffern, die durch die Direktiven proxy_buffer_Size und proxy_buffers festgelegt sind, begrenzt. Die maximale Größe einer temporären Datei wird durch die Direktive proxy_max_temp_file_Size festgelegt.
Syntax: proxy_temp_pfad Pfad [Ebene1 [Ebene2 [Ebene3]]]; Standard: proxy_temp_pfad proxy_temp;
Context: http, server, location
Definiert einen Speicherort für die Speicherung von temporären Dateien mit Daten von proxied Servern. Bis zu einer dreistufigen Unterverzeichnis-Hierarchie kann unter dem angegebenen Verzeichnis verwendet werden.
