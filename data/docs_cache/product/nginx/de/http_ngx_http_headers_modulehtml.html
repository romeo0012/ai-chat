Modul ngx_http_headers_module
Beispiel-Konfigurationsdirektiven add_header, add_header_erben, add_Trailer, add_Trailer_erben

Der Modul ngx_http_headers_module ermöglicht es, den "Expires" und "Cache-Control" Header-Feldern sowie beliebigen Feldern zu einer Antwort-Header-Zeile hinzuzufügen.

Beispiel-Konfiguration 

expires 24h;
expires modified +24h;
expires @24h;
expires 0;
expires -1;
expires epoch;
expires $expires;
add_header Cache-Control private;

Direktiven-Syntax: add_header name value [always];
Standard: —
Kontext: http, server, location, if in location
Fügt das angegebene Feld einer Antwort-Header-Zeile hinzu, sofern der Antwortstatuscode 200, 201 (1.3.10), 204, 206, 301, 302, 303, 304, 307 (1.1.16, 1.0.13), oder 308 (1.13.0) ist. Der Wert kann Variablen enthalten. Es können mehrere add_header-Direktiven vorhanden sein. Diese Direktiven werden von der vorherigen Konfigurationsstufe geerbt, sofern keine add_header-Direktiven auf der aktuellen Stufe definiert sind. Die Erbschaftsregeln können mit dem add_header_erben-Direktiv (1.29.3) neu definiert werden. Wenn das always-Parameter angegeben wird (1.7.5), wird der Header-Feld hinzugefügt, unabhängig vom Antwortstatuscode.

Syntax: add_header_erben on | off | merge;
Standard: add_header_erben on;
Kontext: http, server, location, if in location
Diese Direktive erschien in Version 1.29.3. Erlaubt es, die Erbschaftsregeln für die Werte, die in den add_header-Direktiven angegeben sind, zu ändern. Standardmäßig wird das Standard-Erbschaftsmodell verwendet.

Das epoch-Parameter setzt "Expires" auf den Wert "Don, 01 Jan 1970 00:00:01 GMT", und "Cache-Control" auf "no-cache". Das max-Parameter setzt "Expires" auf den Wert "Don, 31 Dez 2037 23:55:55 GMT", und "Cache-Control" auf 10 Jahre. Das off-Parameter deaktiviert das Hinzufügen oder Ändern der "Expires" und "Cache-Control" Antwort-Header-Felder.
