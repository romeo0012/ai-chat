Modul ngx_http_browser_Modul
Beispiele KonfigurationsDirectives
ancient_browser
ancient_browser_Wert
modern_browser
modern_browser_Wert

Der ngx_http_browser_Modul-Modul erstellt Variablen, deren Werte sich nach dem Wert des "User-Agent"-Anfrageheaderfelds richten: $modern_browser ist der Wert, der durch die modern_browser_Value-Directive festgelegt wird, wenn ein moderner Browser erkannt wurde; $ancient_browser ist der Wert, der durch die ancient_browser_Value-Directive festgelegt wird, wenn ein alter Browser erkannt wurde; $msie ist "1", wenn ein Browser als MSIE irgendeiner Version erkannt wurde.

Beispiel Konfiguration

Wählen Sie eine Indexdatei aus:
modern_browser_Wert ".modern.";
modern_browser msie 5.5;
modern_browser gecko 1.0.0;
modern_browser opera 9.0;
modern_browser safari 413;
modern_browser konqueror 3.0;
index index.${modern_browser}html index.html;

Umleitung für alte Browser:
modern_browser msie 5.0;
modern_browser gecko 0.9.1;
modern_browser opera 8.0;
modern_browser safari 413;
modern_browser konqueror 3.0;
modern_browser unlisted;
ancient_browser Links Lynx netscape4;
if ($ancient_browser) {
rewrite ^ /alte.html;
}

Directives Syntax:
ancient_browser string ...;
Standard: —
Kontext: http, server, location

Wenn irgendeiner der angegebenen Substrings im "User-Agent"-Anfrageheaderfeld gefunden wird, wird der Browser als alt betrachtet. Das spezielle String "netscape4" entspricht der regulären Ausdrucks "^Mozilla/[1-4]".

"Anforderungsspalte des Headerfeldes "User-Agent" wird der Browser als veraltet betrachtet. Der spezielle String "netscape4" entspricht der regulären Ausdruckszeichenfolge "^Mozilla/[1-4]". Syntax: ancient_browser_value string; Standard: ancient_browser_value 1; Kontext: http, Server, Location Setzt einen Wert für die Variable $ancient_browser. Syntax: modern_browser browser version;modern_browser unlisted; Standard: — Kontext: http, Server, Location Gibt eine Version an, ab der ein Browser als modern betrachtet wird. Ein Browser kann ein beliebiger einer folgenden sein: msie, gecko (Browser basierend auf Mozilla), opera, safari, oder konqueror. Versionen können in den folgenden Formaten angegeben werden: X, X.X, X.X.X, oder X.X.X.X. Die Maximalwerte für jedes Format sind 4000, 4000.99, 4000.99.99, und 4000.99.99.99, jeweils. Der spezielle Wert unlisted gibt an, einen Browser als modern zu betrachten, wenn er nicht durch die modern_browser und ancient_browser Direktiven aufgelistet wurde. Andernfalls wird der Browser als veraltet betrachtet. Wenn eine Anforderung nicht das "User-Agent" Feld im Header bereitstellt, wird der Browser als nicht aufgelistet betrachtet. Syntax: modern_browser_value string; Default: modern_browser_value 1; Kontext: http, Server, Location Setzt einen Wert für die Variable $modern_browser.
