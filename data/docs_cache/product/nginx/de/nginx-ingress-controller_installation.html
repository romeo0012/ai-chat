Um vom Ingress-NGINX Controller zum NGINX Ingress Controller zu migrieren, können Sie die folgenden Schritte ausführen:

a. Deinstallieren Sie den Ingress-NGINX Controller.

b. Installieren Sie den NGINX Ingress Controller.

c. Konfigurieren Sie die entsprechenden Ressourcen für den NGINX Ingress Controller.

d. Überprüfen Sie, ob die Migration erfolgreich war.
