Modul ngx_stream_map_module (1.11.2)
Dieser Modul erstellt Variablen, deren Werte sich von Werten anderer Variablen ableiten.

Beispiel-Konfiguration
map $remote_addr $limit {
127.0.0.1 "";
default $binary_remote_addr;
}
limit_conn_zone $limit zone=addr:10m;
limit_conn addr 1;

Syntax: map string $variable { ... }
Standard: —
Kontext: stream
Erstellt eine neue Variable, deren Wert sich von Werten einer oder mehrerer der in dem ersten Parameter angegebenen Quellvariablen ableitet. Da Variablen nur dann bewertet werden, wenn sie verwendet werden, kostet die einfache Erklärung auch von einer großen Anzahl von "map"-Variablen keinen zusätzlichen Kosten für die Verarbeitung von Verbindungen. Die Parameter innerhalb des map-Blocks geben eine Zuordnung zwischen Quell- und Ergebniswerten an. Quellwerte werden als Zeichenfolgen oder Reguläre Ausdrücke angegeben. Zeichenfolgen werden unabhängig von der Groß-/Kleinschreibung verglichen. Ein Regulärer Ausdruck sollte entweder vom "~"-Symbol für sensitives Matching oder vom "~*"-Symbol für insensitives Matching beginnen. Ein Regulärer Ausdruck kann Namen und Positionen von Captures enthalten, die später in anderen Direktiven zusammen mit dem Ergebnisvariablen verwendet werden können. Wenn ein Quellwert den Namen eines speziellen Parameters entspricht, muss er mit dem "\"-Symbol vorangestellt werden. Der Ergebniswert kann Text, Variable und deren Kombination enthalten.

Beschrieben unten sollte der "\-Symbol vorangestellt werden. Das Ergebnis kann Text, Variable oder deren Kombination enthalten. Folgende spezielle Parameter werden auch unterstützt: default-Wert setzt den Ergebniswert, wenn der Quellwert keiner der angegebenen Varianten entspricht. Wenn default nicht angegeben wird, wird der Ergebniswert leer. hostnames gibt an, dass Quellwerte Hostnamen mit einem Präfix- oder Suffix-Mask sein können: \*.beispiel.com 1; beispiel.\* 1; Die folgenden zwei Einträge können kombiniert werden: example.com 1; \*.example.com 1; Dieser Parameter sollte vor der Liste der Werte angegeben werden. include file beinhaltet eine Datei mit Werten. Es können mehrere Einbeziehungen geben. volatile gibt an, dass die Variable nicht zwischengespeichert werden kann (1.11.7). Die Suche erfolgt in folgender Priorität und wird bei dem ersten treffenden Eintrag beendet: der unmaskierte Zeichenfolgenwert der Zeichenfolge mit einem Präfix-Mask, z.B. "\*mail." der erste treffende reguläre Ausdruck (in der Reihenfolge seiner Aufstellung in der Konfigurationsdatei) der default-Wert
