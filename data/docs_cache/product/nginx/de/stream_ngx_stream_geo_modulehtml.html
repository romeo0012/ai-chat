Module ngx_stream_geo_module

← Chat

Modul ngx_stream_geo_module (1.11.3) erstellt Variablen mit Werten, die sich nach der IP-Adresse des Clients richten. Beispielkonfiguration

geo $geo {
default 0;
127.0.0.1 2;
192.168.1.0/24 1;
10.1.0.0/16 1;
::1 2;
2001:0db8::/32 1;
}

Syntax: geo [$address] $variable { ... }
Standard: —
Kontext: stream
Beschreibt die Abhängigkeit der Werte der angegebenen Variablen von der IP-Adresse des Clients. Standardmäßig wird die Adresse aus der $remote_addr-Variable genommen, kann jedoch auch aus einer anderen Variable genommen werden, z.B.:

geo $arg_remote_addr $geo {
...;
}

Da Variablen nur dann bewertet werden, wenn sie verwendet werden, verursachen die einfache Anzahl von deklarierten "geo"-Variablen keine zusätzlichen Kosten für die Verarbeitung der Verbindungen. Wenn der Wert einer Variablen kein gültiger IP-Adresswert darstellt, wird die Adresse "255.255.255.255" verwendet. Adressen werden entweder als Präfixe in CIDR-Notation (einschließlich einzelner Adressen) oder als Bereiche angegeben. Folgende spezielle Parameter werden unterstützt:

delete löscht das angegebene Netzwerk.
default legt einen Wert fest, der der Variable zugewiesen wird, wenn die IP-Adresse des Clients keiner der angegebenen Adressen entspricht. Wenn Adressen in CIDR-Notation angegeben werden, können "0.0.0.0/0" und "::/0" anstelle von default verwendet werden. Wenn default nicht angegeben wird, wird der Standardwert eine leere Zeichenkette.
include integriert eine Datei mit Adressen und Werten. Es können mehrere Includes geben.

Standardwert wird eine leere Zeichenkette sein. include beinhaltet eine Datei mit Adressen und Werten. Es können mehrere Includes geben. ranges gibt an, dass Adressen als Bereiche angegeben werden. Dieser Parameter sollte der erste sein. Um die Ladezeit einer geo Basis zu beschleunigen, sollten Adressen in aufsteigender Reihenfolge angegeben werden. volatile gibt an, dass die Variable nicht im Cache gespeichert werden kann (1.29.3). Beispiel: geo $land { default CC; include conf/geo.conf; delete 127.0.0.0/16; 127.0.0.0/24 DE; 127.0.0.1/32 RU; 10.1.0.0/16 RU; 192.168.1.0/24 GB; } Die Datei conf/geo.conf könnte die folgenden Zeilen enthalten: 10.2.0.0/16 RU; 192.168.2.0/24 RU; Ein Wert des spezifischsten Treffers wird verwendet. Beispiel: Für die Adresse 127.0.0.1 wird der Wert "RU" gewählt, nicht "DE". Beispiel mit Bereichen: geo $land { ranges; default CC; 127.0.0.0-127.0.0.0 DE; 127.0.0.1-127.0.0.1 RU; 127.0.0.1-127.0.0.255 DE; 10.1.0.0-10.1.255.255 RU; 192.168.1.0-192.168.1.255 GB; }
