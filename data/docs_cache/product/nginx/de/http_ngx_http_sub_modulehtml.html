Modul ngx_http_sub_modulExample KonfigurationsDirectiven sub_filter, sub_filter_letzte_änderung, sub_filter_einmalig, sub_filter_typ

Der ngx_http_sub_modul-Modul ist ein Filter, der eine Antwort durch Ersetzen einer angegebenen Zeichenkette durch eine andere ändert. Dieser Modul wird standardmäßig nicht gebaut und muss mit dem --with-http_sub_modul-Konfigurationsparameter aktiviert werden. Beispiel-Konfiguration

location / {
sub_filter '<a href="http://127.0.0.1:8080/' '<a href="https://$host/";
sub_filter '<img src="http://127.0.0.1:8080/' '<img src="https://$host/";
sub_filter_einmalig on;
}

Directives Syntax: sub_filter string ersetzung; Default: — Kontext: http, server, location
Setzt eine Zeichenkette für das Ersetzen und eine Ersetzungszeichenkette. Die Zeichenkette für das Ersetzen wird unabhängig von der Groß-/Kleinschreibung verglichen. Die Zeichenkette für das Ersetzen (1.9.4) und die Ersetzungszeichenkette können Variablen enthalten. Mehrere sub_filter-Directives können auf demselben Konfigurationsniveau angegeben werden (1.9.4). Diese Directives werden von der vorherigen Konfigurationsstufe geerbt, wenn und nur wenn keine sub_filter-Directives auf dem aktuellen Niveau definiert sind.

Syntax: sub_filter_letzte_änderung on | off; Default: sub_filter_letzte_änderung off; Kontext: http, server, location
Diese Directive erschien in Version 1.5.1. Erlaubt die Erhaltung des "Last-Modified"-Headerfelds der originalen Antwort während des Ersetzens, um Antwortspeicherung zu erleichtern. Standardsmäßig wird das Headerfeld entfernt, da die Inhalte der Antwort während der Verarbeitung geändert werden.

Um Antwort-Vorratscaching zu erleichtern. Standardmäßig wird der Headerfeld entfernt, da Inhalte der Antwort während der Verarbeitung modifiziert werden. Syntax: sub_filter_once on | off; Standard: sub_filter_once on; Kontext: http, server, location Gibt an, ob für jede zu ersetzende Zeichenkette einmalig oder wiederholt gesucht werden soll. Syntax: sub_filter_types mime-type ...; Standard: sub_filter_types text/html; Kontext: http, server, location Aktiviert Zeichenersetzung in Antworten mit den angegebenen MIME-Typen zusätzlich zu “text/html”. Der spezielle Wert “*” passt sich jeder MIME-Typ an (0.8.29).
