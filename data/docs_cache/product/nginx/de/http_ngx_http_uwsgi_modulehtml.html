Das ngx_http_uwsgi_module-Modul ermöglicht die Übermittlung von Anfragen an einen uwsgi-Server. Beispielkonfiguration

location / {
include uwsgi_params;
uwsgi_pass localhost:9000;
}

Direktiven Syntax:

Default: —
Context: http, server, location

Diese Direktive ist ab Version 1.29.3 verfügbar. Definiert die Bedingungen, unter denen der Zugriff auf einen uwsgi-Server erlaubt oder verweigert wird. Wenn alle Zeichenfolgenparameter nicht leer sind und nicht mit “0” gleich sind, wird der Zugriff erlaubt. Die Bedingungen werden jedes Mal vor dem Herstellen einer Verbindung zu einem uwsgi-Server bewertet. Die Parameterwerte können Variablen enthalten:

Datei wird umbenannt. Ab der Version 0.8.9 können temporäre Dateien und die persistente Speicherstelle auf verschiedenen Dateisystemen platziert werden. Bitte beachten Sie jedoch, dass in diesem Fall eine Datei über zwei Dateisysteme kopiert wird, anstatt der billigen Umbenennung. Es wird daher empfohlen, dass für jede gegebene Speicherort beide gespeicherten Dateien und ein Verzeichnis, das temporäre Dateien enthält, das durch die uwsgi_temp_path-Direktive festgelegt wird, auf demselben Dateisystem platziert werden. Diese Direktive kann verwendet werden, um lokale Kopien statischer unveränderlicher Dateien zu erstellen, z.B.:

location /images/ {
root /data/www;
error_page 404 = /fetch$uri;
}

location /fetch/ {
internal;
uwsgi_pass backend:9000;
...
uwsgi_store on;
uwsgi_store_access user:rw group:rw all:r;
uwsgi_temp_path /data/temp;
alias /data/www/;
}

Syntax: uwsgi_store_access users:permissions ...;
Default: uwsgi_store_access user:rw;
Context: http, server, location
Setzt die Zugriffsrechte für neu erstellte Dateien und Verzeichnisse fest, z.B.: uwsgi_store_access user:rw group:rw all:r;
Wenn es irgendwelche Gruppen- oder alle Zugriffsrechte gibt, können die Benutzerrechte möglicherweise weggelassen werden: uwsgi_store_access group:rw all:r;

Syntax: uwsgi_temp_file_write_size size;
Default: uwsgi_temp_file_write_size 8k|16k;
Context: http, server, location
Begrenzt die Größe der Daten, die in eine temporäre Datei geschrieben werden, wenn die Antworten des uwsgi-Servers auf temporäre Dateien buffern wird. Standardmäßig ist die Größe durch zwei Büffer, die durch die Direktiven uwsgi_buffer_size und uwsgi_buffers festgelegt sind, begrenzt.

Die folgende Einstellung ermöglicht es, temporäre Dateien zu verwenden. Standardmäßig ist die Größe durch zwei Buffers, die durch die Direktiven uwsgi_buffer_size und uwsgi_buffers festgelegt sind, begrenzt. Die maximale Größe einer temporären Datei wird durch die Direktive uwsgi_max_temp_file_size festgelegt. Syntax: uwsgi_temp_path Pfad [Ebene1 [Ebene2 [Ebene3]]]; Standard: uwsgi_temp_path uwsgi_temp; Kontext: http, server, location

Definiert einen Speicherort für die Speicherung von temporären Dateien, die von uwsgi-Servern empfangen werden. Es kann eine bis zu drei-stufige Unterverzeichnis-Hierarchie unter dem angegebenen Verzeichnis verwendet werden. Beispiel: In der folgenden Konfiguration uwsgi_temp_path /Spool/nginx/uwsgi_temp 1 2; kann eine temporäre Datei wie folgt aussehen: /Spool/nginx/uwsgi_temp/7/45/00000123457

Siehe auch den Parameter use_temp_path der Direktive uwsgi_cache_path.
