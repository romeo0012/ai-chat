Module ngx_stream_proxy_module

← Chat

Modul ngx_stream_proxy_module (1.9.0) ermöglicht das Proxying von Datenstromen über TCP, UDP (1.9.13) und UNIX-Domänen-Sockets.

Beispielkonfiguration: 

server {
    listen 127.0.0.1:12345;
    proxy_pass 127.0.0.1:8080;
}
server {
    listen 12345;
    proxy_connect_timeout 1s;
    proxy_timeout 1m;
    proxy_pass example.com:12345;
}
server {
    listen 53 udp reuseport;
    proxy_timeout 20s;
    proxy_pass dns.example.com:53;
}
server {
    listen [::1]:12345;
    proxy_pass unix:/tmp/stream.socket;
}

Syntax: proxy_bind address [transparent] | off;
Standard: —
Kontext: stream, server

Diese Direktive ist ab Version 1.9.2 verfügbar. Stellt ausgehende Verbindungen zu einem proxieden Server aus der angegebenen lokalen IP-Adresse her. Der Wert des Parameters kann Variablen enthalten (1.11.2).

Verbindet ausgehende Verbindungen mit einem proxyspeisenden Server von der angegebenen lokalen IP-Adresse her. Der Wert des Parameters kann Variablen enthalten (1.11.2). Der Sonderwert off stört die Wirkung der proxy_bind-Direktive, die vom vorherigen Konfigurationsniveau geerbt wurde, was dem System erlaubt, die lokale IP-Adresse automatisch zuzuweisen. Der transparente Parameter (1.11.0) erlaubt ausgehende Verbindungen zu einem proxyspeisenden Server von einer nicht-lokalen IP-Adresse her, z.B. von der echten IP-Adresse eines Clients: proxy_bind $remote_addr transparent;

Um diesen Parameter zu funktionieren, ist es üblich, nginx-Workerprozesse mit den Administratorrechten auszuführen. Auf Linux ist dies nicht erforderlich (1.13.8), da wenn der transparente Parameter angegeben wird, Workerprozesse die CAP_NET_RAW-Berechtigung von der Masterprozess erben. Es ist auch erforderlich, die Kernel-Routingtabelle für das Intercepten von Netzwerkverkehr vom proxyspeisenden Server zu konfigurieren.
