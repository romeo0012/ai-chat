Modul ngx_http_map_module
Beispiel-Konfiguration

Das Modul ngx_http_map_module erstellt Variablen, deren Werte sich von Werten anderer Variablen ableiten.

Beispiel-Konfiguration
map $http_host $name {
hostnames;
default 0;
example.com 1;
*.example.com 1;
example.org 2;
*.example.org 2;
.example.net 3;
wap.* 4;
}
map $http_user_agent $mobile {
default 0;
"~Opera Mini" 1;
}

Syntax: map string $variable { ... }
Standard: —
Kontext: http
Erstellt eine neue Variable, deren Wert sich von Werten einer oder mehrerer der in dem ersten Parameter angegebenen Quellvariablen ableitet. Bis zur Version 0.9.0 konnte nur eine einzige Variable im ersten Parameter angegeben werden. Da Variablen nur dann bewertet werden, wenn sie verwendet werden, fügt die bloße Erklärung auch von einer großen Anzahl von "map"-Variablen keinerlei zusätzliche Kosten für die Anfrageverarbeitung hinzu.

Parameter innerhalb des map-Blocks geben eine Zuordnung zwischen Quell- und Ergebniswerten vor. Quellwerte werden als Zeichenfolgen oder Regulären Ausdrücken (0.9.6) angegeben. Zeichenfolgen werden unabhängig von der Groß-/Kleinschreibung verglichen. Ein Regulärer Ausdruck sollte entweder mit dem "~"-Symbol für eine sensitiven Vergleich oder mit den "~*"-Symbolen (1.0.4) für einen insensitiven Vergleich beginnen. Ein Regulärer Ausdruck kann beliebige benannte und positionelle Kapitüren enthalten, die später in anderen Direktiven zusammen mit dem Ergebnisvariable verwendet werden können. Wenn ein Quellwert den Namen einer der beschriebenen speziellen Parameter entspricht, muss er mit dem "\"-Symbol vorangestellt werden.

Quellewert stimmt auf einen der Namen der speziellen Parameter unten angegebenen überein, sollte er mit dem „\“-Symbol vorangestellt werden. Das Ergebnis kann Text, Variable (0.9.0) und ihre Kombination (1.11.0) enthalten. Die folgenden speziellen Parameter werden auch unterstützt: default-Wert setzt den Ergebniswert, wenn der Quellewert auf keinen der angegebenen Varianten entspricht. Wenn default nicht angegeben ist, wird der Ergebniswert leer. hostnames gibt an, dass die Quellewerte Hostnamen mit einem Präfix- oder Suffix-Mask sein können: \*.beispiel.com 1; beispiel.\* 1; Die folgenden zwei Einträge können kombiniert werden: example.com 1; \*.example.com 1; Dieser Parameter sollte vor der Liste der Werte angegeben werden. include file enthält eine Datei mit Werten. Es können mehrere Einbeziehungen geben. volatile gibt an, dass die Variable nicht zwischengespeichert werden kann (1.11.7). Die Suche erfolgt in folgender Priorität und wird bei dem ersten treffenden Varianten beendet: der unmaskierte Zeichenfolgewert der Zeichenfolge mit keinem Mask die längste Zeichenfolge mit einem Präfix-Mask, z.B. “*.beispiel.com” die längste Zeichenfolge mit einem Suffix-Mask, z.B. “mail.*” die erste treffende reguläre Ausdrucksübereinstimmung (in der Reihenfolge ihrer Aufstellung im Konfigurationsdatei) der default-Wert Syntax: map_hash_bucket_size Größe; Standard: map_hash_bucket_size 32|64|128; Kontext: http Setzt die Größe des Buckets für die Hash-Tabellen der Map-Variablen. Die Standardgröße hängt von der Größe des Cache-Lines des Prozessors ab. Die Einrichtung von Hash-Tabellen wird in einer separaten Dokumentation bereitgestellt.
