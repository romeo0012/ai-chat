Bei HTTP-Anfragen werden die Headerfelder an einen FastCGI-Server als Parameter übergeben. In Anwendungen und Skripten, die als FastCGI-Server ausgeführt werden, werden diese Parameter normalerweise als Umgebungsvariablen verfügbar gemacht.
