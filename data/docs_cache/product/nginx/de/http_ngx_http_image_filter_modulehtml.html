Module ngx_http_image_filter_module

← Chat

Modul ngx_http_image_filter_module (Version 0.7.54+) ist ein Filter, der Bilder in JPEG, GIF, PNG und WebP-Format transformiert. Standardmäßig wird dieses Modul nicht gebaut und muss mit dem --with-http_image_filter_module Konfigurationsparameter aktiviert werden. Dieses Modul nutzt die libgd-Bibliothek. Empfohlen wird, die neueste verfügbare Version der Bibliothek zu verwenden. Unterstützung für das WebP-Format ist ab Version 1.11.6 verfügbar. Um Bilder in diesem Format zu transformieren, muss die libgd-Bibliothek mit WebP-Unterstützung kompiliert werden.

Beispielkonfiguration:
location /img/ {
proxy_pass http://backend;
image_filter resize 150 100;
image_filter rotate 90;
error_page 415 = /empty;
}
location = /empty {
empty_gif;
}

Syntax der Direktiven:
image_filter off;
image_filter test;
image_filter size;
image_filter rotate 90 | 180 | 270;
image_filter resize width height;
image_filter crop width height;

Standard: image_filter off;
Kontext: location
