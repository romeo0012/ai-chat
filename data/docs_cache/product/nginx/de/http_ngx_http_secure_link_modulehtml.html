Module ngx_http_secure_link_module

← Chat

Modul ngx_http_secure_link_module (Version 0.7.18) dient zur Überprüfung der Authentizität von angeforderten Links, zur Sicherung von Ressourcen gegen unautorisierte Zugriffe und zur Begrenzung der Link-Lebensdauer. Die Authentizität eines angeforderten Links wird durch Vergleich des Checksum-Werts, der in einer Anfrage übermittelt wird, mit dem berechneten Wert für die Anfrage überprüft. Wenn ein Link eine begrenzte Lebensdauer hat und die Zeit abgelaufen ist, wird der Link als veraltet betrachtet. Der Status dieser Überprüfungen wird im Variablenwert $secure_link verfügbar gemacht. Das Modul bietet zwei alternative Betriebsmodi an. Der erste Modus wird durch die secure_link_secret Direktive aktiviert und dient zur Überprüfung der Authentizität von angeforderten Links sowie zur Sicherung von Ressourcen gegen unautorisierte Zugriffe. Der zweite Modus (Version 0.8.50) wird durch die secure_link und secure_link_md5 Direktiven aktiviert und dient auch zur Begrenzung der Lebensdauer von Links. Dieses Modul wird standardmäßig nicht gebaut, es muss mit dem --with-http_secure_link_module Konfigurationsparameter aktiviert werden.

Syntax der Direktiven:
secure_link expression;
Standard: —
Kontext: http, server, location

Definiert eine Zeichenkette aus der der Checksum-Wert und die Lebensdauer eines Links extrahiert werden. In einer Zeichenkette verwendete Variablen sind meist mit einer Anfrage verbunden; siehe Beispiel unten. Der extrahierte Checksum-Wert aus der Zeichenkette wird mit dem MD5-Hash-Wert der Zeichenkette definiert durch die secure_link_md5 Direktive verglichen.

Beispiel:
location /my_resource {
secure_link $secure_link_secret;
}

Diese Module ist nicht standardmäßig erstellt, es muss mit dem --with-http_secure_link_module Konfigurationsparameter aktiviert werden.

Wert, der aus der Zeichenkette extrahiert wird, wird mit dem MD5-Hashwert des Ausdrucks, wie von der Direktive secure_link_md5 definiert, verglichen. Wenn die Prüfsummen unterschiedlich sind, wird die Variable $secure_link auf leere Zeichenkette gesetzt. Wenn die Prüfsummen übereinstimmen, wird der Linkzeitraum überprüft. Wenn der Link ein begrenzter Zeitraum hat und die Zeit abgelaufen ist, wird die Variable $secure_link auf "0" gesetzt. Andernfalls wird sie auf "1" gesetzt. Der MD5-Hashwert, der in einer Anfrage übergeben wird, wird in base64url-Kodierung kodiert. Wenn der Link einen begrenzten Zeitraum hat, wird die Ablaufzeit in Sekunden seit Epoch (Thu, 01 Jan 1970 00:00:00 GMT) festgelegt. Der Wert wird in der Ausdrucksauswahl nach dem MD5-Hash angegeben und durch eine Komma getrennt. Der Ablaufzeitwert, der in einer Anfrage übergeben wird, ist über die Variable $secure_link_expires für die Verwendung in der secure_link_md5-Direktive verfügbar. Wenn die Ablaufzeit nicht angegeben ist, hat der Link unbegrenzten Zeitraum. Syntax: secure_link_md5 Ausdruck; Standard: — Kontext: http, server, location Definiert einen Ausdruck, für den der MD5-Hashwert berechnet und mit dem Wert aus einer Anfrage verglichen wird. Der Ausdruck soll den sicheren Teil eines Links (Ressource) und ein geheimes Zutat enthalten. Wenn der Link einen begrenzten Zeitraum hat, soll der Ausdruck auch die Variable $secure_link_expires enthalten. Um unautorisierten Zugriff zu verhindern, kann der Ausdruck Informationen über den Client enthalten, wie seine Adresse und Browserversion.

Syntax: 

secure_link_md5 expression;

Standard: 
—

Kontext: 
http, server, location

Definiert einen Ausdruck, für den der MD5-Hashwert berechnet und mit dem Wert aus einer Anfrage verglichen wird. Der Ausdruck soll den sicheren Teil eines Links (Ressource) und ein geheimes Zutat enthalten. Wenn der Link einen begrenzten Zeitraum hat, soll der Ausdruck auch die Variable $secure_link_expires enthalten. Um unautorisierten Zugriff zu verhindern, kann der Ausdruck Informationen über den Client enthalten, wie seine Adresse und Browserversion.

Um unautorisierten Zugriff zu verhindern, kann die Ausdrucksweise Informationen über den Client enthalten, wie seine Adresse und der Browser-Version. Beispiel: location /s/ { secure_link $arg_md5,$arg_expires; secure_link_md5 "$secure_link_expires$uri$remote_addr secret"; if ($secure_link = "") { return 403; } if ($secure_link = "0") { return 410; } ... } Die „/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647“-Verknüpfung beschränkt den Zugriff auf „/s/link“ für den Client mit der IP-Adresse 127.0.0.1. Die Verknüpfung hat zudem einen begrenzten Lebenszeitraum bis zum 19. Januar 2038 (GMT). Auf UNIX kann der Wert des md5-Anfragearguments wie folgt abgerufen werden: echo -n '2147483647/s/link127.0.0.1 secret' | \ openssl md5 -binary | openssl base64 | tr +/ -_ | tr -d = Syntax: secure_link_secret word; Default: — Kontext: location Definiert ein geheimes Wort, das zur Überprüfung der Authentizität der angeforderten Verknüpfungen verwendet wird. Die vollständige URI einer angeforderten Verknüpfung sieht so aus: /prefix/hash/link, wobei hash ein hexadezimaler Wert ist, der aus der Konkatenation der Verknüpfung und des geheimen Wortes berechnet wurde, und prefix ein beliebiger Zeichenkette ohne Schrägstriche ist. Wenn die angeforderten Verknüpfung die Authentizität überprüft, wird die $secure_link-Variable auf die aus der Anfrage-URI extrahierte Verknüpfung festgelegt. Andernfalls wird die $secure_link-Variable auf einen leeren Zeichenstring festgelegt.

(Technische Terme, Codeblöcke, Befehle, Dateipfade und URLs wurden unverändert übernommen.)

Das folgende Element ist auf den aus der Anforderungs-URI extrahierten Link festgelegt. Andernfalls wird der Wert der Variable $secure_link auf eine leere Zeichenkette festgelegt. Beispiel:

location /p/ {
    secure_link_secret secret;
    if ($secure_link = "") {
        return 403;
    }
    rewrite ^ /secure/$secure_link;
}
location /secure/ {
    internal;
}

Eine Anfrage von “/p/5e814704a28d9bc1914ff19fa0c4a00a/link” wird intern umgeleitet auf “/secure/link”. Auf UNIX kann der Hash-Wert für dieses Beispiel wie folgt berechnet werden:

echo -n 'linksecret' | openssl md5 -hex

Embedded Variablen

$secure_link
Der Wert einer Link-Überprüfung. Der genaue Wert hängt von der ausgewählten Betriebsmodus ab.

$secure_link_expires
Die Lebensdauer eines in einer Anfrage übermittelten Links; sollte nur im secure_link_md5-Directive verwendet werden.
