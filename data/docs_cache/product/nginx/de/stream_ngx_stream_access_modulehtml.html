Modul ngx_stream_zugriffsmodul
Beispiel-Konfigurationsdirektiven erlauben verweigern
Das ngx_stream_zugriffsmodul-Modul (1.9.2) ermöglicht es, den Zugang bestimmter Client-Adressen zu beschränken. Beispiel-Konfiguration

server {
    ...
    verweigern 192.168.1.1;
    zulassen 192.168.1.0/24;
    zulassen 10.1.1.0/16;
    zulassen 2001:0db8::/32;
    verweigern all;
}

Die Regeln werden in Reihenfolge überprüft, bis der erste Treffer gefunden wird. In diesem Beispiel ist der Zugang nur für die IPv4-Netzwerke 10.1.1.0/16 und 192.168.1.0/24 zugelassen, ausgenommen die Adresse 192.168.1.1, und für das IPv6-Netzwerk 2001:0db8::/32.

Direktiven-Syntax:

allow address | CIDR | unix: | all;
Default: —
Context: stream, server
Erlaubt den Zugang für die angegebene Netzwerk- oder Adresse. Wenn der Sonderwert unix: angegeben wird, erlaubt es den Zugang für alle UNIX-Domänen-Sockets.

Direktiven-Syntax:

deny address | CIDR | unix: | all;
Default: —
Context: stream, server
Verweigert den Zugang für die angegebene Netzwerk- oder Adresse. Wenn der Sonderwert unix: angegeben wird, verweigert es den Zugang für alle UNIX-Domänen-Sockets.
