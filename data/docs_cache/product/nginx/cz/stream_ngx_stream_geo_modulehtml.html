Module ngx_stream_geo_module

← Chat

Modul ngx_stream_geo_modul (1.11.3) vytváří proměnné s hodnotami, které závisí na adrese klienta. Příklad Konfigurace 

geo $geo {
    default 0;
    127.0.0.1 2;
    192.168.1.0/24 1;
    10.1.0.0/16 1;
    ::1 2;
    2001:0db8::/32 1;
}

Pravidla syntaxe: geo [$adresa] $proměnná { ... } Výchozí: — Kontext: stream Popisuje závislost hodnot zadané proměnné na adrese klienta. Výchozí adresa je brána z proměnné $remote_addr, ale může být brána také z jiné proměnné, například: geo $arg_remote_addr $geo { ...; } Protože proměnné se vyhodnocují pouze tehdy, když jsou použity, nezpůsobí ani velký počet deklarovaných "geo" proměnných žádné extra náklady na zpracování spojení. Pokud hodnota proměnné nezastupuje platnou IP adresu, použije se adresa "255.255.255.255". Adresy se zadávají buď jako předpony v CIDR notaci (včetně jednotlivých adres) nebo jako rozsahy. Následující speciální parametry jsou také podporovány:
  • delete odstraní zadanou sít.
  • default hodnotu nastaví proměnné, pokud adresa klienta neodpovídá žádné z uvedených adres. Pokud jsou adresy zadány v CIDR notaci, mohou být použity "0.0.0.0/0" a "::/0" místo default. Pokud není default zadán, výchozí hodnota bude prázdná řetězec.
  • include zahrnuje soubor s adresami a hodnotami. Může být zahrnuto několik souborů.

Text v angličtině:

Výchozí hodnota bude prázdná řetězec. include zahrnuje soubor s adresami a hodnotami. Může se jednat o více zahrnutí. ranges ukazuje, že adresy jsou určeny jako rozsahy. Tento parametr by měl být první. Chcete-li rychleji načíst geografickou základnu, adresy by měly být umístěny v rostoucí řadě. volatile ukazuje, že proměnná není uložitelná do cache (1.29.3). Příklad: geo $země { default ZZ; include konfig/geo.conf; delete 127.0.0.0/16; 127.0.0.0/24 US; 127.0.0.1/32 RU; 10.1.0.0/16 RU; 192.168.1.0/24 UK; } Soubor konfig/geo.conf může obsahovat následující řádky: 10.2.0.0/16 RU; 192.168.2.0/24 RU; Hodnota nejvýraznějšího shodu se používá. Například pro adresu 127.0.0.1 bude volena hodnota “RU”, nikoli “US”. Příklad s rozsahy: geo $země { ranges; default ZZ; 127.0.0.0-127.0.0.0 US; 127.0.0.1-127.0.0.1 RU; 127.0.0.1-127.0.0.255 US; 10.1.0.0-10.1.255.255 RU; 192.168.1.0-192.168.1.255 UK; }
