Poznamenejte si, že pokud je direktiva ssl_prefer_server_ciphers nastavena na hodnotu “on”, musí být konfigurovány cifry podle RFC 9113, Dodatek A a podporované klienty. Syntax direktiv: http2 on | off; Výchozí hodnota: http2 off; Kontext: http, server

Proměnné vložené do kódu Tento modul ngx_http_v2_module podporuje následující proměnné vložené do kódu: $http2 identifikátor protokolu HTTP/2, který byl uzavřen: "h2" pro HTTP/2 přes SSL, "h2c" pro HTTP/2 přes čistý TCP, nebo prázdná řetězcová hodnota jinak.
