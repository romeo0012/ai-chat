Module ngx_http_dav_module

← Chat

Modul ngx_http_dav_module je určen k automatizaci správy souborů prostřednictvím protokolu WebDAV. Tento modul zpracovává HTTP a WebDAV metody PUT, DELETE, MKCOL, COPY a MOVE. Tento modul není vytvářen všude výchozí, musí být povolen pomocí konfiguračního parametru --with-http_dav_module. WebDAV klienti, které potřebují další WebDAV metody k provozu, se s tímto modulem nebudou spolupracovat.

Příklad Konfigurace 

location / {
    root /data/www;
    client_body_temp_path /data/client_temp;
    dav_methods PUT DELETE MKCOL COPY MOVE;
    create_full_put_path on;
    dav_access group:rw all:r;
    limit_except GET {
        allow 192.168.1.0/32;
        deny all;
    }
}

Syntaxe direktiv:

  • create_full_put_path on | off; Výchozí: create_full_put_path off; Kontext: http, server, location

WebDAV specifikace umožňuje vytvářet soubory pouze v již existujících adresářích. Tato direktiva umožňuje vytvářet všechny potřebné mezilehlé adresáře.

  • dav_access users:permissions ...; Výchozí: dav_access user:rw; Kontext: http, server, location

Nastavuje přístupová oprávnění pro nově vytvořené soubory a adresáře, například: dav_access user:rw group:rw all:r; Pokud jsou určena jakákoliv skupinová nebo všechna oprávnění, mohou být oprávnění uživatele omítnuty: dav_access group:rw all:r;

  • dav_methods off | method ...; Výchozí: dav_methods off; Kontext: http, server, location

Povoluje zadané HTTP a WebDAV metody.

Příklad konfigurace umožňuje následující metody: PUT, DELETE, MKCOL, COPY a MOVE.

Direktivy umožňují automatizaci správy souborů prostřednictvím protokolu WebDAV.

Syntax: dav_methods off | metoda ...; Výchozí: dav_methods off; Kontext: http, server, location Umožňuje zadané HTTP a WebDAV metody. Parametr off zabírá všechny metody zpracovávané tímto modulem. Následující metody jsou podporované: PUT, DELETE, MKCOL, COPY a MOVE. Soubor nahrán metodou PUT je nejdřív napsán do dočasného souboru a poté je přejmenován. Od verze 0.8.9 mohou být dočasné soubory a trvalá úložiště umístěna na různých soustavách souborů. Ale pozor, v tomto případě je soubor kopírován mezi dvěma soustavami souborů místo levného přejmenování operace. Proto je doporučeno, aby pro každou lokaci oba uložené soubory a adresář obsahující dočasné soubory, nastavený pomocí direktivy client_body_temp_path, byly umístěny na stejné soustavě souborů. Při vytváření souboru metodou PUT je možné určit datum modifikace tím, že ho převezmete do hlavičky "Date".

Syntax: min_delete_depth číslo; Výchozí: min_delete_depth 0; Kontext: http, server, location Umožňuje metodě DELETE odstraňovat soubory, pokud počet prvků v cestě požadavku není menší než zadaný počet. Například příkaz min_delete_depth 4 umožňuje odstraňovat soubory na požadavcích /users/00/00/name, /users/00/00/name/pic.jpg, /users/00/00/page.html a odmítá odstraňování /users/00/00.
