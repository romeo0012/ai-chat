Modul ngx_http_map_module vytváří proměnné, jejichž hodnoty závisí na hodnotách jiných proměnných.
Vzorový Konfigurační map $http_host $name { hostnames; default 0; example.com 1; *.example.com 1; example.org 2; *.example.org 2; .example.net 3; wap.* 4; }
map $http_user_agent $mobile { default 0; "~Opera Mini" 1; }
Rozkazy Syntax: map string $proměnná { ... }
Výchozí: —
Kontext: http
Vytvoří novou proměnnou, jejíž hodnota závisí na hodnotách jedné nebo více zdrojových proměnných uvedených v prvním parametru. Před verzí 0.9.0 mohlo být v prvním parametru uvedena pouze jedna proměnná. Od verze 0.9.0 je možné uvádět více proměnných. Proměnné se vyhodnocují pouze tehdy, když jsou použity, takže pouze deklarace i velkého počtu "map" proměnných nezpůsobuje žádné extra náklady na zpracování požadavku. Parametry v bloku map specifikují mapování mezi zdrojovými a výslednými hodnotami. Hodnoty zdroje jsou uvedeny jako řetězce nebo regulární výrazy (0.9.6). Řetězce se porovnávají bez ohledu na velká a malá písmena. Regulární výraz by měl začínat buď značkou "~" pro citlivé porovnávání, nebo značkami "~*" (1.0.4) pro necitlivé porovnávání. Regulární výraz může obsahovat jména a pozice zajímavých částí, které mohou později být použity v jiných rozkazech společně s výslednou proměnnou. Pokud hodnota zdroje odpovídá jednomu z názvů specializovaných parametrů popsaných níže, musí být předponována značkou "\\".
