Module ngx_http_referer_module

← Chat

Modul ngx_http_referer_module se používá k blokování přístupu k webu pro požadavky s neplatnými hodnotami v poli "Referer" hlavičky. Vědomím by mělo být, že vytvoření požadavku s přijatelnou hodnotou v poli "Referer" je velmi snadné, a proto je účel tohoto modulu především blokovat masový tok požadavků odeslaných běžnými prohlížeči. Bylo by třeba vzít v úvahu, že běžné prohlížeče mohou neposílat polí "Referer" ani pro platné požadavky.

Příklad Konfigurace 

valid_referers none
blocked
server_names *.example.com
example.*
www.example.org/galleries/
~\.google\.
if ($invalid_referer) {
    return 403;
}

Syntaxe: valid_referers none | blocked | server_names | string ...
Výchozí hodnota: valid_referers none
Kontext: server, location
Tento příkaz umožňuje nastavit seznam platných refererů. Může obsahovat hodnoty none, blocked, server_names nebo řetězec. Pokud není nastaven žádný platný referer, je požadavek blokován.

Nastavení hash tabulí je poskytnuto v samostatném dokumentu. Syntax: valid_referers none | blocked | server_names | string ...; Výchozí: — Kontext: server, location
Umožňuje nastavit hodnoty pole "Referer" žádosti hlavičky, která způsobí, že proměnná $invalid_referer bude nastavena na prázdnou řetězec. V opačném případě bude proměnná nastavena na "1". Hledání shody je necitlivé na velká a malá písmena. Parametry mohou být následující:
none - pole "Referer" chybí v hlavičce žádosti;
blocked - pole "Referer" je přítomno v hlavičce žádosti, ale jeho hodnota byla odstraněna bránou nebo proxy serverem;
tato hodnota je řetězec, který nezačíná na "http://" nebo "https://";
server_names - pole "Referer" obsahuje jedno z názvů serverů;
arbitrární řetězec definuje název serveru a volitelný předponu URI. Název serveru může mít "*" v první nebo poslední pozici. Během kontroly je ignorován port serveru v poli "Referer";
regular expression - první symbol by měl být "~". Vyžaduje se vědomí, že výraz bude porovnán s textem začínajícím po "http://" nebo "https://". Příklad: valid_referers none blocked server_names *.example.com example.* www.example.org/galleries/ ~\.google\.;
Zanášené proměnné $invalid_referer Prázdná řetězec, pokud hodnota pole "Referer" žádosti je považována za platnou, jinak "1".
