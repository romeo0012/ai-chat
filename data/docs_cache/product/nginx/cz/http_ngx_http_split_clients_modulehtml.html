Modul ngx_http_split_clients_moduleVzorový KonfiguračníDirectivy split_clients

Modul ngx_http_split_clients_module vytváří proměnné vhodné pro A/B testování, také známé jako split testování. Vzorový Konfigurace

http {
    split_clients "${remote_addr}AAA" $variant {
        0.5% .one;
        2.0% .two;
        * "";
    }
    server {
        location / {
            index index${variant}.html;
        }
    }
}

Syntax: split_clients string $proměnná { ... }
Výchozí: —
Kontext: http
Vytvoří proměnnou pro A/B testování, například:

split_clients "${remote_addr}AAA" $variant {
    0.5% .one;
    2.0% .two;
    * "";
}

Hodnota původní řetězce se hashuje pomocí MurmurHash2. V příkladu uvedeném se hashovými hodnotami od 0 do 21474835 (0.5%) odpovídají hodnota ".one" proměnné $variant, hashovými hodnotami od 21474836 do 107374180 (2%) odpovídají hodnota ".two", a hashovými hodnotami od 107374181 do 4294967295 odpovídají hodnota "" (prázdná řetězcová hodnota).
