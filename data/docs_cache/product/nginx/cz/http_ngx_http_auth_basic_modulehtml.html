Module ngx_http_auth_basic_module

← Chat

Modul ngx_http_auth_basic_module umožňuje omezení přístupu k prostředkům kontrolou platnosti uživatelského jména a hesla pomocí protokolu "HTTP Basic Authentication". Přístup může být omezen také podle adresy, podle výsledku subrequestu nebo podle JWT. Současné omezení přístupu podle adresy a podle hesla je řízeno příkazem satisfy. Příklad Konfigurace

location / {
    auth_basic "closed site";
    auth_basic_user_file conf/htpasswd;
}

Pravidla syntaxe:

  • auth_basic string | off; Výchozí: auth_basic off; Kontext: http, server, location, limit_except
    Enables validation of user name and password using the “HTTP Basic Authentication” protocol. The specified parameter is used as a realm. Parameter value can contain variables (1.3.10, 1.2.7). The special value off cancels the effect of the auth_basic directive inherited from the previous configuration level.
  • auth_basic_user_file file; Výchozí: — Kontext: http, server, location, limit_except
    Specifies a file that keeps user names and passwords, in the following format:
    # komentář
    název1:heslo1
    název2:heslo2:komentář
    název3:heslo3

The file name can contain variables.

Udržuje uživatelské jména a hesla, ve následujícím formátu: # komentář name1:hesl1 name2:hesl2:komentář name3:hesl3
Název souboru může obsahovat proměnné. Následující typy hesel jsou podporovány:

  • šifrované pomocí funkce crypt(); lze je vytvořit pomocí "htpasswd" nástroje z distribuce Apache HTTP Server nebo příkazu "openssl passwd";
  • hashované pomocí Apache verze MD5-závislé heslové algoritmy (apr1); lze je vytvořit stejnými nástroji;
  • uvedené pomocí syntaxe "{schéma}data" (1.0.3+) jako popisované v RFC 2307; aktuálně podporované schéma zahrnují PLAIN (příkladový, nesmí být použito), SHA (1.3.13) (jednoduché SHA-1 hasherování, nesmí být použito) a SSHA (saltované SHA-1 hasherování, používané některými software balíčky, například OpenLDAP a Dovecot). Podpora pro SHA schéma byla přidána pouze k podpoře migrace z jiných webových serverů. Nesmí být používáno pro nová hesla, protože nezasolené SHA-1 hasherování, které používá, je citlivé na útoky s tabulkami dešťíků.
