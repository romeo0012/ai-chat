Modul ngx_http_charset_modulePříklad KonfiguračníDirectivy charset, charset_map, charset_types, override_charset, source_charset Modul ngx_http_charset_module přidá zadaný charset do pole "Content-Type" odpovědi hlavičky. Dále může převod dat z jednoho charsetu do druhého, ale s některými omezeními: převod probíhá pouze v jednom směru – z serveru k klientovi, a mohou být převáděny pouze jednobajtové charsety nebo jednobajtové charsety do/z UTF-8. Příklad Konfigurace obsahuje soubor conf/koi-win; charset windows-1251; source_charset koi8-r; Directivy Syntax: charset charset | off; Výchozí hodnota: charset off; Kontext: http, server, location, if v location Přidá zadaný charset do pole "Content-Type" odpovědi hlavičky. Pokud je zadaný charset odlišný od charsetu zadaného v příkazu source_charset, proběhne převod. Parametr off zrušuje přidání charsetu do pole "Content-Type" odpovědi hlavičky. Charset může být definován proměnnou: charset $charset; V takovém případě musí být všechny možné hodnoty proměnné přítomny v konfiguraci alespoň jednou v podobě příkazu charset_map, charset, nebo source_charset. Pro charsety utf-8, windows-1251, a koi8-r je dostačující zahrnout soubory conf/koi-win, conf/koi-utf, a conf/win-utf do konfigurace.

Poznámka: V tomto překladu jsem se snažil zachovat původní strukturu a formátování kódu, ale některé části mohly být upraveny pro lepší čitelnost a přehlednost.

Příkazové řádky. Pro charktery utf-8, windows-1251 a koi8-r je dostatečné vložit soubory conf/koi-win, conf/koi-utf a conf/win-utf do konfigurace. Pro ostatní charktery stačí vytvořit fiktivní tabulku převodu, například: charset_map iso-8859-5 _ { } Dále může být nastaven charakter v odpovědi hlavičce "X-Accel-Charset". Tato funkce může být zakázána pomocí příkazů proxy_ignore_headers, fastcgi_ignore_headers, uwsgi_ignore_headers, scgi_ignore_headers a grpc_ignore_headers. Syntax: charset_map charset1 charset2 { ... } Výchozí: — Kontext: http Popisuje tabulku převodu z jednoho charsetu do druhého. Vybuduje se také obrácená tabulka pomocí stejných dat. Kódové znaky jsou uvedeny v šestnáctkové soustavě. Chybějící znaky v rozsahu 80-FF jsou nahrazeny "?". Při převodu z UTF-8 jsou chybějící znaky v jednobajtovém charsetu nahrazeny "&#XXXX;". Nápad: charset_map koi8-r windows-1251 { C0 FE ; # malá yu C1 E0 ; # malá a C2 E1 ; # malá b C3 F6 ; # malá ts ... } Popis tabulky převodu do UTF-8, znaky pro charakter UTF-8 by měly být uvedeny v druhém sloupci, například: charset_map koi8-r utf-8 { C0 D18E ; # malá yu C1 D0B0 ; # malá a C2 D0B1 ; # malá b C3 D186 ; # malá ts ... } Plné tabulky převodu z koi8-r na windows-1251, a z koi8-r a windows-1251 na utf-8 jsou poskytovány v distribučních souborech conf/koi-win, conf/koi-utf a conf/win-utf. Syntax: charset_types mime-type ...

Z distribučních souborů se nabízí převod z koi8-r a windows-1251 na utf-8 v adresářích conf/koi-win, conf/koi-utf a conf/win-utf. Syntax: charset_types mime-type ...; Výchozí: charset_types text/html text/xml text/plain text/vnd.wap.wml application/javascript application/rss+xml; Kontext: http, server, location Tento příkaz se objevil v verzi 0.7.9. Povoluje zpracování modulu v odpovědích s uvedenými MIME typy mimo "text/html". Hodnota "*" odpovídá libovolnému MIME typu (0.8.29). Do verze 1.5.4 se používalo jako výchozí MIME typ "application/x-javascript" místo "application/javascript". Syntax: override_charset on | off; Výchozí: override_charset off; Kontext: http, server, location, if v location Určuje, zda se má provést konverze pro odpovědi obdržené z proxied nebo FastCGI/uwsgi/SCGI/gRPC serveru, pokud odpověď již obsahuje charset v poli "Content-Type" v odpovědi. Pokud je konverze povolena, používá se charset z odpovědi jako zdrojový charset. Poznámka: Pokud je odpověď obdržena v podpožadavku, tak je vždy prováděna konverze z charset odpovědi na charset hlavního požadavku, bez ohledu na nastavení příkazu override_charset. Syntax: source_charset charset; Výchozí: — Kontext: http, server, location, if v location Určuje zdrojový charset odpovědi. Pokud je tento charset odlišný od charset zadaného v příkazu charset, proběhne konverze.

Poznámka: Všechny technické termíny, kódy, příkazy, cesty souborů a adresy URL zůstávají v původní anglické podobě.
