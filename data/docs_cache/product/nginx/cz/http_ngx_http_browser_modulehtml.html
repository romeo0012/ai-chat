Modul ngx_http_browser_modul
Příklad KonfiguraceDirectivy
ancient_browser
ancient_browser_hodnota

modern_browser_hodnota

Modul ngx_http_browser_modul vytváří proměnné, jejichž hodnoty závisí na hodnotě pole "User-Agent" žádosti na hlavičce: $modern_browser je rovna hodnotě nastavené direktivou modern_browser_hodnota, pokud byl prohlížeč identifikován jako moderní; $ancient_browser je rovna hodnotě nastavené direktivou ancient_browser_hodnota, pokud byl prohlížeč identifikován jako starý; $msie je "1", pokud byl prohlížeč identifikován jako MSIE jakékoliv verze. Příklad Konfigurace
Vybírání indexového souboru:
modern_browser_hodnota "modern.";
modern_browser msie 5.5;
modern_browser gecko 1.0.0;
modern_browser opera 9.0;
modern_browser safari 413;
modern_browser konqueror 3.0;
index index.${modern_browser}html index.html;
Odkaz na staré prohlížeče:
modern_browser msie 5.0;
modern_browser gecko 0.9.1;
modern_browser opera 8.0;
modern_browser safari 413;
modern_browser konqueror 3.0;
modern_browser unlisted;
ancient_browser Links Lynx netscape4;
Pokud ($ancient_browser) {
rewrite ^ /staré.html;
}
Syntax Directiv:
ancient_browser string ...;
Výchozí: —
Kontext: http, server, location
Pokud je libovolný z uvedených podstrunků nalezen v poli "User-Agent" žádosti na hlavičce, prohlížeč bude považován za starý. Speciální řetězec "netscape4" odpovídá regulárnímu výrazu "^Mozilla/[1-4]".

"Zažádávací hlavička "User-Agent" bude považována za starý prohlížeč. Speciální řetězec "netscape4" odpovídá regulárnímu výrazu "^Mozilla/[1-4]". Syntax: ancient_browser_hodnota string; Výchozí: ancient_browser_hodnota 1; Kontext: http, server, location Určuje hodnotu pro proměnnou $starý_prohlížeč. Syntax: modernní_prohlížeč verze_prohlížeče;modernní_prohlížeč nezapsané; Výchozí: — Kontext: http, server, location Určuje verzi od které se prohlížeč považuje za moderní. Prohlížeč může být libovolný z následujících: msie, gecko (prohlížeče na základě Mozilly), opera, safari, nebo konqueror. Verze mohou být zadány následujícími formáty: X, X.X, X.X.X, nebo X.X.X.X. Maximální hodnoty pro každý formát jsou 4000, 4000.99, 4000.99.99, a 4000.99.99.99, respektive. Speciální hodnota unlisted určuje, aby se prohlížeč považoval za moderní, pokud nebyl zapsán v modernní_prohlížeč a ancient_prohlížeč direktivách. V opačném případě se takový prohlížeč považuje za starý. Pokud žádost neposkytne "User-Agent" pole v hlavičce, považuje se prohlížeč za nezapsaný. Syntax: modernní_prohlížeč_hodnota string; Výchozí: modernní_prohlížeč_hodnota 1; Kontext: http, server, location Určuje hodnotu pro proměnnou $modernní_prohlížeč."
