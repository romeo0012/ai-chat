Module ngx_http_gzip_module

← Chat

Modul ngx_http_gzip_module je filtr, který komprimuje odpovědi metodou "gzip". Tato metoda často pomáhá snížit velikost přenášených dat o polovinu nebo více. Při použití protokolu SSL/TLS mohou komprimované odpovědi být podrobeny útokům BREACH.

Příklad Konfigurace 

gzip on;
gzip_min_length 1000;
gzip_proxied expired no-cache no-store private auth;
gzip_types text/plain application/xml;

Proměnné

Proměnnou $gzip_ratio lze použít k zaznamenání dosaženého poměru komprese.

Syntaxe: gzip on | off; Výchozí: gzip off; Kontext: http, server, location, if in location

Povolí nebo zakáže komprimaci odpovědí.

Syntaxe: gzip_buffers number size; Výchozí: gzip_buffers 32 4k|16 8k; Kontext: http, server, location

Nastaví počet a velikost bufferů používaných k komprimaci odpovědi. Výchozí velikost bufferu je rovna velikosti jedné paměťové stránky. Tato velikost je buď 4K nebo 8K, podle platformy. Do verze 0.7.28 se používaly výchozí čtyři buffery 4K nebo 8K.

Syntaxe: gzip_comp_level level; Výchozí: gzip_comp_level 1; Kontext: http, server, location

Nastaví úroveň komprese odpovědi. Přijímají se hodnoty v rozmezí od 1 do 9.

Syntaxe: gzip_disable regex ...; Výchozí: — Kontext: http, server, location

Tato direktiva se objevila v verzi 0.6.23.

Tato direktiva umožňuje zablokovat komprimaci pro určitý typ obsahu.

Syntaxe: gzip_vary Vary: header; Kontext: http, server, location

Tato direktiva umožňuje zahrnout hlavičku do hlavičky Vary.

Syntaxe: gzip_types type ...; Kontext: http, server, location

Tato direktiva umožňuje zadat typy obsahu, které budou komprimovány.

Syntaxe: gzip_proxied directive ...; Kontext: http, server, location

Tato direktiva umožňuje zadat podmínky pro komprimaci odpovědí z proxy serveru.

Od 1 do 9. Syntax: gzip_disable regex ...; Výchozí: — Kontext: http, server, location Tento příkaz se objevil v verzi 0.6.23. Zakazuje komprimování odpovědí pro požadavky s "User-Agent" hlavičkami shodnými s jakýmkoli z uvedených regulárních výrazů. Speciální maska "msie6" (0.7.12) odpovídá regulárnímu výrazu "MSIE [4-6]\.", ale je rychlejší. Od verze 0.8.11 je "MSIE 6.0; ... SV1" z tohoto masku vyloučeno. Syntax: gzip_http_version 1.0 | 1.1; Výchozí: gzip_http_version 1.1; Kontext: http, server, location Nastavuje minimální verzi HTTP požadavku požadovanou k komprimaci odpovědi. Syntax: gzip_min_length délka; Výchozí: gzip_min_length 20; Kontext: http, server, location Nastavuje minimální délku odpovědi, která bude komprimována. Délka se určuje pouze z "Content-Length" odpovědí hlavičky. Syntax: gzip_proxied off | expired | no-cache | no-store | private | no_last_modified | no_etag | auth | any ...; Výchozí: gzip_proxied off; Kontext: http, server, location Umožňuje nebo zakazuje komprimování odpovědí pro požadavky proxy podle požadavku a odpovědi. Tím, že požadavek je proxy, je určen přítomností "Via" požadavku hlavičky.

Překlad:

Text:
Odpověď. Fakt, že požadavek je proxyován, určuje se podle přítomnosti políčka "Via" v požadavku hlavičky. Instrukce přijímá více parametrů: off zakáže komprese pro všechny proxyované požadavky, ignorující ostatní parametry; expired povolí komprese, pokud odpověď obsahuje pole "Expires" s hodnotou, která zakáže uložení do mezipaměti; no-cache povolí komprese, pokud odpověď obsahuje pole "Cache-Control" s parametrem "no-cache"; no-store povolí komprese, pokud odpověď obsahuje pole "Cache-Control" s parametrem "no-store"; private povolí komprese, pokud odpověď obsahuje pole "Cache-Control" s parametrem "private"; no_last_modified povolí komprese, pokud odpověď neobsahuje pole "Last-Modified"; no_etag povolí komprese, pokud odpověď neobsahuje pole "ETag"; auth povolí komprese, pokud požadavek obsahuje pole "Authorization"; any povolí komprese pro všechny proxyované požadavky. Syntax: gzip_types mime-type ...; Výchozí: gzip_types text/html; Kontext: http, server, location Umožňuje komprimování odpovědí pro určené MIME typy včetně "text/html". Speciální hodnota "*" odpovídá libovolnému MIME typu (0.8.29). Odpovědi s typem "text/html" jsou vždy komprimovány.
