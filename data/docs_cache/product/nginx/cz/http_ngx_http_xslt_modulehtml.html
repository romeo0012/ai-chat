Module ngx_http_xslt_module

← Chat

Modul ngx_http_xslt_module (0.7.8+) je filtr, který převádí XML odpovědi pomocí jednoho nebo více XSLT šablon. Tento modul se výchozí nastavením nebudí, je nutné ho povolit pomocí konfiguračního parametru --with-http_xslt_module. Tento modul vyžaduje knihovny libxml2 a libxslt.

Příklad Konfigurace: 

location / {
    xml_entities /site/dtd/entities.dtd;
    xslt_stylesheet /site/xslt/one.xslt param=hodnota;
    xslt_stylesheet /site/xslt/two.xslt;
}

Návrhy syntaxe:
  • xml_entities cesta;
    Výchozí: —
    Kontext: http, server, location
    Určuje soubor DTD, který deklaruje znakové entity. Tento soubor se překládá v úrovni konfigurace. Pro technické důvody je modul neschopný použít vnější podmnožinu deklarovanou v zpracovaném XML, takže je ignorována a místo toho se používá speciálně definovaný soubor. Tento soubor nemá popisovat strukturu XML. Je dostačující deklarovat pouze požadované znakové entity, například:
      &lt;!ENTITY nbsp "&amp;#xa0;"&gt;
  • xslt_last_modified on | off;
    Výchozí: xslt_last_modified off;
    Kontext: http, server, location
    Tento příkaz se objevil v verzi 1.5.1. Umožňuje uchovávat pole "Last-Modified" hlavičky odpovědi během převodu XSLT, aby se podporovalo ukládání odpovědí do mezipaměti.

V verzi 1.5.1 umožňuje uchovávat hlavičku "Last-Modified" pole z původní odpovědi při přeměnách XSLT, aby se umožnilo ukládání odpovědí do mezipaměti. Výchozí nastavení je odstranění tohoto pole, protože obsah odpovědi je modifikován během přeměn a může obsahovat dynamicky generované prvky nebo části, které se mohou měnit nezávisle na původní odpovědi. Syntax: xslt_param parameter value; Výchozí: — Kontext: http, server, location Tento příkaz se objevil v verzi 1.1.18. Definuje parametry pro XSLT šablony. Hodnota je považována za XPath výraz. Hodnota může obsahovat proměnné. Chcete-li přenést řetězec hodnot do šablony, můžete použít příkaz xslt_string_param. Může být několik příkazů xslt_param. Tyto příkazy jsou děděny z předchozího úrovně konfigurace, pokud a jen pokud na aktuální úrovni nejsou definovány žádné příkazy xslt_param a xslt_string_param. Syntax: xslt_stylesheet stylesheet [parameter=hodnota ...]; Výchozí: — Kontext: umístění Definuje XSLT stylový šabloník a jeho volitelná parametra. Šabloník se přeloží v fázi konfigurace. Parametry mohou být určeny samostatně, nebo seskupené v jedné řádku pomocí značky ":" oddělovače. Pokud parametr obsahuje značku ":", musí být upraveno jako "%3A". Dalším požadavkem je libxslt, aby parametry, které obsahují nealfanumerické znaky, byly obklopeny jedním nebo dvěma dvojitými carkami, například: param1='http%3A//www.example.com':param2=hodnota2 V popisu parametrů mohou být obsahovány proměnné, například celá řádek parametrů může být vzat z jedné proměnné: umístění / { xslt_stylesheet /site/xslt/one.xslt $arg_xslt_params param1='$hodnota1':param2=hodnota2 param3=hodnota3; } Je možné definovat více šabloníků. Budou se aplikovat v pořadí, ve kterém jsou určeny. Syntax: xslt_types mime-type ...; Výchozí: xslt_types text/xml; Kontext: http, server, umístění Umožňuje transformace v odpovědích s určenými MIME typy v přidané k "text/xml". Hodnota "*" odpovídá libovolnému MIME typu (0.8.29). Pokud je výsledkem transformace HTML odpověď, je změněn její MIME typ na "text/html".
