Module ngx_http_ssi_module

← Chat

Modul ngx_http_ssi_module je filtrem, který zpracovává příkazy SSI (Server Side Includes) v odpovědích procházejících jím. Aktuální seznam podporovaných příkazů SSI je neúplný.

Příklad Konfigurace 

location / {
    ssi on;
    ...
}

Directivy

Syntax: ssi on | off; Výchozí: ssi off; Kontext: http, server, location, if in location

Povolí nebo zakáže zpracování příkazů SSI v odpovědích.

Syntax: ssi_last_modified on | off; Výchozí: ssi_last_modified off; Kontext: http, server, location

Tato direktiva se objevila v verzi 1.5.1. Umožňuje uchování pole "Last-Modified" hlavičky odpovědi během zpracování SSI, aby se podporovalo ukládání odpovědi do cache. Výchozí hodnota pole je odstraněna, protože obsah odpovědi je modifikován během zpracování a může obsahovat dynamicky generované prvky nebo části, které se mohou měnit nezávisle na původní odpověď.

Syntax: ssi_min_file_chunk velikost; Výchozí: ssi_min_file_chunk 1k; Kontext: http, server, location

Nastaví minimální velikost částí odpovědi uložené na disk, od které smyslu je posílat pomocí sendfile.

Rozměr částí odpovědi uložené na disk, od kterého smyslu je poslat pomocí sendfile. Syntax: ssi_silent_errors on | off; Výchozí: ssi_silent_errors off; Kontext: http, server, location Pokud je povoleno, potlačí výstup řetězce “[došlo k chybě při zpracování příkazu]”, pokud došlo k chybě při zpracování SSI. Syntax: ssi_types mime-type ...; Výchozí: ssi_types text/html; Kontext: http, server, location Povolí zpracování příkazů SSI v odpovědích s uvedenými MIME typy v případě, že nejsou pouze “text/html”. Hodnota “*” odpovídá jakékoli MIME typu (0.8.29). Syntax: ssi_value_length délka; Výchozí: ssi_value_length 256; Kontext: http, server, location Nastaví maximální délku hodnot parametrů v příkazech SSI. Formát příkazů SSI: <!--# command parameter1=hodnota1 parameter2=hodnota2 ... --> Podporované příkazy:

block
Definuje blok, který může být použit jako stub v příkazu include. Blok může obsahovat další příkazy SSI. Tento příkaz má následující parametr: jméno bloku. Příklad: <!--# block name="one" --> stub <!--# endblock -->

config
Nastaví některé parametry používané při zpracování SSI, včetně:

errmsg Řetězec, který je vypisán, pokud dojde k chybě při zpracování SSI. Výchozí je následující řetězec: [došlo k chybě při zpracování příkazu]

timefmt Formátovací řetězec, který je předán funkci strftime() používané k vypisování datumu a času.

Poznámka: Tento překlad se týká pouze čistého textu. Technické termíny, kódy, příkazy, cesty souborů, adresy URL a struktura odstavce zůstávají nezměněny.

Vyskytla se tato chyba při zpracování direktivy] timefmt, což je formátovací řetězec, který se dává do funkce strftime(), která slouží k vydání datumu a času. Výchozí formát je následující: "%A, %d-%b-%Y %H:%M:%S %Z" Formát "%s" je vhodný k vydání času v sekundách. echo Je příkaz, který vydá hodnotu proměnné. Tento příkaz má následující parametry: var – název proměnné. encoding – metoda kódování. Možné hodnoty zahrnují none, url, a entity. Výchozí hodnotou je entity. default je neobvyklý parametr, který nastaví řetězec k vydání, pokud proměnná není definována. Výchozí hodnotou je "(none)". Tento příkaz --><!--# echo var="name" default="no" --> nahrazuje následující řadu příkazů: --><!--# if expr="$name" --><!--# echo var="name" --><!--# else -->no<!--# endif -->

Pokud obsahuje text proměnné, jejich hodnoty jsou nahrazeny.

if Je příkaz pro podmíněné zahrnutí. Následující příkazy jsou podporovány: --><!--# if expr="..." --> ... --><!--# elif expr="..." --> ... --><!--# else --> ... --><!--# endif -->

Aktuálně je podporováno jen jedno hloubkové zahrnutí. Tento příkaz má následující parametr: expr – výraz. Výraz může být: kontrola existence proměnné: --><!--# if expr="$name" --> porovnání proměnné s textem: --><!--# if expr="$name = text" --> --><!--# if expr="$name != text" --> porovnání proměnné s regulárním výrazem: --><!--# if expr="$name = /text/" --> --><!--# if expr="$name != /text/" -->

Pokud text obsahuje proměnné, jejich hodnoty jsou nahrazeny.

Pokud expr="$name = /text/" --> <!--# if expr="$name != /text/" --> Pokud text obsahuje proměnné, jejich hodnoty se zastaví. Regulární výraz může obsahovat poziciční i jmenované zachycení, která se později mohou použít prostřednictvím proměnných, například: <!--# if expr="$name = /(.+)@(?P<domain>.+)/" --> <!--# echo var="1" --> <!--# echo var="domain" --> <!--# endif --> zahrnuje Zahrnuje výsledek jiného požadavku do odpovědi. Tato příkazová řádka má následující parametry: file určuje zahrnutý soubor, například: <!--# include file="footer.html" --> virtual určuje zahrnutý požadavek, například: <!--# include virtual="/remote/body.php?argument=value" --> Na jedné stránce se nacházejí několik požadavků, které se zpracovávají paralelně proxied nebo FastCGI/uwsgi/SCGI/gRPC servery. Pokud se požaduje sekvenci zpracování, by měl být použit parametr wait. stub je nestandardní parametr, který pojmenuje blok, jehož obsah bude vypisován, pokud požadavek na zahrnutý obsah vytvoří prázdnou tělo nebo pokud dojde k chybě při zpracování požadavku, například: <!--# block name="one" -->&nbsp;<!--# endblock --> <!--# include virtual="/remote/body.php?argument=value" stub="one" --> Obsah zahrnutého bloku se zpracovává v kontextu požadavku na zahrnutí. wait je nestandardní parametr, který instruuje čekat na dokončení požadavku před tím, než se pokračuje v zpracování SSI, například: <!--# include virtual="/remote/body.php?argument=value" wait="true" -->

Tento text vám instruuje, aby čekal na dokončení požadavku před pokračováním v zpracování SSI, například:

&lt;!--# include virtual="/remote/body.php?argument=value" wait="yes" --&gt;

Nastaví nestandardní parametr, který instruuje, aby se úspěšný výsledek zpracování požadavku zapisoval do zadané proměnné, například:

&lt;!--# include virtual="/remote/body.php?argument=value" set="one" --&gt;
``

Maximální velikost odpovědi je nastavena pomocí příkazu subrequest_output_buffer_size direktivy (1.13.10):

location /remote/ {
    subrequest_output_buffer_size 64k;
    ...
}

Před verzí 1.13.10 mohly být do proměnných zapisovány pouze výsledky odpovědí získané pomocí modulů ngx_http_proxy_module, ngx_http_memcached_module, ngx_http_fastcgi_module (1.5.6), ngx_http_uwsgi_module (1.5.6), a ngx_http_scgi_module (1.5.6). Maximální velikost odpovědi byla nastavována pomocí příkazů proxy_buffer_size, memcached_buffer_size, fastcgi_buffer_size, uwsgi_buffer_size, a scgi_buffer_size direktiv.

set Nastaví hodnotu proměnné. Tento příkaz má následující parametry: var jméno proměnné. value hodnota proměnné. Pokud přiřazená hodnota obsahuje proměnné, jejich hodnoty jsou zastupovány.

Vložené proměnné

Modul ngx_http_ssi_module podporuje dvě vložené proměnné:

$date_local aktuální čas v místní časové zóně. Formát je nastavený příkazem config s parametrem timefmt.

$date_gmt aktuální čas v čase GMT. Formát je nastavený příkazem config s parametrem timefmt.
