Instalace
V této části se naučíte nainstalovat NGINX Ingress Controller.

  1. Nainstalujte NGINX Ingress Controller

Nainstalujte NGINX Ingress Controller pomocí následujících kroků:

a) Nainstalujte Helm:

      curl https://raw.githubusercontent.com/helm/helm/master/scripts/get-helm-3 | bash

b) Přidejte repo s helm charty:

      helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx
      helm repo update

c) Nainstalujte NGINX Ingress Controller:

      helm install my-nginx-ingress ingress-nginx/ingress-nginx
  1. Vytvořte licenční tajný klíč

   kubectl create secret nginx-license default nginx-license --from-file=/path/to/your/license
  1. Vytvořte a sestavte NGINX Ingress Controller

   kubectl apply -f https://raw.githubusercontent.com/kubernetes/ingress-nginx/controller-v1.1.0/deploy/static/provider/cloud/deploy.yaml
  1. Aktualizace NGINX Ingress Controller

   helm upgrade my-nginx-ingress ingress-nginx/ingress-nginx
  1. Spuštění více NGINX Ingress Controllerů

   helm install my-nginx-ingress-2 ingress-nginx/ingress-nginx
  1. Migrace z Ingress-NGINX Controlleru na NGINX Ingress Controller

Další informace o migraci najdete [tady](https://kubernetes.github.io/ingress-nginx/user-guide/nginx-configuration/annotations/#migration-from-ingress-nginx-controller-to-nginx-ingress-controller).

  1. Integrace

Další informace o integracích najdete [tady](https://kubernetes.github.io/ingress-nginx/examples/).

  1. Zobrazit zdroj

   git clone https://github.com/kubernetes/ingress-nginx
  1. Upravit tuto stránku

   cd ingress-nginx
