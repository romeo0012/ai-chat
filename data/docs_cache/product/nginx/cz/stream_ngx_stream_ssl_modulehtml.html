Module ngx_stream_ssl_module

← Chat

Modul ngx_stream_ssl_module (1.9.0) poskytuje nutnou podporu pro stream proxy server pro práci se protokolem SSL/TLS. Tento modul není vytvářen všude výchozí, musí být povolen pomocí konfiguračního parametru --with-stream_ssl_module. Tento modul vyžaduje knihovnu OpenSSL.

Příklad Konfigurace

Pro snížení zátěže procesoru je doporučeno nastavit počet procesů pracovníků na počet procesorů, povolit sdílenou cache sesíí, zakázat vlastní cache sesíí a možná zvětšit trvání sesíí (výchozí hodnota je 5 minut):

worker_processes auto;
stream {
    ...
    server {
        listen 12345 ssl;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers AES128-SHA:AES256-SHA:RC4-SHA:DES-CBC3-SHA:RC4-MD5;
        ssl_certificate /usr/local/nginx/conf/cert.pem;
    }
}

Nastavení pro zabezpečení

Následující příklad konfigurace poskytuje některé doporučené nastavení pro zabezpečení.

worker_processes auto;
events { worker_connections 1024; }
stream {
    ...
    server {
        listen 12345 ssl;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers AES128-SHA:AES256-SHA:RC4-SHA:DES-CBC3-SHA:RC4-MD5;
        ssl_certificate /usr/local/nginx/conf/cert.pem;
        ssl_certificate_key /usr/local/nginx/conf/cert.key;
        ssl_session_cache shared:SSL:10m;
        ssl_session_timeout 10m;
        ssl_prefer_server_ciphers on;
        ssl_verify_client optional;
        ssl_verify_depth 2;
    }
}

Poznámka: Výše uvedené nastavení je pouze příkladem a může být nutné je upravit podle potřeby.
