Modul ngx_http_geo_modulePříklad KonfiguraceDirectivy geo Modul ngx_http_geo_module vytváří proměnné se hodnotami, které závisí na adrese klienta. Příklad Konfigurace geo 

geo $geo {
    default 0;
    127.0.0.1 2;
    192.168.1.0/24 1;
    10.1.0.0/16 1;
    ::1 2;
    2001:0db8::/32 1;
}

Syntax: geo [$address] $variable { ... } Výchozí: — Kontext: http Popisuje závislost hodnot zadané proměnné na adrese klienta. Výchozí adresa je brána z proměnné $remote_addr, ale může být brána také z jiné proměnné (0.7.27), například: geo $arg_remote_addr $geo { ...; } Protože proměnné se vyhodnocují pouze tehdy, když jsou použity, není žádný extra náklad na zpracování požadavku způsoben ani velkým počtem deklarovaných "geo" proměnných. Pokud hodnota proměnné nezastupuje platnou adresu IP, použije se adresa "255.255.255.255". Adresy se zadávají buď jako předpony v CIDR notaci (včetně jednotlivých adres) nebo jako rozsahy (0.7.23). Podpora IPv6 předpon je k dispozici od verzí 1.3.10 a 1.2.7. Následující speciální parametry jsou také podporovány:
  • delete odstraní zadanou sít (0.7.23).
  • default nastaví hodnotu proměnné, pokud adresa klienta neodpovídá žádné z uvedených adres. Pokud jsou adresy zadány v CIDR notaci, mohou být použity "0.0.0.0/0" a "::/0" místo default. Pokud není default zadán, výchozí hodnotou bude prázdná řetězcová hodnota.

"::/0" může být použito místo výchozího. Pokud není uvedeno výchozí hodnota, bude hodnota prázdná řetězec. include zahrnuje soubor s adresami a hodnotami. Může se jednat o několik zahrnutí. proxy definuje důvěryhodné adresy (0.8.7, 0.7.63). Pokud požadavek pochází z důvěryhodné adresy, bude adresa z pole "X-Forwarded-For" požadavku hlavičky použita místo toho. V opakovaném porovnání se adresami důvěryhodných adres se kontrolují postupně. Podpora důvěryhodných adres IPv6 začíná od verzí 1.3.0 a 1.2.1. proxy_recursive povoluje rekurzivní hledání adres (1.3.0, 1.2.1). Pokud je rekurzivní hledání zakázáno, pak místo původní adresy klienta, která odpovídá jedné z důvěryhodných adres, bude použita poslední adresa z pole "X-Forwarded-For". Pokud je rekurzivní hledání povoláno, pak místo původní adresy klienta, která odpovídá jedné z důvěryhodných adres, bude použita poslední nevěrná adresa z pole "X-Forwarded-For". ranges ukazuje, že adresy jsou určeny jako rozsahy (0.7.23). Tento parametr by měl být první. Chcete-li zrychlit načítání geo základny, adresy by měly být umístěny v rostoucí řadě. volatile ukazuje, že proměnná není uložitelná (1.29.3). Příklad: geo $country { default ZZ; include conf/geo.conf; delete 127.0.0.0/16; proxy 192.168.100.0/24; proxy 2001:0db8::/32; 127.0.0.0/24 US; 127.0.0.1/32 RU; 10.1.0.0/16 RU; 192.168.1.0/24 UK; } Soubor conf/geo.conf může obsahovat následující řádky: 10.2.0.0/16 RU; 192.168.2.0/24 RU; Hodnota nejvýraznějšího shoda se používá. Například pro adresu 127.0.0.1 bude volena hodnota "RU", nikoli "US". Příklad s rozsahy: geo $country { ranges; default ZZ; 127.0.0.0-127.0.0.0 US; 127.0.0.1-127.0.0.1 RU; 127.0.0.1-127.0.0.255 US; 10.1.0.0-10.1.255.255 RU; 192.168.1.0-192.168.1.255 UK; }
