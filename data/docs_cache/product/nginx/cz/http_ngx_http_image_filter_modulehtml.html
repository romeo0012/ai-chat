Module ngx_http_image_filter_module

← Chat

Modul ngx_http_image_filter_module (0.7.54+) je filtr, který přeměňuje obrázky v formátech JPEG, GIF, PNG a WebP. Tento modul není vytvářen všude výchozí, musí být povolen pomocí konfiguračního parametru --with-http_image_filter_module. Tento modul využívá knihovnu libgd. Doporučujeme používat nejnovější dostupnou verzi knihovny. Podpora formátu WebP se objevila v verzi 1.11.6. Chcete-li přeměňovat obrázky v tomto formátu, musí být knihovna libgd při kompilaci sestavena s podporou WebP.

Příklad Konfigurace umístění /img/ {
proxy_pass http://backend;
image_filter resize 150 100;
image_filter rotate 90;
error_page 415 = /empty;
}

Umístění = /empty {
empty_gif;
}

Syntaxe direktiv:
image_filter off;
image_filter test;
image_filter size;
image_filter rotate 90 | 180 | 270;
image_filter resize šířka výška;
image_filter crop šířka výška;

Výchozí: image_filter off;

Kontext: location
Nastavuje typ přeměny obrázků: off vypne zpracování modulu v okolí location. test zajistí, že odpovědi jsou obrázky v libovolném formátu JPEG, GIF, PNG nebo WebP. Jinak se vrací chyba 415 (Nespodporovaný typ média). size vrací informace o obrázcích v JSON formátu, např.
