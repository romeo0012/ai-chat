Tento modul se nevytváří všude výchozími parametry, musí být povolen pomocí konfiguračního parametru --with-http_perl_module. Tento modul vyžaduje verzi Perlu 5.6.1 nebo vyšší. Kompilátor C by měl být kompatibilní s tím, který byl použit k sestavení Perlu. Významné problémy Modul je experimentální, takže zákazník musí být varován. Chcete-li, aby Perl při přepracování upravených modulů během přepracování, by měl být sestaven s parametry -Dusemultiplicity=yes nebo -Dusethreads=yes. Dále, k tomu, aby Perl vypustila méně paměti během běhu, by měl být sestaven s parametrem -Dusemymalloc=no. Chcete-li zkontrolovat hodnoty těchto parametrů v již sestaveném Perlu (preferované hodnoty jsou uvedeny v příkladu), spusťte: $ perl -V:usemultiplicity -V:usemymalloc usemultiplicity='define'; usemymalloc='n'; Poznámka: Po přestavbě Perlu s novými parametry -Dusemultiplicity=yes nebo -Dusethreads=yes budou muset být přestavovány všechny binární Perl moduly také — budou jen zastavit fungovat s novou Perlou. Existuje možnost, že hlavní proces a pak procesy pracovníků budou rostit v rozměrech po každé přepracování.

Příklad Konfigurace

location ~ \.pl$ {
    set $perl5 "$(which perl)";
    set $perl_args "-w";
    set $perl_code "print 'Hello World!';";
    set $perl_handler perl;
    include fastcgi_params;
    fastcgi_pass unix:/var/run/nginx-fcgi/perl.socket;
}

Perl. Je možné, že hlavní proces a poté procesy pracovníci se zvětšují po každé rekonfiguraci. Pokud se hlavní proces zvětšuje na neakceptovatelné velikosti, může se aplikovat postup živé aktualizace bez změny souboru s executablem. Během provádění Perl modulu dlouho běžící operace, jako je například rozpoznávání domény, připojování k jinému serveru nebo dotazování do databáze, nebudou zpracovávány žádné další požadavky přiřazené k aktuálnímu procesu pracovníka. Proto je tedy doporučeno provádět pouze takové operace, které mají předvídatelnou a krátkou dobu běhu, jako je například přístup k místnímu systému souborů. Příklad Konfigurace

http {
    perl_modules perl/lib;
    perl_require hello.pm;
    perl_set $msie6 ' sub { my $r = shift; my $ua = $r-&gt;header_in("User-Agent"); return "" if $ua =~ /Opera/; return "1" if $ua =~ / MSIE [6-9]\.\d+/; return ""; } ';
    server {
        location / {
            perl hello::handler;
        }
    }
}

Modul Perl/lib/hello.pm:

package hello;
use nginx;
sub handler {
    my $r = shift;
    $r-&gt;send_http_header("text/html");
    return OK if $r-&gt;header_only;
    $r-&gt;print("hello!\n&lt;br/&gt;");
    if (-f $r-&gt;filename or -d _) {
        $r-&gt;print($r-&gt;uri, " exists!\n");
    }
    return OK;
}
1;
__END__

Volitelný parametr typ nastavuje hodnotu pole "Content-Type" hlavičky odpovědi. Pokud je hodnota prázdná řetězec, pole "Content-Type" hlavičky nebude odesláno. $r->status(kód) nastaví kód odpovědi. $r->sleep(mili sekundy, handler) nastaví zadanou funkci a zastaví zpracování požadavku na určitou dobu. Během této doby nginx pokračuje v zpracování dalších požadavků. Po uplynutí určené doby nginx volá zaregistrovanou funkci. Poznámka: Funkce handler musí být předána odkazem. Chcete-li přenášet data mezi funkcemi, $r->variable() by mělo být použito.

Přenos dat mezi funkcemi by mělo být $r->variable() použito. Příklad: package hello; use nginx; sub handler { my $r = shift; $r->discard_request_body; $r->variable("var", "OK"); $r->sleep(1000, \&next); return OK; } sub next { my $r = shift; $r->send_http_header; $r->print($r->variable("var")); return OK; } 1; __END__ $r->unescape(text) dekóduje text kódovaný ve formě "%XX". $r->uri vrátí požadavek URI. $r->variable(jméno[, hodnota]) vrátí nebo nastaví hodnotu zadané proměnné. Proměnné jsou lokální pro každý požadavek.
