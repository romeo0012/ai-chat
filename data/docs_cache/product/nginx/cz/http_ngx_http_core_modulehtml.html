Povoluje nebo zakazuje použití asynchronní I/O souborů (AIO) na FreeBSD a Linux:

location /video/ {
aio on;
output_buffers 1 64k;
}

Na FreeBSD můžete použít AIO od verze FreeBSD 4.3. Před verzí FreeBSD 11.0 můžete AIO buďto staticky vložit do jádra: options VFS_AIO nebo dynamicky jako modul jádra: kldload aio

Na Linuxu můžete použít AIO od verze jádra 2.6.22. Také je nutné povolit directio, jinak čtení bude blokující:

location /video/ {
aio on;
directio 512;
output_buffers 1 128k;
}

Na Linuxu můžete použít directio pouze pro čtení bloků na 512-bajtových hranicích (nebo 4K pro XFS). Pokud je soubor nezarovnaný, jeho nezarovnaný konec se čte v blokujícím režimu. To platí také pro požadavky na byte range a požadavky na formát FLV, které nejsou z počátku souboru: čtení nezarovnaných dat v počátku a konci souboru bude blokující.

Začátek souboru: čtení nezarovnaných dat v počátku a konci souboru bude blokující. Když jsou na Linuxu současně povoleny AIO a sendfile, použije se AIO pro soubory velikosti nebo rovnou velikosti určené v příkazu directio, zatímco sendfile pro menší soubory nebo pokud je directio zakázán.

location /video/ {
    sendfile on;
    aio on;
    directio 8m;
}

Nakonec lze soubory číst a posílat pomocí vícevláknové (1.7.11), bez blokování procesu pracovníka:

location /video/ {
    sendfile on;
    aio threads;
}

Operace čtení a posílání souborů jsou přesunuty na vlákna zadané skupiny. Pokud název skupiny chybí, použije se skupina s názvem “default”. Název skupiny může být také nastaven pomocí proměnných:

aio threads=pool$disk;

Výchozí nastavení je zakázané, by mělo být povolené pomocí konfiguračního parametru --with-threads. V současné době je vícevláknové posílání souborů kompatibilní pouze s metodami epoll, kqueue a eventport. Vícevláknové posílání souborů je podporováno pouze na Linuxu. Viz také příkaz sendfile.
