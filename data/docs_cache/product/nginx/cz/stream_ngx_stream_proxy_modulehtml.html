Module ngx_stream_proxy_module

← Chat

Modul ngx_stream_proxy_module (1.9.0) umožňuje proxyování datových proudů přes TCP, UDP (1.9.13) a UNIX-doménové sockety.

Konfigurační příkazy
server {
listen 127.0.0.1:12345;
proxy_pass 127.0.0.1:8080;
}
server {
listen 12345;
proxy_connect_timeout 1s;
proxy_timeout 1m;
proxy_pass example.com:12345;
}
server {
listen 53 udp reuseport;
proxy_timeout 20s;
proxy_pass dns.example.com:53;
}
server {
listen [::1]:12345;
proxy_pass unix:/tmp/stream.socket;
}

Vyžaduje vycházející spojení k proxovanému serveru, aby pocházely z uvedené lokální IP adresy. Hodnota parametru může obsahovat proměnné (1.11.2).

Přenáší vycházející spojení k serveru proxy zadáné místní IP adresy. Hodnota parametru může obsahovat proměnné (1.11.2). Speciální hodnota off zrušuje efekt direktivy proxy_bind dědictví z předchozí konfigurační úrovně, což umožňuje systému automaticky přiřadit místní IP adresu. Parametr transparent (1.11.0) umožňuje vycházející spojení k serveru proxy vycházet z ne-místní IP adresy, například z skutečné IP adresy klienta: proxy_bind $remote_addr transparent; Pro toto parametro pracovat je obvykle nutné spouštět procesy pracovníka nginxu s oprávněními superuživatele. Na Linuxu to není požadováno (1.13.8), protože pokud je zadán parametr transparent, procesy pracovníka dědí schopnost CAP_NET_RAW z hlavního procesu. Je také nutné konfigurovat tabulku routování jádra pro zachycení sítové komunikace z serveru proxy.
