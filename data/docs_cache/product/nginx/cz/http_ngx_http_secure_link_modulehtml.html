Module ngx_http_secure_link_module

← Chat

Modul ngx_http_secure_link_module (0.7.18) slouží k ověřování autenticity požadovaných odkazů, k ochraně zdrojů před neautorizovaným přístupem a k omezení trvání odkazů. Autenticity požadovaného odkazu se ověří porovnáním hodnoty kontrolní součtu, která je přijata v požadavku, s hodnotou počítanou pro požadavek. Pokud má odkaz omezenou dobu trvání a uplynula doba, považuje se odkaz za zastaralý. Stav těchto kontrol je dostupný v proměnné $secure_link. Modul poskytuje dvě alternativní režimy provozu. První režim je povolený pomocí příkazu secure_link_secret a slouží k ověřování autenticity požadovaných odkazů i k ochraně zdrojů před neautorizovaným přístupem. Druhý režim (0.8.50) je povolený pomocí příkazů secure_link a secure_link_md5 a slouží také k omezení trvání odkazů. Tento modul není vytvářen všude výchozími nastaveními, musí být povolen pomocí konfiguračního parametru --with-http_secure_link_module.

Syntaxe příkazů:
secure_link expression;
Výchozí: —
Kontext: http, server, location
Definuje řetězec s proměnnými, z nichž se extrahuje hodnota kontrolního součtu a trvání odkazu. Proměnné použité v výrazu jsou obvykle spojeny s požadavkem; viz níže uvedený příklad. Extrahovaná hodnota kontrolního součtu z řetězce se porovná s MD5 hash hodnotou výrazu definovaným příkazem secure_link_md5.

Příklad:
location /secure_link {
secure_link $secure_link_secret;
}

Příkazy nejsou vytvářeny všude výchozími nastaveními, musí být povoleny pomocí konfiguračního parametru --with-http_secure_link_module.

Hodnota vystřihnutá z řetězce se porovnává s hodnotou MD5 hashu výrazu definovaným příkazem secure_link_md5 direktivy. Pokud kontrolní součty neodpovídají, proměnná $secure_link se nastaví na prázdnou řetězcovou hodnotu. Pokud kontrolní součty odpovídají, kontroluje se platnost odkazu. Pokud má odkaz omezenou platnost a uplynula doba, proměnná $secure_link se nastaví na "0". V opačném případě se nastaví na "1". Hodnota MD5 hashu přijatá v požadavku je kódována v base64url. Pokud má odkaz omezenou platnost, doba vypršení je nastavena v sekundách od Epoch (Thu, 01 Jan 1970 00:00:00 GMT). Hodnota je zadána v výrazu po MD5 hashu a je oddělena čárkou. Do požadavku je doba vypršení dostupná prostřednictvím proměnné $secure_link_expires pro použití v příkazu secure_link_md5. Pokud doba vypršení není zadána, má odkaz neomezenou platnost. Syntaxe: secure_link_md5 výraz; Výchozí hodnota: — Kontext: http, server, location Definuje výraz, pro který se počítá MD5 hash hodnota a porovná se hodnotou přijatou v požadavku. Výraz by měl obsahovat zabezpečenou část odkazu (zdroj) a tajnou složku. Pokud má odkaz omezenou platnost, výraz by měl obsahovat také $secure_link_expires. K zabránění neautorizovaného přístupu může obsahovat nějakou informaci o klientovi, například jeho adresu a verzi prohlížeče.

Syntax: 

secure_link_md5 expression;

Výchozí hodnota: 
—

Kontext: 
http, server, location

Definuje výraz, pro který se počítá MD5 hash hodnota a porovná se hodnotou přijatou v požadavku. Tento výraz by měl obsahovat zabezpečenou část odkazu (zdroj) a tajnou složku. Pokud má odkaz omezenou platnost, výraz by měl obsahovat také $secure_link_expires. K zabránění neautorizovaného přístupu může obsahovat nějakou informaci o klientovi, například jeho adresu a verzi prohlížeče.

Chcete-li zabránit neautorizovanému přístupu, může výraz obsahovat nějakou informaci o klientovi, například jeho adresu a verzi prohlížeče. Příklad: location /s/ { secure_link $arg_md5,$arg_expires; secure_link_md5 "$secure_link_expires$uri$remote_addr secret"; if ($secure_link = "") { return 403; } if ($secure_link = "0") { return 410; } ... } Tento odkaz "/s/link?md5=_e4Nc3iduzkWRm01TBBNYw&expires=2147483647" omezuje přístup k "/s/link" pro klienta s IP adresou 127.0.0.1. Odkaz také má omezenou platnost do 19. ledna 2038 (GMT). Na UNIXu hodnotu argumentu md5 požadavku můžete získat následovně: echo -n '2147483647/s/link127.0.0.1 secret' | \ openssl md5 -binary | openssl base64 | tr +/ -_ | tr -d = Syntax: secure_link_secret slovo; Výchozí: — Kontext: location Definuje tajné slovo používané k ověření autenticity požadovaných odkazů. Celá URI požadovaného odkazu vypadá následovně: /prefix/hash/link, kde hash je šestnáctkový zástup MD5 hash počítaný pro konkatenaci odkazu a tajného slova, a prefix je libovolná řetězová hodnota bez lomítek. Pokud prochází požadovaný odkaz ověření autenticity, proměnná $secure_link je nastavena na odkaz extrahovaný z požadavku URI. V opačném případě je proměnná $secure_link nastavena na prázdnou řetězec.

Text v anglickém jazyce:

Přijatá hodnota pro proměnnou $secure_link je nastavena na odkaz vytáhnutý z URI požadavku. V opačném případě je proměnná $secure_link nastavena na prázdnou řetězcovou hodnotu. Příklad:
location /p/ {
    secure_link_secret secret;
    if ($secure_link = "") {
        return 403;
    }
    rewrite ^ /secure/$secure_link;
}
location /secure/ {
    internal;
}
Požadavek na "/p/5e814704a28d9bc1914ff19fa0c4a00a/link" bude vnitřně přesměrován na "/secure/link". Na systému UNIX může být pro tento příklad hash hodnota získána pomocí:
echo -n 'linksecret' | openssl md5 -hex
Vložené proměnné
$secure_link - Hodnota odkazu
$secure_link_status - Stav kontroly odkazu. Konkrétní hodnota závisí na zvoleném režimu.
$secure_link_expires - Doba trvání odkazu zahrnutého v požadavku; určena pouze pro příkaz secure_link_md5.

Poznámka: Tento text je určen pro použití v souboru konfigurace Nginxu.
