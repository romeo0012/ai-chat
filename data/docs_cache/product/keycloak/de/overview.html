Als OAuth2, OpenID Connect und SAML kompatibler Server kann Keycloak jede Anwendung und Dienst sichern, sofern die Technologiestack, die sie verwenden, unterstützt, mindestens eines dieser Protokolle. Weitere Informationen zu den von Keycloak unterstützten Sicherheitsprotokollen finden Sie in der Server Administration Guide. Die meisten Unterstützung für einige dieser Protokolle ist bereits von der Programmiersprache, Framework oder Reverse Proxy verfügbar, die sie verwenden. Die Nutzung der bereits vorhandenen Unterstützung aus der Anwendungsumgebung ist ein wichtiger Aspekt, um Ihre Anwendung vollständig mit Sicherheitsstandards und Best Practices in Einklang zu bringen, damit Sie sich nicht in eine Vendor-Lock-in-Situation verwickeln. Für einige Programmiersprachen bietet Keycloak Bibliotheken an, die versuchen, den Mangel an Unterstützung für ein bestimmtes Sicherheitsprotokoll auszufüllen oder eine enger integrierte und reichere Integration mit dem Server zu bieten. Diese Bibliotheken werden als Keycloak Client Adapters bezeichnet und sollten als letztes Reservat verwendet werden, wenn Sie nicht auf das, was aus der Anwendungsumgebung verfügbar ist, vertrauen können. Grundschritte zur Sicherung von Anwendungen und Diensten Diese sind die Grundschritte zur Sicherung einer Anwendung oder eines Dienstes in Keycloak.

Grunde für die Sicherung von Anwendungen und Diensten in Keycloak. Hier finden Sie die Grundschritte zur Sicherung einer Anwendung oder eines Dienstes in Keycloak.

  1. Registrieren Sie einen Client in einem Realm mithilfe einer der folgenden Optionen:

- Keycloak Admin Console
- Clientregistrierungsdienst
- CLI
  1. Aktivieren Sie die OpenID Connect oder SAML-Protokolle in Ihrer Anwendung mithilfe einer der folgenden Optionen:

- Nutzung der vorhandenen OpenID Connect und SAML-Unterstützung aus der Anwendungsumgebung
- Verwendung eines Keycloak-Adapters

Diese Anleitung enthält detaillierte Anweisungen für diese Schritte. Weitere Informationen zum Registrieren eines Clients in Keycloak über die Administration Console finden Sie im Server Administration Guide.

Lexikon

In diesem Leitfaden werden folgende Begriffe verwendet:

Clients sind Entitäten, die mit Keycloak authentifizieren, um Benutzer-Tokens zu erhalten. Meistens sind Clients Anwendungen und Dienste, die auf behalf von Benutzern einen einmaligen Anmeldungserlebnis bereitstellen und auf andere Dienste zugreifen, indem sie von dem Server ausgestellte Tokens verwenden. Clients können auch Entitäten sein, die nur interessiert sind an Tokens zu erhalten und auf eigenen Namen für den Zugriff auf andere Dienste zu handeln.

Anwendungen umfassen einen breiten Bereich an Anwendungen, die für bestimmte Plattformen entwickelt wurden, für jedes Protokoll.

Client-Adapters sind Bibliotheken, die es leicht machen, Anwendungen und Dienste mit Keycloak zu sichern. Sie bieten eine enge Integration in das unterliegende Plattform und Framework.

Erstellen eines Clients und Registrieren eines Clients sind die gleiche Aktion.

Erstellen eines Clients ist der Begriff, der verwendet wird, um einen Client mithilfe der Admin Console zu erstellen.

Registrieren eines Clients ist der Begriff, der verwendet wird, um einen Client mithilfe des Keycloak Client Registration Services zu registrieren.

Ein Service Account ist eine Art von Client, der in Eigenregie Tokens erhalten kann. Auf dieser Seite bearbeiten Sie dieses Leitfaden.
