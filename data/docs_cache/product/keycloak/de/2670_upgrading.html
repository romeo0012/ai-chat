Upgrading

Anleitungen zur Aktualisierung finden Sie in den Release Notes.

Wichtig:

  • Sicherheitsupdates sind wichtig und sollten immer beachtet werden.
  • Stellen Sie sicher, dass Sie eine Backupkopie Ihrer Daten vor der Aktualisierung erstellt haben.
  • Lesen Sie die Release Notes vor der Aktualisierung durch.

Getting Started

Folgen Sie den Anleitungen im Getting Started, um Ihre Anwendung zu installieren und zu konfigurieren.

Sicherheitsanleitungen

Um Ihre Anwendung sicher zu gestalten, lesen Sie die Sicherheitsanleitungen und stellen Sie sicher, dass Sie die empfohlenen Sicherheitsmaßnahmen umsetzen.

Server Administration

Folgen Sie den Anleitungen im Server Administration, um Ihren Server zu verwalten und zu optimieren.

Server Developer

Folgen Sie den Anleitungen im Server Developer, um Ihre Anwendung zu erweitern und zu verbessern.

Authorization Services

Folgen Sie den Anleitungen im Authorization Services, um Ihre Anwendung zu sichern und zu verwalten.

Release Notes

Lesen Sie die Release Notes, um zu erfahren, was in dieser Version neu ist und was geändert wurde.
