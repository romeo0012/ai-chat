Tento vlastnost je experimentální a může zavodit nekompatibilní změny v budoucích verzích Keycloak. Nepoužívejte tuto vlastnost v produkčních prostředích.

(Následující text je kódem a nepotřebuje překlad.)

# Add the Keycloak repository
curl -s https://www.keycloak.org/downloads/keycloak/latest/keycloak.asc | sudo apt-key add -
echo "deb https://www.keycloak.org/downloads/keycloak/latest/deb stable main" | sudo tee /etc/apt/sources.list.d/keycloak.list
Update the package list

sudo apt-get update
Install Keycloak

sudo apt-get install keycloak
Start Keycloak

sudo systemctl start keycloak
Enable Keycloak to start on boot

sudo systemctl enable keycloak
Access the Keycloak admin console

http://localhost:8080/auth/

(Následující text je kódem a nepotřebuje překlad.)

# Create a new realm
curl -X POST -H "Authorization: Bearer &lt;your-admin-token&gt;" -H "Content-Type: application/json" -d '{"realmName":"myrealm"}' http://localhost:8080/auth/admin/realms
Create a new user

curl -X POST -H "Authorization: Bearer &lt;your-admin-token&gt;" -H "Content-Type: application/json" -d '{"username":"user1","enabled":true,"firstName":"John","lastName":"Doe","email":"user1@example.com"}' http://localhost:8080/auth/admin/realms/myrealm/users
