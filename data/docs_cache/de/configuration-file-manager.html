Konfigurationsdateien-Manager
Der Konfigurationsdateien-Manager ist ein mächtiges Werkzeug, das es ermöglicht, die Kontrolle über alle Dateien innerhalb des spezifischen Containers zu erlangen. Dadurch können Sie leicht und schnell allgemeine Konfigurationen auf Ihren Knoten über die bequeme Benutzeroberfläche direkt im Browser anwenden, ohne dass eine SSH-Verbindung hergestellt werden muss, die für komplexe Operationen erforderlich sein kann. Um den Konfigurationsmanager zu öffnen, bewegen Sie den Mauszeiger über den erforderlichen Knoten und klicken Sie auf den Config-Button (der mit einem Wrench-Icon versehen ist). In der Mitte des Dashboards wird die entsprechende Konfigurationsseite geöffnet. Hier sind folgende Abschnitte verfügbar: Wurzel (Dateimanager) - bietet Zugriff auf den lokalen Dateisystem des Containers, wo Sie verschiedene Einstellungen innerhalb der Konfigurationsdateien Ihrer App verwalten können Mount Points - Liste von Verzeichnissen, die physisch auf dem entfernten Knoten gespeichert sind, aber auf dem aktuellen Knoten verwendet werden können (Hier erfahren Sie, wie Sie Daten auf der Plattform montieren können) Exports - Liste von Verzeichnissen, die mit anderen Knoten geteilt werden, also lokal gespeichert sind, aber auch auf den entfernten Instanzen verfügbar sind (Weitere Informationen finden Sie auf der speziellen Dokumentationsseite für Speicherexports) Favorites - Dateien und Verzeichnisse, die Sie als bevorzugt markiert haben, damit Sie schnell und einfach auf sie zugreifen können

Weiter unten in diesem Leitfaden werden die Grundlagen des Konfigurationsmanager-Einsatzes betrachtet, die für jeden Plattformcontainer anwendbar sind.

Um Ihnen schnell und einfach Zugriff auf sie zu haben, werden wir im weiteren Verlauf dieses Leitfadens die Grundlagen der Verwendung des Konfigurationsmanagers betrachten, die für jede Plattform-Container-Umgebung gültig sind. Wenn Sie jedoch die Konfigurationsspezifika für einen bestimmten Knotentyp ermitteln müssen, wählen Sie bitte einen der folgenden Dokumente aus:

  • Arbeit mit dem Dateimanager

Der in das System integrierte Dateimanager bietet ein einfaches und praktikables Zugriff auf Ihre Container-Dateien und ermöglicht die Durchführung der meisten häufig vorkommenden Operationen direkt über das Dashboard. Tip: Sie können auch über SSH auf einen Container zugreifen, um weitere Möglichkeiten für die Verwaltung zu erhalten.

Wenn Sie zum Abschnitt Root des Konfigurationsmanagers wechseln, sehen Sie im rechten Bereich den Dateisystembaum mit dem Pfadzeichen und der erweiterbaren Aktionsliste für den aktuellen Verzeichnis im Werkzeugsfenster oben. Diese Optionen bieten die folgende Funktionalität: Sie können leicht zwischen Verzeichnissen innerhalb des Pfades wechseln, indem Sie auf jedes der intermediären Verzeichnisse klicken.

B. Inhalt aktualisieren, Neues Element erstellen, Hinzufügen des ausgewählten Elements zu den Favoriten, dessen Löschung oder das Montieren eines entfernten Verzeichnisses 2. Unter dem Werkzeugleiste können Sie den Dateibaum sehen, der für eine einfache Navigation zwischen ihnen und die Anzeige zusätzlicher Informationen zu den enthaltenen Dateien gedacht ist. In seinen Spalten werden folgende Daten angezeigt: Name - Dateiname, der durch Klicken auf das Bleistifticon (das beim Hüpfen über dem angezeigt wird) bearbeitet werden kann; außerdem können Sie die ausgewählte Datei verwalten, indem Sie die zusätzliche Liste verwenden. Größe - von der Datei aufgenommene Speicherplatz Größe - Datum der Dateierstellung oder des letzten Änderungsdatums Typ - Kategorie, die eine Datei zugeordnet ist (wo die verfügbaren Typen Regularfile, Verzeichnis, benannte Röhre, Socket, Zeichengerät und Blockgerät sind) Anmerkung: Nur der Regularfile-Typ kann über den Konfigurationsmanager bearbeitet werden. 3. Jede geöffnete Datei (klicken Sie doppelt auf sie oder wählen Sie die entsprechende Öffnen-Aktion für sie aus) wird in einer separaten Unter-Registerkarte angezeigt, sodass Sie zwischen ihnen wechseln können, ohne das vorherige zu schließen, was es Ihnen bei der Erkundung des Dateisystems leichter macht.

Für dieses) wird in einem separaten Unter-Tab angezeigt, sodass Sie zwischen ihnen wechseln können, ohne den vorherigen zu schließen, was es Ihnen bei der Erkundung des Dateisystems leichter macht. Zusätzlich, um die Verwaltung und Bearbeitung von Dateien zu vereinfachen, kann die passende Suche option genutzt werden, die über den gleichennamigen Knopf an der oberen Leiste verfügbar ist. Geben Sie einfach den erforderlichen Text ein, um alle Treffer in Ihrer Datei zu finden und hervorzuheben. Verwenden Sie die zusätzlichen Optionen, um die Suchergebnisse noch weiter zu verengen: Match Case - ermöglicht eine case-sensitive Suche Regex - ermöglicht die Verwendung von regulären Ausdrücken für die Festlegung der Suchbedingungen 4. Nachdem Sie mit den Bearbeitungen an den Dateien fertig sind, vergessen Sie nicht, Änderungen zu speichern, indem Sie den entsprechenden Knopf an der oberen Leiste verwenden. Wenn Sie mit einer Schicht aus mehreren Knoten arbeiten, werden Sie zusätzlich aufgefordert, ob es erforderlich ist, die geänderten Daten nur für die aktuelle Instanz oder für alle Instanzen zu speichern. Tip: Wenn Sie Änderungen an irgendeiner Konfigurationsdatei speichern, wird ein Bestätigungsfenster auftauchen. Wenn Sie sich sicher fühlen und dieses Fenster in Zukunft überspringen möchten, ticken Sie die Option "Dieses Dialogfeld nicht mehr anzeigen". Dadurch werden alle weiteren Änderungen sofort gespeichert, ohne erneut nach Bestätigung zu fragen. Diese Einstellung wird für alle Arten von Konfigurationsdateien in allen Ihren Umgebungen angewendet. 5. Um Änderungen an einem anderen Knoten innerhalb der gleichen Schicht vorzunehmen, können Sie die automatisch geladenen Dropdown-Liste an der oberen Links-Teile des Managers verwenden.

Hinweis: Die bereits geöffneten Dateien werden automatisch für die entsprechenden Knoten neu geladen, wenn Sie wechseln.
