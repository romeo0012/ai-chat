How to Deploy Cyclos 4

← Chat

Wie ein Cyclos 4-Instanz bereitzustellen, kannst du innerhalb von Minuten erledigen, indem du die ein-Klick-Installationsoptionen für beide die kostenlose und die PRO-Version von Cyclos 4 nutzt: Hinweis: Um die PRO-Version (Widget unten) zu nutzen, musst du einen gültigen Cyclos-Lizenzkauf vornehmen, während eine kostenlose Lizenz nach der Registrierung bei license.cyclos.org erhalten werden kann. Der Vorgang ist einfach - klicke einfach auf Get it hosted now, gib deine E-Mail-Adresse ein und installiere Cyclos innerhalb von einer Minute, indem du die manuelle Installationsschritte überspringst. Tip: Auch der automatisierte Installationspaket für Cyclos 4 PRO ist direkt im Dashboard über den Marktplatz verfügbar: Als Alternative folgen Sie den untenstehenden Anweisungen zur manuellen Bereitstellung.   1. Im Fenster Umgebungstopologie wähle Tomcat als deinen Anwendungssервер und PostgreSQL als Datenbank aus. Hinweis: Stelle sicher, dass deine Topologie die Anforderungen von Cyclos 4 erfüllt. Wenn du bereit bist, gib deinen Umgebungsnamen (z.B., cyclos) ein und klicke auf Create.

Database Configuration

  1. Klicke auf den Button Open in Browser neben Ihrer PostgreSQL-Datenbank, um das phpPgAdmin-Panel zu öffnen.
  1. Melde dich mit den Credentials, die Sie per E-Mail nach der Umgebungskreation erhalten haben, an und erstelle eine neue PostgreSQL-Datenbank.
  1. Im offenen Fenster geben Sie den Datenbanknamen (z.B. cyclos4), das Template (template0) und die Zeichenkodierung (UTF8) an. Klicke auf Create, um fortzufahren.
  1. Klicke auf den Namen Ihrer Datenbank und wechsle zum SQL-Tab. Führe das folgende einfache SQL-Code aus, um die erforderlichen Erweiterungen zu erstellen:

1 2 3 4 5
create extension cube;
create extension earthdistance;
create extension postgis;
create extension unaccent;
create extension pgcrypto;
Entferne die Eigenschaft Paginate results und klicke auf Execute.

Cyclos Configuration

  1. Kehre zurück zum Plattform-Dashboard und klicke auf den Button Config für Ihren Tomcat-Server.
  1. Navigiere zum Verzeichnis /opt/tomcat/webapps/ROOT/WEB-INF/classes und erstelle eine neue Datei namens cyclos.properties.
  1. Kopiere den Inhalt des Datei cyclos-release.properties aus demselben Verzeichnis und füge ihn der neu erstellten Datei cyclos.properties hinzu. Führe zusätzliche Anpassungen durch, um eine Verbindung mit Ihrer PostgreSQL herzustellen:

cyclos.datasource.

Füge es dem neu erstellten cyclos.properties-Dateihin ein und mache folgende zusätzlichen Anpassungen, um mit Ihrer PostgreSQL zu verbinden:

cyclos.datasource.dataSourceClassName - JDBC-Klasse für PostgreSQL (ist standardmäßig angegeben - org.postgresql.ds.PGSimpleDataSource)
cyclos.datasource.dataSource.portNumber - Port für die Datenbankverbindung (5432)
cyclos.datasource.dataSource.serverName - Host, um auf die Datenbank zuzugreifen (aus der Email)
cyclos.datasource.dataSource.databaseName - Datenbankname (in der vorherigen Abschnitt, cyclos4, erstellt)
cyclos.datasource.dataSource.user - Datenbankbenutzer (aus der Email)
cyclos.datasource.dataSource.password - Datenbankpasswort (aus der Email)

  1. Speichere die Änderungen und starten Sie Tomcat neu, um sie anzuwenden.
  1. Wenn Tomcat gestartet ist, öffnen Sie Ihre Umgebung im Browser. Hinweis: Der Start von Cyclos zum ersten Mal kann einige Zeit in Anspruch nehmen, da die Datenbankinitialisierung erfolgt.
