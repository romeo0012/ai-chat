Benutzerdefinierte Umgebungsvariablen
Umgebungsvariablen dienen als Art von Platzhaltern, an denen Sie häufig verwendete Parameterwerte oder Zeichenfolgen speichern können, um sie nicht jedes Mal manuell in Ihrem Code einzugeben, wenn sie benötigt werden. Es gibt eine Anzahl an Standardumgebungsvariablen, die vorab konfiguriert sind und in Ihrem Anwendungscode verwendet werden können oder auch noch vor der Erstellung eines Knotens angepasst werden, um eine Anpassung vorzunehmen, was Ihrem Arbeiten mit der Plattform noch mehr Komfort bietet. In dieser Anleitung werden wir die häufigsten Möglichkeiten beschreiben, um Ihre benutzerdefinierten Variablen für jeden Knoten innerhalb der Plattform hinzuzufügen: über eine dedizierte Variablen-Abschnitt des Dashboards mithilfe der Shell-Konfigurationsdateien über die variables.conf-Datei (nur für Java) Benutzerdefinierte Umgebungsvariablen über die UI

  1. Führen Sie den Mauszeiger über den Knotengruppe im Dashboard, erweitern Sie die zusätzlichen Optionen und wählen Sie die Variablen-Option aus.
  1. Im geöffneten Rahmen können Sie eine Liste von Umgebungsvariablen anpassen, wie Sie es für Ihre Anforderungen brauchen (mithilfe der Schaltflächen im Werkzeugbereich). Hinweis: Die Plattform-Implementierung von Docker-Containern erlaubt es, die vorhandenen Umgebungsvariablen zu verwenden, um andere zu definieren. Beispiel: Der Wert MY$HOME wird automatisch in MY\ umgewandelt (oder ähnlich basierend auf dem Wert der HOME-Variable). Erinnern Sie sich bitte, die Änderungen zu übernehmen.

Einrichten von Umgebungsvariablen über Shell-Konfigs
Sie können Ihre benutzerdefinierten Variablen über die Shell-Konfigurationsdateien bereitstellen: ~/.bash_profile wird nur bei Anmeldung über die Konsole ausgeführt ~/.bashrc wird bei jeder Anmeldung ausgeführt

Umgebung Variablen über Shell-Konfigurationen einrichten Sie können Ihre eigenen Variablen über die shell-Konfigurationsdateien bereitstellen: ~/.bash_profile wird nur bei Anmeldung über die Konsole ausgeführt, ~/.bashrc wird für jede neue bash-Instanz ausgeführt. Um Ihnen dabei zu helfen, diese Dateien zu verwalten, wird die Plattform automatisch die Quellen der .bashrc-Konfiguration in .bash_profile einbeziehen. Dadurch können Sie Ihre Variablen über die vorherige Datei einstellen:

  1. Stellen Sie eine SSH-Verbindung zu Ihrem Container her. Zum Beispiel werden wir den eingebetteten Web SSH-Client verwenden:
  1. Erstellen Sie oder passen Sie die .bashrc-Datei in Ihrem Heimverzeichnis an, indem Sie Ihre eigenen Variablen in folgendem Format hinzufügen:

1 export {var_name}= {var_value}

Wobei {var_name} der Name der Variable ist, die Sie angeben möchten
{var_value} ist der Wert Ihrer Variable

  1. Jede neue bash-Instanz wird nun mit Ihren eigenen Variablen versehen. Um die neuen Einstellungen für die aktuelle Sitzung zu aktivieren, müssen Sie die Quellen nur mit dem unten gezeigten Befehl neu laden. Anschließend überprüfen Sie, ob die neuen Variablen verfügbar sind:

1 2 source ~/.bashrc
echo $ {var_name}

Wie Sie sehen können, wurden die Änderungen erfolgreich angewendet.

Java-Umgebung Variablen über Konfigurationsmanager einrichten Die folgende einfache Workflow ist für alle auf der Plattform verwalteten Java-Anwendungssysteme identisch.

  1. Klicken Sie auf den Config-Button für Ihr Anwendungssystem, um den Dateimanager des Containers zu öffnen.
  1. In der geöffneten Registerkarte navigieren Sie zu den Variablen.

Bitte beachten Sie, dass die technischen Terme, Codeblöcke, Befehle, Dateipfade und URLs genau so gelassen werden, wie sie in der Originaltext sind.

1. Klicken Sie auf den Button Config für Ihre Anwendungserverumgebung, um zum Dateimanager der Container zu gelangen.

  1. In der geöffneten Registerkarte navigieren Sie zum Datei "variables.conf" in einem der folgenden Verzeichnisse: Tomcat, TomEE - /opt/tomcat/conf/variables.conf Jetty - /opt/jetty/etc/variables.conf Spring Boot - /opt/shared/conf/variables.conf GlassFish - /opt/glassfish/glassfish/domains/domain1/config/variables.conf Payara - /opt/payara/glassfish/domains/domain1/config/variables.conf WildFly - /opt/wildfly/conf/variables.conf Hier können Sie Ihre eigenen Variablen (jede sollte durch Leerzeichen getrennt oder auf einer neuen Zeile beginnen) oder Java-Optionen für Ihre Anwendung anpassen. Beispiel: -Dvar1=value1 -Dvar2=value2 -Dmy.var3=/my/value Tip: Alternativ bieten einige Anwendungserver (z.B., GlassFish, Payara, WildFly) eine Admin-Oberfläche, die auch die Möglichkeit bietet, JVM-Optionen und benutzerdefinierte Variablen zu konfigurieren: Vergessen Sie nicht, die von Ihnen gemachten Änderungen zu speichern.
  1. Neustarten Sie die Knoten Ihres Anwendungserverumgebung, um die Änderungen anzuwenden.
  1. Die neuen Variablen können durch Ihr Java-Code mittels der Methode System.getProperty("Ihre_Variable") aufgerufen werden, um den angegebenen Werten die notwendigen Argumente zuzuweisen. Beispiel: String var1 = System.getProperty("var1"); String var2 = System.getProperty("var2"); String var3 = System.getProperty("my.var3") Jetzt können Sie Ihre Anwendungscode mit diesen neuen Variablen anpassen.
