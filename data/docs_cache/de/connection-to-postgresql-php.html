Verbindung zu PostgreSQL für PHP-Anwendungen

Folgen Sie den Anweisungen unten, um zu erfahren, wie Sie Ihre PHP-Anwendung, die innerhalb der Plattform gehostet wird, mit dem PostgreSQL-Datenbankserver verbinden: Umgebung erstellen, konfigurieren und PHP-Server überprüfen, Verbindung überprüfen

Erstellen einer Umgebung

  1. Melden Sie sich bei der Plattform-Dashboard an.
  1. Erstellen Sie eine Umgebung mit dem PHP-Anwendungserver (z.B. Apache PHP) und dem PostgreSQL-Datenbankserver.
  1. Überprüfen Sie Ihre E-Mail-Postfach, um eine Nachricht mit Datenbankanmeldeinformationen (Benutzername und Kennwort) zu erhalten. Jetzt können Sie Ihre Datenbank über die Web-Admin-Oberfläche zugreifen und sie mit Ihrer PHP-Anwendung verbinden.

Konfigurieren der Datenbankverbindung

  1. Klicken Sie auf den Button "Config" für Ihren Apache-Server.
  1. Navigieren Sie zum Ordner "etc" und öffnen Sie die Datei php.ini. Fügen Sie die Zeile "extension=pgsql.so" wie im Bild unten dargestellt ein.
  1. Speichern Sie die Änderungen und Starten Sie die Knoten für Ihren Apache-Server(s) neu.
  1. Es gibt zwei Hauptfunktionen von PG, um mit dem Datenbankserver zu arbeiten:

- Öffnen einer PostgreSQL-Verbindung: 1 pg_connect("host={host} port={port} dbname={dbname} user={user} password={password}");
wo: {host} - der PostgreSQL-Server-Host (z.B. Zugriff URL ohne http://), den Sie über die E-Mail erhalten haben, z.B. node171206-php-postgresql.jelastic.com
{port} - der Verbindungsport (der Standardport ist 5432)
{dbname} - der Name Ihrer Datenbank
{user} - der Benutzername zum Zugriff auf die Datenbank (wir werden den Standardbenutzer "webadmin" verwenden)
{password} - das Kennwort für den entsprechenden Benutzer
- Schließen einer PostgreSQL-Verbindung: pg_close()

Hier ist ein Beispiel für eine PHP-Datei, die die Verbindung mit der PostgreSQL-Datenbank herstellt:

&lt;?php
$conn = pg_connect("host=node171206-php-postgresql.jelastic.com port=5432 dbname=mydb user=webadmin password=my_password");
if (!$conn) {
    die('Could not connect: ' . pg_last_error());
}
echo "Connected successfully\n";
pg_close($conn);
?&gt;

Deine Datenbank {user} - ein Benutzername, um auf die Datenbank zugreifen zu können (wir werden den Standard-Benutzer webadmin verwenden) {password} - ein Passwort für den passenden Benutzer. Schließe die PostgreSQL-Verbindung mit pg_close() ab.

  1. Es muss auf jeder *.php-Seite die notwendigen Funktionen geschrieben werden, die mit der Datenbank verbunden sein müssen. Überprüfe die Verbindung mit dem folgenden Code:

&lt;?php
$dbconn = pg_connect("host=postgres.jelastic.com port=5432 dbname=postgres user=webadmin password=passw0rd");
// Verbinden mit einer Datenbank namens "postgres" auf dem Host "host" mit einem Benutzer und Kennwort
if (!$dbconn){
 echo "&lt;center&gt;&lt;h1&gt;Es funktioniert leider nicht =(&lt;/h1&gt;&lt;/center&gt;";
}else echo "&lt;center&gt;&lt;h1&gt;Gute Verbindung&lt;/h1&gt;&lt;/center&gt;";
pg_close($dbconn);
?&gt;

Ausführen einer einfachen Anfrage und geben Sie das Ergebnis in einer Tabelle aus:

&lt;?php
$conn = pg_connect("host=postgres.jelastic.com port=5432 dbname=postgres user=webadmin password=passw0rd");
if (!$conn) {
 echo "Ein Fehler ist aufgetreten.\n";
 exit;
}
$result = pg_query($conn, "SELECT * FROM test_table");
if (!$result) {
 echo "Ein Fehler ist aufgetreten.\n";
 exit;
}
while ($row = pg_fetch_row($result)) {
 echo "value1: $row[0] value2: $row[1]";
 echo "&lt;br /&gt;\n";
}
?&gt;
