How to Deploy JRuby

← Chat

Um JRuby auf die Cloud zu deployen, empfehle ich Ihnen den PaaS (Platform as a Service). JRuby ist eine Java-Implementierung der Ruby-Programmiersprache und ermöglicht es, den Interpreter in jede Java-Anwendung einzubinden, mit vollständigem, zweiwegigem Zugriff auf Java- und Ruby-Code. Wenn Sie als Ruby-Entwickler sind und Ihre Anwendung in die Cloud deployen möchten, ist der PaaS die beste Methode. Er ist leicht und schnell. Um zu sehen, wie leicht es ist, folgen Sie den nächsten Schritten:

Erstellen Sie eine Anwendung

  1. Zunächst müssen Sie JVM für Ihr Betriebssystem installieren.
  1. Navigieren Sie zu jruby.org und downloaden Sie die neueste JRuby-Veröffentlichung (die Plattform unterstützt JVM-basierte Sprachen). Es gibt kein Problem: es handelt sich um Ruby für die JVM und Sie werden keine Probleme haben.
  1. Entpacken Sie die Dateien aus dem zip-Paket, das Sie gerade heruntergeladen haben.
  1. Installieren Sie Rails, eine offene Web-Framework, die Ihnen erlaubt, "schönes Code durch den Vorzug von Konvention über Konfiguration zu schreiben". Es ist sehr einfach, führen Sie die folgenden Zeichenfolgen ein, um Sie am Befehlsc Line einzugeben:

1 2 3
c:\cd jruby-1.6.5.1
c:\ jruby-1.6.5.1>cd bin
c:\ jruby-1.6.5.1\ bin>gem install rails
Gem ist die Befehlszeile für RubyGems, dem standardmäßigen Ruby-Paketmanager. Mit RubyGems können Sie Rails und seine Abhängigkeiten über die Befehlszeile installieren.
  1. Installieren Sie warbler, der Ihnen erlaubt, jar und war-Dateien aus Ihrer Anwendung zu erstellen.

1 c:\jruby-1.6.5.1\bin>gem install warbler
  1. Erstellen Sie ein neues Projekt in rails_projects, z.B. app:

1 c:\rails_projects>rails new app
  1. Erstellen Sie Ihre .WAR-Datei mit nur einer Befehl warble:

1 c: rails_projects\app>warble
Erstellen Sie eine Umgebung
  1. 1 c:\rails_projects>\rails new app
  1. Erstellt Sie Ihr .WAR-Datei-Paket mit nur einem Befehl warble:

1 c: \rails_projects\app>\warble Create Environment
  1. Melden Sie sich bei der Plattform-Dashboard-Anwendung an.
  1. Erstellen Sie eine neue Umgebung.
  1. Öffnen Sie im Fenster "Umgebung Topologie" die Liste mit den Anwendungsservern (z.B., Tomcat 6) und geben Sie Ihren Umgebungsnamen ein, z.B., RubyonRails, und klicken Sie auf den "Erstellen"-Button.
  1. Innerhalb von einer Minute wird Ihre Umgebung mit Tomcat erfolgreich erstellt.

Upload Java Package

  1. Laden Sie Ihr WAR-Datei-Paket im Bereitstellungsmanager hoch.
  1. Sobald das Paket im Dashboard verfügbar ist, lassen Sie es auf die von Ihnen erstellte Umgebung bereitstellen.
