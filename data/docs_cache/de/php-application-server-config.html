PHP Anwendungserver-Konfiguration

Um die notwendigen Konfigurationen durchzuführen, drücken Sie bitte auf den Config-Button neben Ihrem Anwendungserver. Im Falle, dass Sie mehrere Anwendungserver haben, können Sie sie zusammen oder separat konfigurieren. Dazu folgen Sie den Schritten:

  1. Öffnen Sie den Dropdown-Menü an der Spitze der Konfigurationstab. Es enthält die Liste aller App-Server in Ihrer Umgebung.
  1. Wählen Sie den erforderlichen Server aus und konfigurieren Sie ihn.
  1. Um die Änderungen anzuwenden: nur für den ausgewählten Server klicken Sie auf den Speichern-Button nur für die aktuelle Instanz aus dem Dropdown-Menü; für alle Server klicken Sie auf Speichern für alle Instanzen. Hinweis: Wenn Sie eine Datei oder Verzeichnis im Konfigurationsmanager erstellen oder umbenennen, wird dies nur in der Liste des ausgewählten Knotens angewendet. Sie können diese Änderung nicht für alle verfügbaren App-Server in der Umgebung speichern. Wenn Sie auch in den anderen Servern dieselbe Datei oder Verzeichnis erstellen oder umbenennen möchten, müssen Sie dies manuell tun.

ETC Die Hauptkonfigurationen des PHP-Servers werden in der php.ini-Datei vorgenommen, die sich im etc-Ordner befindet. Beispielhaft können hier folgendes eingestellt werden:

  • PHP-Erweiterungen
  • PHP-Beschleuniger
  • PHP-Sessions in Memcached speichern
  • PHP.INI-Sicherheitskonfigurationen

Für den Apache-Anwendungsspeicherserver ist die Hauptkonfigurationsdatei die httpd.conf, die sich im conf-Ordner befindet. Beispielhaft können hier folgendes vorgenommen werden:

  • Einrichtung von Mehrdomänen
  • Aktivierung von benutzerdefinierten Apache-Modulen
  • Verwendung des WebDav-Moduls
  • Durchführung notwendiger Sicherheitskonfigurationen
  • Konfiguration von namensbasierten virtuellen Hosts
  • Aktivierung des Statistikmoduls, um Ihre Serverstatistiken anzuzeigen

Hinweis: Um in der httpd.conf-Datei beliebige benutzerdefinierte Konfigurationen durchzuführen, muss der #Jelastic-Autokonfiguration-Zeichenstreifen am Anfang der Datei entfernt werden:

Die Anzahl der Arbeiter für die Verarbeitung von PHP-Anfragen wird in einem Apache-Server automatisch erhöht, je nach der angegebenen Cloudlet-Menge. Um dies zu überprüfen, suche und merke dich den MaxClients-Wert in der httpd.conf-Datei.

PHP-Anfragen werden automatisch erhöht, je nachdem, wie viele Cloudlets für sie festgelegt wurden, in einem Apache-Server. Um dies zu überprüfen, finden Sie und merken Sie sich den Wert von MaxClients in der httpd.conf-Datei. Danach ändern Sie die Umgebung durch Veränderung des Cloudlet-Limit für Ihren Server. Kehren Sie zur httpd.conf-Datei zurück - der Wert von MaxClients hat sich erhöht/vermindert. Hinweis: Diese Funktionalität wird deaktiviert, wenn Sie die # Jelastic-Konfigurationszeichenfolge am Anfang der httpd.conf-Datei entfernen.

NGINX
Für die Durchführung notwendiger Konfigurationen für einen NGINX-PHP-Server wird die nginx.conf-Datei, die sich im Ordner conf befindet, verwendet. Verwenden Sie sie, um die folgenden Konfigurationen einzurichten:

  • Mehrere Domänen einrichten
  • WebDav-Modul einrichten
  • Notwendige Sicherheitskonfigurationen durchführen

CRON
App-Server enthalten einen Ordner cron mit der Konfigurationsdatei, in der Cronjobs konfiguriert werden können. Weitere Informationen zur Konfiguration von Cronjobs finden Sie im Dokument "Setting Up a Cronjob".

Zurück zur Liste

KEYS
Der keys-Ordner dient als Speicherort für die hochladen Sieben von Ihrer Anwendung benötigte private Schlüssel. Generieren Sie den Schlüssel, speichern Sie ihn als einfaches Datei und hochladen Sie ihn in den keys-Ordner.

Jetzt können Sie ihn für verschiedene Fälle einfach durch Angabe des Pfads zu Ihrer Schlüssel verwenden: /var/lib/jelastic/keys/{key_file_name}

Zurück zur Liste

MODULES
Der modules-Ordner enthält die standardmäßig im Plattform bereitgestellten php-Module. Sie können auch Ihre eigenen php-Module in diesen Ordner hochladen, um sie zu aktivieren. Weitere Informationen finden Sie im Dokument "PHP Modules".
