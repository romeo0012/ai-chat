WordPress-Mehrseitiges Netzwerk
Während der Betrieb mehrerer Websites kann es vorteilhafter sein, ein WordPress-Mehrseitiges Netzwerk zu verwenden, anstatt mehrere einzelne WordPress-Websites zu verwalten: Sie können leicht mehrere Websites von einem einzigen Dashboard verwalten. Andere Benutzer können als Admin hinzugefügt werden, mit beschränkter Zugriffsberechtigung nur auf eine spezifische Website. Neue Plugins und Themen können für mehrere Websites gleichzeitig installiert und aktiviert werden. Aktualisierungen sollten nur auf der Master-Installation durchgeführt werden und werden automatisch auf alle Websites im Netzwerk angewendet. Jede Website oder Blog kann separat angepasst werden, sodass sie nicht durch die einheitliche Verwaltung eingeschränkt sind. Diese Umsetzung kann für viele Branchen und Arten von Organisationen von Nutzen sein, die ihre eigenen Websites haben: Medienressourcen mit einer Anzahl von Abschnitten, die von verschiedenen Teams verwaltet werden; Regierungs- und nicht-staatliche Websites für verschiedene Abteilungen oder Standorte; Bildungsorganisationen mit Unter-Websites, die von Schülern erstellt wurden; Unternehmenswebsites mit Unterkategorien für verschiedene Niederlassungen; private Blogs auf mehreren Unterdomänen, und andere. Ein Mehrseitiges Netzwerk ist eine integrierte Funktion in WordPress, die leicht aktiviert werden kann, aber zugleich eine Reihe von Konfigurationen erfordert, um richtig zu funktionieren. In diesem Artikel werden wir beschreiben, wie Sie in wenigen Minuten mehrere Websites, benutzerdefinierte Domänen binden und SSL-Zertifikate ausstellen können, indem Sie eine einzelne WordPress-Installation verwenden. Dies kann ein Cluster oder ein einzelnes Paket sein. 2. Aktivieren Sie die erforderlichen fortgeschrittenen Funktionen, einschließlich der Option "WordPress-Mehrseitensystem-Netzwerk". Danach können Sie mit der Umgebunginstallation fortfahren. Beispielsweise werden wir WordPress auf LiteSpeed-Servern (mit WAF und Bruteforce-Schutz), MariaDB Galera und GlusterFS-Speicher erstellen. Zusätzlich werden die Optionen Let's Encrypt SSL und Mehrseitensystem aktiviert. Konfigurieren Sie das Mehrseitensystem und erstellen Sie Website A. Wenn Sie jedoch eine zusätzliche Domäne an eine Unterseite binden möchten, ist der Prozess etwas anders.

  1. Erstellen Sie einen A-Eintrag für Ihre zusätzliche Domäne, der sie auf den öffentlichen IP-Adressen des Load Balancers oder des Standalone-Containers verweist.
  1. Suchen Sie den Let’s Encrypt Free SSL-Add-On für Ihr WordPress-Umgebung und klicken Sie auf den "Configure"-Button. Fügen Sie Ihre zusätzliche Domäne der Liste der registrierten Domänen für Ihre Websites hinzu (Verwenden Sie Komma, um mehrere Domänen zu trennen) und klicken Sie auf "Apply".
