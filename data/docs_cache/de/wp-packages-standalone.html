WordPress-Einzelanwendungspaket

Das WordPress-Einzelanwendungspaket ist eine automatisierte Lösung für die kostengünstige Installation von WordPress in einem leichten Container, der für die Ausführung von kleinen und mittleren Projekten verwendet werden kann. Das Paket führt alle notwendigen Konfigurationen durch, sodass Sie sich auf Ihr Projekt konzentrieren können, anstatt Zeit mit der Serververwaltung zu verbringen. Basierend auf Ihren Vorlieben können Sie zwischen den LLSMP (Linux + LiteSpeed + MariaDB + PHP) oder LEMP (Linux + NGINX + MariaDB + PHP) Vorlagen wählen. Ihre WordPress-Einzelanwendungskontainer wird automatisch die folgenden Komponenten ausführen: ein PHP-basiertes Anwendungsserver (entweder LiteSpeed oder NGINX) ein MariaDB-Datenbankserver ein Redis-hochleistungs-RAM-zuweisender Datenstrukturspeicher Zusätzliche Funktionen können über die fortgeschrittenen Einstellungen aktiviert werden.

WordPress-Einzelanwendungseinrichtung

Um das WordPress-Einzelanwendungspaket zu installieren, folgen Sie den folgenden Schritten:

  1. Klicken Sie auf den Marktplatz-Button auf dem Virtuozzo-Anwendungsverwaltungsdashboard.
  1. Verwenden Sie den Suchfeld, um das Paket WordPress Standalone Kit zu finden und klicken Sie auf Installieren.
  1. 1. Klicken Sie auf den Marktplatz-Button auf der oberen Virtuozzo Application Management Dashboard. 2. Verwenden Sie das Suchfeld, um das Paket WordPress Standalone Kit zu finden, und klicken Sie auf Installieren. 3. Im aufgerufenen Installationsfenster können Sie Ihre WordPress-Standalone-Anwendung individuell anpassen, indem Sie die notwendigen Optionen auswählen: wählen Sie die PHP-Version, wählen Sie stattdessen LiteSpeed High-Performance Web Server anstelle des Standard-Webservers NGINX, aktivieren Sie Brute Force Attack Protection und Web Application Firewall-Funktionen für LiteSpeed, installieren Sie Let’s Encrypt SSL mit Auto-Renewal-Add-on, um eine kostenlose SSL-Zertifikat automatisch auszustellen, konfigurieren Sie WordPress Multisite Network und installieren Sie den WooCommerce-Add-on für WordPress zuletzt. Geben Sie schließlich den Umgebungsnamen und den Anzeigenamen an, wählen Sie (wenn verfügbar) die Verfügbarkeitsregion aus und klicken Sie auf Installieren. 4. In wenigen Minuten wird der WordPress-Standalone-Umgebung automatisch erstellt und konfiguriert, wie Sie die ausgewählten Optionen vorgesehen haben. Alles klar!
