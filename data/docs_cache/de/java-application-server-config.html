Java Anwendungserver-Konfiguration

Um die notwendigen Konfigurationen durchzuführen, drücken Sie bitte auf den Config-Button neben Ihrem Anwendungserver. Im Fall, dass Sie mehrere Anwendungserver haben, können Sie sie zusammen oder separat konfigurieren. Dazu folgen Sie den Schritten:

  1. Öffnen Sie den Dropdown-Menü am oberen Rand der Konfigurationstab. Es enthält die Liste aller App-Server in Ihrer Umgebung.
  1. Wählen Sie den benötigten Server aus und konfigurieren Sie ihn.
  1. Um die Änderungen anzuwenden: nur für den ausgewählten Server - klicken Sie auf den Save nur für aktuelles Instanz-Button aus dem Dropdown-Menü. Für alle Server - klicken Sie auf Save.

Hinweis: Wenn Sie eine Datei oder Ordner in der Konfigurations-Manager erzeugen oder umbenennen, wird dies nur in der Liste des ausgewählten Knotens angewendet. Sie können diese Änderung nicht für alle verfügbaren App-Server in der Umgebung speichern. Wenn Sie auch in den anderen Servern die Datei oder den Ordner erzeugen oder umbenennen möchten, müssen Sie dies manuell tun.

container-Konfigurationen werden in den Dateien durchgeführt, die sich im Server-Ordner befinden. Mithilfe der folgenden Konfigurationsdateien können Sie die unten aufgeführten Aktionen durchführen (dies sind nur einige Beispiele):

  • context.xml - Session-Replikation über Memcached konfigurieren
  • web.xml - Remotezugriff über WebDav server konfigurieren
  • server.xml - Mehrere Domänen aktivieren
  • variables.conf - Speichere Speicherparameter für Ihre Java-Container durch Angabe Ihrer eigenen GC, -Xmx, -Xms-Parameter (Verwende Standardparameter, indem jedes auf einer neuen Zeile angegeben wird):

1
2
-Xmx< Größe >m
-Xms< Größe >m

Setze Ihre eigenen systemeigenen Eigenschaften für Ihren Tomcat, TomEE, Jetty oder GlassFish:

2
-Dvar1=value1
-Dvar2=value2
-Dmy.var3=/my/value
