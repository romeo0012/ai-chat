Offentliche IP-Adresse
Die Plattform bietet Benutzern einen Shared Load Balancer (SLB) als Standard-Ein-Punkt für den Zugriff auf alle im Hardwareknoten gehosteten Anwendungen. In Produktionsumgebungen wird jedoch empfohlen, Anforderungen über eine oder mehrere Offentliche IP-Adresse(n) zu empfangen und zu verarbeiten, die einen direkten Zugang zwischen dem Internet und einem bestimmten Container herstellen. Im Vergleich zum Zugriff über SLB bietet dies eine sichere und effektive Interaktion. Eine Offentliche IP-Adresse kann an jede Software-Stack-Umgebung in Ihrem System angehängt werden (außer, Memcached-Knoten), was ein stabileres Lösungsmittel mit weniger Risiko darstellt, betroffen zu werden von anderen Anwendungen. Darüber hinaus ermöglicht es den Zugriff auf solche Funktionen wie FTP-Add-on, Benutzerdefinierte SSL, Remotedebugging aus IDE, WebSockets usw. Die Plattform unterstützt zwei Versionen des Internetprotokolls: Internetprotokollversion 4 (IPv4) ist die vierte Revision in der Entwicklung des IP und die erste Version des Protokolls, die weltweit eingesetzt wurde. Internetprotokollversion 6 (IPv6) ist die neueste IP-Version, die eine evolutionsbasierte Upgrade von IPv4 darstellt und die Bedürfnisse nach mehr Adressen, besseren Multicast-Routing und Vereinfachung der Verarbeitung durch Routers erfüllen soll.

Um eine externe IP-Adresse an den erforderlichen Knoten zu binden, müssen Sie (oder die erforderliche Anzahl von) Offentliche IPv4 / Offentliche IPv6 in der zentralen Teilbereich des Topologie-Assistentenfensters aktivieren. Hinweise: Die Aktivierung von Offentlicher IPv4 deaktiviert standardmäßig den Zugriff über SLB.

Anzahl der erforderlichen Public IPv4 / Public IPv6 im zentralen Teil der Topologie-Assistenten-Fenster. Hinweise: Aktivierung von Public IPv4 deaktiviert standardmäßig den Zugriff über SLB. Dies kann zu einer temporären (einigen Minuten) Störung der Umgebungszugang aufgrund des DNS-Caches führen. Bei der Verbindung externer IPs für die horizontal skalierten Knoten wird jedem Container innerhalb der Schicht ein eigenes Satz von Adressen zugewiesen. Um die zugewiesenen IPs in der aktuellen Umgebung zu finden und zu verwalten, kann der entsprechende Knotenzeichenfolge in der Umgebungstopologie-Liste ausgeklappt werden. Hier können Sie bei Überfahren von IPs auf die folgende Funktionalität zugreifen: Kopieren in die Zwischenablage - kopiert die entsprechende Adresse mit einem Klick Anhängen/Entfernen von IP(s) - ermöglicht es, die Anzahl der öffentlichen IPs (beide IPv4 und IPv6) anzupassen Entfernen von IP - entfernt eine bestimmte Adresse Hinweise: Die öffentliche IP ist ein bezahlter Option, die für jede Stunde ihrer Nutzung berechnet wird. Der genaue Preis wird von Ihrem speziellen Hosting-Dienstleister definiert und kann im Rahmen des Dashboards unter Quotas & Preise > Preise > Optionen gefunden werden. Weitere Informationen zu Ressourcenverbrauch und Rechnungsführung finden Sie im Dokument FAQ zu Preisen. Wenn Sie für einen Knoten in Ihrer Umgebung eine öffentliche IP aktiviert haben, können Sie die Funktionalität des Austauschs von Domänen nicht verwenden. Überlegen Sie es, stattdessen die API für den Austausch öffentlicher IPs zu verwenden. Wenn Sie mit mehreren öffentlichen IPs arbeiten, wird die erste extern angefügte Adresse (jeder IPv4 und IPv6-Typ) als primäre Adresse betrachtet und kann nur zuletzt gelöscht werden.
