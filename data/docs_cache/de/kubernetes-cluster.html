Kubernetes-Übersicht

Kubernetes ist eine offene Quellcode-Plattform, die Container-Orchestrierung und automatisierte Infrastrukturverwaltung für die Entwicklung, Bereitstellung und Skalierung von Anwendungen ermöglicht. Es bietet eine Reihe von Funktionen, die die Verwaltung von Container-Anwendungen erleichtern, einschließlich der automatischen Skalierung, der Lastverteilung und der Selbstheilung.

Systemanforderungen

Um Kubernetes erfolgreich zu installieren und zu betreiben, sind bestimmte Systemanforderungen erforderlich. Hier sind die wichtigsten Anforderungen aufgelistet:

  • Betriebssystem: CentOS 7.x, Ubuntu 16.04 LTS oder höher
  • Prozessor: mindestens 2 Kerne
  • Arbeitsspeicher: mindestens 4 GB
  • Speicherplatz: mindestens 50 GB freier Speicherplatz
  • Netzwerk: mindestens 100 Mbit/s Bandbreite und eine öffentliche IP-Adresse

Clusterinstallation

Um einen Kubernetes-Cluster zu installieren, müssen die folgenden Schritte durchgeführt werden:

  1. Installation von Kubernetes-Paket:

curl -s https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo apt-key add -
echo "deb https://apt.kubernetes.io/ kubernetes-xenial main" | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo apt-get update
sudo apt-get install -y kubelet kubeadm kubectl
  1. Initialisierung des Kubernetes-Clusters:

sudo kubeadm init --pod-network-cidr=10.244.0.0/16
  1. Verbindung mit dem Kubernetes-Cluster:

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config
  1. Installation des Pod-Netzwerks:

kubectl apply -f https://docs.projectcalico.org/manifests/calico.yaml

Clusterversionen

Um die Version und die Änderungsinformationen des Kubernetes-Cluster-Pakets zu überprüfen, können Sie den folgenden Befehl ausführen:

kubeadm version

Dieser Befehl gibt Ihnen die Version des Kubernetes-Cluster-Pakets, die Version des Kubernetes-Servers und die Version des Kubernetes-Apiservers zurück. Um die Änderungsinformationen zu überprüfen, können Sie den folgenden Link aufrufen:

<https://github.com/virtuozzo/vz-k8s/releases>

Dieser Link führt Sie zur Seite mit den Versionen und Änderungsinformationen des Kubernetes-Cluster-Pakets in der Virtuozzo Anwendungsverwaltung.
