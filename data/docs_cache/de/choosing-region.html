Ausgewählte Umgebungsregion: Die PaaS-Lösung bietet beträchtliche Flexibilität, indem sie Hostingdienstanbietern die Möglichkeit gibt, verschiedene Arten von Hardware innerhalb der Grenzen einer einzigen Plattform zu kombinieren. Diese Hardware-Gruppen, die als Umgebungsregionen bezeichnet werden, können unterschiedliche Kapazitäten, Preise und Standorte haben, aber immer noch über eine einzige Infrastruktur verwaltet werden. Obwohl der Begriff selbstverständlich ist, kann diese Anwendung eine Vielzahl von Vorteilen bringen, sodass Sie Ihre App-Hosting-Hardware auswählen können, basierend auf: geografischer Lage - für bessere Antwortzeiten und breitere Verbreitung der Dienstqualität & Kapazität - für die Anpassung der Hostingbedingungen an die aktuellen Anforderungen, z.B. billigere Hardware - für Entwicklung und Testen, eine hochwertigere - für die Produktion, Kosten - für die Auswahl der kostengünstigsten Preispolitik basierend auf dem verfügbaren Budget.

Mit der Auswahl des gewünschten Hardware-Sets während der Erstellung einer neuen Umgebung können Sie zudem bereits laufende Projekte an eine andere Standort verlagern. Falls dies nötig ist, kann dies in wenigen Klicks erfolgen - siehe mehr Details in dem Dokument Migration zwischen Umgebungsregionen. Dadurch erhalten Sie eine beeindruckende Flexibilität für die Organisation des Lebenszyklus Ihrer Anwendung und ihrer Verbreitungspolitik.

Umgebung Region auswählen
Wenn Ihr Dienst-Hosting-Anbieter mehrere Umgebungsregionen anbietet, können Sie die passende Dropdown-Liste auf allen Frames finden, die für die Initiierung der Erstellung einer neuen Umgebung vorgesehen sind: topology wizard platform Marketplace Umgebung import

Die einzige Ausnahme ist die Klon-Operation - in diesem Fall wird eine neue Umgebung automatisch in der gleichen Hardware-Region erstellt. Es kann jedoch leicht manuell in die gewünschte Position verschoben werden, mit Hilfe der Migration-Option. Hinweis: Die Anzahl/Namen/Beschreibungen/Parameter der bereitgestellten Regionen werden von jedem einzelnen Hosting-Anbieter individuell definiert; somit können sie sich bei verschiedenen PaaS-Installationen unterscheiden, wenn Sie für bestimmte Hardware auswählen. In diesem Fall kann auch die Umgebungsdomäne (die neben dem Feld mit seinem Namen angezeigt wird) geändert werden, je nach Regionseinstellungen. Wählen Sie eine der bereitgestellten Regionen (es wird empfohlen, sich vorher über jede von ihnen auszuklagen) aus, um Ihre Umgebung dort automatisch zu platzieren.

je nach der Regionseinstellung wählen Sie eine der bereitgestellten Regionen (empfohlen: die Details zu jeder Region vorher zu erforschen) um Ihre Umgebung dort automatisch zu platzieren. Nach der Erstellung sehen Sie Ihre neue Umgebung auf dem Dashboard, die mit einem speziellen kleinen Icon für die Region versehen wird. Bei Aufschwenken über dieses Icon wird der passende Regionname angezeigt. Dadurch können Ihre Umgebungen schnell nach der Region/Standort unterschieden werden. Weitere Informationen zu Regionen Empfehlen wir, sich mit den Details jeder verfügbaren Region vorher auszukennen, um eine Entscheidung nach Ihren Bedürfnissen zu treffen. Diese Informationen können wie folgt angezeigt werden: jede Region wird mit einer kurzen Beschreibung versehen, die innerhalb der Liste angezeigt wird. Klicken Sie auf den Punkt "Mehr Details" der Liste oben, um Sie auf die Regionstabseite innerhalb des Fensters "Gebühren und Preise" zu leiten. Hier können Sie die detaillierten Informationen zu den bereitgestellten Regionen finden, z.B. eine allgemeine Beschreibung mit der Liste der bereitgestellten Parameter und eingeschlossener Funktionalität. Allerdings hängt es von den Einstellungen Ihres Hostinganbieters ab, dass dieser Link auf eine separate Seite oder Dokumentationsseite leitet.

Wenn mehr Informationen zu einer bestimmten Region erforderlich sind, wenden Sie sich bitte an Ihren Hostinganbieter, um die entsprechende Hilfe zu erhalten.
