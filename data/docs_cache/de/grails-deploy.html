How to Deploy Grails

← Chat

Um Grails zu bereitstellen, ist Grails ein innovatives, hoher-Leistungs-Framework, das sich auf dem Prinzip von „Convention over Configuration“ beruht und daher sehr beliebt ist. Es bietet eine selbstständige Entwicklungsumgebung, während es eine Einfachheit bietet, die den Entwickler daran ermöglicht, sich auf das wirklich wichtige zu konzentrieren: die Entwicklung von hochwertigen, leicht zu nutzenden Anwendungen, die die Benutzer lieben. Grails erleichtert die Entwicklung von Java-Anwendungen, da es auf Spring basiert und auf Groovy aufgebaut ist. Nutze alle Vorteile von Grails mit dem PaaS! Erstellung der Anwendung

  1. Gehe zu grails.org und lade die aktuelle Version von Grails herunter.
  1. Entpacken Sie das heruntergeladene Paket.
  1. Fügen Sie die Umgebungsvariablen (optional): GRAILS_HOME (C:\grails-2.0.0) gibt den Pfad an, an dem Sie das Archiv extrahiert haben; PATH (C:\grails-2.0.0\bin) enthält den Pfad zum bin-Verzeichnis.
  1. Erstellen Sie Ihre App über die Befehlszeile. Mit Umgebungsvariablen (C:\grails auf Windows, ~/grails auf Linux):

1 ...\grails-1.3.7 grails create-app {app_name}
Ohne Umgebungsvariablen:
1 ...\grails-1.3.7\bin\grails create-app {app_name}
Hinweis: Die Anwendung wird in dem Verzeichnis C:\grails-1.3.7\bin\5 erstellt.
  1. Erstellen Sie ein .war-Archiv mit nur einer Befehl:

Mit Umgebungsvariablen (C:\grails auf Windows, ~/grails auf Linux):
1 ...\grails-1.3.7\{app_name} grails war {app_name}.war
Ohne Umgebungsvariablen (C:\grails auf Windows, ~/grails auf Linux):
1 2 ...\grails-1.3.7\bin\{app_name} ...\grails-1.3.7\bin\war {app_name}.war

Auf Linux:
1 ...\grails-1.3.7\{app_name} grails war {app_name}.war Ohne Umgebungsvariablen (C:\grails auf Windows, ~/grails auf Linux):
1 2 ...\grails-1.3.7\bin\{app_name} ...\grails-1.3.7\bin\grails war {app_name}.war Der Archiv-Paket wird an C:\grails-1.3.7\bin\{app_name}\ gespeichert. Erstellen Sie die Umgebung

  1. Melden Sie sich bei der Plattform-Dashboard an.
  1. Erstellen Sie eine neue Umgebung.
  1. Wählen Sie im Umgebungstopologie-Dialog Ihren Anwendungsserver (z.B., Tomcat) aus und geben Sie Ihren Umgebungsnamen ein, z.B., grails, dann klicken Sie auf den Create-Button. Es dauert nur eine Minute, bis Ihre Umgebung erstellt wird.

Hochladen des Java-Pakets

  1. Hochladen Sie Ihr WAR-Paket auf den Deployment-Manager.
  1. Sobald das Paket auf der Plattform hochgeladen ist, lassen Sie es auf Ihre Umgebung bereitstellen. Das ist es. Starten Sie Ihre Anwendung und genießen Sie! Was kommt nachher? Tutorials nach Kategorie Java Tutorials Umgebung einrichten
