WordPress-Migrations-Leitfaden
Dieser Leitfaden dient dazu, die problemlose Migration von WordPress-Webseiten zur Verwendung der Virtuozzo-Anwendungsverwaltung mit vorkonfigurierten WordPress-Paketen im Marktplatz zu unterstützen. Folgen Sie den einfachen Schritten, um die Migration flüssig und sicher zu gestalten. Hinweis: Wenn Sie auf die Migration zu WordPress mit dem Galera-Cluster zielen, stellen Sie sicher, dass alle Tabellen in Ihrer Datenbank eine explizite Primärschlüssel haben, entweder eine einzelne oder eine Mehrspalten-Index. Ignorieren Sie diese Anforderung, wird zu einer Replikationsfehlschlag führen. Sie können sich mit der Vollständigen Liste der Einschränkungen des Galera-Clusters vertraut machen.

  1. Melden Sie sich bei Ihrer Virtuozzo-Anwendungsverwaltungsdashboard an und erstellen Sie eine neue WordPress-Umgebung (Cluster oder Einzelanwendung) aus dem Marktplatz.
  1. Sobald die Umgebung erstellt wurde, navigieren Sie zur WordPress-Admin-Panel und installieren Sie das Migrate Guru-Plugin.
  1. Aktivieren Sie es und navigieren Sie zum Plugin-Tab. Hier können Sie den Migration Key finden, der für den Migrationsprozess verwendet wird.
  1. Jetzt wechseln Sie zur Quell-WordPress-Webseite, die Sie migrieren möchten. Installieren Sie dort das gleiche Migrate Guru-Plugin und aktivieren Sie es. Navigieren Sie zum Plugin-Tab, geben Sie Ihre E-Mail-Adresse ein und akzeptieren Sie die Nutzungsbedingungen. Klicken Sie auf den Migrate-Button, um fortzufahren. Tip: Wir empfehlen, eine vollständige Backup-Kopie Ihrer Quell-WordPress-Webseite vor dem Starten des Migrationsprozesses zu erstellen, falls etwas schief geht.

Öffnen Sie die angezeigte Seite und wählen Sie die Option Other Hosts aus und geben Sie den Migrationsschlüssel ein, den Sie aus der Zielumgebung kopiert haben. Konfigurieren Sie, falls nötig, weitere Einstellungen. Hinweis: Alternativ können Sie sich auf die Option Manually Input Host Details umstellen und die erforderlichen Felder ausfüllen (erfordert eine öffentliche SSH-Schlüssel hinzufügen zur Plattform): Destination Site URL ist ein Link zu einer neuen WordPress-Website (eigener Domain oder Standard-Domäne, die von der Plattform nach Umgebungskreation bereitgestellt wird). SFTP-Protokoll, um sichere Migration zu gewährleisten. Destination Server IP/FTP Address und Port können aus den Feldern Host und Port der Virtuozzo Application Management dashboard kopiert werden. Gehen Sie zu den Einstellungen des Kontos oder der Umgebung, öffnen Sie die SSH-Sektion und wechseln Sie zu der Tabseite SFTP / Direct SSH Access (wählen Sie den WordPress-Anwendungsspeicherknoten aus). FTP-Benutzername sollte aus demselben Abschnitt kopiert werden, wie im obigen Bild gezeigt. SSH Key ist eine private Schlüssel, die mit der hinzugefügten öffentlichen Schlüssel der Plattform verbunden ist. Directory Path ist der Pfad, an dem die WordPress-Anwendung installiert ist. In unserem Fall ist es der /var/www/webroot/ROOT/ Pfad. Klicken Sie auf den Migrate-Button, um den Prozess zu starten. 6. Der Plugin wird alles für Sie automatisch bearbeiten, einschließlich der Dateikopie und der Datenbankkopie. Sie können den Migrationsfortschritt auf derselben Seite verfolgen.

Jetzt können Sie Ihre neu migrierte WordPress-Seite im Virtuozzo Application Management besuchen und überprüfen, ob alles wie erwartet funktioniert. Das ist alles! Genießen Sie die Leistung und Verfügbarkeit Ihrer WordPress-Seite, die durch das Virtuozzo Application Management an einem breiten Netzwerk von Dienstleistern weltweit unterstützt wird.
