WordPress-Backup-Anleitung
Es ist wichtig sicherzustellen, dass Ihre WordPress-Daten gesichert und im Falle von Problemen wiederhergestellt werden können. Wenn Sie WordPress auf der Virtuozzo Anwendungsverwaltung hosten, können Sie leicht Backups der WordPress-Umgebung erstellen und wiederherstellen, indem Sie den dedizierten WordPress Backup/Restore-Add-on verwenden. Er ist mit allen vorab installierten WordPress-Installationen auf der Virtuozzo Anwendungsverwaltung kompatibel und bietet die folgenden Vorteile:
Standalone und Cluster-Kompatibilität: Der Add-on funktioniert sowohl mit Standalone- als auch Cluster-WordPress-Umgebungen, sodass Sie Ihre Anwendung unabhängig von der Bereitstellungstypus sichern können.
Automatisierte Backups: Der Add-on erlaubt es, automatische Backups der WordPress-Umgebung zu erstellen, sodass Ihre Daten regelmäßig gespeichert werden ohne manuelle Eingriffe.
Flexible Zeitplanung: Sie können sich von vorgegebenen Backup-Intervallen (stündlich, täglich, wöchentlich, monatlich) oder einem individuellen Zeitplan basierend auf Ihren Anforderungen bedienen, einschließlich spezifischer Zeitzonen.
Manuelle Backups: Zusätzlich zu den geplanten Backups können Sie auch manuelle Backups jederzeit erstellen, was Flexibilität für dringende Daten-Schutz-Bedürfnisse bietet.
Einfache Wiederherstellung: Im Falle von Datenverlust oder Korruption können Sie Ihre WordPress-Umgebung schnell aus einer Backup-Kopie wiederherstellen, was die Ausfallzeit minimiert und den Betrieb fortsetzt.
Datenbank und Datei-Backup: Der Add-on backt die WordPress-Datenbank und Dateien auf, sodass alle Ihre Inhalte, Themen, Plugins und Einstellungen erhalten bleiben.

Ergänzung stellt eine Backup-Funktion für die WordPress-Datenbank und Dateien bereit, um sicherzustellen, dass alle Ihre Inhalte, Themen, Plugins und Einstellungen erhalten bleiben. Integration mit Backup-Speicher: Der Ergänzung funktioniert schlüssig mit dem Backup-Speicher, um automatisch Backups auf einem externen Speicher zu erstellen und zu speichern, was zusätzliche Sicherheit und Zuverlässigkeit bietet. Hinweis: Bei der Arbeit mit dem MariaDB Galera Cluster beachten Sie die bekannten Einschränkungen. Die erforderlichen zusätzlichen Schritte sind bereits bei der Verwendung des Backup/Wiederherstellungs-Ergänzungssets berücksichtigt. Es wird jedoch empfohlen, sich bei der manuellen Wiederherstellung des Datenbank-Dumps mit dem verlinkten Leitfaden zu befassen. Wenn Sie manuell ein Backup erstellen möchten oder Änderungen an den Erweiterungseinstellungen vornehmen wollen, können Sie dies über die Benutzeroberfläche der Erweiterung tun. Verwalte Erweiterung Nach der Installation wird die Erweiterung im Abschnitt Erweiterungen der Anwendungsserver-Anwendung verfügbar sein. Sie bietet die folgenden Aktionen:

  • Backup jetzt – erstellt ein sofortiges Backup
  • Konfigurieren – stellt Parameter ein, die während der Erstellung festgelegt wurden (Aufgabenschema, Speicherknoten, Anzahl der Backups)
  • Wiederherstellen – wird aus dem Backup wiederhergestellt
  • Entfernen – entfernt die Backup-Erweiterung

Backup WordPress
Die Backup-Aktion für WordPress kann automatisch nach der vorgegebenen Zeitskala gestartet oder manuell über die Benutzeroberfläche der Erweiterung gestartet werden. Sobald die Backup-Aktion gestartet wurde, werden die folgenden Schritte durchgeführt:

  • Die Backup-Speicherung wird über NFS4 auf den Anwendungsserver-Knoten montiert.
  • Ein Dump der Datenbank wird in eine flache Datei erstellt.
  • Der Backup-Snapshot wird erstellt. Der Backup-Snapshot besteht aus dem Dump-Dateiblatt und dem Web-Anwendungsverzeichnis (/var/www/webroot/ROOT/).

Wiederherstellen WordPress aus Backup
Die Wiederherstellung von WordPress aus dem Backup überschreibt alle vorhandenen Daten. Jegliche neueren Änderungen, die seit der Backup-Erstellung vorgenommen wurden, werden dauerhaft verloren gehen. Um Ihre WordPress-Anwendung aus einem Backup wiederherzustellen, müssen Sie die Option Wiederherstellen für die Erweiterung auswählen.

Um Ihre WordPress-Anwendung aus einer Backup-Kopie wiederherzustellen, müssen Sie die Option "Wiederherstellen" für den Add-on auswählen. Dann wird ein Dialogfenster mit den folgenden Optionen geöffnet:

  • Wiederherstellen von – wählen Sie das Zielumgebung (mehrere Optionen können verfügbar sein, wenn der Backup-Add-on auf mehreren Umgebungen verwendet wird)
  • Backup – wählen Sie aus einer Liste der Backups für das ausgewählte Umgebung (Name enthalten Timestamps für schnelle Identifizierung)
  • Klicken Sie auf "Wiederherstellen" und bestätigen Sie dies via Pop-up. Sobald die Aktion gestartet ist, kann sie nicht abgebrochen oder rückgängig gemacht werden. Sie sehen die Erfolgsbenachrichtigung im Dashboard nach Abschluss des Prozesses.
