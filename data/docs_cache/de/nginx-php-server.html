NGINX PHP-Server
Dieser Abschnitt erklärt, wie man NGINX PHP-Server in Virtuozzo Application Management bereitstellt und verwaltet. Er behandelt die Grundlagen des NGINX PHP-Servers, die Konfiguration von Speicherungskacheln, die Sicherheitsverhärtung, die Verwendung des WebDAV-Moduls und die Unterstützung von Apache und NGINX-Modulen zur Erweiterung der Serverfunktionen. In diesem Abschnitt:

  • NGINX PHP
  • NGINX-Sicherheitskonfigurationen
  • NGINX-Module
  • NGINX WebDAV-Modul
  • Caching in NGINX App Server

Speichern Sie die folgenden Schritte aus, um einen NGINX PHP-Server in Virtuozzo Application Management bereitzustellen:

  1. Erstellen Sie ein neues Virtuozzo-Kontrollpanel-Konto.
  1. Erstellen Sie ein neues Virtuozzo-Web-Konto.
  1. Erstellen Sie ein neues Virtuozzo-Datenbankkonto.
  1. Erstellen Sie ein neues Virtuozzo-PHP-Konto.
  1. Erstellen Sie ein neues Virtuozzo-PHP-Skript.
  1. Konfigurieren Sie die NGINX-Webserverkonfiguration.
  1. Konfigurieren Sie die PHP-Webserverkonfiguration.
  1. Konfigurieren Sie die Speicherungskacheln.
  1. Konfigurieren Sie die Sicherheitsverhärtung.
  1. Konfigurieren Sie den WebDAV-Modul.
  1. Testen Sie den NGINX PHP-Server.
