PHP-Composer für intelligentes Abhängigkeitsmanagement Ihrer Cloud-Anwendungen

Composer ist eines der beliebtesten Abhängigkeitsmanagement-Tools für PHP, das sich an den Tools node's npm und ruby's bundler anlehnt. Es wird intelligent alle erforderlichen Bibliotheken und Pakete für Ihre Anwendung verwalten. Es wird auf Projektbasis ausgeführt und bestimmt, welche Versionen von welchen Paketen Ihre Anwendung abhängt und installiert sie in einem Arbeitsverzeichnis. Darüber hinaus bietet dieses Tool die Autoload-Funktion, um Ihre Pakete auf dem neuesten Stand zu halten. Composer ist standardmäßig in allen PHP-Anwendungsservern (Apache, NGINX, LiteSpeed, LEMP und LSSMP) integriert. Es wird in das Verzeichnis /usr/local/bin installiert, das an die PATH-Variable angehängt wird, sodass Composer von jeder Stelle auf dem Knoten über den Komposershortcut (z.B. composer about) ausführbar ist. Zusätzlich kann Composer die Abhängigkeiten direkt während der Installation verwalten, wenn das Projekt einen composer.json-Datei hat, indem es den Post-Deploy hook script verwendet. Alles, was Sie tun müssen, ist, in Ihr Projektverzeichnis zu wechseln und den Befehl composer install auszuführen:

1 2
cd $WEBROOT/{project_name}
composer install

Composer Update

Sie erhalten automatisch die neueste Version von Composer während der Knoten-Erstellung. Wenn jedoch eine neue Version von Composer veröffentlicht wird, können Sie sie leicht bekommen, ohne das Notwendigkeit eines Wiederaufbaus eines ganzen Containers zu haben. Hier sind die nächsten Schritte, um die neueste composer-Version in Ihren PHP-Container zu installieren:

  1. Verbinden Sie sich über SSH mit dem passenden Knoten.

Um die neueste Version von Composer in Ihrem PHP-Container zu installieren, folgen Sie den folgenden Schritten:

  1. Verbinden Sie sich mit dem passenden Knoten über SSH. Beispielhaft mit der eingebauten Web-SSH.
  1. Laden Sie den Composer-Installer mit dem folgenden Befehl herunter:

   php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
  1. Installieren Sie Composer in den aktuellen Verzeichnis.

   php composer-setup.php --install-dir=./ --filename=composer

Tip: Wenn Sie das erforderliche Verzeichnis erreichen müssen, bevor die Operation ausgeführt wird, können Sie dieses Verzeichnis vor der Operation ändern oder den Pfad über den install-dir-Parameter anpassen. Allerdings können Sie das /usr/local/bin/ Verzeichnis nicht mit der initialen Composer-Instanz installieren.
  1. Lassen Sie uns diesen lokalen Composer-Version (z.B. mit relativer oder absolutem Pfad) ausführen, um sicherzustellen, dass alles wie erwartet funktioniert. Beispiel:

   ./composer about

Tip: Wenn der Abhängigkeits-Manager funktioniert, empfehlen wir das Entfernen des Installers (da er nicht mehr benötigt wird).
   php -r "unlink('composer-setup.php');"
