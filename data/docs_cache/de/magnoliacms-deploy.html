Wie eine Magnolia CMS-Installation durchzuführen

Magnolia ist eine open-source Java-basierte Content Management System (CMS), die über JCR (Content Repository API for Java) die Daten speichert, verarbeitet und abruft. Ihr Block-Struktur ermöglicht es, das System-Kern und alle damit verbundenen Komponenten (z.B. Seiten-Editor, Cache, Repository usw.) in separate Modulen zu verpacken, was zu einer hohen Flexibilität führt. Zusätzlich ist diese CMS einfach genug, um auch unbekannte Benutzer eine einfache Inhaltsverwaltung zu ermöglichen, während erfahrene Entwickler durch die flüssige Integration zusätzlicher Werkzeuge für fortgeschrittenen Entwicklungsbedarf sorgen. Dadurch bietet die Magnolia CMS mehrere Wege der Interaktion für verschiedene Benutzertypen an und kann somit jede Management-, Geschäfts- und Marketinganforderung erfüllen. Um sofort eine vorkonfigurierte und lauffähige Magnolia CMS-Instanz unter der Community Edition Lizenz zu erhalten, verwenden Sie den folgenden dedizierten Ein-Klick-Installations-Widget: Klicken Sie bitte auf "Jetzt hosten" und geben Sie Ihre E-Mail-Adresse ein, um Magnolia zu starten, um die Schritte der manuellen Installation zu überspringen (die Vollständige Liste ähnlicher vorbereiteter Lösungen für schnelle Bereitstellung finden Sie im Marketplace der Plattform). Wenn Sie jedoch bevorzugen, sich über die Ausführung der Installation zu informieren oder eine andere Version dieser CMS benötigen, finden Sie im folgenden kurzen Video-Tutorial Einblicke in die Bereitstellung der Magnolia CMS auf der Plattform.

  1. Neues Umgebung erstellen

Melden Sie sich bitte bei der Plattform-Dashboard-Anmeldung mit Ihren Anmeldeinformationen (oder, wenn Sie noch kein Erfahrungswert mit unserer Plattform haben, wählen Sie einen geeigneten Hosting-Anbieter aus unseren Partnern und erstellen Sie ein Konto zuerst) und gehen wir weiter.

  1. Klicken Sie im oberen linken Eck des Dashboards auf „Neues Umgebung“, wechseln Sie zum Java-Tab und wählen Sie Tomcat 7 oder 8 als Ihre Anwendungsserver-Plattform aus. Anschließend legen Sie die gewünschte Ressourcenmenge für dieses Knoten mit Skalierungsgrenzschiebern fest, spezifizieren Sie eine Region und einen Namen für Ihre neue Umgebung und klicken Sie auf „Erstellen“. In wenigen Minuten sollte es im Dashboard erscheinen; währenddessen gehen wir weiter, um Zeit zu sparen.

Magnolia CMS-Paket-Bereitstellung

Während die Umgebung erstellt wird, können Sie das Magnolia CMS-Paket herunterladen.

  1. Navigieren Sie zur Magnolia Download-Seite und klicken Sie auf die bevorzugte Edition-Version, um Sie auf die entsprechenden Quelldateien zu leiten.
  1. In der geöffneten Seite finden Sie den Abschnitt „War-Dateien“ und kopieren Sie die Linkadresse für das Paket „magnolia-enterprise-standard-webapp“.

Speichern Sie die Dateien. 2. Öffnen Sie die Seite und suchen Sie in der Abschnitt War files nach dem Link zum Paket magnolia-enterprise-standard-webapp kopieren. Hinweis: Magnolia CMS ist proprietäre Software, die für ihre Nutzung eine Lizenzkauf erforderlich ist. Sie können jedoch nach einer einfachen Registrierung eine 30-Tage-Lizenz der Enterprise Edition erhalten oder die kostenlose Community Edition nutzen. 3. Kehren Sie zur Plattform-Dashboard zurück (wir nehmen an, dass die Umgebungsbereitstellung bis zu diesem Zeitpunkt abgeschlossen ist) und klicken Sie auf "Hochladen" unter Deployment manager. In dem aufgerufenen Dialogfeld wechseln Sie zum Tab URL, fügen Sie den kopierten Link ein und Hochladen Sie das Paket. Innerhalb von einer Minute wird Ihr WAR-Paket in der Liste der verfügbaren Pakete aufgelistet. 4. Nun bewegen Sie den Mauszeiger über das gerade hochgeladene Projekt, klicken Sie auf den Button "Deploy zu..." neben ihm und wählen Sie die Umgebung, auf die Ihre Anwendung deployen soll (magnolia in unserem Fall). Sie können zusätzlich im offenen Bestätigungsfenster das gewünschte Kontextnamen angeben (oder lassen Sie das entsprechende Feld leer, um die Standard-LOCATION ROOT zu verwenden). Warten Sie, bis die Bereitstellung erfolgreich abgeschlossen ist und wechseln Sie zur nächsten Sektion.

Installation von Magnolia CMS

  1. Klicken Sie auf den Button "Im Browser öffnen", um Ihre Magnolia CMS-Instanz zu starten.
  1. Sie benötigen eine Menge erforderlicher Module, die während dem folgenden Installationsprozess automatisch integriert werden.
  1. Klicken Sie auf den Button Open in browser, um Ihre Magnolia CMS-Instanz zu starten.
  1. In der geöffneten Magnolia-Installationsseite können Sie die Liste der zu installierenden Module überprüfen. Wenn Sie bereit sind, klicken Sie auf Start Installation und warten Sie ein paar Minuten, bis dieses Vorgang abgeschlossen ist.
  1. Sobald alle notwendigen Operationen abgeschlossen sind, sehen Sie die entsprechende Benachrichtigung. Jetzt klicken Sie auf den Button Start Up Magnolia, um auf die Magnolia-Lizenzseite weitergeleitet zu werden, wo Sie Ihre Magnolia CMS-Kopie registrieren können.
  1. In der geöffneten Seite beachten Sie den Link im ersten Schritt, um eine 30-Tage-Testlizenz zu erhalten und sie in der zweiten Abschnitt (oder füllen Sie die entsprechenden Felder ein, wenn Sie sie vorher erhalten haben) mit Ihrer E-Mail-Adresse anzugeben. Wenn Sie fertig sind, wählen Sie Use License.
  1. Cool, alles ist bereit - jetzt können Sie sich mit den Standardanmeldeinformationen des superusers (die als Ihr Benutzername und Passwort angegeben sind) in die eigene Magnolia CMS-Admin-Seite einloggen. Klicken Sie auf Login, um die Authentifizierung durchzuführen und die Magnolia CMS-Shell anzusehen. Das ist es! Ihre Magnolia-Inhaltsverwaltungssystem ist nun innerhalb der Plattform eingerichtet!
