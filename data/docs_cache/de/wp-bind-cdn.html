WordPress CDN Bindung
Eine Content Delivery Network (CDN) ist ein System von verteilten Servern, die Webinhalte an Nutzer nach ihrer geografischen Lage liefern. Durch die Nutzung einer CDN können Sie die Leistung und Zuverlässigkeit Ihrer WordPress-Website verbessern. Wenn Sie eine CDN-Lösung verwenden, können Sie diese Ihrer WordPress-Installation in der Virtuozzo Anwendungsverwaltung binden. Je nach verwendeter Anwendungsserver kann sich der CDN-Bindungsprozess unterscheiden. Hier finden Sie zwei Anweisungen (basierend auf dem Anwendungsserver) zur Bindung einer CDN an Ihre WordPress-Installation:

LiteSpeed-basierter WordPress-Installation
NGINX-basierter WordPress-Installation

LiteSpeed-basierter WordPress-Installation

  1. Zunächst stellen Sie sicher, dass der LiteSpeed Cache Plugin aktiviert ist.
  1. Gehen Sie zu dem Menüpunkt LiteSpeed Cache > CDN und wählen Sie den Tab Other Static CDN aus. Tip: Wenn Sie den QUIC.cloud- oder Cloudflare CDN verwenden, können Sie die speziellen Registerkarten für diese CDNs anstelle des Other Static CDN Tabs verwenden.
  1. Aktivieren Sie die Option Use CDN Mapping und geben Sie Ihre CDN-URL in das entsprechende Feld ein. Dies ist die Basis-URL für Inhalte, die von der CDN bereitgestellt werden. Wenn nötig, können Sie die folgenden Optionen anpassen:

- Include Images - aktivieren Sie diese Option, um Bilder von der CDN zu servieren.
- Include CSS - aktivieren Sie diese Option, um CSS-Dateien von der CDN zu servieren.
- Include JS - aktivieren Sie diese Option, um JavaScript-Dateien von der CDN zu servieren.
- Include File Types - spezifizieren Sie zusätzliche Dateitypen, die von der CDN bereitgestellt werden sollen.
Klicken Sie auf Save Changes.
