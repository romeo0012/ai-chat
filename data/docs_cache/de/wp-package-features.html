WordPress-Installations-Kit-Funktionen
Beim Installieren der Virtuozzo Application Management WordPress-Pakete können Sie Ihre WordPress-Umgebung individualisieren, indem Sie die erforderlichen Optionen in der Installationsfenster auswählen. Folgende Funktionen stehen für die Konfiguration zur Verfügung:

LiteSpeed Hochleistungs-Webserver - installiert eine WordPress-Lösung basierend auf dem LiteSpeed Web Server. Diese Option bietet die höchste mögliche Geschwindigkeit der Inhalterlieferung an Kunden über das moderne HTTP/3-Protokoll. Wenn Sie diese Option unticken, wird die NGINX-basierte Lösung installiert. Die folgenden zwei zusätzlichen Funktionen stehen nur für LiteSpeed-basierte Installationen zur Verfügung:

Brute Force Attack Protection sichert die WordPress-Admin-Panel durch Begrenzung der fehlgeschlagenen Anmeldeversuche. Die Standardaktion ist Throttle, und die Anzahl erlaubter Versuche beträgt 100. Web Application Firewall (WAF) aktiviert/deaktiviert die Funktion, die Ihre WordPress-Website durch Anwendung von Regeln für die Filterung von angreifenden Anfragen schützt, indem sie nach bekannten Angriffssignaturen sucht.

Hinweis: Weitere Informationen zu diesen Funktionen und ihrer Konfiguration finden Sie in der LiteSpeed Web Server-Dokumentation.

Let’s Encrypt SSL mit Auto-Renewal-Add-on erstellt einen vertrauenswürdigen, kostenlosen Zertifikat für eine benutzerdefinierte Domäne. Die integrierte Funktionalität verwendet periodische Renovierung, um die Zertifikatsablauf zu verhindern. Die entsprechenden Benachrichtigungen werden per E-Mail gesendet.
