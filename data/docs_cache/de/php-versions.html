PHP-Version innerhalb der PHP-Hosting-Umgebung der Plattform werden folgende PHP-Engine-Versionen unterstützt:

  • PHP 8.1.33
  • PHP 8.2.31
  • PHP 8.3.31
  • PHP 8.4.22
  • PHP 8.5.7

Die aktuelle Liste der Verfügbarkeitslisten der Plattform wird über das dedizierte, wöchentlich aktualisierte Software Stack Versions Dokument bereitgestellt. Wählen Sie die Version, die Sie benötigen, während der Umgebungskonfiguration und wechseln Sie später leicht zwischen ihnen mithilfe des Topologie-Assistenten. Der Ablauf ist der folgende:

  1. Klicken Sie auf den Schaltflächen "Neue Umgebung" oben in der Startseite, um das Umgebung-Assistenten-Fenster zu öffnen.
  1. Navigieren Sie zum PHP-Sprach-Tab und wählen Sie den bevorzugten Anwendungsspeicher aus. Wählen Sie die gewünschte Engine-Version über das zweite Dropdown-Feld im zentralen Bereich aus. Geben Sie die Ressourcenbegrenzungen an, wählen Sie den bevorzugten Region aus, geben Sie Ihren Umgebungsnamen (oder lassen Sie den Standardnamen) und klicken Sie auf den Schaltflächen "Erstellen". Tip: Für mehr Informationen zu PHP-Hosting-Spezialitäten an der Plattform und die Möglichkeiten, die sie bietet, beziehen Sie sich auf das PHP-Entwickler-Center Dokument.
  1. Um die Version von PHP für eine bereits vorhandene Umgebung zu ändern, klicken Sie auf das Schaltflächen "Redeploy Containers" neben der passenden Schicht.
  1. Wählen Sie die erforderliche Engine-Version aus der Liste der geöffneten Fenster. Klicken Sie auf "Redeploy" um die Änderungen zu bestätigen. Hinweis: Wenn Sie auf PHP 7 umsteigen, müssen Sie möglicherweise manuell bestimmte PHP-Module aktivieren, da einige von ihnen in dynamische Module (d.h., nur bei Bedarf aktivieren) umgewandelt wurden.
