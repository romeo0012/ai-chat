Java-Basis-Server (Java Engine)
Das Java Engine Server ist eine Abbildung einer Grundlage-Vorlage von CentOS/AlmaLinux mit vorinstalliertem JDK. Es bietet ein minimal notwendiges für die Wartung von Java-Anwendungen, während es die Kompatibilität mit allen Plattform-Funktionen sichert (automatisierte vertikale und horizontale Skalierung, öffentliche IP, Isolierungsgruppen, Firewall-Regeln, API- und SSH-Zugriff usw.). Das Java Engine Server ist für die Bereitstellung und Wartung von Java-Anwendungen auf Basis des fat JAR / uber JAR (d.h., ausführbaren JAR mit allen Klassen, Ressourcen und Abhängigkeiten) konzipiert. Es nutzt den Java Memory Agent, um Ihre Anwendung automatisch zu optimieren, indem es Konfigurationen anpasst, je nach Last und verfügbaren Ressourcen. Hinweis: Diese Vorlage nutzt ein modernes systemd-Initialisierungs-Daemon.

Java Engine erstellen
Folgen Sie den nachfolgenden einfachen Schritten, um eine neue Umgebung mit dem Java Engine Server zu erstellen.

  1. Melden Sie sich bei der Plattform-Benutzeroberfläche an und klicken Sie auf den Knopf New Environment in der oberen linken Ecke.
  1. Im geöffneten Topologie-Assistenten wechseln Sie zum Java-Tab, wählen Sie den Java Engine Server und die erforderliche JDK-Version (markiert im Bild unten). Personalisieren Sie weitere Parameter nach Ihren Bedürfnissen, z.B., Ressourcenbegrenzungen, Speicherplatz, externe IPs, Region (falls verfügbar), usw. Klicken Sie auf Create, um fortzufahren.
  1. Ihre Umgebung sollte innerhalb von einer Minute bereitstehen.

Jetzt können Sie Ihre Umgebung verwalten:
Bereitstellen Sie eine Anwendung
Binden Sie eine benutzerdefinierte Domäne
Monitoren Sie die Statistiken & Anzeigen Sie die Log-Dateien
Tun Sie die Server-Konfigurationen an
Zugriff auf die Umgebung über SSH
Referenzieren Sie den Java Developer Center für eine vollständige Übersicht über die Java-Hosting innerhalb der Plattform.
