Kubernetes-Cluster: YAML-Deployments

Kubernetes unterstützt Deployments nativ sowohl aus JSON als auch YAML-Dateien. Allerdings ist innerhalb der Community YAML häufiger und kann als Standard betrachtet werden. Die Deployment aus YAMLs ist in etwa vergleichbar mit den Helm-Charts - das .yaml oder .yml-Dateiformat liefert die Objektdefinition oder eine Liste von Objekten. Dadurch kann es direkt in den Kubernetes-Dashboard oder mit dem kubectl-Befehlszeilentool ohne weitere Softwareinstallation verwendet werden. Wenn Sie über kubectl arbeiten, verwenden Sie den apply-Befehl mit dem richtigen Pfad zu Ihrer Deployment-YAML-Datei:

  1. kubectl apply -f /pfad/zu/deployment.yaml

Andererseits bietet die Vorteile der Helm-Charts eine erweiterte Flexibilität (Unterstützung von Bedingungen, Ersetzungen, Parametern usw.). Was kommt nach? K8s-Helm-Integration K8s-Internes Netzwerk K8s-Exponierende Dienste K8s-Erstellung von Ingresses
