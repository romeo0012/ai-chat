PHP-Anwendungserver
Dieser Abschnitt bietet eine Übersicht über die Optionen von PHP-Anwendungservern, die in der Virtuozzo Anwendungsverwaltung verfügbar sind. Er behandelt Serverstacks für Apache PHP und NGINX PHP, sowie LiteSpeed und LEMP/LLSMP-Umgebungen. Der Abschnitt weist zudem auf server-spezifische Richtlinien für Konfiguration, Sicherheit, Module und Bereitstellungsworkflows hin. In diesem Abschnitt:

  • Apache PHP
  • NGINX PHP
  • LiteSpeed Web Server
  • LEMP & LLSMP
