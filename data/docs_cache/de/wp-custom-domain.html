WordPress Custom Domain Binding

← Chat

Um Ihre WordPress-Webseite für die Produktion bereitzustellen, sollte ein benutzerdefinierter Domainname hinzugefügt und gebunden werden. Dadurch können Sie Ihre Website über einen Domainnamen Ihrer Wahl zugreifen, anstatt dem Standard-Domainnamen des Plattformen-Anbieters. Betrachten wir, dass Sie eine WordPress-Anwendung mit der Verknüpfung aller Stack-Schichten haben. Das bedeutet, dass der Cluster zwei LiteSpeed Web ADC (Load Balancer) hat, die als Eingangspunkte (Origins oder Endpoints) dienen.

  1. Bevor Sie einen benutzerdefinierten Domainnamen für Ihre WordPress-Anwendung verwenden können, müssen Sie ihn bei einem beliebigen Domain-Registrar erwerben. Siehe die Abschnitt "Wählen Sie einen Domainnamen" im All-in-One Guide für einige Tipps zum Auswählen eines Domainnamens.
  1. Danach können Sie ihn Ihrer WordPress-Anwendung binden, indem Sie DNS-Einträge erstellen. Bei dem Domain-Registrar erstellen Sie für jeden Endpunkt einen A-Eintrag, der auf einen benutzerdefinierten Domainnamen zeigt, z.B. wordpress-enterprise.jele.website. Hinweise: Wenn Sie eine einzelne WordPress-Paketversion verwenden, benötigen Sie nur einen A-Eintrag, der auf die öffentliche IP-Adresse des LLSMP/LEMP-Container mit Ihrer WordPress-Anwendung zeigt. Wenn Sie die Load Balancer horizontal skalieren wollen, registrieren Sie jede neu bereitgestellte öffentliche IP-Adresse unter demselben benutzerdefinierten Domainnamen als zusätzlicher A-Eintrag. Wenn Sie eine mehrregionale WordPress-Installation verwenden, müssen Sie A-Einträge für jeden Eingangspunkt in jedem Region bereitstellen.
  1. Ausstellen Sie ein SSL-Zertifikat für den benutzerdefinierten Domainnamen.

record. Wenn Sie eine mehrregionale WordPress-Installation verwenden, müssen Sie A-Einträge für jeden Eintrittspunkt in jeder Region hinzufügen. 3. Lassen Sie sich eine SSL-Zertifikat für den benutzerdefinierten Domänennamen ausstellen. Gehen Sie zum Registerkartenabschnitt für die Schicht des Load Balancers Ihrer WordPress-Cluster und finden Sie den Let’s Encrypt Free SSL-Add-on. 4. Klicken Sie auf den Konfigurieren-Button, um das Konfigurationsfenster zu öffnen, und ersetzen Sie den von der Plattform generierten Domänennamen durch Ihren benutzerdefinierten. Drücken Sie auf Anwenden, um ein gültiges SSL-Zertifikat auszustellen. 5. Nun müssen Sie die URL für Ihre WordPress-Website aktualisieren, was mit dem dedizierten WordPress-Website-Adresse (URL)-Add-on an der Anwendungsschicht Ihrer WordPress-Cluster durchgeführt werden kann. 6. Klicken Sie auf den Site-URL-Button und geben Sie den neuen Domänennamen ein. Das Add-on wird automatisch die WordPress-Konfigurationsdatei und die Datenbank mit dem neuen URL aktualisieren. 7. In diesem Punkt wird Ihre Website über den DNS-Round-Robin-Algorithmus bereitgestellt. Wenn Sie den Domänennamen auflösen, erhalten Sie jedes Mal alle Adressen, die Sie für ihn registriert haben (auch die unerreichbaren). Ab jetzt sollten Sie den benutzerdefinierten Domänennamen zur Zugriffsmöglichkeit auf die WordPress-Website und Admin-Panel verwenden. Wenn Sie mehrere Eintrittspunkte zu Ihrer WordPress-Anwendung haben, sollten Sie eine DNS-Lastenausgleichung einrichten, um sicherzustellen, dass der Verkehr nur an die gesunden Endpunkte geleitet wird.
