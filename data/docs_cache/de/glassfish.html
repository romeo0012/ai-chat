GlassFish Anwendungsserver

GlassFish ist ein offener Quelltext-Anwendungsserver-Projekt, das von Sun Microsystems für die Java EE-Plattform gestartet wurde und jetzt von Oracle Corporation gesponsert wird. Die unterstützte Version heißt Oracle GlassFish Server. GlassFish ist freie Software und wird unter zwei freien Softwarelizenzen bereitgestellt: der Common Development and Distribution License (CDDL) und der GNU General Public License (GPL) mit der classpath-Ausnahme. GlassFish bietet auf Unternehmensniveau Zuverlässigkeit und Leistung mit voller Klustering und hat eine breite Funktionalitätsspektrum. Es ist ziemlich cool, dass es Ihnen erlaubt, die zentrale Repository-Verwaltung über die Admin-Oberfläche zu verwalten, die alle in GlassFish verfügbaren Funktionen unterstützt. Allerdings ist bekannt, dass mehr Funktionen = mehr Ressourcen bedeuten.

GlassFish-Installation

Um Ihr GlassFish-Server-System in der Plattform zu erhalten, führen Sie einfach folgende Schritte aus:

  1. Melden Sie sich bei Ihrer PaaS-Benutzeroberfläche an und klicken Sie auf New Environment.
  1. Wechseln Sie zum Java-Tab und wählen Sie GlassFish innerhalb der Anwendungsserver-Abschnitt aus, wie auf dem Bild unten dargestellt:

![GlassFish-Auswahl](URL-zu-Bild)

  1. Jetzt können Sie das Java-Anwendungspaket WAR hochladen und es in die Umgebung bereitstellen.
  1. Die Glassfish-Verwaltungsseite kann direkt von der Plattform-Benutzeroberfläche erreicht werden: Die Admin-Seite wird in einem neuen Tab verfügbar sein.

Hinweis: Die Plattform verwendet gfcluster als Cluster, also bitte Änderungen anwenden, wenn Sie etwas ändern möchten, auf gfcluster. Wenn Sie eine öffentliche IP an den Anwendungsserverknoten angehängt haben, kann die Standard-GlassFish-Verwaltungspanel-Port (4848) in der Konfigurationsdatei /opt/glassfish3/glassfish/domains/domain1/config/domain.xml geändert werden (ein Serverkürzel in Favoriten) indem Sie folgenden String hinzufügen:

1 2 <http-listener id="admin-listener" port="4848" address="0.0.0.0" default-virtual-server="__asadmin" server-name="" />
