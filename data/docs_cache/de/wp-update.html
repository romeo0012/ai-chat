WordPress-Aktualisierungs-Leitfaden

Aktualisieren von WordPress ist ein wichtiger Bestandteil des Sicherheits- und Leistungsmanagements Ihrer Website. Regelmäßige Aktualisierungen sichern Sie, dass Sie die neuesten Funktionen, Fehlerbehebungen und Sicherheitsupdates haben. Dieser Leitfaden führt Sie durch den Aktualisierungsprozess Ihrer WordPress-Installation: Hinweis: Es ist eine gute Praxis, Ihre WordPress-Website vor der Durchführung von Änderungen, einschließlich der Aktualisierungen, zu sichern. Dadurch können Sie Ihre Website auf einen vorherigen Zustand zurücksetzen, falls etwas schief geht während des Aktualisierungsprozesses.

  1. WordPress-Softwareaktualisierungen (Kern, Themen und Plugins) können über die WordPress-Admin-Oberfläche durchgeführt werden. Falls es Aktualisierungen gibt, sieht Sie eine Benachrichtigung in Ihrer WordPress-Admin-Oberfläche. Sie können WordPress-Kern durch gehen von Dashboard > Updates und klicken auf den Button Update to version X.X.X.
  1. Plugins und Themen können über dieselbe Seite aktualisiert werden. Einfach die gewünschten Elemente auswählen und klicken Sie auf den Button Update Plugins oder Update Themes.
  1. Um die Serverkomponenten zu aktualisieren, auf denen Ihr WordPress läuft (Anwendungsserver, Datenbank usw.), finden Sie die erforderliche Komponente im Virtuozzo-Anwendungsmanagement-Dashboard und klicken Sie auf den Button Redeploy. Dadurch wird das Redeployment-Fenster geöffnet, in dem Sie die neueste Version der Server auswählen können, einschließlich der PHP-Version für den Anwendungsserver: Tip: Wenn Sie skalierte Komponenten des WordPress-Clusters neu bereitstellen, können Sie die Ausfallzeit vermeiden, indem Sie die sequentielle Bereitstellungswahl auswählen.

Dadurch werden Instanzen einzeln aktualisiert, was sicherstellt, dass Ihre WordPress-Website während des Aktualisierungsprozesses verfügbar bleibt.
