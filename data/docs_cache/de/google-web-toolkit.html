Wie das Deployen von Google Web Toolkit-Anwendungen zu funktionieren

Google Web Toolkit (GWT) ist eine open-source Sammlung von Werkzeugen, die für das Erstellen und Optimieren komplexer Java-Anwendungen verwendet werden. GWT wird von vielen Google-Produkten verwendet. Es ist vollständig kostenlos und wird von Tausenden von Entwicklern weltweit verwendet. Lass uns die GWT-Anwendung auf die Plattform deployen und sieh dir selber, wie einfach es ist. Erstellung einer Umgebung

  1. Melde dich bei der Plattform-Dashboard an.
  1. Klicke auf den Schaltflächen "Umgebung erstellen" an der oberen linken Ecke.
  1. Wähle deinen Anwendungserver (z.B. Tomcat) und gib deinen Umgebungsnamen an, z.B. gwttest. Innerhalb von einer Minute wird deine Umgebung erstellt. Anwendung Deployment
  1. Erstellt deine GWT-Anwendung wie du es gewohnt hast.
  1. Erstellt ein WAR-Datei in der Art, wie du es möchtest. Die Ausgabe des GWT-Compiler ist rein statisches Inhalt. Wir verwenden ein einfaches GWT-Hello-Anwendung als Beispiel. Wenn du diese Anwendung auch deployen möchtest, kannst du das Google Web Toolkit SDK herunterladen, dieses Paket entpacken und ein WAR-Datei aus den Inhalten des WAR-Ordners (z.B. gwt-2.4.0/samples/Hello/war) erstellen.
  1. Lade deine Java-Paketdatei auf den Deployment-Manager hoch.
  1. Sobald das Paket in der Plattform ist, deploye es auf die Umgebung, die du zuvor erstellt hast. Öffne deine Anwendung in einem Webbrowser und genieße! Was kommt nachher? Tutorials nach Kategorie Java Tutorials Umgebung einrichten
