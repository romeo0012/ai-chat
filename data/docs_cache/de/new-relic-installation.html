Neue Relic-Überwachung für Ihre Anwendung innerhalb des PaaS

Neue Relic ist ein Leistungsüberwachungstool für Entwickler und Ops, das sich auf die Bereitstellung tiefgreifender Einsichten in die Leistung und Zuverlässigkeit Ihres Projekts in Echtzeit konzentriert. Entwickelt, um augetretene Probleme zu identifizieren und zu diagnostizieren, kann es die Durchsatzleistung Ihrer Web-Transaktionen verfolgen, Anwendungsausnahmen analysieren, Langsamkeiten in Abfragen oder Web-Anfragen finden und insgesamt eine große Menge an nützlichem Daten für schnelles und angenehmes Problembeheben bereitstellen. Da New Relic eines der häufigsten und beliebtesten Lösungen für die Überwachung von Anwendungsmetriken ist, haben wir ein spezielles Add-on bereitgestellt, um seine Lieferung zu vereinfachen. Basierend auf JPS (Packaging Standard), bietet es die Möglichkeit, dieses Softwarepaket in einem einzigen Mausklick zu installieren und die wichtigsten Informationen zu den Anwendungsservern innerhalb von Minuten zu überwachen. Zusätzlich verfügt es über eine eingebaute Option für automatische Installation von verfügbaren New Relic-Updates. Also, lassen Sie uns erkunden, wie Sie die verborgenen Leistungsfähigkeiten Ihrer Anwendung mit Hilfe von New Relic entdecken können, um fortzufahren mit der Add-on-Installation benötigen Sie:

Anwendung mit Hilfe von New Relic - um den Anhang zu installieren, benötigen Sie folgendes: ein bereits registriertes New Relic-Konto mit Ihrer eindeutigen Benutzer-Identifikator (z.B., Lizenzschlüssel) mindestens ein Umgebung, das auf einer unserer Partner-Plattform erstellt wurde, mit dem bereitgestellten App, die Sie verfolgen möchten. Sobald diese Voraussetzungen erfüllt sind, können Sie leicht den New Relic-Agent in Ihre Cloudumgebung integrieren - folgen Sie bitte den Schritten unten. Hinweis: Die installierte New Relic-Monitoring-Software kann später problemlos auf die neueste Version aktualisiert werden, indem Sie die entsprechende integrierte Add-on-Option verwenden.

New Relic Add-On Installation

Mit der Plattform kann der New Relic Add-on auf dem oberen Java-(als Java-Agent behandelt) oder PHP-basierten Umgebung (als PHP-Erweiterung implementiert) installiert werden. Unabhängig davon bleibt die Installationsfolge ähnlich - also, als Beispiel, verwenden wir eine Java-Umgebung mit Tomcat-Anwendungsspeicher. Hinweis: Die derzeit unterstützten Java-Anwendungsspeicher sind Tomcat, TomEE und Jetty aller Versionen. Die Fähigkeit, New Relic-Monitoring auf andere Server anzuwenden, wird später hinzugefügt.

  1. Zum Beginn klicken Sie auf den Marketplace-Button in der oberen Dashboard-Fensterleiste.
  1. Wechseln Sie in das Add-ons-Abschnitt in der geöffneten Registerkarte, finden Sie das New Relic APM-Lösung innerhalb der aufgelisteten Lösungen (Sie können die Sucheleiste oben verwenden) und klicken Sie darauf für Installieren.

Im Abschnitt für Erweiterungen im geöffneten Tab finden Sie die Lösung New Relic APM innerhalb der aufgelisteten Optionen (Sie können hierfür das oben angezeigte Suchfeld verwenden). Klicken Sie darauf, Installieren zu klicken. Tip: Der New Relic APM-Agent ist auch im JPS-Sammlungsfach verfügbar, zusammen mit einer Vielzahl anderer nützlicher JPS-Lösungen, die die Plattform bereitstellt. Sie können sie importieren und integrieren, indem Sie den Link zum Manifest.jps-Datei innerhalb des entsprechenden Repositorys verwenden.

  1. Sie sehen das Installationsfenster erschienen: Hier sollten die folgenden Daten in den entsprechenden Feldern angegeben werden:

Anwendungsname - Geben Sie hierbei einen Label für diese App ein, der auf Ihrer New Relic-Dashboard angezeigt wird, z.B., my-project (hier wird ein Umgebungsdomäne automatisch eingesetzt, wenn Sie zwischen mehreren verfügbaren Umgebungen wechseln)

Lizenzschlüssel - ein eindeutiger Identifikator, der jedem New Relic-Benutzer zugeordnet ist und in der Abschnitt „Einstellungen“ der Admin-Tabelle angezeigt werden kann (durch Angabe sichern Sie, dass die gesammelten Daten auf Ihrer Kontoseite angezeigt werden)

Hinweis: Das Feld für die Lizenzschlüssel im Erweiterungsinstallationsfenster enthält den Schlüssel automatisch verdeckt. Sie können die Installation ohne Änderung fortsetzen, aber natürlich können Sie die gesammelten Statistiken nicht ansehen (weil der zugeordnete New Relic-Konto fehlt). Sie können jedoch dieses Feld später innerhalb der New Relic-Erweiterungs-Einstellungen über die Plattform-Konfigurationsverwalter festlegen.

Die Pfade für die erforderlichen Dateien sind:
für Java-Anwendungsserver: TomEE, Tomcat - /opt/tomcat/lib/newrelic/newrelic.

Einstellungen über die Plattform Configuration Manager. Die Pfade für die erforderte Datei sind: für Java app servers: TomEE, Tomcat - /opt/tomcat/lib/newrelic/newrelic.yml Jetty - /opt/jetty/lib/newrelic/newrelic.yml für PHP app servers: der entsprechende newrelic.license-Parameter kann in der /etc/php.d/newrelic.ini-Datei gefunden werden. Zusätzlich können die Parameter des Add-ons in diesen Dateien auch modifiziert werden. Umgebung name - wählen Sie den Namen der Umgebung, an die der New Relic Agent installiert werden soll (die passenden Namen sind innerhalb der Drop-down-Liste hervorgehoben) Nodes - wählen Sie das Instanz für das Monitoring aus (derzeit sind nur application servers verfügbar) Klicken Sie auf den Install-Button, um Ihre Eingaben zu bestätigen und den Bereitstellungsvorgang zu starten. 4. In mehreren Minuten wird das Add-on Ihrer Anwendung hinzugefügt: 5. Gemäß oben angezeigtem Pop-up müssen Sie obligatorisch die node(s) neu starten, um Ihre App-Leistungstrends zu sammeln. Dies kann mit dem passenden Button neben Ihrer Anwendungserver-Instanz durchgeführt werden. Bitte beachten Sie, dass wenn Ihr Projekt in einer einzelnen app server node läuft, der Neustart wird eine temporäre Ausfallzeit Ihrer Anwendung verursachen, sodass Sie selbst entscheiden können, wann Sie diese Operation durchführen. Allerdings, in Fällen, in denen Ihr Appserver horizontal skaliert ist, wird die Ausfallzeit minimiert, da alle Serverinstanzen sequenziell neu gestartet werden.
