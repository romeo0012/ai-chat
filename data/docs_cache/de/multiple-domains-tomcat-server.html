Multiple Domain Names on Tomcat Server

← Chat

Mehrere Domain-Namen auf Tomcat-Server einrichten, um die Nutzbarkeit, Effizienz und Skalierbarkeit Ihrer Anwendung zu erhöhen sowie Kosten zu sparen, ohne separate Instanzen zu konfigurieren. Dafür müssen Sie einige geringfügige Anpassungen in den Tomcat-Konfigurationsdateien vornehmen, wie hier beschrieben.

  1. Melden Sie sich bei der Plattform-Dashboard an und klicken Sie auf den Button New Environment:
  1. Im Dialog Environment Topology wählen Sie Ihren Anwendungsserver (z.B. Tomcat 9) aus und geben Sie Ihren Umgebungsnamen ein, z.B. multibinding. Innerhalb von einer Minute wird Ihre Umgebung erfolgreich erstellt.
  1. Sie können stattdessen eigene Domain-Namen anstelle der Standard-Domains einrichten, indem Sie einen CNAME-Eintrag hinzufügen oder A-Einträge festlegen. Weitere Informationen finden Sie im Dokument Custom External Domain Name Binding.
  1. Kehren Sie wieder zum Plattform-Dashboard zurück, klicken Sie auf den Settings-Button für Ihre Umgebung und binden Sie Ihre Domains. In unserem Beispiel verwenden wir tomcatfirst.tk für den ersten Domain-Namen und tomcatsecond.tk für den zweiten.
  1. Jetzt müssen Sie die Projekte bereitstellen. Laden Sie die Anwendungsdatei in den Deployment Manager hoch und drücken Sie den Deploy-Button. Als Beispiel verwenden wir Hello World, das im Deployment Manager standardmäßig verfügbar ist. Wenn das Deploy-Form erscheint, wählen Sie Ihre Umgebung aus und weisen Sie den Kontext (tomcatfirst, in unserem Fall) zu. Danach drücken Sie den Deploy-Button. Laden Sie das zweite Anwendungs-Archiv hoch. Wir werden den modifizierten Hello World (die Wörter “You did it!”) verwenden.

Wir werden die modifizierte Welt (die Wörter „Gefällt's dir!“ sind in Rot umgesetzt) nur zum Vergleich in den letzten Schritten verwenden. Dann deploye diese Anwendung in derselben Umgebung, aber mit einem anderen Kontext (z.B., tomcatsecond). Wenn die Bereitstellung abgeschlossen ist, haben Sie zwei Anwendungen in Ihrer Umgebung bereitgestellt.

  1. Klicke jetzt auf die Konfig-Schaltfläche für Tomcat und navigiere zu dem server.xml-Datei (der /opt/tomcat/conf-Verzeichnis). Füge Host-Tags für jeden Domain ein, den Sie binden möchten:

1 2 3 4
&lt;Host name="external.domain.tld" appBase="webapps/context_name" autoDeploy="true"&gt;
  &lt;Alias&gt;external.domain.tld&lt;/Alias&gt;
  &lt;Context path="" docBase="${catalina.base}/webapps/context_name"/&gt;
&lt;/Host&gt;

In unserem Beispiel fügen wir folgenden Code dem server.xml-Datei hinzu:

1 2 3 4 5 6 7 8
&lt;Host name="tomcatfirst.tk" appBase="webapps/tomcatfirst" autoDeploy="true"&gt;
  &lt;Alias&gt;tomcatfirst.tk&lt;/Alias&gt;
  &lt;Context path="" docBase="${catalina.base}/webapps/tomcatfirst"/&gt;
&lt;/Host&gt;
&lt;Host name="tomcatsecond.tk" appBase="webapps/tomcatsecond" autoDeploy="true"&gt;
  &lt;Alias&gt;tomcatsecond.tk&lt;/Alias&gt;
  &lt;Context path="" docBase="${catalina.base}/webapps/tomcatsecond"/&gt;
&lt;/Host&gt;
  1. Speichere die Änderungen und starten Sie Tomcat neu.
  1. Jetzt können Sie die Ergebnisse überprüfen. Beide Ihre Anwendungen sind über die angegebenen Domain-Namen verfügbar, die auf einem einzigen Tomcat-Server laufen.

Hinweis: Wenn Sie eine Anwendung auf den Tomcat-Instanz mit bereits konfiguriertem server.xml wieder bereitstellen möchten, müssen Sie den < Host >-Block vor der Bereitstellung kommentieren und ihn anschließend wieder entfernen.
