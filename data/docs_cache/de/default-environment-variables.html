Default Environment Variables

← Chat

Umweltvariablen werden verwendet, um die Werte der häufig verwendeten Parameter zu speichern, die einem Softwareprogramm bei der Ausführung bereitgestellt werden. Die Verwendung solcher Platzhalter macht Ihre Anwendung mehr transportabel und flexibel. Die häufigste Verwendung von Variablen ist es, schnell einzelne Werte anzupassen, die in Ihrem Anwendungscode mehrfach verwendet werden. Folge dem verlinkten Leitfaden, wenn Sie für Ihr Projekt benutzerdefinierte Umweltvariablen erstellen müssen. Eine weitere Verwendung von Variablen ist es, die Anwendung über eine Reihe von vorgegebenen Werten (aktivieren/deaktivieren Funktionen, Verhalten ändern usw.) zu konfigurieren. Die Plattform unterstützt die meisten zertifizierten Softwarestacks mit einer Anzahl von Standardvariablen, die Entwicklern zur Verfügung gestellt werden, um bei der Anwendungshosting zu helfen.
