Was ist Auto-Clustering Im modernen Zeitalter spielt die Verfügbarkeit von Daten eine unschätzbare Rolle. Hiermit möchten Sie immer auf jede erforderliche Information sofort zugreifen können. Daher empfehlen wir für jede Produktionslösung irgendwelcher Größe, eine Clusterkonfiguration einzurichten. Software-Clustering ist die Technik, mindestens zwei Instanzen für einen Dienst zu verwenden. Diese Redundanz bietet neben der Zuverlässigkeit (das System kann mindestens einen Fehler einer Instanz überstehen) auch Hilfe bei der Bearbeitung hoher Last. Die Konfiguration eines Clusters kann ein herausforderndes Prozess sein, der eine beträchtliche Zeitaufwand erfordert. Um Ihnen dabei zu helfen, bietet die Plattform die Automatisierung einiger der beliebtesten Clusterlösungen an und kann diese für Sie auf-Anforderung direkt über den Topologie-Assistenten durchführen. Diese Automatisierung vereinfacht und beschleunigt die Erstellung einer zuverlässigen Produktionsbereitschaftskluster für Ihr Projekt erheblich. Aktivieren Sie Auto-Clustering Aktuell unterstützen die folgenden Vorlagen die Auto-Clustering-Funktion über den Topologie-Assistenten: Anwendungsserver - Tomcat/TomEE, GlassFish, Payara, Jenkins, WildFly SQL-Datenbanken - MySQL, MariaDB, Percona, PostgreSQL NoSQL-Datenbank - Couchbase, Redis, OpenSearch Speicherserver - Shared Storage Container Tipps: Zusätzlich zur Auto-Clustering-Option im Topologie-Assistenten finden Sie eine Reihe von vorgefertigten Clusterlösungen unter der Kategorie Clusters des Plattform-Marktplatzes.

  1. Topologie-Assistent, eine Anzahl vorbereiteter Klustervorlagen finden Sie in der Kategorie Clusters des Marktplatzes der Plattform.
  1. Wählen Sie eine der in der Topologie-Assistenten aufgeführten Stack-Optionen aus. Der entsprechende Schalter für automatische Klustering wird in der zentralen Anzeigebereich verfügbar sein.
  1. Sie können über den Tippsymbol für zusätzliche Informationen zur automatischen Klustering-Implementierung dieses Stack-Typs schweben. In der Beschreibung finden Sie den Link "Mehr erfahren", um auf umfassendere Dokumentationen mit einer ausführlichen Übersicht zu gelangen.
  1. Zusätzlich werden nach Aktivierung des automatischen Klustering auch weitere Konfigurationen verfügbar sein können, um die Kluster weiter zu individualisieren.

Du findest den Link "Mehr erfahren" zur umfassenderen Dokumentation.
