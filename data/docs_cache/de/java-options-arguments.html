Java-Option und Argumente
Um Kosteneffizienz zu gewährleisten, werden alle Java-Server, die von der Plattform verwaltet werden, automatisch konfiguriert, um die Speicherressourcen in der vorteilhaftesten Weise zu nutzen. Dies wird erreicht, indem die Hauptparameter des Java-Speichers aufgrund der zugewiesenen Ressourcen eines Containers angepasst werden. Tip: Benutzerdefinierte Java-Server (z.B. innerhalb von Docker-Containern oder VPS) können ähnlich optimiert werden, indem Sie den Java-Speicher-Agent-Anhang verwenden. Die Standardoptionen können manuell geändert werden, um eine hohe Leistung zu sichern oder eine benutzerdefinierte Implementierung zu unterstützen.

  1. Um alle bevorzugten Java-Optionen gleichzeitig bereitzustellen, kann die Datei variables.conf verwendet werden. Je nachdem, welcher Anwendungserver Sie verwenden, kann die genaue Position variieren: Tomcat, TomEE - /opt/tomcat/conf/variables.conf Jetty - /opt/jetty/etc/variables.conf Spring Boot - /opt/shared/conf/variables.conf GlassFish - /opt/glassfish/glassfish/domains/domain1/config/variables.conf Payara - /opt/payara/glassfish/domains/domain1/config/variables.conf WildFly - /opt/wildfly/conf/variables.conf Wenn nötig, können die Hauptspeicheroptionen über Containervariablen neu definiert werden.
  1. Erinnern Sie sich bitte, die Knoten neu zu starten, um Änderungen anzuwenden. Das ist es! Jetzt läuft Ihre Anwendung mit Ihren benutzerdefinierten Java-Optionen. Neu definieren der Haupt-Java-Parameter

-XX:MaxPermSize, *-XX:+Use.GC) können über die zugewiesenen Umgebungsvariablen neu definiert werden. Als Beispiel kannst du die -Xmx Option hinzufügen (also Maximum Größe für die Java Heap-Speicher): Tip: Die Plattform unterstützt zwei zusätzliche Variablen, die die Haupt-RAM-Parameter auf Prozent des verfügbaren Gesamtspeichers einstellen können: XMS_DEF_PERCENT - die initiale Größe (%) des Speicher-Zuweisungspools XMX_DEF_PERCENT - die maximale Größe (%) des Speicher-Zuweisungspools Diese Werte werden automatisch überprüft - wenn XMS größer als XMX ist, wird sein tatsächlicher Wert auf XMX gesetzt. Bei der Verwendung der Spring Boot und Java Engine Vorlagen können zwei zusätzliche Variablen bereitgestellt werden: JAVA_OPTS - um Java-Optionen für Ihre App anzupassen (ähnlich dem variables.conf-File) JAVA_ARGS - um Ihrer Anwendung Hauptfunktion einige benutzerdefinierte Argumente zu übergeben Sollte vergessen werden, Ihre Anwendungserver(s) neu zu starten, um Änderungen anzuwenden.
