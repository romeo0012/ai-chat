Plattformzugang per SSH wird unterstützt in einem der folgenden Weisen: Web SSH - Ein Zugang zu einem separaten Knoten in Ihrer Umgebung, der auf der Benutzer-Session basiert; die Verbindung wird durch Klicken auf den Web SSH-Button neben der gewünschten Umgebung in der Dashboard-Ansicht initiiert (was es ermöglicht, über das Internet von irgendeiner Stelle über den Browser zu verbinden). SSH Gate - Diese Verbindungsart basiert auf der Verwendung eines SSH-Schlüsselpaares und ermöglicht den Zugang zu entweder dem gesamten PaaS-Konto oder nur einem bestimmten Container; sie bietet einen hohen Sicherheitsgrad, indem sie nur Instanzen verbindet, die mit einem privaten SSH-Schlüssel verfügen, der mit dem entsprechenden öffentlichen Schlüssel in Ihren Plattform-Kontoeinstellungen gespeichert ist. Nachdem Sie den Knoten über SSH mithilfe eines der oben beschriebenen Verfahrens erreicht haben, können Sie Ihren Container verwalten. Was kommt danach?
