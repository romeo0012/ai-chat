Apache PHP

Apache PHP Plattform adaptiert einen robusten, kommerziell-grade und offenen Apache HTTP Server ("httpd") für die Erstellung eines sicheren, effizienten und skalierbaren Anwendungsservers für PHP-Hosting. Die Apache PHP-Stack der Plattform bietet aus der Schachtel Unterstützung der PHP-Programmiersprache und des HTTP/2-Protokolls (SSL ist erforderlich) durch die Verwendung der Modulien php7_Module und http2_Module. Hinweise: Diese Vorlage nutzt ein modernes systemd-Initialisierungs-Daemon. Die Liste aller auf dem Server geladenen Modulen kann mit dem Befehl apachectl -M angezeigt werden oder auf der Standard-phpinfo-Seite. Um Ihre Apache PHP-Server zu erhalten, folgen Sie den Schritten unten:

  1. Melden Sie sich bei Ihrer PaaS-Konto an und klicken Sie auf New Environment oben.
  1. Im geöffneten Topologie-Assistenten wechseln Sie zum PHP-Tab und wählen Sie Apache als Ihren Anwendungsserver aus. Stellen Sie andere Konfigurationen nach Ihren Bedürfnissen ein (z.B., Cloudlets-Limit, öffentliche IPs, Region, etc.). Geben Sie Ihren Umgebungsnamen ein und klicken Sie auf Create.
  1. Sobald die Umgebung erstellt wurde, können Sie auf den Open in Browser-Button neben dem Apache-Anwendungsserver klicken:
  1. Im geöffneten Standard-Seite sehen Sie Ihre Server-phpinfo-Daten. Jetzt können Sie Ihre PHP-Anwendung in die Umgebung bereitstellen.

Apache-Konfiguration

Apache PHP hat einige Hauptkonfigurationsdateien, die Sie möglicherweise anpassen möchten, um Ihren Anwendungsserver nach Ihren spezifischen Bedürfnissen anzupassen:

/etc/php.ini - listet Direktiven auf, die Ihre PHP-Einstellung konfigurieren
/etc/httpd/conf.d/php.

Um Ihre Anwendungsserveranpassung an Ihre spezifischen Bedürfnisse anzupassen:

/etc/php.ini - listet Direktiven auf, die Ihre PHP-Einstellung konfigurieren
/etc/httpd/conf.d/php.conf - konfiguriert die Ausführung von PHP-Skripts
/etc/httpd/conf/httpd.conf - listet Direktiven auf, die Ihre Apache-Serverkonfiguration konfigurieren

Als Beispiel zeigen wir, wie Sie die Größe der hochzuladenden Dateien Ihrer Anwendung ändern können.

  1. Klicken Sie auf den Config-Button für Ihren Apache-Server, um den Konfigurationsdateimanager zu öffnen:
  1. Öffnen Sie die /etc/php.ini-Datei (verfügbar über den Favoriten-Kurzlink) und suchen Sie die folgenden Parameter:

- upload_max_filesize - maximale Größe der hochzuladbaren Dateien auf dem Server (100MB Standardeinstellung)
- post_max_size - maximale Größe der POST-Daten, die PHP akzeptieren wird (100MB Standardeinstellung)

Hinweis: Unabhängig von diesen Einstellungen ist die maximale Dateigröße, die über die Plattform-Dateimanager von der lokalen Maschine hochgeladen werden kann, 150MB (kann sich nach den Einstellungen des Hostinganbieters ändern). Um größere Dateien zu verwenden, verwenden Sie die URL-Option oder fügen Sie eine öffentliche IP hinzu und verwenden Sie Ihren eigenen Manager (zum Beispiel FTP-Add-on).

  1. Vergessen Sie nicht, die Änderungen zu speichern und die Nodes Ihres Anwendungsservers neu zu starten, um die neuen Einstellungen anzuwenden. Für weitere Informationen zur Konfiguration von PHP-Servern beziehen Sie sich auf die entsprechenden Leitfäden:
