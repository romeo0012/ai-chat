Kubernetes-Cluster: Velero-Backups

Velero ist eine open-source-Werkzeug für die Sicherung und Wiederherstellung von Kubernetes-Cluster bei Katastrophenfallschutz. Es unterstützt auch die Migration von Clusterressourcen und persistente Speichervolumes. Manuelle oder geplante Sicherungen auf externen Speichergarantieren sichern und schützen Ihre Daten. Mit Velero können Sie die folgenden Aufgaben erfüllen:

  • Ihren Kubernetes-Cluster oder ausgewählte Ressourcen / persistente Speichervolumes sichern und im Falle des Verlusts von Clusterdaten wiederherstellen.
  • Ein ganzes Kubernetes-Cluster replizieren (z.B. eine Entwicklungs-/Testinstanz basierend auf der Produktionsinstanz) oder ausgewählte Ressourcen auf andere Cluster verschieben.

Backup-Planung
Velero unterstützt die Automatisierung des Backup-Prozesses über die Planung. Sie können die erforderliche Planungsvorlage über cron-Notation (mit der UTC-Zeitzone) erstellen.

Unterstützt die automatisierte Wiederherstellung von Prozessen durch Planung. Sie können die erforderliche Planungsvorlage über cron-Notation (mit der UTC-Zeitzone) erstellen. Die allgemeine Syntax lautet wie folgt: 1 velero schedule create {scheduleName} --schedule="{schedule}"

  1. Verwenden Sie die Tabelle unten als Verweis, um die erforderliche Planung mit einer Standard-cron-Ausdruckszeichenfolge zu setzen: Zeichenposition Zeichen Periodikität Akzeptable Werte

1 Minute 0-59,*
2 Stunde 0-23,*
3 Tag des Monats 1-31,*
4 Monat 1-12,*
5 Tag der Woche 0-7,*
Beispielhaft kann ein Backup alle sechs Stunden erstellt werden: 1 velero schedule create myschedule --schedule="0 */6 * * *"
  1. Die Planung kann auch mit der @every {Dauer} Syntax ausgedrückt werden. Die Dauer kann mit einer Kombination von Sekunden (s), Minuten (m) und Stunden (h) angegeben werden. Beispielhaft kann ein Backup alle sechs Stunden erstellt werden: 1 velero schedule create myschedule --schedule="@every 6h"
  1. Sie können zusätzliche Planungsoptionen (zum Backup eines bestimmten Namespaces, die Backups-Lebensdauer festzulegen usw.) über spezielle Parameter hinzufügen. Verwenden Sie den Flag -hilfe, um die vollständige Liste der Parameter anzuzeigen: 1 velero schedule create --help
