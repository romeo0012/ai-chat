NGINX PHP

Die NGINX PHP-Stack ist ab der Version 1.16.1 seit der Veröffentlichung von PHP 7.2.26, 7.3.13, 7.4.1 und höher HTTP/3 bereit. Allerdings ist ein öffentlicher IP-Adressraum erforderlich, um den Shared Load Balancer umgehen und direkt mit dem Server über HTTP/3 zu arbeiten. NGINX ist ein schneller und leichter HTTP-Server, der von Entwicklern weltweit verwendet wird. Aufgrund seiner modularen Struktur ist es sehr anpassbar, was zugleich die Möglichkeit ermöglicht, nur die erforderlichen Funktionalitäten zu nutzen und somit effizienten Ressourcenverbrauch sicherzustellen. Die Plattform optimiert und anpasst NGINX, um es als PHP-Anwendungserver bereitzustellen, der vollständig mit der Plattformfunktionalität kompatibel ist. Im Vergleich zur Apache PHP ist es für die Bearbeitung von Websites mit statischem Inhalt besser geeignet, kann jedoch aufgrund der FastCGI-Unterstützung auch komplexe Skripte verarbeiten. Hinweis: Diese Vorlage nutzt ein modernes systemd-Initialisierungs-Daemon. NGINX-Konfiguration Während Sie NGINX als Anwendungsserver verwenden, gibt es einige Einschränkungen bei der Größe der hochgeladenen Dateien an die Anwendung. Sie können die folgenden Konfigurationen ausführen, um sie anzupassen:

  1. Hoveren Sie über den NGINX-Anwendungsserver und klicken Sie auf den aufgeführten Config-Button.
  1. Im geöffneten Konfigurationsdateimanager suchen und ändern Sie die Datei /etc/nginx/nginx.conf indem Sie der folgenden Zeichenfolge in der http-Sektion hinzufügen: 1 client_max_body_size 50m; Sie können beliebiger Wert anstelle des 50MB im Beispiel oben verwenden. Hinweis: Unabhängig von der Einstellung oben sind Sie bei der Arbeit über die inbetriebnehmende Dateimanager-Plattform auf eine Uploadgröße von 150MB (kann sich nach den Einstellungen des Hostinganbieters ändern) beschränkt. Um größere Dateien zu verwenden, müssen Sie eine öffentliche IP-Adresse zuweisen und eigene Manager verwenden (z.B. können Sie den FTP-Add-on verwenden).
  1. Speichern Sie die vorgenommenen Änderungen und wenden Sie sie an durch Klicken auf den Restart Nodes-Button.
