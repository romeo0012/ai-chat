WordPress-Geschwindigkeitsoptimierung: Geschwindige Geschäftswebsite ist für beide Google-Rangierung und insgesamt Umsatzrate wichtig. Aufgrund von Kissmetrics verlassen 40% der Seitenbesucher eine Seite, die drei Sekunden oder mehr benötigt, um zu laden. Früher berechnete die BBC, dass sie für jeden zusätzlichen Sekundenaufwand 10% zusätzliche Nutzer verloren. Ihre Web-Hosting-Geschwindigkeit bestimmt, wie schnell sie Code ausführen kann, und wie viele Besucher sie verarbeiten kann. Vergleichen Sie Ihre Website mit einem Auto. Um ein Auto schneller zu machen, erhöhen Sie entweder die Leistung des Motors und/oder verringern Sie das Gewicht. Für Websites ist der Webserver der „Motor“ und der Code das „Gewicht“. Ziel ist es, unseren Webserver „Motor“ zu verbessern, während wir den Code „Gewicht“ verringern. Das Wechseln Ihrer Web-Hosting ist eine der einfachsten Möglichkeiten, um Geschwindigkeit zu verbessern. Wenn Sie auf billigem $5/Monats gemeinsamem Webhosting sind, werden Sie sich am meisten durch den Wechsel zu einem verwalteten Hostingdienst oder sogar Ihrer eigenen VPS (Virtual Private Server) nutzen. Der Unterschied wird nacht-und-taglich sein, ohne dass Sie irgendwelche Seitenänderungen vornehmen müssen. Der Wechsel von verwaltetem Hosting auf optimierte VPS oder eine dedizierte „bare metal“ Server (nackter Metallserver) wird noch ein weiterer nacht-und-taglicher Sprung bedeuten. Der Unterschied besteht nicht nur in der Geschwindigkeit, sondern auch in einer Frage der Kosten (Einsparungen). Ein schneller Server kann mehr Besucher verarbeiten als ein langsamer. Wenn Ihr Server doppelt viele Besucher verarbeiten kann, ist theoretisch die Rechnung doppelt so billig. Das ist für kleine Websites kein großer Deal, aber was für eine große E-Commerce-Website mit einem $1k/Monats Server-Gebühr? Eine 50%ige Kosteneinsparung klingt sehr attraktiv!
